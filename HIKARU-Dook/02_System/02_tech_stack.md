# 技術スタック

## 確定技術一覧

| カテゴリ | 技術 | バージョン | 用途 |
|---|---|---|---|
| フレームワーク | Next.js | 15.x | フロントエンド・API Routes |
| 言語 | TypeScript | 5.x | 全コード |
| スタイリング | Tailwind CSS | 4.x | UIスタイリング |
| UIコンポーネント | shadcn/ui | 最新 | 共通UIコンポーネント |
| 状態管理 | Zustand | 5.x | クライアントサイド状態管理 |
| データベース | Supabase | 2.x | DB・Auth・Storage |
| AI | OpenAI API | 4.x | 全AI機能 |
| PDF生成 | React PDF | 最新 | 報告書PDF生成 |

> shadcn/uiはnpmパッケージではなくコンポーネントコピー方式のため、依存関係には含まれない。

## 外部サービス

| サービス | 用途 | 備考 |
|---|---|---|
| **OpenAI API** | チャット・Vision・文書生成・分析 | APIキーは.env.local必須 |
| **Supabase** | DB・Storage・Auth | 利用者は直接操作しない |

## OpenAIモデル方針

| AI機能 | 使用モデル（予定） | 理由 |
|---|---|---|
| AIマニュアル（RAG） | gpt-4o | テキスト理解・回答精度 |
| AI品質管理（Vision） | gpt-4o | 画像認識・比較評価 |
| AI報告書 | gpt-4o | 文書生成品質 |
| AI分析 | gpt-4o | 複合データ解析 |

モデル名は`lib/openai/client.ts`で定数管理。変更時は1箇所のみ修正。

---

## ライブラリ追加ルール

新規ライブラリを追加する際は以下を必ず明示して提案すること：

1. **目的** — なぜ必要か
2. **代替案** — 他の選択肢との比較
3. **バンドルサイズへの影響** — パフォーマンスへの影響
4. **メンテナンス状況** — 最終更新・スター数・継続性

独断でのライブラリ追加は禁止。

## 開発環境要件

| 項目 | 要件 |
|---|---|
| Node.js | 20.x 以上 |
| パッケージマネージャー | npm |
| 対象ブラウザ | Chrome最新・Safari最新・モバイルSafari・モバイルChrome |
| デバイス | PC・タブレット・スマートフォン（レスポンシブ必須） |
| HTTPS | 本番環境必須（Camera API要件） |
