## v1.0 実装済み機能（2026年8月完成）

### 基盤

- [x] Next.js 15 App Router + TypeScript + Tailwind CSS v4
- [x] npm workspaces モノレポ（HIKARU-System / HIKARU-CONSOLE / packages）
- [x] Supabase Auth（ロールベース認証: admin / worker / client）
- [x] Supabase RLS（全テーブルで会社データを自動分離）
- [x] Supabase Storage（写真ファイル管理）
- [x] 共有パッケージ（@hikaru/types / @hikaru/lib / @hikaru/ui）
- [x] middleware によるロール別ルーティング保護

### HIKARU-System（作業者アプリ）

- [x] ホーム画面・案件一覧・本日の作業サマリー
- [x] 案件詳細（店舗情報・撮影箇所一覧・作業進捗）
- [x] Before/After撮影（カメラAPI・スポット別管理・再撮影対応）
- [x] AIマニュアルチャット（RAG + SSEストリーミング + マークダウン表示）
- [x] AI品質評価（一括評価・スコア/判定/比較コメント/改善提案）
- [x] AI報告書生成（プレビュー・印刷/PDF・バージョン管理・履歴）
- [x] プロフィール・通知・作業完了フロー

### HIKARU-CONSOLE（管理者アプリ）

- [x] ダッシュボード（KPI統計）
- [x] 顧客・店舗・案件・ユーザー・マニュアルのCRUD
- [x] 撮影箇所設定（ドラッグ並び替え・必須/任意・削除）
- [x] 通知管理・設定
- [x] 報告書管理（一覧・詳細プレビュー・印刷）
- [x] AI分析ダッシュボード（4タブ: 概要/品質/ランキング/AI提案）
- [x] 店舗・作業者別詳細分析（月別推移・箇所別スコア・AIフィードバック）

### AIモジュール（全4機能）

- [x] **AIマニュアル（manual-ai）**: RAGベースQAチャット + マニュアル参照元表示
- [x] **AI品質管理（quality-ai）**: Vision API による写真品質チェック・Before/After比較
- [x] **AI報告書（report-ai）**: クライアント提出品質の報告書自動生成（文章・写真・スコア）
- [x] **AI分析（analyze-ai）**: 全体/店舗/作業者/時系列の4軸AI分析
