# コンセプト・思想

## HIKARUのコアコンセプト

### 「AIが中心に存在するシステム」

多くのシステムはまず業務フローを設計し、後からAIを追加します。  
HIKARUはこの逆です。

```
一般的なシステム:  業務フロー → 後付けAI
HIKARU:          AI設計 → その上に業務フローを構築
```

AIが意思決定・評価・教育・分析のすべてに関与し、  
人間はAIの判断を参照しながら作業を進めます。

---

## 5つの機能軸

### 1. 教育
新人でもベテランと同じ品質で作業できる仕組み。  
AIマニュアルが現場でいつでも回答する。

### 2. 品質管理
担当者の経験や主観に依存せず、AIが客観的に評価する。  
Before/After写真の比較でゼロベースの品質チェックを実現。

### 3. AI評価
写真から汚れの残存・除去状況を数値化。  
評価基準を統一することで品質の均一化を実現。

### 4. 報告書作成
1タップで完成するクライアント提出用報告書。  
作業者の負担を最小化し、品質の高い記録を自動生成。

### 5. データ分析
蓄積データから店舗・作業者・期間の横断分析。  
AIが時系列トレンドから改善提案を自動生成。

---

## データが価値を生む設計

```
初回利用
  → AI評価データが蓄積
  → パターン学習
  → 精度向上
  → より精密な改善提案
  → 利用価値が高まる
```

利用すればするほど精度が上がり、価値が増す設計を目指します。

## ユーザー体験の目標

### 作業者
> 「考えなくてもAIが教えてくれる。写真を撮るだけで報告書ができる。」

### 管理者
> 「現場に行かなくてもリアルタイムで品質が把握できる。」

### クライアント
> 「作業のたびに写真付きの報告書が届く。品質の推移も見える。」
