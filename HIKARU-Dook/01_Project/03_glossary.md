# 用語集

プロジェクト内で使用する固有名詞・専門用語を定義します。

---

## プロジェクト固有名称

| 用語 | 定義 |
|---|---|
| **HIKARU** | 本プロジェクト全体の名称 |
| **HIKARU-System** | 清掃作業者向けWebアプリ |
| **HIKARU-CONSOLE** | 管理者向け管理コンソール |
| **HIKARU-Dook** | プロジェクト全体の知識ベース（本ドキュメント群）。設計書・仕様書・開発ルールを管理するフォルダ |
| **クライアントポータル** | クライアント（オーナー）専用の閲覧画面 |

---

## ユーザー種別

| 用語 | 定義 |
|---|---|
| **管理者** | HIKARUシステム全体を管理するユーザー。案件・店舗・作業者・マニュアルを管理する |
| **作業者** | 現場で清掃を行うユーザー。HIKARU-Systemを使用する |
| **クライアント / オーナー** | 清掃を依頼する施設のオーナー。報告書・品質確認のみ行う |

---

## 業務用語

| 用語 | 定義 |
|---|---|
| **案件** | 清掃業務の単位。1つの施設・契約に対して作成される |
| **店舗** | 清掃対象の施設・場所 |
| **作業** | 特定の日付・案件に対して行われる1回の清掃業務 |
| **撮影場所（ロケーション）** | 管理者が案件ごとに設定する写真撮影箇所（入口・床・トイレ等） |
| **Before写真** | 清掃開始前に撮影する写真 |
| **After写真** | 清掃完了後に撮影する写真 |
| **品質スコア** | AIが算出する清掃品質の数値評価 |
| **再清掃** | AI評価がNGだった箇所に対して行う追加清掃 |

---

## AI用語

| 用語 | 定義 |
|---|---|
| **AIマニュアル** | 案件に登録されたマニュアルをもとにAIが回答するRAGチャット機能 |
| **AI品質管理** | Before/After写真をAIが比較・評価する機能 |
| **AI報告書** | 作業データからAIが自動生成する報告書 |
| **AI分析** | 蓄積データから改善提案・トレンド分析を行う機能 |
| **RAG** | Retrieval-Augmented Generation。登録された文書を検索して回答を生成する技術 |
| **Vision AI** | 画像を認識・評価するAI機能（OpenAI GPT-4o Vision使用） |

---

## 技術用語

| 用語 | 定義 |
|---|---|
| **Supabase** | データベース・ストレージ・認証に使用するBaaSサービス。利用者は直接操作しない |
| **OpenAI API** | AIチャット・画像評価・文書生成に使用するAPI |
| **RLS** | Row Level Security。Supabaseの行レベルアクセス制御 |
| **SSoT** | Single Source of Truth。HIKARU-Dookはこれを担う |
