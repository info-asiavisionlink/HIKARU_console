# ユーザーフロー

## 作業者フロー（HIKARU-System）

現場作業の標準フローです。スマートフォンでの利用を前提とします。

```
[ログイン]
    ↓
[案件一覧] ← 当日の案件が上部に表示される
    ↓ 案件をタップ
[作業詳細] ← 今日やること・担当場所の確認
    ↓
    ├─── [AIマニュアル] ← いつでも戻れる（疑問があれば質問）
    │
    ↓
[Before撮影]
  ↓ 箇所リストが表示される（例：入口・床・トイレ）
  ↓ 1箇所ずつ撮影
  ↓ AI品質チェック → NG時は撮り直し
  ↓ 全箇所完了
    ↓
[清掃作業] ← チェックリスト形式で進捗管理
    ↓
[After撮影]
  ↓ Before同様に箇所ごとに撮影
  ↓ AI品質チェック → NG時は撮り直し
  ↓ AI Before/After比較評価が表示される
  ↓ スコアが低い場合は再清掃提案
    ↓
[報告書確認]
  ↓ AI生成の報告書プレビューを確認
  ↓ 特記事項を任意入力
  ↓ 「提出」ボタン
    ↓
[完了] ← クライアントへ自動通知
```

## 管理者フロー：案件作成

```
[CONSOLE ダッシュボード]
    ↓
[案件一覧] → [新規案件作成]
    ↓ STEP1: 基本情報
    店舗選択（既存）or 新規店舗作成
    案件名・概要入力
    ↓ STEP2: 担当設定
    担当作業者の割り当て
    スケジュール設定
    ↓ STEP3: 撮影場所設定
    プリセットから選択（入口・床・トイレ等）
    自由入力で追加
    表示順の変更
    ↓ STEP4: マニュアル登録
    PDFアップロード
    テキスト手順入力
    FAQ登録
    参考写真・動画追加
    ↓
[案件作成完了] ← 担当作業者へ通知
```

## 管理者フロー：AI分析確認

```
[CONSOLE ダッシュボード]
    ↓ アラート確認（品質NGなど）
[AI分析ダッシュボード]
    ↓
    ├── 店舗別タブ → 特定店舗の品質推移を確認
    ├── 作業者別タブ → 特定作業者のパフォーマンス確認
    └── AI改善提案 → 自動生成された提案を確認・対応
```

## クライアントフロー

```
[ログイン]
    ↓
[ダッシュボード] ← 直近の作業状況・品質スコア
    ↓
[報告書一覧]
    ↓ 報告書をタップ
[報告書詳細]
  ↓ Before/After写真を左右スワイプで比較
  ↓ 箇所別AIスコア確認
  ↓ 作業者コメント・特記事項確認
    ↓
[品質推移] ← 過去データのグラフ表示
```

---

## 画面遷移の原則

1. **作業者画面は直線的なフロー** — 前後のステップが明確で、迷子にならない
2. **管理者画面はハブ型** — ダッシュボードから全機能へアクセス可能
3. **クライアント画面は閲覧専用** — 操作は最小限、情報を見やすく
4. **AIマニュアルはどこからでもアクセス** — 作業中いつでも質問できる
