# 分析ダッシュボード設計（第9回実装済み）

## 概要

蓄積した全データをAIが分析し、管理者・オーナーが清掃品質・業務状況を一目で把握できるシステム。

---

## 画面構成

### `/analytics`（メインダッシュボード・タブ型）

#### 概要タブ
- KPIカード × 5（総作業回数・平均品質スコア・総評価数・写真枚数・報告書数）
- 月別品質スコア推移グラフ（過去12ヶ月）
- 判定分布ドーナツグラフ（合格/要確認/再清掃）
- 月別作業件数縦棒グラフ
- 業務指標カード（AIチャット利用・稼働案件・店舗数）

#### 品質分析タブ
- スコア分布（5段階レンジ別）
- 撮影箇所別品質スコア横棒グラフ（要改善順）
- 再清掃率の高い箇所リスト
- 品質スコアサマリー（スコアリング + 判定内訳）

#### ランキングタブ
- 店舗品質ランキング（1位〜10位・詳細ページへリンク）
- 作業者ランキング（1位〜10位・詳細ページへリンク）

#### AI提案タブ
- 「AIに分析させる」ボタンで初回実行
- AI総合評価（趣旨コメント・トレンド判定）
- 強み・課題の対比表示
- 優先改善提案（高/中/低 優先度バッジ付き）
- 再分析ボタン

---

### `/analytics/store/[id]`（店舗詳細）
- KPIカード × 4（作業回数・平均スコア・住所・最終作業日）
- スコアリング（円形）
- 月別品質スコア推移（過去6ヶ月）
- 撮影箇所別スコア（要改善順）
- 最近の報告書一覧
- AIボタン→AI分析・改善提案表示

### `/analytics/worker/[id]`（作業者詳細）
- KPIカード × 4（作業回数・合格率・再清掃件数・AIチャット利用）
- 平均品質スコアリング
- 月別スコア推移
- 撮影箇所別スコア
- AIチャット活用状況
- AIフィードバック（強み・改善点・研修アドバイス）

---

## チャート仕様

| チャート | 実装方式 | 用途 |
|---|---|---|
| 折れ線グラフ | インラインSVG | 月別スコア推移 |
| 横棒グラフ | CSS + div | ランキング・箇所別スコア |
| ドーナツグラフ | SVG (strokeDasharray) | 判定分布 |
| 縦棒グラフ | CSS + div | 月別作業件数 |
| スコアリング | SVG円形 | スコアサマリー |

**ライブラリ不要**（依存関係ゼロ）

---

## UI設計原則

1. **タブ型ナビゲーション** — 情報密度を高めつつ画面遷移を最小化
2. **カードベースレイアウト** — PC/タブレット両対応のグリッド
3. **オンデマンドAI実行** — ページ読み込み時はデータのみ、AI分析はボタンで実行（APIコスト・速度最適化）
4. **ランキングリンク** — 一覧から詳細ページへのシームレスな遷移
5. **スコアカラー統一** — 緑(≥75)/黄(60-74)/赤(<60) でUI全体を統一
