# 従業員管理・協力業者管理 画面構成

---

## サイドメニュー変更

| 変更前 | 変更後 |
|---|---|
| ユーザー管理 (`/workers`) | 従業員管理 (`/employees`) + 協力業者管理 (`/partners`) |

---

## 従業員管理

### 一覧 `/employees`
- 検索（名前/社員番号/メール）
- ステータスフィルター（在籍中/休職中/退職/利用停止）
- テーブル表示: 社員番号、氏名、フリガナ、部署/役職、電話番号、ステータス、入社日
- 行クリックで詳細へ遷移

### 新規登録 `/employees/new`
- **基本情報**: 氏名、フリガナ、生年月日、性別、電話番号、メール、住所、緊急連絡先
- **雇用情報**: 入社日、部署、役職、資格、備考
- **ログイン情報**: 権限（管理者/従業員）、ログインID（メール）、パスワード
  - ログインアカウントなしも選択可能
  - 招待メールは送信しない

### 詳細/編集 `/employees/[id]`
- 全項目表示（表示・編集切替）
- ステータス変更（ドロップダウン）
- パスワード変更ボタン → ダイアログで変更
- 担当案件一覧（project_assignments経由）
- 削除ボタン → 確認ダイアログ → 論理削除

---

## 協力業者管理

### 一覧 `/partners`
- 検索（会社名/担当者/メール）
- ステータスフィルター（契約中/一時停止/契約終了）
- テーブル表示: 会社名、担当者、電話番号、メール、契約期間、ステータス

### 新規登録 `/partners/new`
- **基本情報**: 会社名、会社名カナ、担当者名/カナ、電話番号、メール、住所
- **契約情報**: 契約開始/終了日、対応エリア、対応業務、資格、備考
- **ログイン情報**: ログインID（メール）、パスワード
  - 協力業者は HIKARU-System のみアクセス可能

### 詳細/編集 `/partners/[id]`
- 全項目表示（表示・編集切替）
- ステータス変更（ドロップダウン）
- パスワード変更ボタン
- 担当案件一覧
- 削除ボタン → 確認ダイアログ → 論理削除

---

## 案件管理への変更

### 担当者セクション（新設）

案件の新規作成・編集フォームに担当者セクションを追加。

```
担当先タイプ: [従業員 ▼] [候補一覧 ▼] [+ 追加]

追加済み担当者:
  👤 田中 太郎 (EMP-0001)  [従業員] [×]
  👤 株式会社〇〇 / 佐藤 [協力業者] [×]
```

- 従業員と協力業者を混在して複数登録可能
- `PUT /api/projects/[id]/assignments` で一括更新

## 権限設計（画面アクセス）

| ロール | HIKARU-CONSOLE | HIKARU-System |
|---|---|---|
| admin（管理者従業員）| ✅ 全機能 | ❌ アクセス不可 |
| worker（従業員）| ❌ | ✅ 担当案件のみ |
| worker（協力業者）| ❌ | ✅ 担当案件のみ |

## ステータス一覧

### 従業員ステータス
| 値 | 表示名 | 説明 |
|---|---|---|
| active | 在籍中 | 通常勤務中 |
| on_leave | 休職中 | 一時的に業務なし |
| resigned | 退職 | 在籍終了 |
| suspended | 利用停止 | アカウント停止 |
| deleted | 削除済み | 論理削除 |

### 協力業者ステータス
| 値 | 表示名 | 説明 |
|---|---|---|
| active | 契約中 | 現在契約中 |
| suspended | 一時停止 | 一時的に停止 |
| terminated | 契約終了 | 契約完了 |
| deleted | 削除済み | 論理削除 |
