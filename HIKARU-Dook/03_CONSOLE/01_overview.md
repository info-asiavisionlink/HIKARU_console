# HIKARU-CONSOLE 概要

## 概要

HIKARU-CONSOLEは管理者が使用するWebコンソールです（ポート3001）。  
PC利用を中心に設計。Supabaseの直接操作は一切行わず、すべての操作はCONSOLE画面上で完結します。

---

## 対象ユーザー

| ユーザー | 権限 |
|---|---|
| 管理者（admin） | 全機能にアクセス可能 |

---

## 画面一覧（第4回実装済み）

| 画面名 | パス | 概要 |
|---|---|---|
| ダッシュボード | /dashboard | 案件・店舗・ユーザー統計サマリー |
| 案件一覧 | /projects | 案件検索・フィルター・ページネーション |
| 案件詳細 | /projects/[id] | 案件情報・マニュアルへのリンク |
| 案件作成 | /projects/new | 新規案件フォーム |
| 案件編集 | /projects/[id]/edit | 案件情報編集 |
| マニュアル管理 | /projects/[id]/manuals | 案件ごとのマニュアル登録・編集・削除 |
| 顧客一覧 | /clients | 顧客企業管理 |
| 顧客詳細 | /clients/[id] | インライン編集・紐づき店舗一覧 |
| 顧客作成 | /clients/new | 新規顧客フォーム |
| 店舗一覧 | /stores | 店舗管理 |
| 店舗詳細 | /stores/[id] | タブ：店舗情報・作業場所・撮影箇所 |
| 店舗作成 | /stores/new | 新規店舗フォーム（顧客選択必須） |
| 店舗編集 | /stores/[id]/edit | 店舗情報編集 |
| ユーザー一覧 | /workers | 管理者・作業者・オーナー管理 |
| ユーザー詳細 | /workers/[id] | ユーザー情報・権限変更 |
| ユーザー招待 | /workers/new | 招待メール送信 |
| マニュアル一覧 | /manuals | 全案件マニュアルの一覧・検索 |
| 通知管理 | /notifications | 既読・未読管理 |
| 設定 | /settings | 会社情報・バージョン情報 |

---

## データ階層

```
会社（Company）
└── 顧客（Client）
    └── 店舗（Store）
        ├── 作業場所（Location）   ← ドラッグ順序管理対応設計
        ├── 撮影箇所（PhotoSpot）  ← 必須／任意・参考画像
        └── 案件（Project）
            └── マニュアル（Manual） ← PDF/画像/動画/文章/FAQ/注意事項
```

---

## UI方針

- PC中心のレイアウト（左サイドバーナビゲーション）
- テーブルはすべて 検索・フィルター・ページネーション 標準装備
- フォームはページ遷移型（プロジェクト作成・編集）
- 詳細ページはインライン編集対応（顧客・ユーザー）
- 店舗詳細はタブ型UI（情報・作業場所・撮影箇所）
- 削除は確認ダイアログ必須
