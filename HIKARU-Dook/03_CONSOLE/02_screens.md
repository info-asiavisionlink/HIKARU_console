# HIKARU-CONSOLE 画面仕様

---

## 案件管理

案件は **3種類** に分かれており、それぞれ専用の一覧・登録・詳細画面を持つ。

```
案件管理（親メニュー）
  ├── 全案件      /projects          ← 3種横断一覧
  ├── 単発案件    /projects/spot
  ├── 定期案件    /projects/recurring
  └── ホテル案件  /projects/hotel
```

---

### 定期案件 `/projects/recurring`

#### 一覧画面

| 項目 | 詳細 |
|---|---|
| 検索 | 案件名（部分一致） |
| フィルター | ステータス（稼働中/停止中/完了/キャンセル） |
| ソート | 登録日降順（固定） |
| ページネーション | 20件/ページ |
| 表示カラム | 案件名・顧客・作業場所・作業周期・期間・ステータス |
| アクション | 詳細へ遷移（行クリック・目のアイコン） |

#### 新規登録 `/projects/recurring/new`

| フィールド | 必須 | 説明 |
|---|---|---|
| 案件名 | ✅ | 定期清掃案件の名称 |
| 作業場所 | - | 現場住所・施設名 |
| 顧客 | - | プルダウン選択 |
| 開始日・終了日 | - | 日付ピッカー |
| 作業周期 | ✅ | 毎日/毎週/毎月/隔週/第○曜日/カスタム |
| 必要人数 | - | 数値 |
| 作業開始・終了時刻 | - | タイムピッカー |
| 備考 | - | テキストエリア |
| 担当者 | - | 従業員・協力業者を複数登録 |

#### 詳細ページ `/projects/recurring/[id]`

**表示モード（閲覧）**
- 案件情報（作業場所・周期・必要人数・作業時間・備考）
- **年間作業スケジュール**: 1〜12月の清掃内容を一覧表示（月名ゴールド強調）
- **年間単価**: 月別税込金額グリッド + 年間税抜/税込合計サマリー
- **請求情報**: 請求状況・見積番号・契約日・請求予定日・入金予定日・入金日
- **担当者**: サイドバーに従業員/協力業者を表示

**編集モード**（「編集」ボタンで切替）
- 全フィールドをインライン編集
- 年間作業スケジュール: 月ごとにテキストエリアで清掃内容を入力
- 年間単価: `RecurringPriceCard` コンポーネントで月別入力
- 請求情報: `BillingInfoCard` コンポーネント
- 担当者: `AssigneeSelector` コンポーネント

**保存動作**
- 案件基本情報 + 月次スケジュール + 担当者 → `PATCH /api/projects/recurring/[id]`
- 単価・請求情報 → `PUT /api/projects/[id]/pricing`
- 両方成功時のみ「保存しました」toast

### ホテル案件 `/projects/hotel`

#### 一覧画面

| 表示カラム | 詳細 |
|---|---|
| ホテル名 | 案件名 |
| 顧客 | 紐づく顧客名 |
| 総階数 | hotel_project_details.total_floors |
| 稼働時間 | 開始〜終了時刻 |
| 契約期間 | 開始〜終了日 |
| ステータス | バッジ表示 |

#### 新規登録 `/projects/hotel/new`

| フィールド | 必須 | 説明 |
|---|---|---|
| ホテル名 | ✅ | |
| 作業場所 | - | 住所 |
| 顧客 | - | プルダウン |
| 開始日・終了日 | - | |
| 総階数 | - | 数値 |
| 稼働開始・終了時刻 | - | |
| 担当責任者・電話番号 | - | |
| フロア情報 | - | フロア名・部屋数（複数行・順序変更可） |
| 稼働ルール | - | 時間帯・必要人数（複数行） |
| 作業エリア | - | エリア名・説明（複数行） |
| 担当者 | - | 従業員・協力業者を複数登録 |

#### 詳細ページ `/projects/hotel/[id]`

- ホテル基本情報（稼働時間・担当責任者・契約期間）
- フロア一覧（フロア名・部屋数テーブル）
- 稼働ルール（時間帯・必要人数テーブル）
- 作業エリア（エリア名・説明テーブル）
- 年間単価（税抜・税率・税込・1室単価・客室数）
- 請求情報

## 店舗管理

### 店舗登録項目

| フィールド | 必須 | 説明 |
|---|---|---|
| 顧客 | ✅ | プルダウン（顧客一覧より） |
| 店舗名 | ✅ | 店舗の名称 |
| 店舗コード | - | STR-001 形式 |
| 住所 | - | 店舗の所在地 |
| 電話番号 | - | 店舗の連絡先 |
| 営業時間 | - | テキスト自由入力 |
| 責任者 | - | 担当者名 |
| 緊急連絡先 | - | 緊急時の連絡先 |
| 契約情報 | - | 契約内容のメモ |
| 備考 | - | その他特記事項 |

### 店舗詳細 タブ構成

- **店舗情報**: 基本情報の閲覧・インライン編集
- **作業場所**: 上下移動による並び替え・追加・削除・有効/無効切替
- **撮影箇所**: 必須/任意設定・説明・参考画像URL・並び替え

---

## 撮影箇所管理

| フィールド | 必須 | 説明 |
|---|---|---|
| 撮影箇所名 | ✅ | 例: 入口ドア |
| 必須撮影 | ✅ | ON/OFFスイッチ |
| 説明 | - | 撮影のポイント |
| 参考画像URL | - | Supabase Storage URL |
| 表示順 | 自動 | 上下ボタンで並び替え |

## マニュアル管理

### マニュアル種別

| 種別 | 用途 |
|---|---|
| 文章 (text) | 手順・説明テキスト |
| FAQ (faq) | よくある質問と回答 |

## ユーザー管理

### 権限種別

| 権限 | ラベル | 用途 |
|---|---|---|
| admin | 管理者 | HIKARU-CONSOLE アクセス |
| worker | 作業者 | HIKARU-System アクセス（現場） |
| client | オーナー | クライアント閲覧アクセス |

### 操作

- 一覧（権限フィルター・名前/メール検索）
- 詳細・権限変更・電話番号編集
- 招待（メールアドレス・名前・権限を指定してSupabase Auth経由で招待メール送信）
- 無効化（将来実装予定）
