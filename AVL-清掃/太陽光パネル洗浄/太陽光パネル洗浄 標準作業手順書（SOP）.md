# 太陽光パネル洗浄 SOP

**対象：野立て・屋根上・水上・カーポート・農地設置型 太陽光パネル**

---

# 1. 適用範囲

## 対象施設・設備

本SOPは以下に設置された太陽光パネル（太陽電池モジュール）の洗浄作業に適用する。

- 野立て発電所（低圧・高圧・特別高圧）
- 屋根上発電所（住宅・アパート・マンション・工場・倉庫・商業施設）
- 水上発電所（池・調整池・ダム湖等）
- カーポート発電所
- 農地設置型（ソーラーシェアリング）

## 対象作業

- 定期洗浄（ロボット洗浄・ブラシ洗浄・純水洗浄）
- 鳥害汚れ除去（スポット洗浄）
- 砂埃・黄砂・花粉汚れ除去
- 工業地帯・海岸近辺における特殊汚れ除去

## 適用外

- パネルの電気的点検・修理
- パネルの取り外し・交換
- ストリング配線・接続箱の作業
- 架台の修繕

---

## 施工可能条件

| 条件 | 基準 |
|---|---|
| 天候 | 晴れ〜曇り（雨・雷は中止。施工後1時間以内に雨の予報がある場合は延期） |
| 気温 | 5℃〜40℃（高温パネルへの冷水散布による熱衝撃を防ぐため。夏季は早朝・夕刻を推奨） |
| パネル表面温度 | 40℃以下（超える場合は早朝・夕刻・曇天時に実施） |
| 凍結 | 外気温5℃以上かつ架台・路面が凍結していないこと |
| 強風 | 瞬間風速10m/s未満（旗が強くなびく状態は中止） |
| 直射日光 | 高温パネルへの冷水散布は熱衝撃によるひび割れリスクあり。直射日光下の夏季昼間は避ける |
| 純水 | TDS概ね10ppm以下の純水が使用可能であること |
| 感電リスク対策 | 接続箱・配線・コネクタへの水・薬剤散布禁止。電気設備から1m以上の距離を保つこと |
| 高所作業 | フルハーネス・足場・高所作業車が適切に確保できること（高さ2m以上は必須） |
| 水上作業 | 救命胴衣着用・2名以上での作業が可能なこと |

## 施工不可条件

| 条件 | 対応 |
|---|---|
| 強風（瞬間風速10m/s以上） | 即時作業中止・安全な場所へ退避 |
| 雷鳴・落雷の兆候 | 即時作業中止・建物内へ退避 |
| パネル表面に亀裂・破損がある | 洗浄中止・施設担当者へ報告 |
| 接続箱・ケーブルの損傷がある | 洗浄中止・電気技術者へ連絡 |
| TDS基準値（10ppm超）の水での洗浄 | 純水機フィルター交換後に施工 |

## 作業中止基準

| 発見内容 | 対応 |
|---|---|
| 落雷・雷鳴が発生 | 即時退避・建物内へ |
| 強風が急変（10m/s超） | 即時作業中止・退避 |
| パネルのひび割れ・破損を施工中に発見 | 作業中止・写真撮影・施設担当者報告 |
| 洗浄中に発煙・異臭 | 作業中止・119番通報・避難 |
| 水上作業での浮体異常 | 即時退避・119番通報 |

# 2. 目的

本SOPは太陽光パネル洗浄作業の手順・安全・品質を標準化し、以下を目的とする。

- 汚れによる発電効率低下の回復および防止
- パネル表面・反射防止コーティングへの損傷ゼロ
- 高所・電気・水による労働災害の防止
- 新人作業者でも同一品質を再現できる作業手順の確立

参考：汚れにより約10%の発電効率が低下した発電所において、適切な洗浄により運転開始時の発電効率へ回復した実績がある（参照URL2）。

# 3. 用語の定義

| 用語 | 内容 |
|---|---|
| 純水 | イオン交換または逆浸透膜処理等により不純物（カルキ・ミネラル等）を除去した水。TDS（総溶解固形物）が概ね10ppm以下のもの。 |
| TDS | Total Dissolved Solids。水中の溶解固形物総量。純水品質の指標。 |
| 純水機 | 水道水を純水に変換する装置（逆浸透膜方式・イオン交換方式等）。 |
| 高圧送水機 | 純水をホースを通じてパネル洗浄箇所へ送水するポンプ。 |
| 洗浄ロボット | パネル上を走行しながら洗浄するロール式ブラシ搭載の専用機器。 |
| EL検査 | エレクトロルミネッセンス検査。パネル内部のクラック・欠陥を可視化する非破壊検査。 |
| 反射防止コーティング | パネルガラス表面に施された光反射を低減するコーティング。薬剤・研磨により損傷するおそれがある。 |
| 野立て | 地面に架台を設置した地上設置型太陽光発電システム。 |
| 水上発電 | 池・調整池等の水面に浮体を設置した太陽光発電システム。 |
| カーポート発電 | 駐車場の屋根部分に設置した太陽光発電システム。 |
| KY活動 | 危険予知活動。作業前に潜在危険を洗い出し共有する活動。 |
| ビフォーアフター | 洗浄前後の状態を記録・比較すること。 |

# 6. 主な汚れと発生原因

| 汚れの種類 | 発生原因 | 発生しやすい環境 |
|---|---|---|
| 砂埃・土埃 | 風による砂・土の付着 | 農地・工事現場周辺・乾燥地域 |
| 黄砂 | 大陸からの黄砂飛来 | 春季・日本海側・西日本 |
| 花粉 | 植物の花粉付着 | 春季・スギ・ヒノキ林周辺 |
| 鳥のフン | 鳥の糞便付着 | 電線・木・架台上に鳥が集まる環境 |
| スス・排気ガス | 工場・道路からの排気付着 | 工業地帯・幹線道路沿い |
| 塩分 | 海塩粒子の付着 | 海岸近辺（2km以内） |
| コケ・藻類 | 湿潤環境での生物付着 | 日陰・湿度が高い地域 |
| 水垢（ミネラル） | 水道水・雨水に含まれるカルシウム・マグネシウムの固着 | 雨の少ない地域・硬水地域 |
| 落ち葉・虫 | 植物・昆虫の付着 | 樹木周辺・水辺 |

水道水を洗浄に使用すると、水中のカルキ（カルシウム・マグネシウム等）が蒸発後に白い水垢として残留し、仕上がりを著しく損なう（参照URL2）。このため洗浄には純水を使用する。

---

# 7. 汚れが落ちにくい原因

| 原因 | 詳細 |
|---|---|
| 長期間の固着 | 汚れが乾燥・焼き付きを繰り返し、ガラス表面に化学的に結合する |
| 鳥フンの固着 | 酸性・タンパク質を含む鳥糞は短期間で固着し、乾燥後は除去困難になる |
| 水垢（スケール）固着 | 水道水使用や雨水乾燥後のカルシウム塩が結晶化して固着 |
| コーティングへの浸透 | 反射防止コーティングの微細構造に汚れが入り込む |
| 静電気による引きつけ | パネル表面の静電気が細かい塵を吸引・保持する |
| 油分含有汚れ | 排気ガス由来の油成分と埃が混合し粘着性を持つ |

---

# 8. 汚れを放置した場合の影響

| 影響 | 内容 |
|---|---|
| 発電効率低下 | 汚れによる遮光・反射増加で最大10%以上の発電量低下が生じる（参照URL2） |
| パネル劣化促進 | 鳥フンの酸性成分がガラス・コーティングを侵食する |
| ホットスポット発生 | 部分的な遮光により過熱セルが生じ、パネル破損・火災リスクが高まる |
| 水垢の永久固着 | 長期放置した水垢は専用薬剤でも除去困難になる |
| コケ・藻の繁殖 | 一度繁殖すると除去が困難になり、表面を傷める |
| 収益損失 | 売電量の低下により事業収益が減少する |

# 9. 清掃の基本原則

1. **純水を使用する**：水道水は使用しない。純水機を使用し、TDS概ね10ppm以下の水で洗浄・すすぎを行う（参照URL2）。
2. **パネルに乗らない**：人間がパネル上に乗ることはパネルの割れ・傷の原因となる。専用ロボットまたは延長ポール付きブラシを使用する（参照URL2）。
3. **過重量機材は使用しない**：パネル1枚あたり60kgを超える負荷を与える機材は破損リスクがある（参照URL2）。
4. **上から下へ洗浄する**：重力方向に汚れを流すため、パネル上部から下部へ洗浄する。
5. **研磨材を使用しない**：金属ブラシ・研磨スポンジ・スチールウールはガラス・コーティングを傷める。
6. **電気設備に近づかない**：接続箱・配線・コネクタへの水かけ・触れを禁止する。
7. **熱いパネルに冷水を当てない**：夏季の高温パネルへの冷水噴射は熱衝撃による割れの原因となる。早朝または夕刻に作業する。
8. **化学薬剤は最小限に使用する**：メーカーが認めていない薬剤はコーティングを損傷する。原則純水のみ使用し、必要な場合はメーカー承認品を使用する。
9. **写真記録を必ず行う**：作業前・中・後の状態を記録し、品質証明と問題発生時の根拠とする。
10. **2名以上で実施する**：安全確保・緊急時対応のため、高所作業・大規模現場では原則2名以上で作業する。

# 12. 使用薬剤の基本選定

太陽光パネルの洗浄は、原則として**純水のみ**を使用する。薬剤を使用する場合は必ずパネルメーカーの許可・指定薬剤を確認する。

| 区分 | 薬剤タイプ | 使用条件 |
|---|---|---|
| 基本洗浄 | 純水（TDS概ね10ppm以下） | 全洗浄で使用。必須 |
| 頑固汚れ（鳥フン等） | パネルメーカー承認の中性洗剤 | メーカー確認後のみ使用 |
| 水垢除去 | パネルメーカー承認の弱酸性スケール除去剤 | メーカー確認・テスト施工後のみ使用 |
| コケ・藻除去 | パネルメーカー承認の生物系除去剤 | メーカー確認・テスト施工後のみ使用 |

薬剤の希釈率・使用量・作用時間はパネルメーカーの承認を得てから使用し、薬剤ラベルを必ず確認する。

# 13. 薬剤使用上の禁止事項

- 強アルカリ性洗剤の使用禁止（反射防止コーティング・アルミフレーム腐食の原因）
- 強酸性洗剤の使用禁止（アルミフレーム・接続部の腐食原因）
- 研磨剤入り洗剤の使用禁止（ガラス・コーティングに傷が生じる）
- 有機溶剤（シンナー・アセトン等）の使用禁止
- 漂白剤・次亜塩素酸系の使用禁止
- メーカー未承認薬剤の使用禁止
- 複数薬剤の混合使用禁止
- パネルが高温の状態での薬剤散布禁止（蒸発による濃縮・固着）
- 薬剤を電気配線・接続箱へかけることの禁止

# 14. 作業前確認

## 現地確認（前日または作業当日）

□ 発電所・施設の管理者へ作業通知済みであるか

□ 作業エリアへの入場許可を取得済みであるか

□ パネル枚数・配置・設置形式を確認済みであるか

□ 架台の状態（ゆるみ・腐食・変形）を確認済みであるか

□ 接続箱・ケーブルの損傷がないか

□ 水道水の供給可能か（純水機接続先）、または持参水量が十分か

□ 作業エリアへのトラック搬入経路を確認済みであるか

□ 天気予報を確認済みであるか（強風・雷雨時は作業禁止）

□ 気温を確認済みであるか（パネル表面温度が40°Cを超える時間帯は避ける）

## 機材確認

□ 純水機の動作を確認済みであるか

□ 発電機の燃料・動作を確認済みであるか

□ ホースに破れ・接続不良がないか

□ 洗浄ロボットの動作・ブラシ状態を確認済みであるか

□ 安全帯・ヘルメットの点検を完了しているか

□ 作業前写真撮影を完了しているか

# 15. 作業中止・報告基準

以下の状況が発生した場合は作業を中止し、管理者・施設担当者へ報告する。

| 状況 | 対応 |
|---|---|
| 強風（目安：瞬間風速10m/s以上） | 即時作業中止・安全な場所へ退避 |
| 落雷・雷鳴が聞こえる | 即時作業中止・建物内へ退避（太陽光システムは常時通電） |
| 豪雨・あられ | 即時作業中止 |
| パネルのひび割れ・破損を発見 | 作業中止・管理者へ報告・写真撮影 |
| 配線・接続箱の損傷を発見 | 作業中止・施設管理者・電気技術者へ連絡 |
| 作業者の体調不良 | 作業中止・休憩・必要に応じ救急連絡 |
| 洗浄中に異常な発煙・異臭 | 作業中止・119番通報・避難 |
| パネル表面に異常（変色・黒ずみ等） | 作業中止・施設管理者へ報告 |
| 水上発電所での浮体異常 | 作業中止・浮体から退避 |

# 17. 詳細作業手順

## 工程1　現地確認・作業計画

### 作業内容

発電所・施設の状態・安全条件・機材搬入経路・パネル配置を確認し、当日の作業計画を確定する。

### 使用道具

- カメラ（スマートフォン可）
- チェックシート
- メジャー（必要に応じ）


### 作業方法

1. 施設担当者と合流し、入場許可・作業範囲を確認する。
2. 全パネルの外観を目視で確認し、ひび割れ・破損・汚れの程度を記録する。
3. 接続箱・ケーブルの損傷がないか確認する。
4. 機材搬入経路・純水機接続可能な水道栓を確認する。
5. 天候・風速・パネル表面温度を確認する。
6. 作業前の全景・代表的な汚れ箇所を写真撮影する。
7. 当日の作業順序・担当区画を作業者間で共有する。

### 清掃方法・やり方（技術解説）

パネル表面温度は早朝に最も低く、夏季の日中は60°C以上になることがある。温度が高い状態で冷水を当てると熱衝撃でガラスにひびが入るリスクがある。作業開始前にパネル表面温度を確認し、必要であれば作業時間帯を調整する。

### ポイント

- 事前に施設担当者と発電モニタリングの記録を取得しておく（洗浄前後比較用）
- ひび割れ・接続箱損傷を発見した場合は、その箇所を洗浄対象から除外し報告する

### 注意事項

- 接続箱・配線には触れない
- パネルに乗らない
- 損傷パネルへの洗浄は施設管理者の指示を仰ぐ

### 作業時間目安

約15〜30分（現場規模・移動距離による）

### 必要人数

通常：1名
推奨：2名

### 完了基準

□ パネル枚数・配置確認完了
□ 損傷箇所の記録・写真撮影完了
□ 作業前写真撮影完了
□ 作業計画の作業者間共有完了

---

## 工程2　機材搬入・設置

### 作業内容

トラックから純水機・タンク・発電機・高圧送水機・ホース・洗浄機を降ろし、作業に適した位置へ設置する。

### 使用道具

- 2tトラック
- 純水タンク
- 純水機
- 発電機
- 高圧送水機
- ホース


### 作業方法

1. トラックを作業エリアに隣接した位置へ駐車する。
2. 発電機を安全な場所（換気良好・可燃物から離れた場所）へ設置・接地する。
3. 純水機を水道栓へ接続し、排水路を確保する。
4. 純水タンクを純水機出口に接続する。
5. 高圧送水機を純水タンクに接続する。
6. ホースを洗浄開始点まで延長し、折れ・ねじれがないよう配置する。
7. 全接続部を確認し、漏れがないかチェックする。

### 清掃方法・やり方（技術解説）

ホースは最大200m延長が可能（参照URL2）。延長距離が長いほど送水圧力が下がるため、高圧送水機の出力を適宜調整する。発電機は太陽光システムのパワーコンディショナー（PCS）から離れた場所へ設置し、排気が発電機器に当たらないようにする。

### ポイント

- 発電機の燃料は作業開始前にフルにしておく
- ホースに車両が乗り上げないよう養生カバーを敷く

### 注意事項

- 発電機の排気を密閉空間に向けない（一酸化炭素中毒リスク）
- ホースを架台・パネルのフレームに引っかけない
- 機材の重量が架台・屋根へ過度な負荷をかけないよう配置する

### 作業時間目安

約30〜60分（現場規模・機材量による）

### 必要人数

通常：2名
推奨：3名

### 完了基準

□ 発電機設置・起動確認完了
□ 純水機接続・動作確認完了
□ ホース延長・接続確認完了
□ 各機材の漏れなし確認完了

---

## 工程3　純水生成・水質確認

### 作業内容

純水機を稼働させ、TDS値が基準値（概ね10ppm以下）を満たした純水を十分量生成する。

### 使用道具

- 純水機
- TDSメーター
- 純水タンク


### 作業方法

1. 純水機の電源を入れ、稼働を開始する。
2. 初期の水（フラッシング水）は排水する（メーカー指定時間に従う）。
3. TDSメーターで生成された水の数値を計測する。
4. TDS概ね10ppm以下であることを確認する。基準を超えている場合は純水機フィルターを点検する。
5. 純水タンクへ十分量の純水を貯留する（当日使用見込み量の110%以上）。
6. TDS値・生成量を記録する。

### 清掃方法・やり方（技術解説）

水道水にはカルキ（カルシウム・マグネシウム等）が含まれており、洗浄・すすぎに使用すると乾燥後に白い水垢（スケール）が残る（参照URL2）。純水は不純物が少ないため蒸発後に残留物を残しにくく、仕上がりが向上する。

### ポイント

- TDS値は毎回記録し、フィルター交換時期の管理に活用する
- 夏季は純水タンクが高温になりやすいため、直射日光を避けて保管する

### 注意事項

- TDS基準値を超えた水での洗浄を行わない
- 純水機フィルター・メンブレンの交換はメーカー指定に従う

### 作業時間目安

約20〜45分（純水機の処理能力・必要量による）

### 必要人数

通常：1名

### 完了基準

□ TDS値が概ね10ppm以下であることを確認
□ TDS値を記録済み
□ 必要量の純水を生成完了

## 工程4　安全確認・立入禁止区域設置

### 作業内容

作業区域の安全確認を行い、第三者が誤って立ち入らないよう表示・ロープ等で区画する。高所作業の場合は墜落防止措置を講じる。

### 使用道具

- 立入禁止ロープ
- カラーコーン
- 作業中表示板
- フルハーネス・ランヤード（高所作業時）


### 作業方法

1. 作業エリア周囲にカラーコーンを配置し、立入禁止ロープで囲む。
2. 「作業中・立入禁止」表示板を設置する。
3. 屋根上作業の場合：親綱を設置し、作業者全員がフルハーネスを装着・接続する。
4. 水上作業の場合：救命胴衣を全員が装着する。
5. 風速を確認する（手持ち風速計または施設のデータを活用）。
6. 作業開始前ミーティングを実施し、KY活動を行う。

### 清掃方法・やり方（技術解説）

太陽光パネルは常時発電している。屋根上・架台周辺は濡れると非常に滑りやすくなる。洗浄水が流れ落ちる経路を事前に把握し、第三者が濡れた床面を歩かないよう誘導する。

### ポイント

- 強風（目安：瞬間風速10m/s以上）の場合は作業を中止する
- 高所作業は必ずフルハーネス着用。安全帯のランヤードを親綱に接続してから移動する

### 注意事項

- 高さ2m以上の作業は必ずフルハーネス型安全帯を使用する（労働安全衛生規則に準ずる）
- 通電中の太陽光システムには水をかけた状態で接触しない

### 作業時間目安

約10〜20分

### 必要人数

通常：2名
推奨：2名（高所・水上では最低2名）

### 完了基準

□ 立入禁止区域設置完了
□ KY活動・作業前ミーティング実施完了
□ 全作業者のフルハーネス装着確認完了（高所の場合）
□ 救命胴衣装着確認完了（水上の場合）

---

## 工程5　ホース・洗浄機設置・最終確認

### 作業内容

ホースを洗浄開始位置まで延長し、洗浄ロボットまたはブラシをセットして洗浄準備を完了する。

### 使用道具

- ホース（必要長さ分）
- 洗浄ロボット（または延長ポール付きブラシ）
- リモコン（ロボット使用時）
- 接続継手


### 作業方法

1. ホースを洗浄開始パネル位置まで引く。折れ・ねじれを解消する。
2. 洗浄ロボットをパネル上の作業開始位置にセットする（参照URL2）。パネルには乗らず、架台沿いに設置する。
3. ホースをロボットまたはブラシに接続する（参照URL2）。
4. 全機材の最終確認を実施する（参照URL2）。
5. 試験的に約1L（バケツ半杯程度）の純水を流して漏れ・水流を確認する。
6. リモコン操作でロボットの動作を確認する（ロボット使用時）。

### 清掃方法・やり方（技術解説）

洗浄ロボットはパネル1枚当たり60kgを超える負荷を与えるものは使用してはならない（参照URL2）。ホースの延長距離が長くなると水圧が下がるため、洗浄機の出力設定を確認する。

### ポイント

- ロボット設置時は架台の側面・ラダー等を使い、パネル上に体重をかけない
- ホースが架台・パネルに巻きつかないよう経路を整理する

### 注意事項

- ロボットがパネルから落下しないよう、ロープ等の落下防止措置を講じる
- ホース接続はしっかり行い、作業中に外れないことを確認する

### 作業時間目安

約15〜30分

### 必要人数

通常：2名

### 完了基準

□ ホース延長・接続完了
□ 洗浄機・ロボット設置完了
□ 試運転・水流確認完了
□ 落下防止措置確認完了

---

## 工程6　パネル洗浄実施

### 作業内容

純水を使用してパネル表面の砂埃・花粉・汚れをロボットまたはブラシで洗浄する。1日2,000〜3,000枚の洗浄が目安（参照URL2）。

### 使用道具

- 洗浄ロボット（またはポール付きソフトブラシ）
- リモコン
- ホース

### 使用薬剤

純水（TDS概ね10ppm以下）

### 作業方法

1. 高圧送水機を起動し、純水を洗浄機へ送水する。
2. 上部（パネル上端）から洗浄を開始する。
3. ロボットをリモコンで操作しパネル上を走行させる（参照URL2）。
4. 汚水がパネル下端から流れ落ちることを確認しながら進める。
5. 一列（ストリング単位等）を完了したら次の列へ移動する。
6. 洗浄中にパネルひび割れ・異常を発見した場合は直ちに停止・報告する。
7. 洗浄進捗をチェックシートに記録する。

### 清掃方法・やり方（技術解説）

ロボット洗浄では日本製特殊ナイロンロールブラシがパネル表面を均一に清掃する（参照URL2）。人間がパネルに乗ることはパネルの割れ・傷の原因となるため、ロボットまたは延長ポールで作業する。ブラシは上から下への一方向に動かし、汚れを下方へ流す。

### ポイント

- 洗浄順序をあらかじめ決めて、抜けが生じないよう系統的に進める
- 洗浄後のパネルが乾燥する前にすすぎ工程へ移る

### 注意事項

- パネルへの直接乗り込み禁止（参照URL2）
- ロボット・ブラシでパネルエッジ（フレーム角）に強くぶつけない
- 接続箱・ケーブルへの水かけ禁止

### 作業時間目安

約2〜6時間（パネル枚数・設備規模による。ロボット使用時の目安：1日2,000〜3,000枚）

### 必要人数

通常：2名
推奨：3名（大規模現場）

### 完了基準

□ 全洗浄対象パネルの洗浄完了
□ 進捗チェックリスト確認完了
□ パネル損傷・異常なし確認

---

## 工程7　頑固汚れ・スポット手動洗浄

### 作業内容

ロボット洗浄・ブラシ洗浄で除去できなかった鳥のフン・固着汚れ・積み重なった埃を手動でスポット洗浄する。

### 使用道具

- 柔らかいスポンジ（マイクロファイバー等）
- スプレーボトル（純水）
- 延長ポール付きソフトブラシ

### 使用薬剤

純水（メーカー承認の中性洗剤が必要な場合はメーカー確認後使用）

### 作業方法

1. 洗浄後に残留する頑固汚れ箇所をリストアップする。
2. スプレーボトルで純水を固着汚れに吹きかけ、数分間湿らせて軟化させる。
3. 柔らかいスポンジまたはブラシで優しく円を描かずに一方向に擦る。
4. 純水で3〜5回すすぐ。
5. 鳥のフンは中性洗剤を使用する場合、メーカー確認後に希釈してクロスに含ませてから拭き取る。
6. 水垢（白いスケール）が残る場合は、メーカー承認の弱酸性除去剤をテスト施工後に使用する。

### 清掃方法・やり方（技術解説）

鳥のフンは乾燥前の方が除去しやすい。乾燥・固着している場合は水を全面に均一にかけて5分以上湿らせてから除去する。絶対に乾いた状態でこすらない（ガラス表面に傷が入る）。

### ポイント

- テスト施工は目立たない隅で行い、変色・白化がないことを確認する
- 薬剤使用後は必ず純水で3〜5回すすぐ

### 注意事項

- 鳥のフンには病原体が含まれる場合がある。手袋・マスクを必ず着用する
- 強くこすらない（コーティング・ガラス傷つけ防止）
- 酸性薬剤を長時間パネル上に放置しない

### 作業時間目安

約30〜90分（汚れの量・程度による）

### 必要人数

通常：1〜2名

### 完了基準

□ 固着汚れ（鳥フン等）の除去完了
□ 薬剤使用後のすすぎ確認完了
□ スポット洗浄箇所の記録完了

---

## 工程8　純水すすぎ・仕上げ

### 作業内容

洗浄後のパネル全体を純水で最終すすぎを行い、洗剤成分・汚れ残りを完全に除去する。

### 使用道具

- ホース（純水供給）
- スクイジー（水切り仕上げ用、必要に応じ）

### 使用薬剤

純水（TDS概ね10ppm以下）

### 作業方法

1. 純水を上部から均一にパネル全面へ流しかける。
2. 洗剤を使用した箇所は特に十分量の純水を流してすすぐ。
3. 水が濁っていないことを目視で確認する。
4. スクイジーを使用する場合は、上から下へ一方向に水切りを行う（ガラス面に傷をつけないよう適切な圧力で行う）。
5. 乾燥後に水垢が残らないことを確認できるよう、仕上げ後は日陰・曇天であることが望ましい。

### 清掃方法・やり方（技術解説）

純水は不純物が少ないため、乾燥後も残留物が残りにくく仕上がりが均一になる（参照URL2）。強い直射日光の下での作業は蒸発が早く、水垢・ムラが生じやすい。できれば曇天・早朝・夕刻に最終すすぎを行う。

### ポイント

- 最終すすぎは各パネルに対して上から下への一方向に流す
- パネル下端に溜まった水も流し切る

### 注意事項

- 水道水による最終すすぎは絶対に行わない
- パネルが乾燥した後にムラ・白い残留物がないか確認する

### 作業時間目安

約30〜60分（パネル枚数による）

### 必要人数

通常：1〜2名

### 完了基準

□ 全パネルへの純水すすぎ完了
□ 洗剤残留なし確認
□ 水垢・ムラなし確認（乾燥後）

---

## 工程9　最終確認・ビフォーアフター記録

### 作業内容

洗浄完了後のパネル全体を目視点検し、作業前後の写真を比較して品質を確認する。

### 使用道具

- カメラ（スマートフォン可）
- チェックシート


### 作業方法

1. 乾燥後のパネル全体を目視で確認する（汚れ残り・水垢・傷の有無）。
2. 代表的な複数箇所で作業後写真を撮影する（作業前と同じアングル）。
3. 施設の発電モニタリングを確認できる場合は数値を記録する。
4. パネルの損傷・異常が見つかった場合は写真撮影し、施設担当者へ報告する。
5. チェックリストに基づき完了確認を行う。

### 清掃方法・やり方（技術解説）

ビフォーアフターの写真は発電量回復の証拠になるとともに、パネル損傷が洗浄前から存在していたことを証明する重要な記録となる（参照URL2）。

### ポイント

- 光の当たり方により確認精度が変わる。複数角度から確認する
- 洗浄後すぐより、乾燥後（20〜30分後）に確認する方が水垢・残留物が見えやすい

### 注意事項

- 損傷パネルは洗浄前から存在したことを確認・記録しておく
- ロボットや工具をパネル上に置いたまま立ち去らない

### 作業時間目安

約15〜30分

### 必要人数

通常：1〜2名

### 完了基準

□ 全パネル目視確認完了
□ 作業後写真撮影完了
□ 損傷・異常箇所の記録完了
□ チェックリスト確認完了

## 工程10　機材撤収・現場清掃・報告書作成

### 作業内容

洗浄機材をすべて撤収し、現場を元の状態に戻す。作業報告書を作成し施設担当者へ引き渡す。

### 使用道具

- ホース収納リール
- 2tトラック


### 作業方法

1. ホースを収納する（純水を排水した後、折れないよう巻き取る）。
2. 洗浄ロボット・ブラシを清掃し、指定位置に収納する。
3. 高圧送水機・発電機・純水機の電源を切り、冷却後にトラックへ積み込む。
4. 排水ホース・接続部を取り外し、使用した水道栓を閉じる。
5. 現場周辺の養生・コーン・ロープを撤去する。
6. 作業エリアに工具・機材の置き忘れがないかを確認する。
7. 足元・通路の水濡れを拭き取り、第三者が転倒しないようにする。
8. 作業報告書を作成し、施設担当者と内容を確認の上、署名をもらう。

### 清掃方法・やり方（技術解説）

機材の内部に残った水は次回作業までに排水・乾燥させておく。特に純水機・高圧送水機の内部に水が残ったまま長期保管すると機材が劣化する。

### ポイント

- 発電量のモニタリングデータを施設担当者と一緒に確認する
- 次回洗浄推奨時期を報告書に記載する

### 注意事項

- 水上発電所では機材の水没・落下に注意する
- 発電所ゲート・鍵の施錠を確認する

### 作業時間目安

約30〜60分

### 必要人数

通常：2名

### 完了基準

□ 機材全量撤収完了
□ 工具・忘れ物なし確認完了
□ 現場足元乾燥確認完了
□ 作業報告書完成・施設担当者確認完了

# 18. 部品・箇所別清掃手順

## パネル表面ガラス

1. 純水を全面に均一に流す
2. ソフトブラシまたはロボットで上から下へ洗浄する
3. 純水で十分にすすぐ
4. 乾燥後に水垢・残留物がないか確認する

## アルミフレーム

1. ソフトブラシで埃・汚れを落とす

1. 取付部に土・堆積物が溜まっていないか確認する
2. ブラシで清掃し、純水で流す
3. 腐食・ゆるみがないか確認し、施設担当者へ報告する

## 架台（アルミ・スチール）

1. 架台上の落ち葉・堆積物をブラシで除去する
2. 純水で洗い流す
3. 腐食・変形を目視確認する

## パネル周辺地面・排水経路

1. 洗浄水が適切に排水されているか確認する
2. 排水路の詰まりがあれば施設担当者へ報告する

# 23. 汚れの重度別施工基準詳細

## 軽度（砂埃・花粉・薄い堆積）

- 純水をホースで全面に流す
- ブラシ使用なしでも除去可能な場合がある
- 純水すすぎで仕上げる

## 中度（砂埃層状固着・少量鳥フン）

- 純水を事前に流してから、ソフトブラシ（ロボット含む）で洗浄する
- ブラシは上から下への一方向
- 純水で3〜5回すすぐ

## 重度（鳥フン多量固着・初期水垢）

1. 純水を十分量流し、固着物を軟化させる（5〜10分）
2. ソフトスポンジ・クロスで優しく除去
3. パネルメーカー承認の中性洗剤が必要な場合はテスト施工後に使用
4. 純水で十分にすすぐ
5. 乾燥後に再確認し、除去できなければ施設担当者へ報告

## 超重度（コケ・藻・永久固着水垢）

- 通常洗浄では除去不能と判断
- 施設担当者・パネルメーカーへ相談
- 専門業者による特殊洗浄または修理・交換を検討

# 29. 教育ポイント（新人向け）

## 最初に覚えること

- 太陽光パネルは日中常時発電している（触れると感電する）
- パネルには絶対に乗らない
- 純水以外の水で洗浄しない
- フルハーネスは高さ2m以上で必ず装着する
- 強風・落雷時は作業禁止

## 失敗しやすいポイント

- TDS確認を省略して水道水で洗浄してしまう
- ブラシが強くてパネルに傷をつける
- 接続箱・ケーブルへ水をかけてしまう
- 高温のパネルに冷水を当てて熱衝撃を与える
- ロボット・ブラシが汚れたまま使用して傷をつける
- フルハーネスのランヤードを親綱に接続し忘れる

## 事故が多い作業

- 屋根上での移動（濡れた屋根面での転倒・転落）
- ロボットの設置・回収（パネル周辺での作業）
- 水上発電所での乗り降り
- 発電機の設置・燃料補充（排気ガス・燃料引火）

## 品質が落ちやすいポイント

- 最終すすぎが不十分で洗剤が残る
- 直射日光・高温下での仕上げ（蒸発による水垢）
- ブラシの方向が不均一でムラが出る
- 鳥フンを水で湿らせずに乾いたまま擦る（傷・ガラス破損）
- 洗浄後の乾燥確認が不足

## 道具の正しい使い方

- **ソフトブラシ**：先端が軟らかいナイロン毛。パネル表面へ強く押し付けない。毛先が汚れていないか確認してから使用する
- **スクイジー**：上から下へ一方向。ゴム部分に砂・異物が付いていないか確認する
- **ホース**：折れ・ねじれがないよう配置する。接続部が外れないよう確認する
- **純水機**：フィルター状態をメーカー指定に従い定期確認する
- **TDSメーター**：使用前に校正・動作確認を行う

## 薬剤の取り扱い

- 原則として純水のみ使用する
- 薬剤を使用する場合は必ずパネルメーカー承認後、薬剤ラベルを確認する
- 薬剤はパネルが冷えた状態で使用する（高温時は禁止）
- 薬剤の混合は絶対禁止
- 残った薬剤液は廃棄基準に従って処分する

## 作業姿勢

- 屋根上では腰を低くし、常に3点支持を意識する
- ランヤードの接続先を確認してから動く
- 重量物の持ち上げは腰を曲げず膝を使う
- 熱中症予防のため、30〜60分ごとに水分補給と日陰での休憩を取る

## プロが意識しているポイント

- TDSを記録し、フィルター交換時期を予測する
- ビフォーアフター写真で発電量回復の証明資料を作る
- ブラシの状態を毎回確認し、摩耗したものは使わない
- 施設担当者に洗浄後の発電量モニタリングを促す

## 品質確認方法

- 目視（乾燥後20〜30分以上経過してから斜光で確認）
- 手触り（スジ・ザラつきがないか）
- 写真比較（ビフォーアフター）
- 発電量の前後比較（施設モニタリングを活用）

## 先輩が確認する項目

□ TDS確認の実施

□ フルハーネスの接続状態

□ 接続箱へ水をかけていないか

□ パネルへの踏み込みがないか

□ ブラシ・スポンジが清潔か

□ 最終すすぎが十分か

□ 乾燥後の水垢確認

□ 写真撮影の完了

## 一人作業を許可する判断基準

- 地上設置・野立てで高所作業がない場合のみ
- TDS確認・機材設置が単独で正確にできる
- 安全知識・緊急連絡手順を理解している
- フルハーネスが不要な環境

## 一人作業禁止条件

- 高さ2m以上の屋根上作業
- 水上発電所での作業
- 初めての現場
- 悪天候・強風

## 教育時のチェックポイント

□ 純水の必要性と確認方法（TDS）を説明できるか

□ パネルに乗らない理由を説明できるか

□ フルハーネスの装着・接続を正確に行えるか

□ 洗浄の順序（上から下）を実践できるか

□ 接続箱・ケーブルへの水かけ禁止を守れるか

□ 緊急連絡先・緊急時手順を把握しているか

# 41. 日常管理・汚れ予防

- 定期的な目視確認（月1回以上を推奨）
- 鳥のフン・異物を発見した場合は早期に除去する（固着前の方が容易）
- 鳥が集まりやすい場所（電線・架台の上）への鳥よけ設置を施設担当者へ推奨する
- 発電量モニタリングの継続的実施（急激な発電量低下は汚れのサイン）
- 架台・フレームの腐食・ゆるみを定期確認する
- 隣接する樹木の枝葉が伸びてパネルに触れていないか確認する

# 43. 使用禁止事項

- 水道水による洗浄・すすぎ（水垢原因）
- パネル上への乗り込み（破損原因）

- メーカー未承認薬剤の使用
- 接続箱・ケーブル・コネクタへの水・薬剤散布
- 乾燥した状態でのパネル擦り（傷・コーティング剥離）
- 高温のパネルへの冷水散布（熱衝撃によるひび割れ）
- 強風（目安：瞬間風速10m/s以上）時の作業
- 落雷・雷鳴時の屋外作業
- フルハーネス未装着での高所（2m以上）作業
- 救命胴衣未着用での水上作業
- 一人での高所・水上作業
