# ブラインド清掃 標準作業手順書（SOP）

**対象：横型アルミブラインド・耐水ブラインド・木製ブラインド・竹製ブラインド・樹脂製ブラインド・バーチカルブラインド**

---

# 1. 適用範囲

## 対象施設・設備

| 区分 | 対象 |
|---|---|
| 対象施設 | オフィス・店舗・病院・クリニック・介護施設・福祉施設・ホテル・宿泊施設・学校・保育施設・飲食店・工場・マンション共用部・一般住宅 |
| 対象設備 | 横型アルミブラインド・耐水ブラインド・木製ブラインド・竹製ブラインド・樹脂製ブラインド・バーチカルブラインド・操作棒・昇降コード・ボトムレール・ヘッドボックス・取付金具 |

## 対象作業

- 日常除塵（ハンディモップ）
- スラット拭き清掃（中性洗剤）
- 低圧噴霧洗浄（油煙・ヤニ・固着汚れ）
- 耐水ブラインドの丸洗い
- 木製・竹製ブラインドの乾式清掃
- バーチカルブラインドの洗浄
- 操作棒・昇降コード・ボトムレールの清掃
- 最終動作確認

## 施工可能条件

| 条件 | 基準 |
|---|---|
| 水洗い可否 | 取扱説明書または素材確認済みのもの |
| 室内気温 | 5℃〜40℃（乾燥に影響） |
| 天候・強風・直射日光 | 室内作業のため天候不問 |
| 凍結 | 室内での作業のため通常不問 |
| 脚立設置 | 水平な床・ブラインド直下にスペースが確保できること |
| 高所作業 | ブラインドが高所にある場合、脚立が安全に設置できること |
| 感電リスク対策 | 電気設備（コンセント・照明スイッチ）周辺は養生し、水・薬剤がかからないようにすること |
| 排水 | 丸洗い・噴霧洗浄時は排水経路の確保 |
| 養生 | 床・壁・電気設備への水・薬剤飛散防止養生が実施可能なこと |

## 施工不可条件

| 条件 | 対応 |
|---|---|
| スラットが多数破損している | 清掃中止・報告。清掃による破損と区別するため先に写真撮影 |
| ヘッドボックスが外れかけている | 清掃中止・報告。無理に操作しない |
| 昇降コードが切れかけている | 清掃中止・報告。コードに張力をかけない |
| 取付金具が緩んでいる | 清掃中止・報告 |
| 水洗い可否が確認できない | テスト施工で確認してから実施 |
| 電気設備へ水がかかる危険がある | 養生を完全にしてから実施（不可能なら湿式清掃は中止） |

## 作業中止基準

以下を発見した場合は即時作業を停止し、管理者・お客様へ報告する。

| 発見内容 | 対応 |
|---|---|
| スラット・ヘッドボックスの破損を発見（施工中） | 即時中止・写真撮影・報告 |
| 昇降コードが断裂しそう | 即時中止・報告 |
| 薬剤が目・皮膚に付着 | 流水で15分以上洗浄・受診 |
| 電気設備への水・薬剤浸入の疑い | 即時中止・電源遮断・乾燥確認後に再開 |
| お客様から中止指示 | 即時中止 |

# 2. 素材別施工方法の選択

**素材によって使える薬剤・方法が全く異なる。必ず素材を確認してから施工方法を決める。**

| 素材 | 判断方法 | 使用可能な清掃方法 | 水拭き | 噴霧洗浄 | 丸洗い |
|---|---|---|---|---|---|
| アルミ製スラット | 光沢・軽量・曲がりやすい | 乾式除塵→拭き清掃→噴霧洗浄 | ○ | ○（低圧） | △（耐水仕様のみ） |
| 樹脂製スラット | 軽量・弾力あり | 乾式除塵→拭き清掃→噴霧洗浄 | ○ | ○（低圧） | △（耐水仕様のみ） |
| 耐水ブラインド | 取扱説明書に「水洗い可」の表記 | 乾式除塵→拭き清掃→丸洗い | ○ | ○ | ○ |
| **木製スラット** | 木の手触り・重量感あり | **乾式除塵のみ** | **禁止** | **禁止** | **禁止** |
| **竹製スラット** | 節あり・独特の光沢 | **乾式除塵のみ** | **禁止** | **禁止** | **禁止** |
| バーチカル（布） | 縦長のルーバー・布製 | 乾式除塵→取外し洗浄（洗濯表示確認） | △ | △ | △（洗濯表示確認） |

| カビ | 黒・緑の斑点。湿気のある部位 | 窓際・浴室用ブラインド | カビ除去剤（CHEM-003） | スプレー・クロス | 10〜20倍 | 5〜10分 | 木製・布製に塩素系禁止。強く払うと胞子飛散 |
| 水垢・石鹸カス | 白い輪状・うろこ状 | 耐水ブラインド・浴室用 | 弱酸性洗剤（クエン酸系） | クロス | 10〜20倍 | 5〜10分 | 金属部への長時間接触禁止。テスト施工必須 |
| ホコリ固着（長期未清掃） | グレー〜黒の硬い層 | スラット表面 | 弱アルカリ洗剤（CHEM-002） | 低圧噴霧器→クロス | 30〜50倍 | 3〜5分 | 乾式除塵→噴霧の順番を守る |
| クモの巣・虫の死骸 | 白い糸状・黒い点 | ヘッドボックス周辺・窓際 | 不要 | ハンディモップ・綿棒 | — | — | 先に乾式除去してから拭き清掃へ進む |

# 6. 使用薬剤一覧（AVL Facilities 推奨基準）

## CHEM-001　中性洗剤

| 項目 | 内容 |
|---|---|
| 液性 | 中性（pH 6〜8） |
| 使う理由 | 素材へのダメージが最も少ない。軽度の汚れはまずこれを使う。全素材に使用可能 |
| 対象汚れ | 皮脂・手垢・ホコリ・軽度の黄ばみ |
| 対象素材 | アルミ・樹脂・耐水ブラインド・操作棒・コード・ボトムレール |
| 推奨希釈倍率 | 50〜100倍（水500mlに対し5〜10ml程度） |
| 使用量目安 | 約30〜50ml/台（クロスに含ませる量） |
| 放置時間 | 1〜3分 |
| 使用できない素材 | 特になし（最も安全な洗剤） |
| 注意事項 | 汚れが落ちない場合はCHEM-002へ切り替える。水拭き後に乾拭き必須 |

---

## CHEM-002　弱アルカリ洗剤（油汚れ・ヤニ用）

| 項目 | 内容 |
|---|---|
| 液性 | 弱アルカリ性（pH 8〜10） |
| 使う理由 | アルカリ成分が油分・ヤニのベタつきを鹸化（乳化）して浮かせる。中性洗剤で落ちない固着汚れに使用 |
| 対象汚れ | 油汚れ・ヤニ・排気ガス・長期固着ホコリ |
| 対象素材 | アルミ製スラット・樹脂製スラット・耐水ブラインド |
| 推奨希釈倍率 | 通常油汚れ：50倍 / 重度ヤニ：20〜30倍 |
| 使用量目安 | 約30〜50ml/台（クロス・噴霧器に含ませる量） |
| 放置時間 | 3〜5分 |
| 使用できない素材 | **木製・竹製スラット（変色・反りの原因）・布製バーチカル（染料脱色の恐れ）** |
| 注意事項 | 放置時間を超えると塗装に影響する場合あり。必ず時間を守る。すすぎ（水拭き）を徹底する |

---

## CHEM-003　カビ除去剤

| 項目 | 内容 |
|---|---|
| 液性 | アルカリ性（塩素系または非塩素系） |
| 使う理由 | カビの菌糸を分解する成分を含む。拭き取りだけでは菌糸の根が残り再発する |
| 対象汚れ | カビ・黒ずみ（生物汚染） |
| 対象素材 | アルミ製・樹脂製・耐水ブラインド（テスト施工必須） |
| 推奨希釈倍率 | 10〜20倍（スポット使用が基本） |
| 使用量目安 | 汚染箇所のみに約10〜20ml |
| 放置時間 | 5〜10分 |
| 使用できない素材 | **木製・竹製・布製に塩素系禁止。金属部への長時間接触禁止** |
| 注意事項 | 必ずテスト施工を実施。換気しながら使用。他の薬剤と混合禁止 |

## CHEM-004　弱酸性洗剤（水垢・石鹸カス用）

| 項目 | 内容 |
|---|---|
| 液性 | 弱酸性（pH 4〜6、クエン酸系） |
| 使う理由 | 酸がミネラル成分（水垢・石鹸カス）を溶解する。耐水ブラインドの浴室汚れに効果的 |
| 対象汚れ | 水垢・石鹸カス・白いミネラル汚れ |
| 対象素材 | 耐水ブラインド・樹脂製スラット（テスト施工必須） |
| 推奨希釈倍率 | 10〜20倍 |
| 使用量目安 | 約20〜30ml/台 |
| 放置時間 | 5〜10分 |
| 使用できない素材 | **アルミ製スラット（腐食の原因）・金属部品（錆の原因）・木製・竹製** |
| 注意事項 | テスト施工必須。アルカリ性薬剤との混合禁止（有害ガス発生） |

# 8. 清掃作業フロー

```text
作業開始
　↓
工程1　事前点検・養生・作業前写真撮影
　↓
工程2　乾式除塵（全素材共通・必須）
　↓
素材・汚れの種類で分岐
　↓
工程3　横型ブラインドの拭き清掃（アルミ・樹脂・耐水）
　↓　または
工程4　低圧噴霧洗浄（油汚れ・ヤニ・固着汚れ）
　↓　または
工程5　耐水ブラインドの丸洗い
　↓　または
工程6　木製・竹製ブラインドの乾式清掃
　↓
工程7　操作棒・昇降コード・ボトムレール清掃（全素材共通）
　↓
工程8　最終確認・動作確認・作業後写真撮影
　↓
養生撤去・現場復旧
　↓
作業完了
```

## 基本原則

1. **必ず乾式除塵を先に行う**：ホコリが残った状態で濡らすと泥状になりスラットへ固着する
2. **上から下へ施工する**：ヘッドボックス→スラット→ボトムレールの順
3. **スラットの長手方向に沿って動かす**：横方向の力は曲がり・折れの原因
4. **力で擦らない**：薬剤の化学力で汚れを浮かせてから、軽い物理力で除去する
5. **木製・竹製は絶対に濡らさない**：水分は反り・染み・膨張の原因

## 工程1　事前点検・養生・作業前写真撮影

**目安時間：約3〜5分/台　必要人数：1名（大型・高所は2名）**

### 何を行うか

ブラインドの素材・破損・動作状態を確認し、周辺を養生する。**施工前からの破損を記録することで、作業中に起きた破損と区別できる。絶対に省略しない。**

### 施工順序

1. ブラインドの素材を確認する（「Section 2 素材別判断フロー」参照）。
2. スラットの曲がり・折れ・塗装剥離を目視確認する。
3. 操作棒を動かしてスラットの角度調整を確認する（回転方向・可動域）。
4. 昇降コードを操作して上下動を確認する（スムーズに動くか）。
5. ヘッドボックスと取付金具の固定を確認する（緩みがないか）。
6. 作業前写真を撮影する（全景・汚染箇所・破損箇所）。
7. OA機器・家具を移動または養生する。
8. 窓台・床・壁に養生シートを敷く。重なり部分はテープで固定する。
9. 脚立を平らで安定した場所に設置する。

**【写真①：ブラインド全景（作業前）】**

**【写真②：汚染箇所・破損箇所（発見時）】**

### 使用工具

TOOL-009（脚立）/ TOOL-011（養生シート）/ TOOL-014（カメラ）

### ⚠ 失敗しやすいポイント

- **写真撮影を省略する** → 施工中に破損した場合に「作業前から破損していた」証明ができない。必ず最初に撮影する。
- **素材確認を怠る** → 木製ブラインドを水拭きして反りが発生した、など。素材を必ず最初に確認する。
- **操作棒を回しすぎる** → 操作限界以上に回すとルーバーが外れる。1〜2回転させて確認する程度にする。

### 【プロのコツ】

- LEDライトをスラットに対して斜め30〜45°で当てると、汚れ・傷・曲がりが見えやすい。
- 塗装剥離・スラットの曲がりは清掃前から存在することが多い。施工前の写真は「証拠」として残す習慣をつける。

### 次工程へ進む判断

✅ 素材確認完了

✅ 破損・動作確認完了（発見時は写真撮影・記録済み）

✅ 作業前写真撮影完了

✅ 養生完了

→ 工程2へ進む

## 工程2　乾式除塵（全素材共通・必須工程）

**目安時間：約5〜10分/台　必要人数：1名**

### 何を行うか

スラット・ヘッドボックス・コードに付着したホコリ・花粉・クモの巣を、薬剤を使う前に除去する。**この工程を省略すると、濡らした際にホコリが泥状になってスラットへ固着し、拭き取りに何倍もの時間がかかる。**

### 施工順序

1. スラットを閉じる（室内側へ傾ける）。
2. ヘッドボックスの上部から始める（上から下へ）。
3. ハンディモップをスラットの長手方向に沿って、上から下へ動かす（速度：約10〜15cm/秒）。
4. ボトムレールを除塵する。
5. 操作棒・昇降コードを除塵する。
6. スラットを反転させる（反対方向へ傾ける）。
7. 裏面を同様に上から下へ除塵する。
8. 床に落ちたホコリを掃除機で回収する。

### 使用工具

TOOL-001（ハンディモップ）/ TOOL-010（掃除機）

### ⚠ 失敗しやすいポイント

- **スラットを横方向に動かす** → スラットが曲がる。必ず長手方向（左右）に動かす。
- **強く叩いてホコリを飛ばそうとする** → ホコリが室内に飛散して再付着する。モップを当てながら1〜2cm/秒の速度でゆっくり移動する。
- **カビがある場合に強く払う** → カビ胞子が飛散して感染リスクが高まる。マスクを着用し、払わずにクロスで取り除く。
- **裏面の除塵を省略する** → 裏面にホコリが残った状態で拭き清掃しても裏面は汚れたまま。両面必ず実施する。

### 【プロのコツ】

- 窓を背にして室内側からブラインドを見ると、光が透けてスラットの汚れ具合が確認しやすい。
- ハンディモップは「当てながら滑らせる」イメージ。押し付けるとスラットが動く。

### 次工程へ進む判断

✅ スラット表裏のホコリなし

✅ ヘッドボックス上部除塵完了

✅ ボトムレール除塵完了

✅ 床のホコリ回収完了

→ 素材・汚れに応じて工程3〜6へ進む

## 工程3　横型ブラインドの拭き清掃（アルミ・樹脂・耐水）

**目安時間：約10〜20分/台　必要人数：1名（大型は2名推奨）**

### 何を行うか

横型ブラインドのスラット両面に付着した皮脂・手垢・軽度の油分・ヤニを、中性洗剤（または弱アルカリ洗剤）を使って除去する。

### 薬剤を選ぶ理由

| 汚れの種類 | 使用薬剤 | 選ぶ理由 |
|---|---|---|
| 皮脂・手垢・ホコリ | CHEM-001（中性洗剤） | 素材ダメージが最も少ない。まず中性洗剤から試す |
| 油汚れ・ヤニ | CHEM-002（弱アルカリ洗剤） | アルカリ成分が油分を鹸化して浮かせる。中性洗剤で落ちない場合に使用 |

### 施工順序

1. ゴム手袋を着用し、その上から清潔な軍手を着用する。
2. バケツに水を入れ、使用薬剤を希釈する（計量カップで計量する）。
3. 軍手またはクロスに薬剤液を含ませる（絞って余分な水分を除く）。
4. スラットの端から、人差し指と親指でスラットを**約100〜150g（アルミ製）/ 約150〜200g（樹脂製）**の力で挟む。
5. スラットの長手方向へ左から右へ滑らせる（速度：約10〜15cm/秒）。
6. 片面が終わったらスラットを反転させる。
7. 同じ要領で裏面を清掃する。
8. 上のスラットから順に下へ進める（1枚ずつ）。
9. 固く絞ったクロスで水拭きする（洗剤を完全に拭き取る）。
10. 乾いたクロスで乾拭きして水分を除去する。

### 使用工具

TOOL-002（マイクロファイバークロス）/ TOOL-003（乾拭きクロス）/ TOOL-006（軍手）/ TOOL-007（ゴム手袋）

### ⚠ 失敗しやすいポイント

- **スラットを強く挟む** → アルミスラットは約200g以上の力で折れ曲がる。軽く支える程度の力にする。
- **洗剤をスラットに一度に30ml以上直接噴霧する** → ヘッドボックス内部に洗剤が入り、サビ・動作不良の原因になる。クロスまたは軍手に含ませてから施工する。
- **水拭きを省略する** → 洗剤が乾燥すると白いムラが残る。必ず水拭き→乾拭きを行う。
- **軍手が汚れたままで継続する** → 汚れを他のスラットへ移してしまう。汚れたら即交換する。
- **滑り止め付き軍手をそのまま使う** → スラットに引っかかって傷が入る。裏返して使用する。

### 【プロのコツ】

- 「指でスラットを挟む」より「スラットが軍手の中に入っている」感覚で施工すると力加減が安定する。
- スラット1枚の幅（約25〜50mm）に対して、軍手の人差し指と中指を使うと広い面積を一度に拭ける。
- スラットの端部（切断面）は鋭利なことがある。指を端部の方向へ滑らせると切創が起きる。中央から端へ向けて動かす。

### 次工程へ進む判断

✅ スラット表裏の汚れなし

✅ 洗剤残りなし（乾燥後に白いムラがない）

✅ 水滴なし

✅ スラットの曲がり・折れなし

→ 工程7へ進む

## 工程4　低圧噴霧洗浄（油汚れ・ヤニ・固着汚れ）

**目安時間：約20〜40分/台　必要人数：2名推奨（大型・高所は2名以上）**

### 何を行うか

工程3の拭き清掃では落ちない、長期固着した油煙・ヤニ・黒ずみを低圧噴霧で薬剤を全体に浸透させて除去する。

### 薬剤を選ぶ理由

**CHEM-002（弱アルカリ洗剤）を使う理由**：油分・ヤニのベタつきはアルカリ成分による鹸化（乳化）が最も効果的。低圧噴霧で均一に浸透させることで、クロス拭きでは届かない細部まで洗浄できる。

### 施工順序

1. 床・窓台・OA機器・電気設備を完全に養生する。
2. 素材と耐水性を再確認する（木製・竹製には実施しない）。
3. 目立たない場所でテスト施工する（30cm×30cm程度）。乾燥後5分で変色・白化がないことを確認する。
4. スラットを閉じる。
5. 低圧噴霧器（0.1〜0.3MPa）を壁面から20〜30cm離し、上から下へ均一に噴霧する。
6. 放置時間：油汚れ3〜5分、重度ヤニ5〜7分（乾燥したら追い噴霧する）。
7. 固着汚れが残っている場合はクロスで約100〜150gの力でブラッシングする。
8. スラットを反転させる。
9. 裏面も同様に施工する。
10. 固く絞ったクロスで洗剤を拭き取る（2〜3回繰り返す）。
11. 乾拭きして水分を除去する。
12. 吸水シートで窓台・床の水分を回収する。

### 使用工具

TOOL-004（低圧噴霧器）/ TOOL-002（マイクロファイバークロス）/ TOOL-003（乾拭きクロス）/ TOOL-013（吸水シート）/ TOOL-011（養生シート）

### ⚠ 失敗しやすいポイント

- **高圧で噴霧する** → スラットの変形・塗装剥離の原因。低圧（0.1〜0.3MPa）のみ使用。
- **テスト施工を省略する** → 素材によっては変色・白化が起きる。全現場で必ず実施。
- **ヘッドボックス内部に噴霧する** → 内部の機構がサビる・動作不良の原因。スラットのみに噴霧する。
- **放置中に乾燥させる** → 洗剤が乾くと白いムラになる。乾燥したら追い噴霧する。
- **木製・竹製に実施する** → 反り・染み・膨張が発生する。実施禁止。

### 【プロのコツ】

- 噴霧量は「泡が薄く全面を覆う程度」が適切。液垂れするほど噴霧すると汚水が床へ流れ落ちる。
- 日当たりの良い南面は乾燥が早い。1〜2枚ずつ区切って施工すると乾燥を防げる。
- 2名作業の場合：1人が噴霧、もう1人が拭き取りを追いかけるように分担すると効率が良い。

### 次工程へ進む判断

✅ 油汚れ・ヤニが除去されている

✅ 洗剤残りなし・拭きムラなし

✅ 周辺への飛散なし（養生確認）

✅ スラットの変形なし

→ 工程7へ進む

## 工程5　耐水ブラインドの取り外し・丸洗い

**目安時間：約30〜60分/台（乾燥時間は別途1〜2時間）　必要人数：小型1名・標準以上2名**

### 何を行うか

メーカーが水洗い可能としている耐水ブラインドを取り外し、浴室等の洗浄可能な場所で丸洗いする。**取扱説明書で「丸洗い可」を確認してから実施する。確認できない場合は実施しない。**

### 施工順序

**① 取り外し前の確認・記録**

1. 取扱説明書で丸洗い可能であることを確認する。
2. 作業前の取付状態を写真撮影する（再取付け時の参照）。

**② 取り外し**

3. ブラインドを上げた状態で昇降コードを固定する。
4. 取付金具から本体を取り外す（機種により外し方が異なる。説明書を参照）。
5. **2名でスラットが曲がらないよう水平に支えながら**搬送する。

**③ 丸洗い**

6. 洗浄場所へ水平に置く。スラットを広げる。
7. バケツに水を入れ、CHEM-001（中性洗剤）を50〜100倍に希釈する。
8. スポンジに薬剤液を含ませ、スラットの長手方向に沿って**約100〜150gの力**で撫でるように洗浄する。
9. 裏面も同様に洗浄する。
10. **弱い水圧（シャワー30cm以上離す）**でしっかりすすぐ（すすぎ水が透明になるまで）。
11. 乾いたクロスで水分を除去する。
12. 風通しの良い日陰で水平に乾燥させる（直射日光禁止・高温乾燥禁止）。
13. **完全乾燥後**（2〜3時間以上）に元の位置へ取り付ける。
14. 昇降・角度調整の動作確認をする。

### 使用工具

TOOL-002（マイクロファイバークロス）/ TOOL-003（乾拭きクロス）/ TOOL-014（カメラ）

### ⚠ 失敗しやすいポイント

- **水洗い不可の製品を丸洗いする** → スラット変形・機構部のサビが発生する。必ず説明書を確認する。
- **強い水圧ですすぐ** → スラットが変形する。シャワーを30cm以上離し、弱い水圧でゆっくりすすぐ。
- **湿った状態で取り付ける** → ヘッドボックスの機構部がサビる。完全乾燥後（触って水気が全くない状態）に取り付ける。
- **メラミンスポンジで擦る** → 塗装が剥がれる。柔らかいスポンジのみ使用。
- **直射日光で急速乾燥する** → スラットが反る・変色する。日陰・常温で乾燥させる。

### 【プロのコツ】

- 洗浄場所が浴室の場合、スラットを浴槽に水を張って浸け置き（3〜5分）してから洗うと汚れが浮かせやすい。
- 取り外し前に「このスラットは○番目」と番号順に記録しておくと再取付け時に向きを間違えない。

### 次工程へ進む判断

✅ 両面の汚れなし・洗剤残りなし

✅ 完全乾燥している（触って水気がない）

✅ 取付状態正常・昇降動作正常・角度調整正常

→ 工程7へ進む

## 工程6　木製・竹製ブラインドの乾式清掃

**目安時間：約10〜20分/台　必要人数：1名（大型は2名推奨）**

### 何を行うか

木製・竹製スラットは水分を吸収すると染み・反り・膨張・変形が発生する。**原則として乾式清掃のみ。水拭き・噴霧洗浄・丸洗いは絶対に行わない。**

### 施工順序

1. スラットを閉じる。
2. 上部から下部へハンディモップで除塵する（スラットの木目方向に沿って）。
3. スラットを反転させて裏面も同様に除塵する。
4. 乾いた柔らかいクロスで木目に沿って軽く拭く（約100〜150gの力）。
5. 操作棒・昇降コードを乾拭きする。
6. ボトムレールを乾拭きする。
7. 乾拭き後も白い粉状の汚れや色あせが残っている場合は、メーカー指定の木部用クリーナー・ワックスを使用する。

### 使用工具

TOOL-001（ハンディモップ）/ TOOL-003（乾拭きクロス）/ TOOL-005（柔らかいブラシ）

### 禁止事項（絶対厳守）

- **水拭き禁止**（染み・反り・膨張の原因）
- **中性洗剤・弱アルカリ洗剤の使用禁止**（水分が木材を傷める）
- **重曹・クエン酸禁止**（アルカリ・酸が木材を侵す）
- **噴霧洗浄禁止**
- **丸洗い禁止**
- **高温・高湿度環境での施工禁止**

### ⚠ 失敗しやすいポイント

- **「少し湿らせたクロスなら大丈夫」と思う** → 木材は微量の水分でも時間をかけて吸収し、乾燥後に変色・反りが発生する。乾拭きのみ。
- **横方向にクロスを動かす** → 木目に対して垂直方向は傷が入りやすい。必ず木目方向（長手方向）に動かす。

### 【プロのコツ】

- 木製ブラインドは乾式清掃のみなので、ホコリを溜めないことが重要。週1回の頻度で日常除塵を行うとケア負担が大幅に減る。
- メーカー指定ワックスを使用する場合は、クロスに少量（1〜2滴）含ませてから施工する。直接塗布すると液だまりができる。

### 次工程へ進む判断

✅ ホコリなし

✅ 水染みなし・反り・変形なし

✅ 表面損傷なし

✅ 動作正常

→ 工程7へ進む

---

## 工程7　操作棒・昇降コード・ボトムレール清掃（全素材共通）

**目安時間：約3〜7分/台　必要人数：1名**

### 何を行うか

手垢・皮脂・ヤニ・ホコリが付着しやすい操作部分と下部部材を清掃する。

### 薬剤を選ぶ理由

| 対象部位 | 薬剤 | 選ぶ理由 |
|---|---|---|
| 操作棒・ボトムレール | CHEM-001（中性洗剤）50〜100倍 | 手が触れる部位。素材ダメージなく皮脂・手垢を除去 |
| 昇降コード（汚れあり） | CHEM-001（中性洗剤）100倍 | コードは繊維製が多い。中性洗剤のみ使用 |

### 施工順序

1. クロスに中性洗剤液（50〜100倍希釈）を含ませる（絞って余分な水分を除く）。
2. 操作棒を上から下へ全面拭く（力：約200〜300g）。
3. 水拭きをする。
4. 乾拭きする。
5. 昇降コードを固く絞ったクロスで軽く挟み拭きする（コードを支えながら、約100〜150gの力）。
6. ボトムレールの上面・側面・裏面を順番に清掃する。
7. 細部（操作棒の根元・コードの結び目など）を綿棒で清掃する。
8. 操作棒とコードの動作を確認する。

### 使用工具

TOOL-002（マイクロファイバークロス）/ TOOL-003（乾拭きクロス）/ TOOL-012（綿棒）

### ⚠ 失敗しやすいポイント

- **コードを強く引っ張る** → 内部機構や接続部を傷める。片手でコードを支えながら、もう一方の手でクロスを持って軽く挟み拭きする。
- **コードを勝手に分解する** → 再取付けができない場合があり、昇降不良になる。分解せずに外側のみ清掃する。
- **操作棒を無理に回す** → 回転限界以上に回すと内部のギアが破損する。スラットが水平になったら止める。

### 【プロのコツ】

- コードは「上から下へ滑らせる」ように拭くと均一に清掃できる。横方向に拭くとねじれてしまう。
- ボトムレールの裏面は見落としやすい。仕上がり確認のときに裏返して確認する習慣をつける。

### 次工程へ進む判断

✅ 操作棒：手垢・皮脂汚れなし・ヤニなし・洗剤残りなし

✅ 昇降コード：汚れなし・損傷なし

✅ ボトムレール：上面・側面・裏面ホコリなし

✅ 操作棒・昇降コードの動作が正常

→ 工程8へ進む

# 11. よくある失敗と対策

| 失敗 | 原因 | 対処法 | 防止策 |
|---|---|---|---|
| スラットが曲がる | 強く挟む・横方向に力をかけた | 軽く起こす（完全に戻らない場合は報告） | 約100〜150gの力で長手方向にのみ動かす |
| ホコリが泥状になる | 乾式除塵前に水拭きした | 乾いたクロスで除去後に洗剤施工 | 必ず乾式除塵を先に行う |
| 洗剤跡・白いムラが残る | 水拭きが不十分 | 清水クロスで2〜3回水拭き | 水拭き後に乾拭き必須。洗剤を乾燥させない |
| 塗装が剥がれる | 強薬剤・研磨材・高圧噴霧 | 現時点では戻らない。記録・報告 | 中性洗剤と柔らかいクロスを使用。高圧禁止 |
| ヘッドボックスが錆びる | 機構部へ水・洗剤が入った | 乾燥させる。改善しない場合は報告 | 外装のみ拭き。内部へ液体を入れない |
| 木製ブラインドが反る | 水拭き・噴霧洗浄をした | 乾燥させる（完全には戻らない場合あり）。報告 | 木製・竹製は乾式清掃のみ |
| 昇降不良になる | コードを強く引いた・分解した | コードの状態を確認。解消しない場合は報告 | コードは支えながら軽く拭く。分解禁止 |
| ヤニ臭が残る | 表面のみ清掃・裏面未施工 | 裏面・操作部・ボトムレールまで再施工 | 表裏両面・全部位の施工を徹底 |
| 周辺床・OA機器が汚れる | 養生不足 | 拭き取り。電気機器は電源を切って確認 | 施工前に完全養生。吸水シートを敷く |
| 動作不良（清掃後） | 動作確認を省略した | 動作確認して問題箇所を特定 | 施工前後に必ず動作確認 |

# 12. 安全管理

## 切創防止（アルミスラット特有）

- 金属スラットの端部は鋭利なため、ゴム手袋＋軍手を着用する
- 素手でスラットを挟まない
- スラットの端部へ指を滑らせる方向で動かさない（中央から端へ動かす）

## 転落・転倒防止

- 脚立は水平な床に設置する。天板に乗らない
- 脚立上でスラットを引っ張らない（重心が崩れる）
- 床の養生シートはテープで固定する（めくれて転倒する）
- 通路に道具を放置しない

## 感電防止

- コンセント・OA機器を養生してから湿式清掃を開始する
- 電気設備へ直接噴霧しない
- 濡れた手で電源に触れない

## 薬剤管理

- 薬剤ラベルの注意事項を確認してから使用する
- 推奨希釈倍率を厳守する（計量カップで計量する）
- 薬剤を混合しない（酸性とアルカリ性を混ぜると有害ガス発生）
- 容器に名称・希釈率を記載する

## カビ・粉塵対策

- カビがある場合はマスク・保護メガネを着用する
- 乾いたカビを強く払わない（胞子が飛散して感染リスク）
- 施工中は換気する
- カビ除去に使ったクロスは他箇所へ転用しない

## 緊急時対応

| 事故 | 対応 |
|---|---|
| 薬剤が目に入った | 作業停止。その場で15分以上流水で洗眼。医療機関を受診 |
| スラットで切創した | 作業停止。流水で洗浄。止血・応急処置。責任者へ報告 |
| 脚立から転落した | 動かさない。119番通報。責任者へ報告 |
| ブラインドが脱落した | 周辺を立入禁止にする。本体に触れない。責任者へ報告。専門業者による再取付け |

# 15. 新人教育ポイント

## 最初に覚えること（優先順）

| 優先度 | 覚えること | なぜ重要か |
|---|---|---|
| 1 | 素材を必ず確認してから施工方法を決める | 木製に水拭きをすると反りが発生する |
| 2 | 乾式除塵を先に行う | ホコリを残したまま濡らすと泥状になる |
| 3 | スラットは長手方向にのみ動かす | 横方向の力は曲がり・折れの原因 |
| 4 | 洗剤を直接大量噴霧しない | ヘッドボックス内部に洗剤が入るとサビる |
| 5 | 水拭き後は必ず乾拭きする | 乾燥すると洗剤跡・白いムラになる |
| 6 | 動作確認を施工前後に必ず行う | 施工後に動かなくなった場合の原因特定のため |

## 新人が間違えやすいポイントと正しい対応

| 間違い | 正しい対応 | なぜそうするか |
|---|---|---|
| スラットを強く挟む | 約100〜150gの力（ペットボトル軽く持つ程度）にする | アルミは200g以上の力で折れ曲がる |
| 裏面の清掃を省略する | スラットを必ず反転させて両面施工する | 裏面にホコリ・カビが残ると臭気の原因 |
| 木製ブラインドを水拭きする | 乾拭きのみ実施する | 水分で反り・染みが発生する |
| ヘッドボックスに噴霧する | 外装のみ乾拭き。内部への液体浸入禁止 | 内部の機構がサビる・動作不良になる |
| 操作棒を限界以上に回す | スラットが水平になったら止める | 内部ギア・コネクターの破損 |
| コードを勝手に分解する | 外側のみ拭く。分解禁止 | 再取付けができず昇降不良になる |
| テスト施工を省略する | 全現場で目立たない場所にテスト施工 | 素材によっては変色・白化が起きる |

## 独立施工を許可する基準（自己確認）

以下を全て自己確認できること：

- ブラインドの素材（アルミ・樹脂・木製・耐水・布製）を見分けられる
- 素材に合った清掃方法（乾式のみか湿式可か）を判断できる
- スラットを折らずに施工できる（約100〜150gの力加減）
- 洗剤の希釈倍率を正確に管理できる
- 施工前後の動作確認ができる

## 早めの施工を推奨するケース

- スラットに目視できる油膜・ヤニが付着している
- カビが発生している（放置すると素材が腐食する）
- 光透過量が著しく低下している（採光性の悪化）
