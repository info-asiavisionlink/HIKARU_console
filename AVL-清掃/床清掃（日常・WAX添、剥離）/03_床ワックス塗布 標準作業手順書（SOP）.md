| 対象施設 | オフィス・商業施設・ホテル・病院・学校・工場・公共施設・マンション共用部・食品施設 |
| 対象床材 | 長尺シート・Pタイル・コンポジションタイル・フローリング（メーカー確認必須） |
| 対象外床材 | 磁器タイル（原則不要）・天然石・テラゾー（専用品・メーカー確認必須） |
| 作業人数 | 1〜3名（現場規模による） |
| 作業時間 | 2時間〜6時間（面積・層数・乾燥時間による） |
| 推奨施工時間帯 | 営業時間外・夜間・早朝（利用者不在時を強く推奨） |
| 作業頻度 | 月1回〜年2回（現場仕様・ワックス摩耗状態による） |

## 施工可能条件

| 条件 | 基準 |
|---|---|
| 室温 | 10℃〜35℃（5℃以下はワックス成膜不可・高温では乾燥不良） |
| 湿度 | 80%以下（高湿度はワックスが白化・乾燥不良の原因） |
| 床面 | 洗浄後完全乾燥済みであること（目視で水分がなく、手で触れて湿気を感じない状態） |
| 利用者の有無 | 完全不在・乾燥まで立入禁止確保できること |
| 換気 | ワックス臭気のため適切な換気があること |
| 電源 | ワックス乾燥促進用送風機の電源が確保できること（推奨） |

## 施工不可条件

| 条件 | 対応 |
|---|---|
| 床が完全に乾燥していない | 乾燥確認後に施工（最低120分以上） |
| 室温5℃未満 | 施工禁止（成膜不可） |
| 天然石・テラゾー（専用品未確認） | メーカー確認後のみ施工 |
| 前回剥離から相当期間経過し層が厚すぎる | 先に剥離洗浄（04_床剥離洗浄）を実施 |

## 作業中止基準

| 発見内容 | 対応 |
|---|---|
| ワックス塗布後に白化・曇りが発生 | 施工中止・原因確認（湿度・温度・異物） |
| 利用者が乾燥前の床に入った | 足跡除去・その部分を再施工 |
| ワックスが目・皮膚に付着 | 流水で洗浄。異常があれば受診 |
| 施設担当者から中止指示 | 即時中止 |

## 薬剤選択フロー

床材とワックス摩耗状態を確認する
　↓

# 2. 作業目的

床ワックス塗布は、洗浄・乾燥済みの床面に樹脂ワックスの保護膜を形成し、以下を実現する。

- 床材の保護（摩耗・傷防止）
- 美観の向上・光沢の付与
- 汚れの付着防止（表面硬化による汚れ除去性向上）
- 滑り防止（ワックス成分による表面安定化）
- 床材寿命の延長
- 日常清掃効率の向上（ワックス表面は汚れが落ちやすい）
- 施設資産価値の維持
- 衛生管理対応（食品施設）
- クレーム防止

**理由：** ワックスを塗布しない床面は土砂・皮脂が直接床材に接触して摩耗が進む。ワックスの保護膜が床材を守り、日常清掃の効率を高めることで長期的なコスト削減につながる。「厚く塗る」のではなく「薄く均一に重ねる」ことが最も重要である。

# 5. 放置した場合のリスク

| リスク | 内容 |
|---|---|
| 床材摩耗の進行 | ワックス保護膜がないと土砂・皮脂が直接床材を削る |
| 光沢の消失 | 美観が損なわれ施設イメージが低下する |
| 汚れの床材への直接付着 | ワックスがないと汚れが床材に直接浸透し除去困難になる |
| 滑り事故リスク増大 | ワックス保護膜の摩耗で床面が不安定になる |
| 日常清掃コスト増大 | ワックスのない床面は汚れが落ちにくく清掃時間が増加する |
| 床材交換コスト増大 | ワックス管理不足による早期床材劣化 |
| クレーム発生 | 美観低下・光沢消失による利用者クレーム |

# 12. 詳細作業手順

---

## 工程1　現場確認・KY実施

### 作業内容

作業開始前に施工範囲・床材・前工程完了状態・乾燥状態・安全環境を確認し、KY（危険予知）を実施する。

### 理由

ワックス塗布は床面が完全に清潔・乾燥していることが絶対条件である。前工程（洗浄）の完了確認なしに施工すると、汚れ・洗剤残留・水分がワックス内部に閉じ込められ、密着不良・白化・剥がれが必ず発生する。KYによりワックス特有の危険（乾燥前の歩行・蒸気・立入禁止管理）を全員で共有する。

### 使用工具

- チェックリスト
- 図面（あれば）

### 使用薬剤

なし

### 作業方法

1. 作業範囲を目視で確認する
2. 床材の種類を確認し、ワックス適合を確認する
3. 前工程（洗浄：AVL-SOP-FLOOR-02）が完了しているか担当者に確認する
4. 床面の汚れ・水分・洗剤残留がないことを目視・手触りで確認する
5. 床材の破損・浮き・剥がれを確認する
6. 現在のワックス状態（ワックスの残量・劣化状況）を確認する
7. 電源位置・給水位置・避難経路を確認する
8. 施工温度・湿度がメーカー指定範囲内であることを確認する
9. KYを実施し、本日の危険ポイントを全員で共有する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 前工程未完了での施工（ワックス密着不良） | 前工程完了を担当者・チェックリストで確認する |
| 乾燥不足の床面へのワックス施工（白化） | 目視・手触りで完全乾燥を確認する |
| ワックス非対応床材への施工（損傷） | 床材種類・メーカー適合を確認する |
| 乾燥中の歩行による転倒・品質不良 | KYで「乾燥中立入禁止」を全員に徹底する |

### 品質基準

- 床材が正確に識別されワックス適合が確認されている
- 前工程完了が担当者・記録で確認されている
- 床面の完全乾燥が確認されている
- KYが完了し危険ポイントが全員で共有されている

| 乾燥不足での施工 | 中 | 高 | 目視・手触りによる乾燥確認 |

### 作業時間目安

10〜20分

### 必要人数

1名

### NG例

- 前工程完了確認をせずにワックスを塗布する
- 乾燥確認をせずに施工を開始する
- ワックス非対応床材（天然石・テラゾー）に一般ワックスを施工する

### OK例

- 前工程担当者に確認し、洗浄完了・乾燥完了を書面で確認する
- 床材を目視・触感・担当者確認で識別してからワックスを選定する
- KYで「乾燥中の立入禁止管理」を全員で確認する

### よくある失敗

- 洗浄後の乾燥時間が不十分なまま施工してワックスが白化した
- 前工程担当者への確認をせずに施工してワックスが剥離した

### 改善方法

- 前工程完了確認をチェックリストの必須項目とし、記録なしでは施工できないルールを設ける

### 写真撮影位置

- 床材の現状・ワックス状態の近景（比較用）

### クレーム防止

- 前工程未完了・乾燥不足でのワックス施工は密着不良・白化クレームの直接原因。必ず確認する
- 既存破損（割れ・欠け・浮き）を施工前に写真記録し「施工前からの状態」を証明する

## 工程2　安全確保・表示設置・養生

### 作業内容

ワックス乾燥中の立入禁止管理・利用者転倒防止・周辺設備保護のための安全確保を実施する。

### 理由

ワックス塗布後の乾燥中は床面が滑りやすく、また乾燥前のワックスは足跡・汚れが混入すると品質が著しく損なわれる。表示設置と立入禁止管理はワックス施工において品質管理と安全管理の両方を兼ねる最重要事項である。養生不足でワックスが巾木・壁・設備に付着すると除去が困難になる。

| TOOL-006 | カラーコーン（最低4個） | 作業区画・立入禁止区域設定 |
| TOOL-007 | 「清掃中」「乾燥中・立入禁止」表示板 | 利用者への注意喚起 |
| TOOL-011 | 養生テープ | 巾木・設備・壁際の養生 |
| TOOL-012 | 養生シート | 大面積養生（必要時） |

### 使用薬剤

なし

1. 作業エリアの全入口にカラーコーン（TOOL-006）を設置する

3. 巾木・壁際・コンセント・スイッチ・金属部品・ドア枠を養生テープで養生する

### 写真撮影位置

## 工程3　最終除塵（ワックス施工前）

### 作業内容

ワックス塗布直前に、床面の微細なホコリ・ゴミ・砂を乾式で完全除去する。

### 理由

ワックスは液体であるため、塗布時に床面のホコリ・ゴミ・毛髪を巻き込む。ホコリ混入は仕上がり品質を著しく低下させ、光沢のムラ・突起物の発生・外観不良の直接原因となる。前工程（洗浄）後に時間が経過している場合は空気中のホコリが再付着するため、ワックス施工直前の最終除塵は必須工程である。

### 使用工具

| 管理番号 | 工具 | 用途 |
|---|---|---|
| TOOL-003 | ドライモップ（ダスター） | 主要面の除塵 |
| TOOL-004 | マイクロファイバーモップ | 精密除塵・壁際仕上げ |
| TOOL-014 | ハンドブラシ（コーナー用） | 壁際・隅・角部の除塵 |
| TOOL-015 | ゴミ袋 | 回収ゴミの廃棄 |

### 使用薬剤

なし（乾式除塵）

### 作業方法

1. 奥から出口方向へ、一方向にドライモップ（TOOL-003）を施工する
2. ドライモップは床面に密着させ、浮かせずに一定方向へ動かす
3. 往復掛けは行わず、一方向施工を徹底する
4. 壁際・隅・角部はハンドブラシ（TOOL-014）で除塵する
5. 集めたゴミを回収してゴミ袋（TOOL-015）に入れる
6. 除塵後に目視・照明光を使用してホコリが残っていないことを確認する
7. 確認後は人の立入を禁止し、除塵直後にワックス塗布を開始する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 除塵後にホコリが再付着する | 除塵後は速やかにワックス塗布を開始する |
| 往復除塵によるホコリの舞い上がり | 一方向施工を徹底する |
| 除塵後に人が入室してホコリを持ち込む | 除塵後は立入禁止とする |
| 腰痛（前屈姿勢） | モップ柄の長さを身長に合わせる |

### 品質基準

- 床全面・壁際・隅部のホコリ・ゴミ・毛髪が除去されている
- 照明光を使用して目視でホコリが確認できない状態である
- ワックス塗布開始まで人の立入が禁止されている

### 床材別注意

| 床材 | 注意事項 |
|---|---|
| 長尺シート | 継ぎ目部分・端部のホコリを重点除塵する |
| Pタイル | 目地に溜まったホコリをハンドブラシで除塵する |
| フローリング | 木目・板継ぎ目のホコリを柔らかいモップで除塵する |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 商業施設 | 棚下・什器周辺のホコリを重点除塵する |
| 病院 | 医療廃棄物・危険物の混入がないか確認しながら除塵する |
| 食品施設 | 毛髪・異物の完全除去は衛生管理上必須 |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 除塵完了確認・チェックリスト記録 |
| ISO 14001 | 回収ゴミの適切な分別廃棄 |

### 食品施設への対応

- 食品エリアの毛髪・異物・ゴミを完全除去する
- 除塵完了を衛生管理記録に記載する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| ホコリ混入によるワックス品質不良 | 高（省略時） | 高 | ワックス施工直前の最終除塵を必須とする |
| 除塵後の再ホコリ付着 | 中 | 高 | 除塵後速やかに施工開始・立入禁止徹底 |

### 作業時間目安

10〜20分（面積による）

### 必要人数

1名

### NG例

- 除塵を省略してワックスを塗布する
- ドライモップを往復で動かす
- 除塵後に時間をおいてからワックスを塗布する（ホコリが再付着する）

### OK例

- 奥から出口方向へ一方向施工する
- 壁際・隅部はハンドブラシで丁寧に除塵する
- 除塵後すぐにワックス塗布を開始する

### よくある失敗

- 除塵後に施設担当者との打ち合わせに時間がかかり、ホコリが再付着してワックスに混入した
- 壁際の除塵を省略してワックス塗布後に壁際だけホコリ混入が目立った

### 改善方法

- 除塵後の施設担当者との打ち合わせは除塵前に済ませ、除塵後すぐに施工できる体制を整える

### 写真撮影位置

- 除塵前の床状態（ホコリが目立つ箇所・近景）
- 除塵完了後の床状態（照明光で確認できる状態）

### クレーム防止

- ホコリ混入によるワックスの品質不良クレームを防ぐ。最終除塵を必ず実施する
- 毛髪・ゴミがワックスに混入した場合の美観クレームを防ぐ

## 工程4　床面洗浄完了・完全乾燥確認

### 作業内容

ワックス塗布前の最終確認として、床面の洗浄完了・汚れ残留なし・完全乾燥を確認する。

### 理由

ワックスは床面の状態を「そのまま封じ込める」性質がある。汚れ・水分・洗剤が残った状態でワックスを塗布すると、それらが保護膜の中に閉じ込められ、ワックスの白化・密着不良・剥離・変色が発生する。この確認工程は品質を左右する最重要チェックポイントである。

### 使用工具

| 管理番号 | 工具 | 用途 |
|---|---|---|
| TOOL-005 | マイクロファイバークロス | 確認・局所拭き取り |

### 使用薬剤

なし

### 作業方法

1. 床全面を目視で確認する（汚れ・黒ずみ・水分・洗剤残留の有無）
2. 手触りで確認する（ベタつき・水分・ザラつきの有無）
3. 窓際・照明下・入口付近を重点確認する（光の角度で汚れが見えやすい）
4. 壁際・隅部の乾燥状態を確認する
5. 疑わしい箇所はマイクロファイバークロス（TOOL-005）で拭き取り確認する
6. 異常がある場合は施工を中止し、前工程担当者に連絡する
7. 全て問題なければワックス準備に進む

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 乾燥不足の床面へのワックス施工（白化） | 手触りで水分がないことを確認する |
| 洗剤残留のある床面へのワックス施工（密着不良） | 手触りでベタつきがないことを確認する |
| 汚れ残留の封じ込め | 目視・照明光で汚れがないことを確認する |

### 品質基準

- 床全面に汚れ・黒ずみが残っていない
- 水分・水滴が残っていない
- 洗剤残留・ベタつきがない
- 壁際・隅部も乾燥が確認できている

### 床材別注意

| 床材 | 確認ポイント |
|---|---|
| 長尺シート | 継ぎ目の水分残留に特に注意する |
| Pタイル | 目地の水分・洗剤残留を確認する |
| フローリング | 木目・継ぎ目の水分残留を特に確認する。膨張の兆候がないか確認する |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 広面積施設 | 全エリアを確認する。一部の見落としがワックス品質全体に影響する |
| 食品施設 | 洗剤残留の確認を衛生管理記録に記載する |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 前工程完了確認・乾燥確認の記録 |

### 食品施設への対応

- 洗剤残留ゼロを確認してから衛生管理適合ワックス（CHEM-007）を塗布する
- 確認結果を衛生管理記録に記載する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 乾燥不足での施工によるワックス白化 | 中（確認省略時） | 高 | 手触り・目視で完全乾燥を確認 |
| 汚れ封じ込めによる品質不良 | 中（確認省略時） | 高 | 照明下での目視確認を徹底 |

### 作業時間目安

5〜15分（面積による）

### 必要人数

1名

### NG例

- 前工程担当者確認なしに自己判断でワックスを塗布する
- 壁際・隅部の確認を省略する
- 「たぶん乾いた」という推測で施工を開始する

### OK例

- 目視・手触りで全面を確認してから施工を開始する
- 疑わしい箇所はクロスで拭き取り確認する
- 水分・ベタつきが残っている場合は乾燥完了まで待機する

### よくある失敗

- 乾燥したと思って施工したら一部に水分が残っており、その箇所だけワックスが白化した
- 洗剤残留に気づかずワックスを塗布して密着不良が発生した

### 改善方法

- 「目視で乾燥しているように見える」ではなく「手触りで水分がないことを確認する」を標準手順とする

### 写真撮影位置

- 乾燥確認後の床状態（均一な乾燥状態が確認できる状態）

### クレーム防止

- 乾燥不足・洗剤残留は後から修正できないワックス白化・密着不良の原因。確認を省略しない

## 工程5　ワックス準備・テスト施工

### 作業内容

施設・床材に適したワックスをワックスバケットに準備し、目立たない箇所でテスト施工を実施する。

### 理由

ワックスは種類によって乾燥速度・光沢・密着性が異なる。テスト施工で仕上がり・乾燥時間・密着状態を事前確認することで、全面施工後の品質不良を防ぐ。また異なるメーカーのワックスの混合は化学的に不適合になる場合があるため、バケットの清潔さとワックスの純度管理が重要である。

### 使用工具

| 管理番号 | 工具 | 用途 |
|---|---|---|
| TOOL-001 | ワックスモップ（専用） | テスト塗布 |
| TOOL-002 | ワックスバケット（専用） | ワックス供給 |

### 使用薬剤

| 管理番号 | 薬剤 | 希釈率 |
|---|---|---|
| CHEM-001〜007 | 施設・床材に適合したワックス | 原液（希釈禁止） |

### 作業方法

1. 薬剤ラベルを確認してから施設・床材に適合したワックス（CHEM管理番号）を選定する
2. ワックスバケット（TOOL-002）が清潔・乾燥していることを確認する
3. 必要量のワックスをバケットに移す（異物混入防止）
4. 使用するワックスの種類・管理番号・数量を報告書に記録する
5. 目立たない箇所（入口から見えない隅など）で30cm四方のテスト施工を実施する
6. テスト後にメーカー指定の乾燥時間を確認する
7. 乾燥後に変色・白化・密着不良・光沢不均一がないことを確認する
8. 問題がある場合は施工を中止し、別のワックスでテストするか担当者に連絡する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 異なるメーカーのワックスの混合による不適合 | バケットの清潔確認・前回使用ワックスの確認 |
| テスト省略による全面施工後の品質不良 | テスト施工を必須工程として実施する |
| ワックスの皮膚・眼への付着 | 手袋・保護メガネを着用する |

### 品質基準

- 選定したワックスが施設・床材に適合している
- バケットが清潔・乾燥している
- テスト施工で変色・白化・密着不良がない
- 乾燥後の光沢が均一である

## 工程6　ワックス塗布（1層目）

### 作業内容

テスト施工で適合を確認したワックスをワックスモップで床面全体に均一・薄く塗布する。

### 理由

ワックス塗布の基本原則は「薄く均一に重ねる」である。厚塗りは乾燥不良・白化・気泡・ひび割れの原因になる。1層目は下地密着層として最も重要であり、塗布ムラ・液だまりを作らないことが全体品質の基礎となる。施工方向は奥から出口方向に固定し、自分が塗布済み面を踏まないよう退路を確保しながら進める。

### 使用工具

| 管理番号 | 工具 | 用途 |
|---|---|---|
| TOOL-001 | ワックスモップ（専用） | ワックス塗布 |
| TOOL-002 | ワックスバケット（専用） | ワックス供給 |

### 使用薬剤

| 管理番号 | 薬剤 | 希釈率 | 塗布量 |
|---|---|---|---|
| 選定済みワックス（CHEM-001〜007） | 1層目塗布 | 原液（希釈禁止） | メーカー指定 |

### 作業方法

1. ワックスモップ（TOOL-001）をワックスバケット（TOOL-002）に浸し、モップの端で軽く絞って余分なワックスを除く（滴らない程度）
2. 奥（出口から最も遠い場所）から出口方向へ施工を開始する
3. モップは一定方向に動かし、「コの字」または直線方向で施工する
4. 重ね幅を約5〜10cmとり、塗り残しを防止する
5. ワックスは薄く均一に塗布する（厚塗り禁止）
6. 液だまり・気泡・モップ跡ができないよう一定速度で塗布する
7. 壁際・柱周辺は特に液だまりができやすいため塗布量に注意する
8. 塗布済みのワックス面を絶対に踏まない（退路を確保しながら施工する）
9. 施工中に立ち止まらない（液だまりの原因になる）

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 塗布済みのワックス面を踏んで転倒 | 奥から出口方向へ施工し退路を確保する |
| ワックスの眼・皮膚への付着 | 手袋・保護メガネを着用する |
| 換気不足によるワックス蒸気の蓄積 | 換気を確保しながら施工する |
| 液だまりによる乾燥不良・剥離 | 均一な薄塗りを徹底する |
| モップのワックス過剰含浸 | バケットで適切に絞ってから塗布する |

### 品質基準

- 床全面・壁際まで均一に塗布されている
- 液だまり・気泡・モップ跡がない
- 厚塗り箇所がない
- 塗りムラがない
- 塗布済みの面に歩行跡・ゴミ混入がない

### 床材別注意

| 床材 | 注意事項 |
|---|---|
| 長尺シート | 継ぎ目部分への液だまりに注意。継ぎ目を超えるように塗布する |
| Pタイル | 目地への液だまりに注意。目地に沿って均一に塗布する |
| フローリング | 木目に沿って塗布する。木目を横切る方向への施工禁止 |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 広面積施設 | ワックスバケットの残量を管理して途中補充する |
| ホテルロビー | 光沢が求められるため特に均一な塗布を徹底する |
| 病院 | 帯電防止ワックス（CHEM-003）使用時は層数をメーカー指定に従う |
| 食品施設 | 衛生管理適合ワックス（CHEM-007）のみ使用する |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 塗布均一性確認・施工記録（層数・使用ワックス管理番号） |
| ISO 14001 | ワックス使用量の管理・廃棄物の適切処理 |
| ISO 45001 | 塗布済み面の転倒防止・換気確保 |

### 食品施設への対応

- 衛生管理適合ワックス（CHEM-007）のみ使用する
- ワックス塗布中に食品エリアへの汚染が発生しないよう区画管理する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 塗布済み面の転倒 | 中 | 高 | 奥から出口方向への施工・退路確保 |
| 厚塗りによる乾燥不良 | 中 | 高 | 薄塗りの徹底・塗布量の管理 |
| ゴミ・ホコリの混入 | 中 | 中 | 除塵直後の施工・立入禁止徹底 |

### 作業時間目安

20〜60分（面積による）

### 必要人数

1〜2名

### NG例

- ワックスを厚く塗れば効果が上がると思い厚塗りする
- 施工中に立ち止まって液だまりを作る
- 塗布済みのワックス面を踏んで歩行跡を残す
- モップを往復で動かしてモップ跡を作る

### OK例

- モップをバケットで適切に絞り、薄く均一に塗布する
- 奥から出口方向へ一定速度で施工し退路を確保する
- 重ね幅5〜10cmを守りながら一定方向に施工する
- 壁際の液だまりを確認しながら施工する

### よくある失敗

- ワックスを厚く塗りすぎて液だまりが発生し、乾燥後に白濁した
- 施工途中で立ち止まってモップ圧力のムラが生じた
- 施工方向を間違えて塗布済み面を踏み、歩行跡が残った

### 改善方法

- 施工前に「奥から出口方向」「薄く均一」「立ち止まらない」の3原則を全員で確認する

### 写真撮影位置

- 1層目塗布中の施工状況（施工方向・塗布状態が分かる全景）
- 壁際・隅部の塗布状態（近景）

### クレーム防止

- 厚塗り・液だまりによる白化・剥離クレームを防ぐ。薄塗りを徹底する
- 歩行跡・ゴミ混入クレームを防ぐ。塗布済み面の踏込禁止・立入禁止を徹底する

## 工程7　乾燥確認（1層目）

### 作業内容

1層目のワックス塗布後、メーカー指定の乾燥時間を確保し、完全乾燥を確認してから2層目の施工に進む。

### 理由

1層目が完全に乾燥していない状態で2層目を塗布すると、2層が混ざって白化・剥離・密着不良が発生する。「表面が乾いた」状態と「完全乾燥」は異なる。メーカー指定の乾燥時間を遵守し、手触りで確認することが品質の根幹となる。乾燥中は立入禁止を維持する。

### 使用工具

| 管理番号 | 工具 | 用途 |
|---|---|---|
| TOOL-008 | 送風機 | 乾燥促進 |
| TOOL-009 | ブロワー | 乾燥促進 |
| TOOL-010 | サーキュレーター | 空気循環 |
| TOOL-007 | 「乾燥中・立入禁止」表示板 | 乾燥中の立入防止 |

### 使用薬剤

なし

### 作業方法

1. 1層目塗布完了後すぐに「乾燥中・立入禁止」表示板（TOOL-007）を設置する
2. 送風機（TOOL-008）・サーキュレーター（TOOL-010）を使用して乾燥を促進する
3. メーカー指定の乾燥時間が経過するまで待機する
4. 乾燥確認は端部の目立たない箇所を約100〜200gの力で指で触れて確認する（中央部は避ける）
5. 表面乾燥のみでなく内部乾燥まで確認する（ベタつきがないこと）
6. 完全乾燥が確認できたら2層目の施工に進む

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 乾燥中の利用者侵入・転倒 | 「乾燥中・立入禁止」表示板を維持する |
| 乾燥不足での2層目施工 | メーカー指定乾燥時間を守る |
| 確認時に指で中央部を触れて跡を残す | 端部の目立たない箇所で確認する |

### 品質基準

- メーカー指定の乾燥時間が経過している
- 手触りでベタつき・湿潤感がない
- 光沢が均一に出ている
- 気泡・白化・ムラがない
- 歩行跡・ゴミ混入がない

### 床材別注意

| 床材 | 注意事項 |
|---|---|
| フローリング | 木材の調湿作用で乾燥時間が長くなる場合がある。メーカー指定に従う |
| 長尺シート・Pタイル | 標準乾燥時間はメーカー指定に従う |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 換気が悪い施設 | 送風機・換気扇を使用して乾燥を促進する |
| 高湿度環境 | 乾燥時間が延長する場合がある。メーカー確認 |
| 低温環境 | 乾燥時間が大幅に延長する。メーカー指定温度条件を確認する |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 乾燥時間・完了確認の記録 |
| ISO 45001 | 乾燥中の安全区画維持・転倒防止 |

### 食品施設への対応

- ワックス乾燥中に発生する蒸気が食品エリアに流入しないよう換気・区画管理する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 乾燥不足での2層目施工 | 中（時間短縮時） | 高 | メーカー指定時間を厳守する |
| 乾燥中の転倒 | 中（表示なし時） | 高 | 表示板を維持する |

### 作業時間目安

メーカー指定乾燥時間（確認含む）

### 必要人数

1名（待機・管理）

### NG例

- 表面が乾いたように見えたらすぐに2層目を塗布する
- メーカー指定乾燥時間を短縮して施工する
- 乾燥確認を床中央で行い指跡を残す

### OK例

- メーカー指定の乾燥時間が経過してから乾燥確認を行う
- 端部の目立たない箇所で指触確認をする
- 完全乾燥が確認できてから2層目に進む

### よくある失敗

- 乾燥時間を短縮して2層目を施工し、1層目と混ざって白化した
- 乾燥中に利用者が侵入して歩行跡が残った

### 改善方法

- 乾燥開始時刻と完了予定時刻を記録し、時刻管理で乾燥時間を厳守する

### 写真撮影位置

- 1層目乾燥確認後の床状態（光沢・均一性が分かる状態）

### クレーム防止

- 乾燥不足での2層目施工による白化・剥離クレームを防ぐ。乾燥時間を厳守する
- 乾燥中の歩行跡クレームを防ぐ。立入禁止を徹底する

## 工程8　ワックス塗布（2層目）

### 作業内容

1層目が完全乾燥したことを確認してから、2層目のワックスを1層目と交差する方向（90°変えた方向）に塗布する。

### 理由

2層目を1層目と直交する方向（90°）に施工することで、1層目の塗布ムラを補完し、均一な光沢と厚みを得ることができる。2層塗布によりワックス保護膜の強度・耐久性・美観が大幅に向上する。1層目と同じ方向に塗布すると塗布ムラが蓄積するため、方向の転換が必須である。

### 使用工具

| 管理番号 | 工具 | 用途 |
|---|---|---|
| TOOL-001 | ワックスモップ（専用） | 2層目塗布 |
| TOOL-002 | ワックスバケット（専用） | ワックス供給 |

### 使用薬剤

| 管理番号 | 薬剤 | 希釈率 | 塗布量 |
|---|---|---|---|
| 選定済みワックス（CHEM-001〜007） | 2層目塗布 | 原液（希釈禁止） | メーカー指定 |

### 作業方法

1. 1層目の完全乾燥を確認してから2層目を開始する
2. 2層目の施工方向は1層目と90°転換する（例：1層目が縦方向なら2層目は横方向）
3. ワックスモップ（TOOL-001）にワックスを約80〜100ml含ませ、端で余分な液を除く（滴らない程度）
4. 奥から出口方向（2層目の施工方向で設定した方向）へ薄く均一に塗布する
5. 1層目と同様に液だまり・気泡・モップ跡を作らない
6. 塗布済み面を踏まない（退路確保）
7. 壁際・隅部まで均一に塗布する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 塗布済み面での転倒 | 施工方向を確認してから退路を確保して施工する |
| 1層目の完全乾燥確認不足 | 2層目開始前に必ず乾燥確認を行う |
| ワックスの液だまり | 均一な薄塗りを徹底する |

### 品質基準

- 2層目が1層目と90°異なる方向で施工されている
- 床全面・壁際まで均一に塗布されている
- 液だまり・気泡・モップ跡がない
- 歩行跡・ゴミ混入がない

### 床材別注意

| 床材 | 注意事項 |
|---|---|
| 長尺シート | 継ぎ目を超えて均一に塗布する |
| Pタイル | 目地への液だまりに注意する |
| フローリング | 木目方向と直交する方向が2層目の場合は特に薄塗りを徹底する |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 広面積施設 | 2層目の施工方向を施工前に確認・計画してから開始する |
| 食品施設 | 衛生管理適合ワックス（CHEM-007）のみ使用する |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 2層目施工方向・完了確認の記録 |
| ISO 45001 | 塗布済み面の転倒防止 |

### 食品施設への対応

- 衛生管理適合ワックス（CHEM-007）のみ使用する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 1層目乾燥不足での2層目施工 | 中 | 高 | 乾燥確認を必ず実施する |
| 施工方向誤りによるムラ蓄積 | 低 | 中 | 施工前に方向を確認する |
| 転倒 | 中 | 高 | 退路確保・施工方向の事前確認 |

### 作業時間目安

20〜60分（面積による）

### 必要人数

1〜2名

### NG例

- 1層目と同じ方向に2層目を塗布する
- 2層目を厚く塗ることで1層目の補完をしようとする
- 1層目の乾燥確認なしに2層目を開始する

### OK例

- 施工前に1層目の方向を確認し、2層目は90°変えた方向で施工する
- 1層目と同様に薄く均一に塗布する
- 退路を確保してから施工を開始する

### よくある失敗

- 施工方向を変えることを忘れ、同方向に2層目を塗布して縦縞状のムラが発生した
- 2層目を厚く塗りすぎて白化・気泡が発生した

### 改善方法

- 1層目の施工方向を作業記録に記載し、2層目の施工前に確認する習慣をつける

### 写真撮影位置

- 2層目塗布中の施工状況（1層目と異なる方向が分かる全景）

### クレーム防止

- 同方向施工による縦縞状ムラクレームを防ぐ。方向転換を徹底する
- 厚塗りによる白化クレームを防ぐ。2層目も薄塗りを徹底する

## 工程9　乾燥確認（2層目）

### 作業内容

2層目のワックス塗布後、メーカー指定の乾燥時間を確保し完全乾燥を確認する。3層目施工が必要な場合は乾燥確認後に進む。3層目が不要な場合は最終乾燥確認へ進む。

### 理由

なし

## 工程10　（施設基準による）3層目施工・乾燥確認

### 作業内容

施設の品質基準・仕様で3層目が必要な場合、2層目完全乾燥後に3層目を塗布し乾燥確認を実施する。3層目が不要な場合はこの工程をスキップして工程11（最終乾燥確認）へ進む。

### 理由

高負荷施設（商業施設・工場・ホテルロビー等）では、耐久性・光沢向上のために3層塗布が推奨される場合がある。3層目は2層目と同方向（1層目と同方向）に塗布し、層ごとに方向を変えることで均一な保護膜を形成する。

### 使用工具

| 管理番号 | 工具 | 用途 |
|---|---|---|
| TOOL-001 | ワックスモップ（専用） | 3層目塗布 |
| TOOL-002 | ワックスバケット（専用） | ワックス供給 |
| TOOL-008 | 送風機 | 乾燥促進 |
| TOOL-007 | 「乾燥中・立入禁止」表示板 | 乾燥中の立入防止 |

### 使用薬剤

| 管理番号 | 薬剤 | 希釈率 |
|---|---|---|
| 選定済みワックス（CHEM-001〜007） | 3層目塗布 | 原液（希釈禁止） |

### 作業方法

1. 2層目の完全乾燥を確認する
2. 3層目の施工方向を確認する（1層目と同方向・2層目と直交）
3. ワックスモップにワックスを約80〜100ml含ませ、薄く均一に塗布する
4. 奥から出口方向へ退路を確保しながら施工する
5. 塗布完了後すぐに送風機で乾燥を促進する
6. メーカー指定の乾燥時間を確保し、完全乾燥を確認する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 塗布済み面での転倒 | 退路を確保して施工する |
| 2層目の乾燥不足での3層目施工 | 2層目乾燥確認後に施工を開始する |

### 品質基準

- 3層目が2層目と90°異なる方向で施工されている（＝1層目と同方向）
- 液だまり・気泡・モップ跡がない
- 3層目が完全乾燥している

### 床材別注意

| 床材 | 注意事項 |
|---|---|
| 長尺シート・Pタイル | 3層目を施工する場合は過度な厚みにならないよう塗布量を管理する |
| フローリング | 3層目が必要かどうかはメーカー指定に従う |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 商業施設・ホテル | 高光沢・高耐久が求められる場合に3層施工が有効 |
| 工場 | 高負荷環境では高耐久ワックス（CHEM-002）での3層施工を検討 |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 3層目施工有無・完了確認の記録 |

### 食品施設への対応

- 施設仕様で3層が必要な場合も衛生管理適合ワックス（CHEM-007）を使用する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 過剰な層数によるワックスの剥離 | 低 | 高 | 施設仕様・メーカー推奨層数を遵守する |
| 転倒 | 中 | 高 | 退路確保を徹底する |

### 作業時間目安

20〜60分の塗布＋メーカー指定乾燥時間

### 必要人数

1〜2名

### NG例

- 施設仕様を超えた層数を「良かれ」と思って施工する
- 3層目も同じ方向（2層目と同方向）に塗布する

### OK例

- 施設仕様・担当者指示に従い3層目の要否を決定する
- 3層目は1層目と同方向（2層目と直交する方向）に塗布する

### よくある失敗

- 過剰に厚く仕上げようとして規定以上の層数を塗布し、ワックスが剥離した

### 改善方法

- 施工前に施設担当者と層数を確認し、書面で記録してから施工する

### 写真撮影位置

- 3層目塗布中の施工状況（必要時）
- 3層目乾燥確認後の光沢状態

### クレーム防止

- 過剰な層数によるワックス剥離クレームを防ぐ。施設仕様の層数を遵守する

## 工程11　最終乾燥確認

### 作業内容

全層の塗布完了後、床面全体が完全乾燥していることを確認し、利用者の歩行が安全に行える状態であることを確認する。

### 理由

最終乾燥確認は品質確認と安全確認の両方を兼ねる最重要チェックポイントである。乾燥不足で表示板を撤去すると利用者転倒・歩行跡・品質不良が同時に発生する。光沢・均一性・気泡の有無を確認する最後の機会でもある。

### 使用工具

| 管理番号 | 工具 | 用途 |
|---|---|---|
| TOOL-008 | 送風機 | 乾燥促進（必要時） |
| TOOL-005 | マイクロファイバークロス | 確認用 |

### 使用薬剤

なし

### 作業方法

1. 全層の塗布完了後、メーカー指定の最終乾燥時間を確保する
2. 送風機を使用して乾燥を促進する（必要時）
3. 床全面を目視で確認する（光沢均一性・白化・気泡・ムラの有無）
4. 端部の目立たない箇所で指触確認を行う（ベタつきがないこと）
5. 光沢の均一性を入口側・窓際・照明下で確認する
6. 歩行テストを端部から慎重に実施する（全面乾燥確認後）
7. 完全乾燥が確認できたら復旧工程（表示撤去）へ進む

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 乾燥確認前の表示撤去による転倒 | 必ず全面乾燥確認後に表示を撤去する |
| 歩行テスト中の転倒 | 端部から慎重に一歩ずつ確認する |

### 品質基準

- 全面が完全乾燥している（目視・指触確認）
- 光沢が均一に出ている
- 白化・気泡・ムラがない
- 液だまり・モップ跡がない
- 歩行跡・ゴミ混入がない

### 床材別注意

| 床材 | 確認ポイント |
|---|---|
| 長尺シート | 継ぎ目部分の乾燥・密着状態を確認する |
| Pタイル | 目地部分の仕上がり状態を確認する |
| フローリング | 木目への密着状態・変色がないか確認する |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| ホテルロビー | 斜め光・照明光で光沢均一性を徹底確認する |
| 商業施設 | 営業開始前に完全乾燥することを確認してから引き渡す |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 最終乾燥確認の記録 |
| ISO 45001 | 乾燥確認後の安全区画解除 |

### 食品施設への対応

- 最終乾燥後に食品エリアへの安全性を確認して衛生管理記録に記載する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 乾燥不足での表示撤去 | 中 | 高 | 全面乾燥確認後に表示を撤去する |
| 品質不良の見落とし | 中 | 高 | 照明下での全面目視確認 |

### 作業時間目安

10〜20分

### 必要人数

1名

### NG例

- 一部だけ確認して全体を乾燥済みとみなす
- 乾燥確認前に表示板を撤去する

### OK例

- 全面を目視・指触で確認してから表示板を撤去する
- 照明下・窓際で光沢均一性を確認する

### よくある失敗

- 端部だけ乾燥確認して全体が乾燥したと判断し、中央部に乾燥不足箇所が残っていた

### 改善方法

- 全面確認チェックリストを使用し、エリアを分割して確認する

### 写真撮影位置

- 最終乾燥確認後の全景（光沢・均一性が分かる状態）
- 照明下・窓際の光沢確認状態（近景）

### クレーム防止

- 乾燥不足での歩行開始による歩行跡クレームを防ぐ。全面乾燥を確認してから引き渡す

## 工程12　復旧（表示・養生撤去・原状回復）

### 作業内容

最終乾燥確認後、カラーコーン・表示板・養生を撤去し、施工前の状態に現場を戻す。

### 理由

ワックス乾燥確認後に表示物・養生を速やかに撤去することで、施設の通常使用を再開できる。養生テープの長時間放置は巾木への糊残りの原因となる。家具・備品の復旧時にワックス面を傷つけないよう細心の注意が必要である。

### 使用工具

- カラーコーン（TOOL-006）
- 表示板（TOOL-007）
- 養生テープ除去（ケレン・必要時）

### 使用薬剤

なし

### 作業方法

1. 最終乾燥確認後にカラーコーン（TOOL-006）を撤去する
2. 「乾燥中・立入禁止」表示板（TOOL-007）を撤去する
3. 養生テープをゆっくりと斜め方向に剥がす（巾木・壁を傷つけないよう注意）
4. 養生シートを撤去する
5. 移動させた備品・家具を元の位置に戻す（ワックス面を引きずらず持ち上げて移動）
6. 全ての表示物・養生材が撤去されていることを確認する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 乾燥確認前の表示撤去 | 乾燥確認後に撤去する |
| 養生テープ剥がし時の巾木損傷 | ゆっくり斜め方向に剥がす |
| 家具復旧時のワックス面への傷 | 持ち上げて移動する。フェルトパッドを使用する |

### 品質基準

- 全カラーコーン・表示板が撤去されている
- 養生テープの糊残りがない
- 家具・備品が元の位置に戻っている
- ワックス面に復旧作業による傷がない

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| オフィス | 机・椅子・備品の位置を元通りにする |
| ホテル | アメニティ・備品の位置を元通りにする |
| 病院 | 医療機器・備品は担当者立会いのもと復旧する |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 復旧確認チェックリストへの記録 |

### 食品施設への対応

- 食品エリアへの養生材残留がないことを確認する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 家具復旧時のワックス面への傷 | 中 | 高 | 持ち上げて移動・フェルトパッド使用 |
| 養生糊残りによる巾木損傷 | 中 | 中 | ゆっくり斜め方向に剥がす |

### 作業時間目安

10〜20分

### 必要人数

1〜2名

### NG例

- 家具を床に引きずって移動してワックス面を傷つける
- 養生テープを急いで剥がして巾木を傷める

### OK例

- 家具を持ち上げて移動する。底面にフェルトパッドを使用する
- 養生テープをゆっくり斜め方向に剥がす

### よくある失敗

- 家具を引きずって移動し、ワックスをかけたばかりの床面に傷をつけた
- 養生テープを勢いよく剥がして巾木の塗装が剥がれた

### 改善方法

- 復旧チェックリストを使用して全項目を確認してから施設担当者への引き渡しを行う

### 写真撮影位置

- 復旧完了後の全景

### クレーム防止

- 家具復旧時のワックス面傷クレームを防ぐ。家具は必ず持ち上げて移動する

## 工程13　最終品質確認

### 作業内容

全工程が完了した状態で品質基準に基づき仕上がりを確認し、施設担当者への引き渡し品質を保証する。

### 理由

最終品質確認は施設担当者への引き渡し前の唯一のチェックポイントである。ワックス施工は定期清掃として費用が発生するため、施設担当者の期待品質が高い。特に光沢均一性・モップ跡・液だまり・ゴミ混入の有無が確認のポイントである。

### 使用工具

- チェックリスト
- 懐中電灯（必要時）

### 使用薬剤

なし

### 作業方法

1. 入口側から床全景を目視で確認する（遠景・近景）
2. 照明下・窓際で光の角度を変えながら光沢均一性を確認する
3. モップ跡・液だまり・気泡・ムラを確認する
4. ゴミ混入・歩行跡・変色を確認する
5. 壁際・隅部の仕上がりを近景で確認する
6. 施工前の汚染箇所が改善されていることを確認する
7. チェックリストに全項目を記入する
8. 問題がある場合は即座に対応する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 確認漏れによる品質不良の引き渡し | チェックリストで全項目確認する |
| 光が不十分で仕上がりを見落とす | 照明・懐中電灯を活用する |

### 品質基準

| 確認項目 | 品質基準 |
|---|---|
| 光沢 | 全面に均一な光沢が出ている |
| ムラ | 塗りムラ・光沢ムラがない |
| モップ跡 | モップ線・跡が残っていない |
| 液だまり | 液だまりがない |
| 気泡 | 気泡がない |
| ゴミ混入 | ゴミ・ホコリ・毛髪の混入がない |
| 歩行跡 | 歩行跡がない |
| 白化 | 白濁・白化がない |
| 壁際 | 壁際まで均一に仕上がっている |
| 臭気 | 強い薬剤臭が残っていない |
| 巾木 | ワックスの付着・糊残りがない |
| 傷 | 施工による傷がない |

### 床材別注意

| 床材 | 確認ポイント |
|---|---|
| 長尺シート | 継ぎ目部分の仕上がり・液だまり |
| Pタイル | 目地部分の仕上がり・ムラ |
| フローリング | 木目への密着・変色・光沢 |

### 場所別注意

| 場所 | 確認ポイント |
|---|---|
| ホテルロビー | 光沢・ゴミ混入・モップ跡（照明下で斜め確認） |
| 食品施設 | ワックスの安全性確認・異物混入確認 |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 品質確認チェックリストへの記録・承認 |

### 食品施設への対応

## 工程14　写真撮影・報告書作成

### 作業内容

施工記録として写真撮影を行い、作業報告書を作成・提出する。

### 理由

写真・報告書は施工品質の証明・クレーム時の証拠資料・次回施工時の参考資料として活用する。ワックス施工は定期清掃として記録を継続することで、剥離洗浄のタイミング管理・ワックス蓄積量の管理に活用できる。ISO・衛生管理の記録要件を満たすためにも必須である。

### 使用工具

- スマートフォン・デジタルカメラ（800万画素以上推奨）
- 報告書（紙または電子）

### 使用薬剤

なし

### 作業方法

**写真撮影**

1. 作業前写真：施工前の床全景・ワックス劣化状態・汚染箇所の近景を撮影する
2. 作業中写真：除塵・1層目塗布・乾燥状態・2層目塗布・最終乾燥状態を撮影する
3. 作業後写真：完了後の床全景・光沢状態・壁際仕上がりを撮影する
4. 異常箇所写真：床材破損・浮き・剥がれを発見した場合は撮影する

**撮影ルール**

- 作業前後は同じ位置・同じ高さ・同じ方向から撮影する
- 日付・時刻記録機能をONにする
- 照明・窓光を利用して光沢が分かりやすい角度で撮影する
- 全景（遠景）と詳細（近景）をセットで撮影する

**報告書作成**

1. 基本情報（日時・現場名・作業者・天候・温度・湿度）を記入する
2. 使用ワックス（CHEM管理番号・製品名・施工層数）を記入する
3. 作業内容（除塵・テスト施工・各層塗布・乾燥時間）をチェックする
4. 作業結果（良好・一部改善必要）を記入する
5. 異常箇所（発見した場合は写真と共に記載）を記入する
6. 次回推奨作業（日常清掃・定期洗浄・剥離洗浄時期目安）を記入する
7. 写真を添付して施設担当者・管理者へ提出する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 個人情報・機密情報の写り込み | 撮影前に確認する |
| 写真データの紛失 | バックアップを取ってから添付する |

### 品質基準

- 作業前・中・後の写真が揃っている
- 使用ワックスのCHEM管理番号・施工層数が記録されている
- 報告書が全項目記入されている
- 提出が完了している

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 品質記録の作成・保管 |
| ISO 14001 | 使用薬剤・廃棄物の記録 |
| ISO 45001 | 安全管理記録の作成 |

### 食品施設への対応

- 衛生管理記録として清掃日時・使用ワックス・施工者・確認結果を記録・保管する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 記録不備によるクレーム対応不能 | 低（省略時は高） | 高 | 作業前・中・後の写真を必ず撮影する |

### 作業時間目安

10〜20分

### 必要人数

1名

### NG例

- 作業後写真のみ撮影して作業前写真を省略する
- 使用ワックスのCHEM管理番号を記録しない
- 施工層数を報告書に記載しない

### OK例

- 作業前・中・後を同じ構図で撮影する
- 使用ワックスのCHEM管理番号・施工層数を全て記録する
- 報告書を全項目記入して施設担当者へ提出する

### よくある失敗

- 撮影を忘れて施工後に気づき、施工前の状態が記録に残らなかった

### 改善方法

- 作業フローの最初（カラーコーン設置直後）に「作業前写真撮影」を必須ステップとする

### 写真撮影位置

- 施工前の床全景・ワックス劣化状態
- 1層目・2層目の塗布状況（施工方向が分かる角度）
- 各層乾燥確認後の光沢状態
- 施工完了後の全景・光沢・壁際近景

### クレーム防止

- 施工前の既存破損を写真記録することで「施工でつけた傷」クレームを防ぐ
- 使用ワックスの記録は「適切なワックスを使用した」ことの証明になる

## 工程15　資機材清掃・後片付け

### 作業内容

使用した全ての資機材を洗浄・整理し、次回使用できる状態にして保管する。

### 理由

ワックスモップ（TOOL-001）・ワックスバケット（TOOL-002）にワックスが残ったまま保管すると、次回使用時にワックスが固化して品質不良の原因になる。ワックスモップは清掃用モップと共用禁止であり、専用品として適切に管理する。

### 使用工具

- 水道・ホース
- ブラシ
- 清潔なクロス

### 使用薬剤

なし（清水による洗浄）

### 作業方法

1. ワックスモップ（TOOL-001）を清水で洗浄する。ワックスが完全に除去されるまで洗う
2. モップを絞り、伸ばした状態で乾燥させる（丸めたまま保管禁止）
3. ワックスバケット（TOOL-002）のワックスを適切に廃棄または保管する
4. バケットを清水で洗浄して内部をきれいにする
5. 送風機（TOOL-008）・サーキュレーター（TOOL-010）を清水で拭き取り清掃する
6. カラーコーン（TOOL-006）・表示板（TOOL-007）を清水で拭き取り汚れを除去する
7. 全資機材を所定の保管場所に収納する
8. ワックスの残液を現場指定の方法で適切に処理する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| ワックス残液の不適切処理 | 現場指定の方法で処理する |
| モップを丸めたまま保管することによるカビ | 伸ばした状態で乾燥保管する |

### 品質基準

- ワックスモップが清潔に洗浄・乾燥保管されている
- ワックスバケットが清潔に洗浄されている
- 全資機材が所定の場所に収納されている
- ワックス残液が適切に処理されている

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 14001 | ワックス廃液の適切処理 |
| ISO 9001 | 資機材管理手順の標準化 |

### 食品施設への対応

- 食品施設で使用した資機材は他エリアと区別して保管する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| ワックス残液の環境汚染 | 低 | 中 | 現場指定方法で処理する |
| モップのカビ・劣化 | 中（保管不備時） | 中 | 伸ばした状態で乾燥保管 |

### 作業時間目安

15〜25分

### 必要人数

1名

### NG例

- ワックスモップを洗わずに丸めて保管する
- ワックスバケットにワックスを残したまま保管する
- ワックス残液を排水溝に無処理で流す

### OK例

- ワックスモップを清水で十分洗浄して伸ばして乾燥保管する
- ワックスバケットを清水で洗浄してから保管する
- ワックス残液を現場指定の方法で処理する

### よくある失敗

- ワックスモップを洗わずに保管し、次回使用時に固化したワックスで床面を汚染した
- バケット内に残ったワックスが固化してバケットが使用不能になった

### 改善方法

- 資機材清掃チェックリストで全項目を確認してから保管する

### クレーム防止

- 管理不足のワックスモップによる次回施工品質不良クレームを防ぐ

# 17. よくある失敗と改善方法

# 20. 異常時対応

## ワックス施工中に問題が発生した場合

| 異常 | 対応 |
|---|---|
| ワックスが白化した | 施工を中止する。原因（乾燥不足・洗剤残留）を確認する。施設担当者に報告する。再施工の要否を判断する |
| 気泡が大量に発生した | 施工を一時中止する。塗布量・速度を見直す。問題が続く場合は施設担当者に報告する |

| 乾燥が極端に遅い | 温度・湿度を確認する。換気・送風機を増強する。メーカーに確認する |

## 緊急時対応

| 事故 | 対応 |
|---|---|
| 利用者転倒（乾燥中） | 安全確保→負傷確認→管理者へ報告→カラーコーン追加設置 |
| ワックスが眼に入った | 大量の清水で15分以上洗眼→医療機関受診 |
| ワックスが皮膚に付着 | 清水で洗浄→異常があれば受診 |
| 火災（ワックス蒸気） | 初期消火が可能な場合のみ対応→119番通報→避難誘導 |
