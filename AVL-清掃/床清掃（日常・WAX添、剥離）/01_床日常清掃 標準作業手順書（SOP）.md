# 01_床日常清掃 標準作業手順書（SOP）

---

# 1. 作業概要

| 項目 | 内容 |
|---|---|
| 作業名称 | 床日常清掃 |
| 目的 | 床面の日常的な土砂・ホコリ・汚れを除去し、美観・衛生・安全を維持する |
| 対象施設 | オフィス・商業施設・ホテル・病院・学校・工場・公共施設・マンション共用部・食品施設 |
| 対象床材 | 長尺シート・Pタイル・コンポジションタイル・磁器タイル・テラゾー・フローリング・天然石・カーペット隣接エリア |
| 作業人数 | 1〜3名（現場規模による） |
| 作業時間 | 15分〜2時間（面積による） |
| 推奨施工時間帯 | 営業時間外・夜間・早朝・利用者が少ない時間帯（現場確認） |
| 作業頻度 | 毎日（現場仕様） |

---

## 施工可能条件

| 条件 | 基準 |
|---|---|
| 利用者の有無 | 利用者が退出または動線が確保されていること |
| 床材確認 | 床材の種類を確認し、適合した薬剤・道具を選択できること |
| 水道 | 湿式清掃時は水道が使用可能であること |
| 立入禁止表示 | 床清掃中の転倒防止のため「清掃中」表示が設置できること |

## 施工不可条件

| 条件 | 対応 |
|---|---|
| 利用者が多数いる時間帯での湿式清掃 | 乾式清掃のみ実施。湿式は閉館後に実施 |
| フローリング・天然石への大量散水 | 固く絞ったモップのみ使用 |
| 床が極端に凹凸・破損している | 施工前に管理者へ報告 |

## 作業中止基準

| 発見内容 | 対応 |
|---|---|
| 利用者の転倒 | 救護対応・119番通報・報告書作成 |
| 利用者が作業区域へ侵入した | 安全確認・「清掃中」表示の再設置 |
| 施設担当者から中止指示 | 即時中止 |

## 薬剤選択フロー

```
汚れを確認する
　↓
ホコリ・土砂（乾いた汚れ）
→ 乾式除塵のみ（ドライモップ・掃除機）。薬剤不要
　↓
皮脂・水分・軽度汚れ（湿った汚れ）
→ 中性床用洗剤（50〜100倍）モップ施工→水拭き→乾拭き
　↓
油汚れ・部分的な黒ずみ
→ 弱アルカリ洗剤（30〜50倍）スポット施工
　※フローリング・天然石には弱アルカリ禁止
　↓
床材確認
→ フローリング：固く絞ったモップ・木床専用中性洗剤のみ
→ 天然石：石材専用洗剤のみ
```

# 2. 作業目的

床日常清掃は、毎日の歩行により蓄積する土砂・ホコリ・水分・部分汚れを早期に除去することで以下を実現する。

- 美観維持
- 衛生環境の維持
- 転倒事故防止
- ワックス保護膜の長期維持
- 床材寿命の延長
- 施設資産価値の維持
- 衛生管理対応
- 次回定期清掃コストの低減
- クレーム防止

**理由：** 日常清掃を怠ると土砂・ホコリが床材表面に研磨剤として作用し、ワックス膜・床材そのものを摩耗させる。早期除去が長期コスト削減につながる。

---

# 3. 放置した場合のリスク

| リスク | 内容 |
|---|---|
| 黒ずみ蓄積 | 土砂・皮脂が圧着し除去困難になる |
| ワックス摩耗 | 砂が研磨剤となりワックス膜を損傷する |
| 光沢低下 | 美観が損なわれ施設イメージが低下する |
| 転倒事故 | 水分・油汚れの放置が滑り事故を招く |
| 床材摩耗 | 汚れが研磨剤となり床材そのものを傷める |
| 定期清掃コスト増 | 汚れが蓄積すると剥離・重洗浄が必要になる |
| 衛生環境悪化 | 食品施設で汚染管理が不十分になる |
| クレーム発生 | 利用者から美観・衛生に関するクレームが発生する |

---

# 4. 主な対象汚れ

| 汚れ | 発生原因 | 特徴 |
|---|---|---|
| 土砂・砂 | 靴裏・外部持込 | 研磨剤として床材を傷める |
| ホコリ | 空気中・衣類 | 蓄積すると黒ずみになる |
| 皮脂・足跡 | 歩行 | 油分を含み汚れが定着しやすい |
| 水分・水滴 | 飲料・雨・洗面 | 乾燥後に水垢・輪ジミになる |
| 飲料こぼれ | 飲食 | 放置で固着・変色する |
| ヒールマーク | 靴底ゴム | ワックス面に付着しやすい |
| 軽度のタイヤ痕 | 台車 | 定期清掃での対応が必要な場合あり |

# 9. 詳細作業手順

## 工程1　現場確認・KY実施

### 作業内容

作業開始前に施工範囲・床材・汚染状況・安全環境を確認し、KY（危険予知）を実施する。

### 理由

床材によって使用薬剤・道具・作業方法が大きく変わるため、事前確認なしで施工すると床材破損・薬剤被害・クレームの原因となる。KYにより作業者の安全意識を高め事故を予防する。

### 使用工具

- チェックリスト
- 図面（あれば）

### 使用薬剤

なし

### 作業方法

1. 作業範囲を目視で確認する
2. 床材の種類を確認する（長尺シート・Pタイル・磁器タイル・フローリング・天然石など）
3. ワックス施工履歴を確認する
4. 床面の汚染状況・破損・水漏れ箇所を確認する
5. 利用者動線・出入口・避難経路を確認する
6. 電源位置・給水位置を確認する
7. KYを実施し、本日の危険ポイントを全員で共有する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 床材誤認による薬剤被害 | 目視・素材確認を徹底する |
| 確認不足による作業範囲ミス | 図面・担当者確認を実施する |
| 出入口閉鎖による避難経路遮断 | 非常口・避難経路を事前確認する |

### 品質基準

- 床材が正確に識別できている
- KYが完了し危険ポイントが共有されている
- 作業範囲が明確になっている

### 床材別注意

| 床材 | 確認ポイント |
|---|---|
| 長尺シート | 浮き・剥がれ・ジョイント部の状態確認 |
| Pタイル | 欠け・浮き・接着不良の確認 |
| 磁器タイル | 目地の状態・ひび割れ確認 |
| フローリング | 水分による膨らみ・傷の確認 |
| 天然石 | 酸・アルカリ接触歴の確認 |
| テラゾー | 光沢状態・研磨歴の確認 |

### 場所別注意

| 場所 | 確認ポイント |
|---|---|
| オフィス | 執務時間帯・利用者の動線確認 |
| 商業施設 | 営業時間・搬入動線との重複確認 |
| ホテル | チェックイン・アウト時間との調整確認 |
| 病院 | 感染管理エリア・処置室周辺の確認 |
| 食品施設 | 食品管理区域の境界確認 |
| マンション共用部 | 騒音・振動発生時間帯の制限確認 |
| 工場 | 作業中機械・フォークリフト動線確認 |

### 教育

- 床材識別方法（目視・素材感触・ラベル確認）
- KY実施手順（危険洗い出し→対策→確認）
- 異常発見時の報告方法

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 作業前確認の手順遵守・チェックリスト記録 |
| ISO 45001 | KY実施による作業前リスクアセスメント |

### NG例

- 床材確認をせずに施工を開始する
- KYを省略する
- 利用者動線を確認せずに作業区画を設定する

### OK例

- 床材を目視・触感で確認してから薬剤を決定する
- KYで「本日のリスク」を全員で口頭確認する
- 避難経路を確保した上で作業区画を設定する

### 写真撮影位置

- 作業前の床全景（入口側から奥に向けて）
- 汚染箇所・破損箇所（近景）

### クレーム防止

- 床材誤認で薬剤被害が発生した場合のクレームを防ぐため、不明な床材は必ず施設担当者へ確認する
- 作業範囲の行き違いを防ぐため、作業開始前に施設担当者へ確認・承認を得る

## 工程2　安全確保・表示設置・養生

### 作業内容

利用者と作業者の安全を確保するため、カラーコーン・表示板を設置し必要箇所を養生する。

### 理由

水を使用するウエットモップ清掃は床を濡らすため、利用者の転倒事故が発生しやすい。表示設置は事故防止の最優先事項である。養生は洗剤・水による周辺設備への被害を防ぐ。

### 使用工具

- カラーコーン（最低2個）
- 「清掃中」「濡れ床注意」表示板
- 養生テープ
- 養生シート（必要時）

### 使用薬剤

なし

### 作業方法

1. カラーコーンを作業区画の入口・出口に設置する
2. 「清掃中」「濡れ床注意」表示板を利用者の目線に合わせて設置する
3. 壁際・巾木・コンセントを養生テープで養生する（洗剤が付着しやすい箇所）
4. 作業区画内に利用者が侵入しないよう動線を確保する
5. 避難経路が塞がれていないことを確認する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 濡れ床による利用者転倒 | カラーコーン・表示板を必ず設置する |
| 避難経路遮断 | 作業区画設定後に避難経路を必ず確認する |
| 洗剤による巾木・コンセント腐食 | 養生を確実に実施する |
| カラーコーン不足による表示漏れ | 現場規模に応じた数量を準備する |

### 品質基準

- カラーコーンが作業区画の全入口に設置されている
- 表示板が利用者の目線の高さに設置されている
- 避難経路が確保されている
- 養生が確実に実施されている

### 床材別注意

| 床材 | 養生ポイント |
|---|---|
| 全床材共通 | 巾木・コンセント・金属部品は必ず養生する |
| 天然石 | 石材周辺の金属（ステンレス枠など）も養生する |
| フローリング | 水分が侵入しやすい継ぎ目・端部を養生する |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 病院 | 緊急搬送・医療行為の動線を必ず確保する |
| 商業施設 | 非常口・防火扉周辺を塞がない |
| 工場 | フォークリフト・台車の動線と重複させない |
| オフィス | 非常階段・エレベーターホールへのアクセスを確保する |
| マンション共用部 | 住民の居室入口へのアクセスを塞がない |

### 教育

- カラーコーンの正しい設置位置・間隔
- 表示板の高さ・向きの確認方法
- 避難経路の確保方法

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 45001 | 作業区画の安全確保・利用者保護 |
| ISO 9001 | 養生チェック手順の標準化 |

### NG例

- カラーコーンを設置せずに水拭き清掃を開始する
- 表示板を壁に立て掛けただけで固定しない
- 避難経路の確認をせずに作業区画を設定する

### OK例

- 作業開始前に必ずカラーコーンと表示板を設置する
- 表示板は利用者の進行方向から視認できる位置に設置する
- 避難経路を確保した上で最小限の作業区画を設定する

### 写真撮影位置

- カラーコーン・表示板の設置状況（全景）
- 養生実施箇所（巾木・コンセント近景）

### クレーム防止

- 転倒事故は最大のクレームリスクである。表示設置を省略しない
- 養生不足で洗剤が巾木・設備に付着した場合の設備損傷クレームを防ぐ

## 工程3　除塵作業（ドライモップ・ダスター）

### 作業内容

ウエットモップ清掃の前に、床面の砂・ホコリ・ゴミを乾式で除去する。

### 理由

砂・ホコリが残った状態でウエットモップを施工すると、砂が研磨剤としてワックス膜・床材表面を傷める。除塵は床清掃の最重要工程である。また水分と混ざった砂泥は清掃困難となる。

### 使用工具

| 工具 | 用途 |
|---|---|
| ドライモップ（ダスター） | 主要面の除塵 |
| マイクロファイバーモップ | 精密除塵・仕上げ |
| ハンドブラシ（コーナー用） | 壁際・隅・角部の除塵 |
| ゴミ袋 | 回収ゴミの廃棄 |

### 使用薬剤

なし（乾式除塵）

### 作業方法

1. 作業エリアの奥（最も遠い場所）から出口方向へ施工する
2. ドライモップを床面に密着させ、浮かせずに一定方向へ動かす
3. 往復掛けは行わず、一方向施工を徹底する
4. モップは床に押し付けず、自重で密着させる
5. 壁際・隅・角部はハンドブラシで除塵する
6. 集まったゴミ・砂を回収してゴミ袋へ入れる
7. モップに溜まったホコリが落ちないよう、定期的に払い落とす

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 除塵中のホコリ吸入 | 防塵マスクを着用する |
| ドライモップ操作中の転倒 | 周囲の安全を確認しながら施工する |
| ゴミの中に危険物（ガラス・鋭利物）混入 | ゴミ回収時はクロス等で包んで回収する |
| 腰痛（前屈姿勢） | モップ柄の長さを身長に合わせる |

### 品質基準

- 床全面・壁際・隅部のホコリ・砂・ゴミが除去されている
- 目視でホコリ・砂が確認できない状態である
- ウエットモップ施工前に完全除塵が完了している

### 床材別注意

| 床材 | 注意事項 |
|---|---|
| 長尺シート | 継ぎ目部分・端部に砂が溜まりやすい。重点除塵する |
| Pタイル | タイル間の目地に砂が入りやすい。ハンドブラシで除塵する |
| 磁器タイル | 目地に砂・汚れが残りやすい。ハンドブラシを使用する |
| フローリング | 木目・板継ぎ目に砂が入る。柔らかいモップを使用する |
| 天然石 | 砂による傷が致命的になる。徹底除塵を行う |
| テラゾー | 細かな砂でも傷になるため、完全除塵後に水拭きする |
| カーペット隣接部 | カーペットから飛散したホコリが床材に落ちやすい。境界を重点清掃する |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| オフィス・エントランス | 外来者の持込土砂が多い。入口マット周辺を重点除塵する |
| 商業施設売場 | 商品陳列棚下・什器周辺に砂が溜まりやすい |
| 工場 | 金属粉・切粉が混在する場合がある。素手で触れない |
| 病院廊下 | 医療廃棄物・鋭利物が混在する可能性がある。目視確認を徹底する |
| ホテルロビー | 24時間利用施設では作業時間帯に特に注意する |
| 食品施設 | ゴミ・異物の完全除去は衛生管理上必須 |

### 教育

- ドライモップの正しい持ち方・動かし方（一方向施工・床密着）
- 往復掛けを行わない理由（ホコリを舞わせるため）
- ハンドブラシの使い方（壁際・隅部除塵）
- 危険物が混入している場合の対処方法

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 除塵完了後のチェックリスト確認 |
| ISO 14001 | 回収ゴミの適切な分別廃棄 |
| ISO 45001 | 防塵マスク着用・危険物混入確認 |

### 食品施設への対応

- 食品エリアの異物（ゴミ・砂・虫）を完全除去する
- 除塵したゴミは食品エリア外へ速やかに搬出する
- 除塵記録を衛生管理記録として保管する

### NG例

- 水拭き前に除塵を省略する
- ドライモップを往復で動かす
- 壁際・隅部の除塵を省略する

### OK例

- 奥から出口方向へ一方向施工する
- 壁際・隅部はハンドブラシで丁寧に除塵する
- 集めたゴミをまとめて回収してからウエットモップを開始する

### 写真撮影位置

- 除塵前の床状態（汚染が目立つ箇所・近景）
- 隅部・壁際の除塵作業中（必要時）

### クレーム防止

- 除塵不足でウエットモップ施工後に砂泥が広がるとクレームの原因になる
- 工場・病院では危険物の処理方法を事前に施設担当者と確認する

## 工程4　洗剤準備（2バケツ方式）

### 作業内容

床材に適した洗剤を希釈し、2バケツ方式で準備する。

### 理由

2バケツ方式は、洗浄に使用した汚れた水を床面に再塗布することを防ぐための方法である。1バケツ方式では汚水を繰り返し床に塗り広げることになり、清掃効果が著しく低下する。また適正希釈は床材保護と清掃効果の両立に不可欠である。

### 使用工具

| 工具 | 用途 |
|---|---|
| バケツ2個 | 1個：洗浄水用　1個：すすぎ水用 |
| モップレンチ（絞り器） | 適切な含水率管理 |
| スプレーボトル | 部分洗浄用の希釈洗剤 |

### 使用薬剤

| 薬剤 | 希釈率 |
|---|---|
| 中性床用洗剤 | メーカー指定 |
| 部分汚れ除去洗剤 | メーカー指定 |
| 食品施設対応洗剤（食品施設のみ） | 現場確認 |

### 作業方法

1. 薬剤ラベルを確認してから薬剤を選定する
2. バケツAに洗剤液（メーカー指定希釈）を準備する
3. バケツBに清水（すすぎ用）を準備する
4. スプレーボトルに部分汚れ用洗剤液を準備する
5. バケツに「洗浄」「すすぎ」のラベルを貼る
6. 使用前に洗剤液の色・泡立ちで正しい希釈か目視確認する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 高濃度による床材腐食・変色 | 濃すぎる場合は廃棄して再調製する |
| 洗剤の皮膚・眼への付着 | 手袋・保護メガネを着用する |
| 酸性洗剤との誤混合 | 薬剤ラベルを必ず確認する。混合禁止 |
| バケツの誤用（汚水と清水の取り違え） | バケツにラベルを必ず貼る |

### 品質基準

- 薬剤ラベルが確認されている
- 正しい希釈率で調製されている
- 2バケツが正しく準備されている
- スプレーボトルに希釈済み洗剤が準備されている

### 床材別注意

| 床材 | 使用薬剤注意 |
|---|---|
| 長尺シート | 中性床用洗剤を使用する。アルカリ洗剤使用はメーカー確認 |
| Pタイル | 中性床用洗剤を使用する。濃すぎると変色リスクあり |
| 磁器タイル | 中性洗剤適合 |
| フローリング | 木床対応中性洗剤を使用する。アルカリ禁止 |
| 天然石 | 石材専用洗剤のみ使用する。一般洗剤・酸性・アルカリ禁止 |
| テラゾー | 石材対応洗剤のみ使用する。メーカー確認必須 |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 食品施設 | 食品施設対応洗剤を使用する。一般洗剤不可 |
| 病院 | 感染管理基準に適合した洗剤を使用する（現場確認） |
| 学校 | 子供の触れる環境を考慮し洗剤の安全性を確認する |

### 教育

- 2バケツ方式の意義（汚水の再塗布防止）
- バケツの使い分け方法
- 洗剤希釈の確認方法（ラベル確認・目視確認）
- 薬剤ラベル確認の手順

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 薬剤選定・希釈手順の標準化 |
| ISO 14001 | 最小必要量の調製による廃液削減 |

### 食品施設への対応

- 食品エリアに使用する洗剤は食品施設対応洗剤のみとする
- 洗剤の種類・希釈率・使用量を清掃記録に記載する

### NG例

- 1バケツのみで洗浄・すすぎを兼用する
- 洗剤を薬剤ラベル未確認で使用する
- 汚れたバケツの水を継ぎ足して使い続ける

### OK例

- バケツAを洗浄用、バケツBをすすぎ用と明確に区分する
- バケツに「洗浄」「すすぎ」のラベルを貼ってから使用する
- 水が汚れたら新しい水に交換してから継続する

### クレーム防止

- 希釈不良で洗浄効果が不十分だった場合のクレームを防ぐ
- 濃すぎる洗剤による床材変色・腐食クレームを防ぐ

## 工程5　ウエットモップ清掃

### 作業内容

希釈した床用洗剤を含ませたモップで床面全体を湿式清掃する。

### 理由

除塵で除去できなかった皮脂・水分・軽度の油汚れを洗剤の力で除去する。水分量が多すぎると床材を傷め、水分が少なすぎると清掃効果がない。適正含水率の管理が重要である。

### 使用工具

| 工具 | 用途 |
|---|---|
| ウエットモップ | 床面湿式清掃 |
| マイクロファイバーモップ | 精密清掃・壁際仕上げ |
| バケツ（2バケツ方式） | 洗浄水・すすぎ水分離 |
| モップレンチ（絞り器） | 含水率管理 |

### 使用薬剤

| 薬剤 | 用途 |
|---|---|
| 中性床用洗剤（希釈済み） | ウエットモップ洗浄 |

### 作業方法

1. モップをバケツA（洗浄液）に浸し、モップレンチで十分に絞る（滴らない程度）
2. 作業エリアの奥から出口方向へ施工する
3. モップは「コの字」を描くように動かす
4. 重ね幅を約10cmとり、洗い残しを防止する
5. モップが汚れたらバケツA（洗浄液）で洗い、バケツB（すすぎ水）ですすいでから再使用する
6. 壁際・柱周辺・隅部はマイクロファイバーモップで仕上げる
7. バケツの水が汚れたら新しい水に交換する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 濡れ床による作業者転倒 | 滑りにくい安全靴を着用する |
| 濡れ床への利用者侵入 | カラーコーン・表示板を確認する |
| 水分過多による床材膨張（フローリング等） | モップは水滴が垂れない状態まで絞る |
| バケツの水こぼれ | バケツを安定した場所に設置する |
| 腰痛（前屈姿勢） | モップ柄の長さを適切に設定する |

### 品質基準

- 床全面・壁際・隅部が均一に清掃されている
- 洗い残し・汚れ残りがない
- モップ跡・水溜まりがない
- 過剰な水分が残っていない

### 床材別注意

| 床材 | 注意事項 |
|---|---|
| 長尺シート | 水分を残さず拭き上げる。継ぎ目への浸水注意 |
| Pタイル | 水分が目地に入りやすい。拭き取りを徹底する |
| 磁器タイル | 目地部分の洗浄を徹底する。滑りやすいため注意 |
| フローリング | モップは固く絞る（滴らない状態）。水分の残留禁止。木目に沿って施工 |
| 天然石 | 石材専用洗剤を使用する |
| テラゾー | 石材対応洗剤使用。擦りすぎで光沢を損なわない |
| カーペット隣接部 | カーペットへの水分浸透を防ぐ。境界部を慎重に施工 |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| オフィス廊下 | 頻繁な往来があるため区画を分割して施工する |
| ホテルロビー | 光沢床材が多い。モップ跡が残らないよう含水率を管理する |
| 病院廊下 | 水分残留で車椅子・ストレッチャーが滑る。拭き取りを徹底する |
| 食品施設 | 食品施設対応洗剤のみ使用。洗剤残留を厳禁とする |
| 工場 | 油汚れが多い場合は洗剤濃度・種類をメーカー確認のうえ変更する |
| マンション共用部 | 他棟・階への水の流れ出しに注意する |

### 教育

- ウエットモップの「コの字」施工方法
- 正しいモップの絞り加減の確認方法
- 2バケツ方式の実施手順
- 壁際・隅部の施工方法（マイクロファイバーモップの使い方）

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 施工手順の標準化・施工記録 |
| ISO 14001 | 使用水量・洗剤量の最小化 |
| ISO 45001 | 濡れ床の安全確保・転倒防止 |

### 食品施設への対応

- 食品接触面・調理台周辺の床は食品施設対応洗剤で清掃する
- 洗剤残留ゼロを確認する（目視で泡・洗剤痕がないこと）
- 清掃後に乾燥・換気を実施する

### NG例

- 水を200ml/m²以上撒いてから拭き取る施工をする（床材を傷める）
- 1バケツで洗浄とすすぎを兼用する
- バケツの水を交換しないで使い続ける
- フローリングに水分を多量に含ませる

### OK例

- モップを「コの字」で動かし重ね幅10cmを守る
- 水が汚れたら交換してから継続する
- バケツBのすすぎ水でモップをすすいでから再使用する
- 壁際・隅部はマイクロファイバーモップで丁寧に清掃する

### 写真撮影位置

- 清掃作業中の全景
- 壁際・隅部の清掃状況（必要時）

### クレーム防止

- 水分残留による利用者転倒はクレームの最大要因。モップは必ず水滴が垂れない状態まで絞る
- フローリングへの水分過多は膨張・変色クレームの原因。固絞りを徹底する
- 洗剤残留でベタつき感が残るとクレームになる。水が汚れたら必ず交換する

## 工程6　部分汚れ・スポット対応

### 作業内容

ウエットモップで除去できなかった部分的な汚れ（ヒールマーク・飲料こぼれ・油分等）を局所対応する。

### 理由

ウエットモップ清掃は広範囲の汚れを均一に除去するが、固着した汚れ・油分・ヒールマークには効果が不十分な場合がある。局所対応で残汚れを確実に除去することで品質を高める。

### 使用工具

| 工具 | 用途 |
|---|---|
| スプレーボトル（部分洗浄用） | 局所への洗剤散布 |
| マイクロファイバークロス | 局所拭き取り |
| ハンドブラシ（柔らかめ） | 軽い擦り洗浄 |

### 使用薬剤

| 薬剤 | 用途 | 希釈率 |
|---|---|---|
| 部分汚れ除去洗剤 | スポット洗浄 | メーカー指定 |
| 中性床用洗剤 | 軽度スポット洗浄 | メーカー指定 |

### 作業方法

1. ウエットモップ清掃後に残った汚れ箇所を目視で確認する
2. スプレーボトルで汚れ箇所に局所的に洗剤を散布する
3. メーカー指定の作用時間を確保する
4. マイクロファイバークロスで拭き取る
5. 固着汚れが残っている場合はハンドブラシで約300〜500gの力で擦る（床材に適合した硬さのブラシを使用）
6. 清水で洗剤を拭き取る
7. 除去できない場合は施設担当者へ報告する（定期清掃での対応を提案）

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 局所洗剤散布による床材変色 | 目立たない箇所でテスト後に施工する |
| 擦りすぎによる床材傷・ワックス損傷 | 軽い力で施工し状態を確認しながら進める |
| 洗剤の皮膚・眼への付着 | 手袋・保護メガネを着用する |

### 品質基準

- 対象の部分汚れが除去されている
- 洗剤が残留していない
- ハンドブラシによる傷がない
- 周辺床面との色・光沢の差がない

### 床材別注意

| 床材 | 注意事項 |
|---|---|
| 長尺シート | ヒールマーク専用リムーバーを使用する場合はメーカー確認必須 |
| Pタイル | 強く擦るとワックスが剥がれる。力加減を注意する |
| 磁器タイル | 目地部分は専用ブラシで対応する |
| フローリング | 水分を最小限にする。木目に沿って拭き取る |
| 天然石 | 洗剤選定を誤ると致命的な損傷になる。石材専用品以外使用禁止 |
| テラゾー | 研磨剤含有クロス・ブラシは禁止 |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 商業施設 | 飲料こぼれは乾燥前に早期対応で除去しやすくなる |
| 食品施設 | 食品汚れは衛生管理上速やかに除去する |
| 病院 | 体液・医療廃棄物が混在する場合は適切な保護具で対応する |

### 教育

- 部分汚れの種類判別方法（油系・水溶性・固着汚れ）
- スプレーボトルの正しい使い方
- テスト施工の手順
- 除去できない汚れの報告手順

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | スポット対応後の品質確認・記録 |
| ISO 45001 | 適切な保護具着用（病院・工場） |

### 食品施設への対応

- 食品こぼれは即座に除去し、食品施設対応洗剤でスポット洗浄する
- 洗浄後の清水拭き取りを徹底し、食品エリアへの洗剤残留ゼロを確認する

### NG例

- 固着汚れを強く擦り続けて床材を傷める
- テスト施工なしで天然石・フローリングに強い洗剤を使用する
- 除去できない汚れを放置して報告しない

### OK例

- 目立たない箇所でテスト後に施工する
- 汚れの種類を確認してから適切な洗剤を選ぶ
- 除去できない汚れは担当者へ報告し定期清掃で対応を提案する

### 写真撮影位置

- 部分汚れの対応前（近景）
- 対応後（近景、比較写真として撮影）

### クレーム防止

- スポット洗剤によるシミ・変色クレームを防ぐため、天然石・フローリングは必ずテスト施工する
- 除去できない汚れの放置クレームを防ぐため、状況を報告し定期清掃を提案する

## 工程7　水分拭き取り・乾燥確認

### 作業内容

清掃後の床面に残った水分を拭き取り、完全乾燥を確認する。

### 理由

水分が残った状態で利用者が歩行すると転倒事故が発生する。フローリング・天然石・Pタイルは水分の残留で膨張・水垢・変色が起こる。乾燥確認は安全・品質の両面で不可欠な工程である。

### 使用工具

| 工具 | 用途 |
|---|---|
| マイクロファイバークロス（乾燥用） | 水分拭き取り |
| スクイジー（小型） | 壁際の水分除去 |
| 送風機・サーキュレーター（必要時） | 乾燥促進 |

### 使用薬剤

なし

### 作業方法

1. ウエットモップ清掃後に床全面の水分残留を目視で確認する
2. 壁際・隅部・継ぎ目部分の水分をマイクロファイバークロスで拭き取る
3. 水滴・水溜まりが確認された場合は即座に拭き取る
4. 必要に応じて送風機・サーキュレーターで乾燥を促進する
5. 乾燥状態を目視・手触りで確認する（水分が残っていないこと）
6. 乾燥確認後にカラーコーン・表示板の撤去を実施する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 水分残留による利用者転倒 | 乾燥確認前に表示板を絶対に撤去しない |
| フローリングへの水分残留による膨張 | 継ぎ目・端部の水分を確実に除去する |
| 乾燥中の利用者侵入 | カラーコーンを乾燥完了まで設置し続ける |

### 品質基準

- 床全面・壁際・隅部・継ぎ目に水分が残っていない
- 水滴・水溜まりがない
- 目視・手触りで乾燥が確認できる
- 乾燥確認後にカラーコーンを撤去している

### 床材別注意

| 床材 | 注意事項 |
|---|---|
| フローリング | 継ぎ目・端部の水分を特に徹底拭き取りする。水分放置で膨張リスク高 |
| 天然石 | 水分で輪ジミ・水垢が生じやすい。拭き取りを徹底する |
| Pタイル | 目地・継ぎ目の水分を拭き取る |
| 磁器タイル | 目地の水分を除去する |
| 長尺シート | 継ぎ目への浸水に注意する |
| テラゾー | 水垢が発生しやすい。十分な拭き取りを行う |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 病院 | 車椅子・ストレッチャー通行前に完全乾燥を確認する |

### 教育

- 乾燥確認の方法（目視・手触り・光沢確認）

## 工程8　復旧（表示・養生撤去・原状回復）

### 作業内容

床の乾燥確認後、カラーコーン・表示板・養生を撤去し、施工前の状態に現場を戻す。

### 理由

養生・表示物の撤去忘れは施設担当者からのクレームとなる。また養生テープの長時間放置は壁・巾木への糊残りの原因となる。作業の完結は現場の原状回復まで含む。

### 使用工具

- カラーコーン
- 表示板
- 養生テープ除去道具（ケレン・必要時）

### 使用薬剤

なし

### 作業方法

1. 床の乾燥を確認してからカラーコーンを撤去する
2. 表示板を撤去する
3. 養生テープを丁寧に剥がす（糊残りがないよう慎重に剥がす）
4. 養生シートを撤去する
5. 移動させた備品・家具を元の位置に戻す
6. カラーコーン・表示板・養生材が全て撤去されていることを確認する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 乾燥前の表示撤去による転倒 | 必ず乾燥確認後に撤去する |
| 養生テープ剥がし時の巾木・壁面傷 | ゆっくりと角度をつけて剥がす |
| 家具・備品を床に引きずる傷 | 持ち上げて移動する |

### 品質基準

- カラーコーン・表示板が全て撤去されている
- 養生テープの糊残りがない
- 家具・備品が元の位置に戻っている
- 現場が施工前の状態に復旧されている

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| オフィス | 机・椅子の位置を元通りに戻す |
| 商業施設 | 商品陳列・什器の位置を元通りにする |
| ホテル | アメニティ・備品の位置を元通りにする |
| 病院 | 医療機器・備品の配置は施設担当者立会いのもと復旧する |

### 教育

- 養生テープの正しい剥がし方（糊残りを防ぐ方法）
- 家具・備品の安全な移動方法
- 復旧確認チェックリストの使用方法

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 復旧確認チェックリストへの記録 |

### NG例

- カラーコーンを設置したまま作業を終了する
- 養生テープを力任せに剥がして巾木を傷める
- 家具を引きずって床面を傷める

### OK例

- 乾燥確認後に全ての表示・養生を撤去する
- 養生テープはゆっくりと斜め方向に剥がす
- 家具は持ち上げて移動する

### クレーム防止

- 表示物・養生材の撤去忘れはクレームの原因。作業完了前に全点確認する
- 養生テープの糊残りによる壁・巾木の損傷クレームを防ぐため丁寧に撤去する

## 工程9　最終品質確認

### 作業内容

作業の全工程が完了した状態で、品質基準に基づき仕上がりを確認する。

### 理由

最終確認で問題を発見し、その場で対応することが施設担当者への引き渡し品質を保証する唯一の機会である。確認を省略すると施設担当者・利用者からクレームが発生する。

### 使用工具

- チェックリスト
- 懐中電灯（必要時）

### 使用薬剤

なし

### 作業方法

1. 入口側から床全景を目視で確認する（遠景・近景）
2. 窓際・照明下・入口付近を重点確認する（光の角度で汚れが見えやすい）
3. 壁際・隅部を近景で確認する
4. 光沢・均一性を確認する
5. 水滴・洗剤残留・モップ跡を確認する
6. 異常箇所（傷・変色・浮き・破損）を確認する
7. チェックリストに全項目記入する
8. 問題があれば即座に対応する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 確認漏れによる残汚れ放置 | チェックリストを使用して全項目確認する |
| 仕上がり不良の見落とし | 光の角度を変えて目視確認する |

### 品質基準

| 確認項目 | 品質基準 |
|---|---|
| 汚れ | 目視で汚れ・黒ずみ・油分が残っていない |
| ホコリ | 床面・隅・壁際に残っていない |
| 洗剤残留 | 洗剤・泡が残っていない |
| 水滴 | 水滴・水溜まりがない |
| モップ跡 | モップ跡・線が残っていない |
| 光沢 | 均一な状態である |
| 滑り | 滑りやベタつきがない |
| 臭気 | 薬剤臭・異臭が残っていない |
| 傷 | 施工による傷・変色がない |
| 周辺設備 | 巾木・壁・コンセントに薬剤・水分が残っていない |
| 表示物 | カラーコーン・表示板が全て撤去されている |
| 養生 | 養生テープ・養生シートが全て撤去されている |

### 床材別注意

| 床材 | 確認ポイント |
|---|---|
| 長尺シート | 継ぎ目部分の水分残留・浮き |
| Pタイル | 目地の汚れ残り・ワックス損傷 |
| 磁器タイル | 目地の汚れ残り・光沢不均一 |
| フローリング | 水分残留・木目に沿った傷 |
| 天然石 | 水垢・輪ジミ・変色 |
| テラゾー | 光沢均一性・水垢 |

### 場所別注意

| 場所 | 確認ポイント |
|---|---|
| ホテルロビー | 光沢・ゴミ混入・モップ跡 |
| 病院 | 感染管理基準での衛生確認 |
| 食品施設 | 洗剤残留・水分残留 |
| オフィス | 家具・備品復旧状態 |

### 教育

- 品質確認チェックリストの使用方法
- 光の角度を利用した目視確認方法
- 問題発見時の対応手順・報告方法

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 品質確認チェックリストへの記録・承認 |
| ISO 14001 | 洗剤残留の確認（環境汚染防止） |

### 食品施設への対応

- 食品エリアの床面に洗剤残留がないことを確認し、衛生管理記録に記載する
- 異物・ゴミの完全除去を確認する

### NG例

- 最終確認をせずに作業完了と判断する
- チェックリストを記入せずに報告書を作成する
- 発見した問題を放置して施設担当者に報告しない

### OK例

- チェックリストを使用して全項目を1つずつ確認する
- 窓際・照明下で光の角度を変えながら確認する
- 問題を発見したら即座に対応してから再確認する

### 写真撮影位置

- 作業後の床全景（入口側から奥に向けて）
- 壁際・隅部の仕上がり（近景）
- 問題が発見された箇所（対応後も撮影）

### クレーム防止

- 最終確認の省略はクレームの直接原因。必ず全項目確認してから施設担当者に引き渡す
- 異常箇所は施設担当者への報告が必要。放置・隠蔽は信頼失墜につながる

## 工程10　写真撮影・報告書作成

### 作業内容

施工記録として写真撮影を行い、作業報告書を作成・提出する。

### 理由

写真・報告書は施工品質の証明であり、クレーム時の証拠資料となる。また次回清掃の品質向上・異常箇所の継続管理に活用する。ISO・衛生管理の記録要件を満たすためにも必須である。

### 使用工具

- スマートフォン・デジタルカメラ（800万画素以上推奨）
- 報告書（紙または電子）

### 使用薬剤

なし

### 作業方法

**写真撮影**

1. 作業前写真：施工前の床全景・汚染箇所・破損箇所を撮影する
2. 作業中写真：除塵・モップ清掃・スポット対応の作業状況を撮影する
3. 作業後写真：完了後の床全景・壁際・仕上がり状態を撮影する
4. 異常箇所写真：傷・浮き・破損・水漏れを発見した場合は必ず撮影する

**撮影ルール**

- 同じ位置・同じ高さ・同じ角度で撮影する
- 日付・時刻の記録機能をONにする
- 前後比較できるよう同じ構図を維持する
- ピントを合わせてブレを防止する
- 全景（遠景）と問題箇所（近景）をセットで撮影する

**報告書作成**

1. 基本情報（日時・現場名・作業者・天候）を記入する
2. 作業内容（除塵・ウエットモップ・スポット対応）をチェックする
3. 使用薬剤名・希釈率・使用量を記入する
4. 使用機材を記入する
5. 作業結果（良好・一部改善必要）を記入する
6. 異常箇所（発見した場合は写真と共に記載）を記入する
7. 次回推奨作業を記入する
8. 写真を添付して施設担当者・管理者へ提出する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 個人情報・機密情報の写り込み | 撮影前に不要な情報が映らないか確認する |
| 写真データの紛失 | バックアップを取ってから報告書に添付する |

### 品質基準

- 作業前・中・後の写真が揃っている
- 写真が同じ構図で撮影されている
- 報告書が全項目記入されている
- 異常箇所が写真付きで報告されている
- 提出が完了している

### 教育

- 正しい写真撮影方法（位置・高さ・構図）
- 報告書の記入方法（全項目の記入）
- 異常箇所の報告方法

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 品質記録の作成・保管 |
| ISO 45001 | 安全管理記録の作成 |

### 食品施設への対応

- 衛生管理記録として清掃日時・洗剤・清掃者・確認結果を記録する
- 記録は施設の衛生管理計画に基づき保管する

### NG例

- 作業後写真のみ撮影し、作業前写真を省略する
- 異常箇所を発見しても報告書に記載しない
- 報告書を提出せずに終了する

### OK例

- 作業前・中・後を同じ構図で撮影する
- 異常箇所は発見後すぐに撮影し、報告書に詳細を記載する
- 報告書を全項目記入して施設担当者へ提出する

### クレーム防止

- 写真・報告書はクレーム時の唯一の証拠。省略するとクレームへの反証ができなくなる
- 施工前に既存の傷・破損を写真で記録することで「施工中に傷つけた」というクレームを防げる

## 工程11　資機材清掃・後片付け

### 作業内容

使用した全ての資機材を洗浄・整理し、次回使用できる状態にして保管する。

### 理由

使用後の資機材に洗剤・汚れが残ると、次回使用時に床面への汚れ再付着・薬剤被害が発生する。資機材の適切な管理は品質維持と施工コスト削減に直結する。

### 使用工具

- 水道・ホース
- ブラシ
- 清潔なクロス

### 使用薬剤

なし（清水による洗浄）

### 作業方法

1. モップを清水で3〜5回すすぐ。洗剤成分が残らないまで洗い流す
2. モップを絞り、伸ばした状態で乾燥させる（丸めたまま保管禁止）
3. バケツを清水で洗浄して汚れ・洗剤を除去する
4. スプレーボトルの残液を廃棄し、清水で洗浄する
5. ハンドブラシ・クロスを洗浄・乾燥させる
6. カラーコーン・表示板を清水で拭き取り、汚れを除去する
7. 資機材を所定の保管場所に収納する
8. 廃液・汚水を現場指定の方法で適切に処理する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 洗浄中の洗剤・汚水の飛散 | 手袋・保護メガネを着用する |
| 廃液の不適切な処理 | 現場指定の排水方法・廃棄方法で処理する |
| 重量物（バケツ・機材）の落下 | 重さを確認してから持ち運ぶ |

### 品質基準

- 全資機材が清潔に洗浄されている
- モップが伸ばした状態で乾燥保管されている
- バケツに洗剤・汚れが残っていない
- 廃液が適切に処理されている
- 全資機材が所定の場所に収納されている

### 教育

- モップの正しい洗浄・保管方法
- 廃液の適切な処理方法
- 資機材の収納ルール

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 14001 | 廃液の適切な処理・排水管理 |
| ISO 9001 | 資機材管理手順の標準化 |

### 食品施設への対応

- 食品施設で使用した資機材は他エリアと区別して保管する
- モップ・クロスは用途別に色分け管理する（現場仕様）

### NG例

- モップを洗わずに丸めて保管する
- バケツに洗剤液が残ったまま保管する
- 廃液を排水溝に無処理で流す

### OK例

- モップを十分洗浄して伸ばした状態で乾燥保管する
- バケツを清水で洗浄してから保管する
- 廃液を現場指定の方法で適切に処理する

### クレーム防止

- 洗浄不足のモップによる翌日の汚れ転写クレームを防ぐ
- 廃液の不適切な処理による環境クレーム・法令違反を防ぐ

# 13. よくある失敗と改善方法

| 失敗 | 原因 | 改善方法 |
|---|---|---|
| 除塵なしでウエットモップ施工 | 工程省略・時間不足 | 除塵は絶対省略しない。スケジュールを見直す |
| モップ跡が残る | モップの水分過多 | 絞り器で十分に絞ってから施工する |
| 壁際・隅部の汚れ残り | モップが届かない | ハンドブラシ・マイクロファイバーモップで対応する |
| 洗剤残留によるベタつき | すすぎ不足・洗剤過多 | バケツBのすすぎ水でモップをすすいでから再使用する |
| 水分残留で転倒事故 | 乾燥確認省略 | 乾燥確認後にカラーコーンを撤去する |
| カラーコーン設置忘れ | 準備不足 | 作業開始前のチェックリストで確認する |
| 写真撮影忘れ | 作業に集中しすぎる | 作業前写真はカラーコーン設置後に必ず撮影する |
| フローリングに水分過多 | 床材特性の理解不足 | 床材確認後に適切な絞り加減を調整する |
| バケツの水を交換しない | 面積が大きく忘れる | バケツの水が汚れたら必ず交換する |
| 養生テープの糊残り | 急いで剥がす | ゆっくり斜め方向に剥がす |

# 14. NG例・OK例まとめ

## 除塵

| NG | OK |
|---|---|
| 除塵せずにウエットモップを開始する | 除塵を完全に終えてからウエットモップを開始する |
| ドライモップを往復で動かす | 一方向施工を徹底する |
| 壁際・隅部の除塵を省略する | ハンドブラシで壁際・隅部まで除塵する |

## ウエットモップ

| NG | OK |
|---|---|
| 水を撒いてから拭き取る施工をする | モップを絞ってから均一に塗布する |
| 1バケツで洗浄とすすぎを兼用する | 2バケツ方式で洗浄とすすぎを分ける |
| バケツの水を交換しないで使い続ける | 水が汚れたら交換してから継続する |

## 安全管理

| NG | OK |
|---|---|
| カラーコーンなしで水拭き施工する | 施工前に必ずカラーコーン・表示板を設置する |
| 乾燥確認前に表示板を撤去する | 乾燥確認後に表示板を撤去する |
| 避難経路を塞ぐ作業区画設定 | 避難経路を確保した上で区画を設定する |

## 床材対応

| NG | OK |
|---|---|
| フローリングに水を大量に使用する | 固く絞ったモップで最小限の水分で施工する |
| 天然石に一般洗剤を使用する | 石材専用洗剤のみ使用する |
| 床材確認なしで施工を開始する | 施工前に床材を確認してから薬剤・工具を選定する |

## 写真・報告

| NG | OK |
|---|---|
| 作業後写真のみ撮影する | 作業前・中・後を同じ構図で撮影する |
| 異常箇所を報告書に記載しない | 異常箇所を写真付きで報告書に記載する |

# 15. クレーム防止

| クレーム事例 | 原因 | 防止策 |
|---|---|---|
| 施工後に転倒事故が発生 | 水分残留・カラーコーン設置忘れ | カラーコーン設置・乾燥確認の徹底 |
| 床が傷ついた | 床材に不適合な工具・薬剤の使用 | 施工前の床材確認・適合確認 |

| 以前あった傷を施工でつけたと言われた | 作業前写真がない | 施工前に傷・破損を写真で記録する |
| フローリングが膨れた | 水分過多 | 固絞りモップ・水分拭き取り徹底 |
| 食品に洗剤が混入した | 食品施設での洗剤残留 | 食品施設対応洗剤使用・洗剤残留確認 |
