# 2. 作業目的

床表面洗浄は、日常清掃では除去できない固着汚れ・黒ずみ・ヒールマーク・油汚れを機械的・化学的に除去することで床面の美観・衛生・安全を回復させる。

- 固着した黒ずみ・土砂の除去
- ヒールマークの除去
- タイヤ痕の除去
- 油汚れ・皮脂の除去
- ワックス表面の汚染除去
- 床材光沢の回復
- 衛生環境の維持・向上
- 次回剥離洗浄までの施工サイクル延長
- 衛生管理対応
- クレーム防止

**理由：** 日常清掃のモップだけでは、床材に圧着した固着汚れ・ヒールマーク・黒ずみの除去は困難である。これらが蓄積すると剥離洗浄が必要になりコストが増大する。定期的な表面洗浄で蓄積を防ぐことが長期的なコスト削減と品質維持につながる。

# 3. 放置した場合のリスク

| リスク | 内容 |
|---|---|
| 固着黒ずみの悪化 | 除去困難になり剥離洗浄が必要になる |
| ヒールマークの深部定着 | ワックスに浸透し表面洗浄では除去できなくなる |
| タイヤ痕の固着 | 時間経過で除去が極めて困難になる |
| ワックス汚染の蓄積 | 光沢が失われ施設イメージが低下する |
| 滑り事故 | 汚れによる滑り・ワックス劣化による転倒リスク |
| 剥離洗浄コスト増 | 蓄積汚れが剥離洗浄の頻度を増加させる |
| クレーム発生 | 清潔感・美観の低下による利用者クレーム |
| 衛生基準違反 | 食品施設での衛生基準未達 |

## 工程1　現場確認・KY実施

### 作業内容

作業開始前に施工範囲・床材・汚染状況・安全環境を確認し、KY（危険予知）を実施する。

### 理由

表面洗浄ではポリッシャーと弱アルカリ〜アルカリ洗剤を使用するため、床材誤認は取り返しのつかない損傷につながる。機械操作・汚水発生・強い洗剤という複数の危険要素があるため、KYで全員が本日の危険ポイントを共有することが事故防止の基本となる。

### 使用工具

- チェックリスト
- 図面（あれば）

### 使用薬剤

なし

### 作業方法

1. 作業範囲を目視で確認する
2. 床材の種類を確認する（長尺シート・Pタイル・磁器タイル・フローリング・天然石など）
3. ワックス施工履歴を確認する（有無・層数・最終施工日）
4. 汚染状況（黒ずみ・ヒールマーク・固着汚れ・油汚れの分布）を確認する
5. 床材の破損・浮き・剥がれ・亀裂を確認する
6. 電源位置・給水位置・排水位置を確認する
7. 利用者動線・出入口・避難経路を確認する
8. KYを実施し、本日の危険ポイントを全員で共有する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 床材誤認による洗剤被害・ポリッシャー傷 | 目視・素材確認・担当者確認を徹底する |
| 電源コードと水の接触による感電 | 電源位置と水道位置を事前に確認する |
| 避難経路遮断 | 作業区画設定前に非常口・避難経路を確認する |
| ワックス状態確認不足によるパッド選定ミス | ワックス履歴を確認してからパッドを選定する |

### 品質基準

- 床材が正確に識別されている
- 汚染分布が把握されている
- KYが完了し全員が本日の危険ポイントを共有している
- 作業範囲・電源・給水・排水が確認されている

### 床材別注意

| 床材 | 確認ポイント |
|---|---|
| 長尺シート | 継ぎ目の浮き・剥がれ。ポリッシャー端部巻き込みリスク確認 |
| Pタイル | 接着不良・浮きの確認。ポリッシャー圧力で剥離するリスク |
| 磁器タイル | 目地の状態・ひび割れ確認 |
| フローリング | ポリッシャー使用可否をメーカー確認 |
| 天然石 | アルカリ洗剤適合可否を確認。施工歴・現在の状態確認 |
| テラゾー | 石材専用洗剤の適合確認 |

### 場所別注意

| 場所 | 確認ポイント |
|---|---|
| オフィス | 残業者・警備員の動線確認 |
| 商業施設 | 閉店後施工確認。警備システムの確認 |
| ホテル | 深夜施工の場合、客室への騒音影響確認 |
| 病院 | 感染管理区域・ICU周辺の施工可否確認 |
| 工場 | 機械稼働状況・フォークリフト動線確認 |
| 食品施設 | 食品管理区域の特定・施設担当者承認取得 |

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 作業前確認の手順遵守・チェックリスト記録 |

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 床材誤認による損傷 | 中 | 高 | 目視・担当者確認・テスト施工 |

### NG例

- 床材確認を省略して施工を開始する
- KYを行わずに機械操作を開始する
- ワックス施工履歴を確認せずにパッドを選定する

### OK例

- 床材を目視・触感・施設担当者確認で識別してから薬剤を決定する
- KYで「本日使用するポリッシャーによる危険」を全員で口頭確認する
- ワックス有無を確認してから適合パッドを選定する

### よくある失敗

- 天然石とテラゾーを誤認し一般洗剤を使用して損傷させた
- ワックス未施工の磁器タイルにワックスを前提とした洗浄をした

### 改善方法

- 不明な床材は絶対に施工しない。施設担当者または専門家に確認してから施工する

### 写真撮影位置

- 作業前の床全景（入口側から奥に向けて）
- 汚染箇所（黒ずみ・ヒールマーク・固着汚れ）の近景（比較用）

### クレーム防止

- 床材誤認による薬剤被害は重大クレームの原因。不明な床材は施設担当者に確認する
- 既存破損（割れ・欠け・浮き）を事前に写真記録し「施工前からの状態」を証明する

## 工程2　安全確保・表示設置・養生

### 作業内容

ポリッシャーと弱アルカリ〜アルカリ洗剤を使用する表面洗浄において、利用者・設備・周辺環境を保護するための安全確保を実施する。

### 理由

ポリッシャーは大型機械であり、回転するパッドへの巻き込みや汚水の飛散が起こりやすい。弱アルカリ洗剤が巾木・金属部品・コンセントに付着すると腐食の原因となる。安全確保と養生は表面洗浄において日常清掃以上に重要である。

### 使用工具

- カラーコーン（最低4個以上）
- 「清掃中」「機械使用中」「濡れ床注意」表示板
- 養生テープ
- 養生シート（必要時）

### 使用薬剤

なし

### 作業方法

1. 作業エリアの全入口にカラーコーンを設置する
2. 「清掃中」「機械使用中」「濡れ床注意」表示板を利用者の目線高さに設置する
3. 壁際・巾木・コンセント・スイッチ・金属部品を養生テープで確実に養生する
4. ドア枠・木部・ゴム部品を養生テープで養生する（洗剤接触防止）
5. 避難経路が確保されているか確認する
6. 電源コードの引き回しルートを決定し、つまずき防止のためにテープで固定する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 利用者のポリッシャーへの接触 | 全入口にカラーコーンと表示板を設置する |
| アルカリ洗剤の金属部品への付着による腐食 | 全金属部品・巾木・木部を養生する |
| 電源コードへの躓き・転倒 | コードをテープで固定して通行の邪魔にならないよう配線する |
| 避難経路遮断 | 作業区画設定後に避難経路を再確認する |
| ポリッシャー騒音による苦情 | 施設担当者への事前通知・施工時間帯の調整 |

### 品質基準

- 全入口にカラーコーンが設置されている
- 養生が全金属部品・巾木・コンセント・木部に実施されている
- 避難経路が確保されている
- 電源コードが安全に配線・固定されている

### 床材別注意

| 床材 | 養生ポイント |
|---|---|
| 全床材共通 | 巾木・コンセント・金属部品・木部は必ず養生 |
| 天然石 | 石材周辺のステンレス・アルミ枠を養生 |
| フローリング | 継ぎ目・端部への水分侵入防止養生 |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 病院 | 緊急搬送・医療行為の動線を必ず確保する |
| 商業施設 | 警備員への施工開始・終了の報告 |
| 工場 | フォークリフト・台車の動線と完全に分離する |
| ホテル | 深夜施工の場合、ポリッシャーの音を最小化する工夫をする |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 45001 | 機械使用時の作業区画安全確保 |
| ISO 9001 | 養生・安全確認チェックリストの標準化 |

### 食品施設への対応

- 食品エリアへの洗剤・汚水の流出を防ぐため、食品管理区域境界を養生シートで仕切る

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 利用者のポリッシャー接触 | 中 | 高 | 全入口のカラーコーン設置 |
| 洗剤による金属腐食 | 中 | 高 | 全金属部品の養生 |
| 感電（コード・汚水接触） | 低 | 高 | コード配線の安全確認 |

### 作業時間目安

15〜30分

### 必要人数

1〜2名

### NG例

- カラーコーンを入口の一部にしか設置しない
- 金属部品・コンセントの養生を省略する
- 電源コードをテープ固定せずに床に放置する

### OK例

- 全金属部品・巾木・コンセントを養生テープで確実に養生する
- 電源コードをテープで床に固定して通行の邪魔にならないようにする

### よくある失敗

- コードを養生せず利用者が躓いて転倒事故になった

### 改善方法

- 養生チェックリストを使用し全項目を確認してから施工を開始する

### 写真撮影位置

- 電源コードの配線状況

### クレーム防止

- 電源コードへの躓きによる転倒事故クレームを防ぐ。コードは必ず固定する

## 工程3　除塵作業（ドライモップ）

### 作業内容

ポリッシャー洗浄の前に、床面の砂・ホコリ・ゴミを乾式で完全除去する。

### 理由

砂・ゴミが残った状態でポリッシャーを施工すると、砂が研磨剤として床材表面・ワックス膜を削り、深刻な傷の原因となる。ポリッシャーは回転力が強いため、砂による傷は日常清掃のモップとは比較にならないほど大きくなる。また砂が洗剤と混ざると泥水となり汚水回収の効率が著しく低下する。

### 使用工具

| 工具 | 用途 |
|---|---|
| ドライモップ（ダスター） | 主要面の除塵 |
| マイクロファイバーモップ | 精密除塵・仕上げ |
| ハンドブラシ（コーナー用） | 壁際・隅・角部の除塵 |
| ゴミ袋 | 回収ゴミの廃棄 |

### 使用薬剤

なし（乾式除塵）

### 作業方法

1. 奥から出口方向へ、一方向にドライモップを施工する
2. ドライモップは床面に密着させ、浮かせずに動かす
3. 往復掛けは行わず、一方向施工を徹底する
4. 壁際・柱周辺・隅部・角部はハンドブラシで除塵する
5. 什器・机・棚の下など、届きにくい場所も必ず除塵する
6. 集めたゴミ・砂を回収してゴミ袋に入れる
7. 除塵後に目視で砂・ゴミが残っていないことを確認する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 除塵中のホコリ吸入 | 防塵マスクを着用する |
| 工場・病院での危険物混入（ガラス・金属片） | ゴミ回収時は目視で確認してから回収する |
| ドライモップ操作中の転倒 | 周囲を確認しながら施工する |
| 腰痛（前屈姿勢） | モップ柄の長さを身長に合わせる |

### 品質基準

- 床全面・壁際・隅部・什器下のホコリ・砂・ゴミが除去されている
- 目視で砂・ゴミが確認できない状態である
- ポリッシャー施工前に完全除塵が完了している

### 床材別注意

| 床材 | 注意事項 |
|---|---|
| 長尺シート | 継ぎ目・端部に砂が溜まりやすい。重点除塵する |
| Pタイル | 目地に砂が入りやすい。ハンドブラシで丁寧に除塵する |
| 磁器タイル | 目地に砂・汚れが残りやすい。ハンドブラシ必須 |
| フローリング | 木目・板継ぎ目に砂が入る。柔らかいモップを使用する |
| 天然石 | 砂による傷が致命的。徹底除塵後にテスト施工する |
| テラゾー | 細かな砂でも傷になる。完全除塵後にテスト施工する |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 工場 | 金属粉・切粉が混在する。素手で触れない |
| 病院 | 医療廃棄物・鋭利物が混在する可能性あり。目視確認必須 |
| 商業施設 | 商品陳列棚下・什器周辺に砂が溜まりやすい |
| 食品施設 | 異物の完全除去は衛生管理上必須 |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 除塵完了確認・チェックリスト記録 |
| ISO 14001 | 回収ゴミの適切な分別廃棄 |
| ISO 45001 | 防塵マスク着用・危険物混入確認 |

### 食品施設への対応

- 食品エリアの異物（ゴミ・砂・虫・毛髪）を完全除去する
- 除塵したゴミは食品エリア外へ速やかに搬出する
- 除塵完了を衛生管理記録に記載する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 砂残留でポリッシャー施工時に床材傷 | 高（省略した場合） | 高 | 完全除塵・目視確認後にポリッシャー施工 |
| 危険物混入による怪我 | 低（工場・病院は中） | 高 | 目視確認・クロスによる回収 |
| ホコリ吸入 | 中 | 中 | 防塵マスク着用 |

### 作業時間目安

15〜30分（面積による）

### 必要人数

1〜2名

### NG例

- 除塵を省略してポリッシャー施工を開始する
- ドライモップを往復で動かす
- 壁際・隅部・什器下の除塵を省略する

### OK例

- 奥から出口方向へ一方向施工する
- 壁際・隅部はハンドブラシで丁寧に除塵する
- 除塵後に目視確認してからポリッシャー施工に進む

### よくある失敗

- 除塵を急いで済ませ、ポリッシャー施工後に砂傷が発生した
- 棚下・什器下の除塵を忘れ、施工後に汚れが残っていると指摘された

### 改善方法

- 除塵完了チェックリストを使用し、全エリアの除塵を確認してからポリッシャー施工に進む

### 写真撮影位置

- 除塵前の床状態（汚染が目立つ箇所・近景）
- 什器下・壁際の除塵作業状況（必要時）

### クレーム防止

- 除塵不足によるポリッシャー施工後の砂傷クレームを防ぐ
- 工場・病院では危険物の処理方法を事前に施設担当者と確認する

## 工程4　薬剤準備・希釈

### 作業内容

床材・汚染状況に適した洗剤を選定し、安全に希釈してポリッシャー施工に備える。

### 理由

表面洗浄では中性〜アルカリ性の洗剤を使用するため、希釈が不正確な場合に床材への化学的損傷が発生する。過希釈では洗浄効果が不十分となり、高濃度では床材・ワックスへのダメージリスクが高まる。床材別・汚染度別の適切な薬剤選定と正確な希釈が品質の根幹となる。

### 使用工具

| 工具 | 用途 |
|---|---|
| バケツ2個 | 1個：洗浄水用　1個：すすぎ水用 |
| モップレンチ（絞り器） | 含水率管理 |
| スプレーボトル | スポット洗浄用希釈液 |

### 使用薬剤

| 薬剤 | 希釈率 | 用途 |
|---|---|---|
| 中性床用洗剤 | メーカー指定 | 軽度汚染・デリケート床材 |
| 弱アルカリ床用洗剤 | メーカー指定 | 固着汚れ・黒ずみ・通常汚染 |
| アルカリ床用洗剤 | メーカー指定 | 重度固着汚れ・油汚れ（床材確認必須） |
| 食品施設対応洗剤 | 現場確認 | 食品エリア専用 |

### 作業方法

1. 薬剤ラベルを確認して床材と汚染状況に適した薬剤を選定する
2. バケツAに選定した洗剤液（薬剤ラベルの希釈倍率）を準備する
3. バケツBに清水（すすぎ用）を準備する
4. スプレーボトルにスポット洗浄用洗剤液を準備する
5. バケツに「洗浄（洗剤名）」「すすぎ」のラベルを貼る
6. 使用前に洗剤液の状態で正しい希釈か目視確認する
7. 使用薬剤・希釈率を報告書に記録する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 高濃度アルカリ洗剤による皮膚・眼への刺激 | 手袋・保護メガネを着用する |
| 過希釈による洗浄効果不足 | 薬剤ラベルの希釈倍率を厳守する |
| 高濃度による床材・ワックスへのダメージ | テスト施工で事前確認する |
| 酸性洗剤との誤混合 | ラベルを必ず確認する。混合禁止 |
| バケツの誤用（汚水と清水の取り違え） | バケツにラベルを必ず貼る |

### 品質基準

- 薬剤ラベルが確認されている
- 床材と汚染状況に適した薬剤が選定されている
- 正しい希釈率で調製されている
- バケツにラベルが貼られている
- 使用薬剤・希釈率が記録されている

### 床材別注意

| 床材 | 使用薬剤選定 |
|---|---|
| 長尺シート | 中性〜弱アルカリ。アルカリ使用はメーカー確認 |
| Pタイル | 中性〜弱アルカリ。高濃度は変色リスクあり |
| 磁器タイル | 中性〜弱アルカリ適合 |
| フローリング | 木床対応中性洗剤のみ。アルカリ・溶剤禁止 |
| 天然石 | 石材専用洗剤のみ。一般洗剤・アルカリ禁止 |
| テラゾー | 石材対応洗剤のみ。メーカー確認必須 |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 食品施設 | 食品施設対応洗剤を使用する。一般洗剤不可 |
| 病院 | 感染管理基準に適合した洗剤を使用する（現場確認） |
| 工場（油汚れ重度） | アルカリ洗剤の床材適合を担当者に確認してから選定 |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 薬剤選定・希釈の記録・標準化 |
| ISO 14001 | 最小必要量の調製による廃液削減 |

### 食品施設への対応

- 食品エリアは食品施設対応洗剤のみ使用する
- 洗剤の種類・希釈率を清掃記録に記載する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 高濃度洗剤による床材損傷 | 中 | 高 | 薬剤ラベルの希釈倍率厳守・テスト施工 |
| 洗剤の皮膚・眼への付着 | 中 | 中 | 手袋・保護メガネ着用 |
| 薬剤混合による有害反応 | 低 | 高 | ラベル確認・混合禁止の徹底 |

### 作業時間目安

10〜15分

### 必要人数

1名

### NG例

- 薬剤ラベル未確認で薬剤を使用する
- 汚れが落ちないからと目分量で濃くする
- 1バケツで洗浄とすすぎを兼用する

### OK例

- 薬剤ラベルを確認してから薬剤を選定する
- 薬剤ラベルの希釈倍率を厳守して調製する
- バケツA（洗浄）・バケツB（すすぎ）にラベルを貼って区別する

### よくある失敗

- 洗剤を濃くすれば効果が高いと思い高濃度で使用してワックスが白化した
- 床材を確認せずにアルカリ洗剤を天然石に使用して変色させた

### 改善方法

- 洗浄効果を高めたい場合は濃度を上げるのではなく、作用時間を確保するか、次工程テスト施工で効果を確認する

### 写真撮影位置

- 使用薬剤・ラベルの確認状態（記録用）

### クレーム防止

- 希釈ミスによる床材損傷・ワックス白化クレームを防ぐ
- 食品施設対応洗剤以外の食品施設使用によるクレームを防ぐ

## 工程5　テスト施工

### 作業内容

本施工前に目立たない箇所で薬剤・ポリッシャー・パッドの床材への適合性を確認する試験施工を実施する。

### 理由

表面洗浄では弱アルカリ〜アルカリ洗剤とポリッシャーを使用するため、床材への影響が日常清掃とは比較にならないほど大きい。テスト施工で問題を事前に発見することで、施設全体への重大被害・クレームを防止できる。テスト施工の省略は絶対に禁止する。

### 使用工具

| 工具 | 用途 |
|---|---|
| ポリッシャー | 小面積での施工テスト |
| 選定パッド | テスト対象パッド |
| マイクロファイバークロス | テスト後拭き取り |

### 使用薬剤

選定済み洗剤（薬剤ラベルの希釈倍率）

### 作業方法

1. 目立たない場所（入口から見えない隅・棚下など）を選定する
2. 約30cm四方の範囲で施工する
3. 薬剤を塗布し、メーカー指定の作用時間を確保する
4. ポリッシャーで数秒間施工する
5. 汚水を回収し、清水で拭き取る
6. 乾燥後に変色・白化・傷・焼き付き・ワックス状態変化がないことを確認する
7. 問題がある場合は施工を中止し、別の薬剤・パッドで再テストするか施工を中止する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| テスト施工で問題が出た場合の継続施工 | 問題が発見されたら必ず施工を中止し対策を講じる |
| テスト範囲が小さすぎて問題を見落とす | 最低30cm四方で施工する |
| テスト確認が乾燥前で不十分 | 乾燥後に十分な時間を確保して確認する |

### 品質基準

- テスト範囲で変色・白化・傷・焼き付きがない
- 洗剤が適切に機能している（汚れが落ちている）
- 問題がある場合は施工を中止し記録している

### 床材別注意

| 床材 | テスト確認ポイント |
|---|---|
| 長尺シート | 変色・白化・ワックスの状態変化 |
| Pタイル | 変色・ワックス密着への影響 |
| 磁器タイル | 目地の状態変化 |
| フローリング | 木材の変色・膨張・光沢変化 |
| 天然石 | 変色・エッチング・光沢損失 |
| テラゾー | 光沢変化・変色 |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 全施設共通 | テスト後に問題がなくても、本施工前に施設担当者に報告する |
| 高級施設（ホテル等） | テスト範囲を極力目立たない箇所に設定する |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | テスト施工結果の記録・品質確認 |

### 食品施設への対応

- テスト後の汚水・洗剤残留を食品エリア外に確実に除去する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| テスト省略による全面施工での床材損傷 | 高（省略した場合） | 高 | テスト施工を絶対に省略しない |
| テスト確認不足による問題見落とし | 中 | 高 | 乾燥後に十分な時間を確保して確認する |

### 作業時間目安

10〜20分（テスト・乾燥確認含む）

### 必要人数

1名

### NG例

- 時間がないからとテスト施工を省略する
- テスト結果に問題があるのに本施工を続行する
- テスト範囲が狭すぎて効果を確認できない

### OK例

- 30cm四方以上の範囲で薬剤とポリッシャーをテストする
- 乾燥後に変色・傷・焼き付きがないことを確認してから本施工に進む
- 問題が発見された場合は施工を中止し、施設担当者に報告する

### よくある失敗

- テスト施工を省略して全面施工後に天然石が変色した
- テスト確認を乾燥前に行い、問題を見落として本施工を行った

### 改善方法

- テスト施工は省略不可の必須工程として全作業者に教育する
- テスト結果を写真で記録する

### 写真撮影位置

- テスト施工前の箇所（近景）
- テスト施工後・乾燥確認後の箇所（近景・比較用）

### クレーム防止

- テスト省略は重大クレームの最大原因。テスト施工を全工程で必須とする
- テスト施工写真を保存することで「確認した」ことの証明になる

## 工程6　薬剤塗布（モップ）

### 作業内容

テスト施工で適合を確認した洗剤を、ウエットモップを使用して床面全体に均一に塗布する。

### 理由

薬剤を均一に塗布することで洗浄効果にムラがなくなる。一度に広範囲へ塗布すると薬剤が乾燥し、ポリッシャー施工時に効果が得られない。区画ごとの施工が洗浄品質の安定に直結する。

### 使用工具

| 工具 | 用途 |
|---|---|
| ウエットモップ | 薬剤塗布 |
| バケツA（洗剤液） | 薬剤の供給 |
| モップレンチ（絞り器） | 含水率管理 |

### 使用薬剤

| 薬剤 | 希釈率 |
|---|---|
| 選定済み床用洗剤（中性〜アルカリ） | メーカー指定 |
| 食品施設対応洗剤（食品施設のみ） | 現場確認 |

### 作業方法

1. モップをバケツA（洗剤液）に浸し、モップレンチで適切に絞る（薬剤が広がる程度・滴らない程度）
2. 奥から出口方向へ、「コの字」を描きながら均一に塗布する
3. 一度に施工できる区画（乾燥する前に洗浄できる面積）ごとに塗布する
4. 壁際・柱周辺まで確実に塗布する
5. 薬剤を塗布した区画はメーカー指定の作用時間を確保する
6. 薬剤が乾燥しそうな場合は追加塗布する（乾燥禁止）

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 薬剤塗布後の床面での転倒 | 滑りにくい安全靴を着用する |
| 薬剤乾燥による洗浄効果の低下 | 区画を小さく設定し乾燥させない |
| モップへの薬剤過剰含浸による広がりすぎ | モップレンチで適切に絞ってから塗布する |
| 利用者の薬剤接触 | カラーコーンの設置状態を確認する |

### 品質基準

- 薬剤が床全面・壁際まで均一に塗布されている
- 薬剤が乾燥していない
- 作用時間が確保されている
- 塗り残しがない

### 床材別注意

| 床材 | 注意事項 |
|---|---|
| 長尺シート | 継ぎ目部分への薬剤浸透に注意。過剰塗布禁止 |
| Pタイル | 目地への薬剤浸透を均一にする |
| 磁器タイル | 目地にも確実に薬剤を行き渡らせる |
| フローリング | 木床対応中性洗剤のみ使用。水分量を最小限にする |
| 天然石 | 石材専用洗剤のみ使用。過剰塗布禁止 |
| テラゾー | 石材対応洗剤のみ使用 |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 広面積施設（商業施設・公共施設） | 乾燥する前に洗浄できる区画に分割して施工する |
| 食品施設 | 食品施設対応洗剤のみ塗布する |
| 病院 | 薬剤が医療機器に付着しないよう注意する |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 薬剤塗布の均一性確認・区画管理 |
| ISO 14001 | 必要最小限の薬剤使用量管理 |

### 食品施設への対応

- 食品エリアは食品施設対応洗剤のみ塗布する
- 薬剤が食品接触面に到達しないよう注意する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 薬剤乾燥による洗浄ムラ | 中 | 中 | 区画を小さく設定して施工する |
| 転倒（薬剤塗布後の床面） | 中 | 高 | 安全靴着用・ゆっくり移動する |
| 薬剤の設備への飛散 | 低 | 中 | 養生確認・適切な塗布量管理 |

### 作業時間目安

10〜30分（面積による）

### 必要人数

1名

### NG例

- 一度に全面積へ薬剤を塗布する（乾燥リスク）
- モップに薬剤を200ml/5m²以上含ませて撒くように塗布する（NG例）
- 薬剤の作用時間を確保せずにすぐポリッシャー施工する

### OK例

- 乾燥する前に洗浄できる区画ごとに塗布する
- モップを絞って均一な薄塗りを行う
- 塗布後にメーカー指定の作用時間を確保してからポリッシャーに進む

### よくある失敗

- 広範囲に薬剤を塗布しすぎて一部が乾燥し、洗浄ムラが発生した
- 作用時間を確保せずにポリッシャー施工を開始し、固着汚れが除去できなかった

### 改善方法

- 施工面積を事前に確認し、乾燥しない区画サイズに分割して施工計画を立てる

### 写真撮影位置

- 薬剤塗布中の状況（区画ごとの塗布状況が分かる全景）

### クレーム防止

- 薬剤乾燥による洗浄ムラは施工後の光沢不均一クレームにつながる。区画管理を徹底する

## 工程7　ポリッシャー洗浄

### 作業内容

ポリッシャーに適合パッドを装着し、薬剤が塗布された床面を機械的に全面洗浄する。

### 理由

ポリッシャーの回転力と洗剤の化学作用を組み合わせることで、人力では除去できない固着汚れ・黒ずみ・ヒールマーク・タイヤ痕を効率的に除去できる。停止したままパッドを回転させると床材の焼き付き・損傷が発生するため、常に移動しながら施工することが絶対条件である。

### 使用工具

| 工具 | 用途 |
|---|---|
| ポリッシャー | 機械洗浄 |
| 適合パッド（白・赤・青） | 汚染度・床材による選定 |
| パッドホルダー | ポリッシャーへの取り付け |
| コードリール・延長コード | 電源供給 |

### 使用薬剤

塗布済みの洗剤（前工程で塗布完了）

### 作業方法

1. ポリッシャーに床材・汚染度に適したパッドを装着する
2. 電源コードを肩にかけ、コードの巻き込みを防止する
3. 両手でしっかりポリッシャーを保持する
4. 奥から出口方向へ、左右のバランスをとりながら一定速度で施工する
5. 重ね幅を約1/3確保しながら前進する（洗い残し防止）
6. ポリッシャーを停止させたまま回転させない（焼き付き防止）
7. 壁際はポリッシャーが届く限り施工し、残った箇所はハンドブラシで対応する
8. パッドが汚れたら交換または洗浄する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| ポリッシャー停止による床材焼き付き | 常に移動しながら操作する。停止禁止 |
| コードの巻き込みによる転倒・感電 | コードを肩にかけて操作する |
| 汚水の飛散による転倒・感電 | 保護メガネ着用・電源コードへの汚水接触防止 |
| ポリッシャーの暴走（操作ミス） | 両手でしっかり保持し、重心を安定させる |
| 過剰圧力による床材傷・パッド焼き付き | 適切な圧力で施工する（押し付けすぎない） |
| 腰痛（長時間操作） | 適切な姿勢で操作する。定期的に休憩する |

### 品質基準

- 全面均一に洗浄されている
- 重ね幅1/3が確保され洗い残しがない
- 焼き付き・傷・パッドライン（筋）がない
- 壁際まで洗浄されている（ハンドブラシ施工含む）

### 床材別注意

| 床材 | パッド選定・注意事項 |
|---|---|
| 長尺シート（軽度汚染） | 白パッドまたは赤パッド。端部の巻き込みに注意 |
| 長尺シート（重度汚染） | 赤〜青パッド。過圧力禁止 |
| Pタイル | 赤〜青パッド。目地への圧力に注意 |
| 磁器タイル | 赤〜青パッド。硬質床材のためパッドの摩耗が早い |
| フローリング | 原則ポリッシャー使用禁止（メーカー確認必須）。使用可の場合は白パッドのみ |
| 天然石 | 原則一般ポリッシャー使用禁止。専門施工確認必須 |
| テラゾー | 石材対応設定で使用。研磨パッド禁止 |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| ホテルロビー | 高光沢床材が多い。パッドの選定を慎重に行う |
| 工場 | 油汚れが多い場合はパッドの汚れが早い。こまめに交換する |
| 病院廊下 | 施工音が医療行為の妨げにならないよう時間帯を調整する |
| 商業施設 | 広面積施工の場合は複数台のポリッシャーで効率化する（現場仕様） |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | ポリッシャー操作手順の標準化・施工記録 |
| ISO 45001 | 機械操作安全・感電防止・転倒防止 |
| ISO 14001 | 使用水量・洗剤量の最小化 |

### 食品施設への対応

- ポリッシャー施工による汚水の飛散が食品管理区域に入らないよう養生を確認する
- 施工後の汚水は食品エリア外へ確実に排出する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 床材焼き付き（停止回転） | 低（操作正常時）・高（停止時） | 高 | 常に移動操作を徹底する |
| コード巻き込みによる転倒 | 中 | 高 | コードを肩にかけて操作する |
| 汚水飛散による感電 | 低 | 高 | 保護メガネ着用・コード防水確認 |
| 過圧力による床材損傷 | 中 | 高 | 適切な圧力管理・テスト施工で確認 |

### 作業時間目安

30分〜2時間（面積・汚染度による）

### 必要人数

1〜2名（操作者1名＋補助者1名が望ましい）

### NG例

- ポリッシャーを停止させたまま回転させ続ける
- コードを床に引きずったまま操作する
- 同じ場所を長時間施工する
- 重ね幅を確保せずに隙間ができる施工をする

### OK例

- 常に移動しながら操作する
- コードを肩にかけて操作する
- 重ね幅1/3を守りながら一定速度で施工する
- パッドが汚れたらこまめに交換する

### よくある失敗

- 狭い箇所でポリッシャーを停止させ床材に焼き付きを起こした
- コードを引きずって洗剤液に浸かり絶縁不良のリスクが生じた
- 重ね幅が不足して洗浄ムラ（縦縞状の洗い残し）が発生した

### 改善方法

- 施工前にポリッシャーの正しい操作方法を確認し、「停止状態での回転は絶対禁止」を全員に徹底する
- コードの取り回しを施工前に計画してから開始する

### 写真撮影位置

- ポリッシャー施工中の全景（施工状況・パッドが分かる角度）
- 施工前後の汚染箇所（比較写真）
- 使用パッド（色・種類が分かる状態）

### クレーム防止

- ポリッシャー焼き付き・傷クレームを防ぐ。「停止回転禁止」を厳守する
- 洗浄ムラによる光沢不均一クレームを防ぐ。重ね幅1/3を徹底する

## 工程8　壁際・隅部ブラッシング（ハンドブラシ）

### 作業内容

ポリッシャーが届かない壁際・柱周辺・隅・角部を、ハンドブラシ・デッキブラシを使用して手作業で洗浄する。

### 理由

ポリッシャーは壁際10〜15cm程度まで施工できない構造になっている。この未施工箇所を放置すると洗浄ムラが生じ、壁際だけ黒ずみが残るというクレームの原因になる。壁際・隅部こそ汚れが溜まりやすく重点洗浄が必要な箇所である。

### 使用工具

| 工具 | 用途 |
|---|---|
| ハンドブラシ（コーナー用） | 壁際・隅・角部の洗浄 |
| デッキブラシ | 壁際の手作業洗浄 |
| マイクロファイバーモップ | 壁際の薬剤塗布・すすぎ |

### 使用薬剤

| 薬剤 | 用途 |
|---|---|
| 選定済み床用洗剤 | 壁際・隅部洗浄 |

### 作業方法

1. ポリッシャーが届かなかった壁際・隅部・角部を確認する
2. 薬剤を薄く塗布し、作用時間を確保する
3. ハンドブラシで壁際・隅部を丁寧にブラッシングする
4. 角部（コーナー）はブラシを回転させるように使用して隅まで洗浄する
5. 柱周辺は四方向から洗浄する
6. 汚水が発生するため隣接床面への広がりに注意する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 前屈姿勢による腰痛 | 定期的に姿勢を変える。長時間の前屈禁止 |
| ハンドブラシで壁・巾木を傷つける | ブラシの向きに注意して施工する |
| 薬剤が眼に飛散 | 保護メガネを着用する |
| 膝関節への負担 | 膝当てを使用する（必要時） |

### 品質基準

- 壁際・隅部・角部・柱周辺の固着汚れが除去されている
- ポリッシャー施工箇所と壁際施工箇所で洗浄品質が均一である
- 巾木・壁面への薬剤・汚水の付着がない

### 床材別注意

| 床材 | 注意事項 |
|---|---|
| 長尺シート | 継ぎ目・端部を傷つけないブラシ硬さを選定する |
| Pタイル | 目地部分を重点的にブラッシングする |
| 磁器タイル | 目地は専用ブラシで丁寧に施工する |
| フローリング | 木目に沿ってブラッシングする。過剰な水分禁止 |
| 天然石 | 柔らかいブラシを使用する。研磨剤入りブラシ禁止 |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| オフィス | 壁際のコード類・コンセントへの薬剤付着に注意 |
| 商業施設 | 棚脚・柱根元の汚れが蓄積しやすい。重点洗浄する |
| 食品施設 | 壁際の汚れは衛生管理上最重要箇所。徹底洗浄する |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 壁際・隅部洗浄の完了確認 |
| ISO 45001 | 腰痛防止・保護具着用 |

### 食品施設への対応

- 食品施設の壁際・隅部は汚れが蓄積しやすく衛生管理上の重点箇所である
- 徹底洗浄後に衛生管理記録へ完了を記載する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 腰痛（前屈施工） | 中 | 中 | 定期的に姿勢を変える・膝当て使用 |
| 巾木・壁への薬剤付着 | 中 | 中 | 養生確認・慎重なブラッシング |
| 薬剤の眼への飛散 | 中 | 高 | 保護メガネ着用 |

### 作業時間目安

10〜30分（壁際延長・隅部の数による）

### 必要人数

1名

### NG例

- 壁際・隅部のブラッシングを省略する
- ポリッシャーを無理に壁に押し当てて施工する
- 硬いブラシで天然石・フローリングの壁際を強く擦る

### OK例

- ポリッシャーが届かなかった全箇所をハンドブラシで施工する
- 角部はブラシを回転させながら隅まで洗浄する
- 床材に適した硬さのブラシを選定して施工する

### よくある失敗

- 壁際施工を省略し、最終確認で壁際だけ黒ずみが残っていることが判明した
- 硬いブラシでフローリング壁際を擦り傷をつけた

### 改善方法

- ポリッシャー施工と並行してブラッシング担当者を配置し、効率よく施工する

### 写真撮影位置

- 壁際・隅部のブラッシング作業状況（近景）
- 施工前後の壁際汚れ比較（近景）

### クレーム防止

- 壁際だけ汚れが残っているクレームを防ぐ。ブラッシングを必ず実施する
- ブラシによる巾木・壁への傷クレームを防ぐ。適切な硬さのブラシを選定する

## 工程9　汚水回収（ウエットバキューム）

### 作業内容

ポリッシャー洗浄および壁際ブラッシング後に発生した汚水をウエットバキュームで完全に回収する。

### 理由

汚水を床面に残した状態ですすぎに移行すると、汚れた水が広がり洗浄効果が著しく低下する。また汚水残留で滑り事故が発生するリスクがある。ウエットバキュームによる完全回収はすすぎ品質と安全確保の両方において必須の工程である。

### 使用工具

| 工具 | 用途 |
|---|---|
| ウエットバキューム | 汚水の機械的回収 |
| スクイジー（大型） | 汚水をウエットバキューム吸引口に誘導 |
| スクイジー（小型） | 壁際・隅部の汚水誘導 |

### 使用薬剤

なし

### 作業方法

1. スクイジーで汚水を一か所に集める（ウエットバキュームの吸引しやすい位置へ誘導する）
2. ウエットバキュームで汚水を回収する
3. 壁際・隅部はスクイジー（小型）で汚水を誘導してからウエットバキュームで回収する
4. ウエットバキュームのタンクが満水になる前に排水する
5. 排水は現場指定の方法で適切に処理する
6. 汚水が残っていないことを目視で確認する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 汚水残留による転倒 | 全面の汚水を確実に回収する |
| ウエットバキュームタンク満水による溢れ | 定期的にタンク残量を確認して排水する |
| 汚水の電源コードへの接触による感電 | 電源コードに汚水が接触しないよう注意する |
| 汚水の廃棄場所への不適切排出 | 現場指定の排水方法で処理する |
| スクイジー操作中の転倒 | 安全靴着用・ゆっくりと操作する |

### 品質基準

- 床全面・壁際・隅部の汚水が回収されている
- 目視で汚水・水溜まりが確認できない状態である
- ウエットバキュームのタンクが溢れていない
- 排水が適切に処理されている

### 床材別注意

| 床材 | 注意事項 |
|---|---|
| 長尺シート | 継ぎ目への汚水浸透を防ぐ。素早く回収する |
| Pタイル | 目地の汚水を確実に回収する |
| 磁器タイル | 滑りやすいため汚水残留に特に注意する |
| フローリング | 汚水を速やかに回収する。木材への浸透防止 |
| 天然石 | 汚水が石材に長時間接触しないよう速やかに回収する |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 食品施設 | 汚水が食品管理区域の食品エリアに流れないよう管理する |
| 工場 | 排水基準を施設担当者に確認して処理する |
| 商業施設 | 排水口の位置を確認して効率的な誘導方向を決める |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 汚水回収完了の確認・記録 |
| ISO 14001 | 汚水の適切な排水処理・環境管理 |
| ISO 45001 | 汚水による転倒・感電リスク管理 |

### 食品施設への対応

- 汚水が食品エリアに流出しないよう区画管理を徹底する
- 汚水処理方法を衛生管理記録に記載する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 汚水残留による転倒 | 中 | 高 | 完全回収・目視確認 |
| タンク満水による溢れ | 中 | 中 | 定期的なタンク確認・早めの排水 |
| 感電（汚水とコードの接触） | 低 | 高 | コード管理の徹底 |
| 排水の不適切処理 | 低 | 中 | 現場指定方法での処理 |

### 作業時間目安

15〜30分（面積による）

### 必要人数

1〜2名（スクイジー誘導担当＋バキューム操作担当）

### NG例

- 汚水を残したまますすぎに移行する
- ウエットバキュームのタンクが満水のまま使用し続ける
- 汚水を排水溝に無処理で流す（排水基準を確認すること）

### OK例

- スクイジーで汚水を誘導してからウエットバキュームで回収する
- タンクが7〜8割になったら排水する
- 回収後に目視で汚水残留がないことを確認する

### よくある失敗

- 汚水回収が不完全なままで清水すすぎを行い、汚れが広がってしまった
- ウエットバキュームタンクが満水になり汚水が溢れた

### 改善方法

- 汚水回収はすすぎの前の必須工程として手順書に明記し、省略を防ぐ
- 大面積施工時はタンク容量を計算して計画的に排水する

### 写真撮影位置

- ウエットバキューム施工状況（全景）
- 汚水回収後の床状態（汚水がないことの確認）

### クレーム防止

- 汚水回収不足による施工後の汚染残留クレームを防ぐ
- 不適切な排水による環境クレームを防ぐ。現場指定方法で処理する

## 工程10　すすぎ洗浄

### 作業内容

汚水回収後の床面を清水で1〜3回すすぎ、洗剤残留・汚染物を完全に除去する。

### 理由

アルカリ洗剤が床面に残留すると、ワックス塗布の際に密着不良・白化の原因になる。また残留した洗剤は利用者の靴底に付着してベタつき・臭気のクレームになる。すすぎの回数・徹底度が最終仕上がり品質を大きく左右する。

### 使用工具

| 工具 | 用途 |
|---|---|
| ウエットモップ | 清水すすぎ |
| バケツB（清水） | すすぎ水の供給 |
| マイクロファイバーモップ | 壁際・精密すすぎ |
| ウエットバキューム | すすぎ後の汚水回収 |
| スクイジー | すすぎ後の水分誘導 |

### 使用薬剤

なし（清水のみ）

### 作業方法

1. バケツBに清水を準備する
2. モップを清水に浸し、モップレンチで水滴が垂れない状態まで絞る
3. 奥から出口方向へ「コの字」を描きながら清水ですすぐ
4. モップが汚れたら清水で洗い、清水ですすいでから再使用する
5. バケツの水が汚れたら新しい清水に交換する
6. 1回目のすすぎ後にウエットバキュームで汚水を回収する
7. 2回目のすすぎを実施する（洗剤が完全に除去されるまで繰り返す）
8. 最終すすぎ後にウエットバキュームで完全回収する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| すすぎ不足による洗剤残留 | バケツの水が汚れたら交換してから継続する |
| すすぎ後の床面での転倒 | 安全靴着用・乾燥確認まで表示板を維持する |
| フローリングへの水分過多 | モップを固く絞り水分を最小限にする |

### 品質基準

- 洗剤・泡・汚水が床全面から除去されている
- モップのすすぎ水が透明に近い状態になっている
- 床面にベタつき・白濁がない
- 壁際・隅部のすすぎが完了している

### 床材別注意

| 床材 | 注意事項 |
|---|---|
| 長尺シート | 継ぎ目への清水浸入に注意。素早くすすいで回収する |
| Pタイル | 目地のすすぎを徹底する |
| 磁器タイル | 目地に洗剤が残らないよう徹底すすぎする |
| フローリング | モップは固く絞る（滴らない状態）。水分を最小限にする |
| 天然石 | 清水で2〜3回すすぐ。洗剤残留は変色の原因になる |
| テラゾー | 清水で2〜3回すすぐ。水垢に注意して速やかに拭き取る |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 食品施設 | 洗剤残留ゼロを必達とする。すすぎ回数を増やす |
| 病院 | 洗剤残留が医療機器・患者に影響する可能性あり。徹底すすぎ |
| ホテルロビー | 仕上がり光沢に影響するため完全すすぎを実施する |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | すすぎ回数・完了確認の記録 |
| ISO 14001 | 最小限の清水使用で効率的なすすぎ |
| ISO 45001 | すすぎ後の床面安全確保 |

### 食品施設への対応

- 食品エリアは洗剤残留ゼロが必達。最低2回以上のすすぎを実施する
- すすぎ完了を衛生管理記録に記載する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 洗剤残留によるワックス密着不良 | 中（すすぎ不足時） | 高 | 十分なすすぎ回数の確保 |
| すすぎ後の転倒 | 中 | 高 | 乾燥確認まで表示板を維持する |
| フローリングへの水分過多 | 中 | 高 | 固く絞ったモップで最小限に施工 |

### 作業時間目安

15〜40分（面積・すすぎ回数による）

### 必要人数

1〜2名

### NG例

- すすぎを1回で終了する（洗剤が残留する）
- バケツの水を交換せずにすすぎを続ける
- すすぎ後にウエットバキュームで水分を回収しない

### OK例

- バケツの水が汚れたら新しい清水に交換してからすすぎを続ける
- 洗剤残留がなくなるまで（2〜3回）すすぎを繰り返す
- 各すすぎの後にウエットバキュームで汚水を回収する

### よくある失敗

- すすぎを1回で終了したため洗剤残留でベタつきクレームが発生した
- すすぎ水を交換せずに使い続けて汚れを広げた

### 改善方法

- すすぎ完了の判断基準を「モップのすすぎ水が透明に近い状態になるまで」と明確化する

### 写真撮影位置

- すすぎ洗浄作業の状況（全景）
- すすぎ後の床状態（水分・泡の有無確認）

### クレーム防止

- 洗剤残留によるベタつき・臭気クレームを防ぐ。十分なすすぎ回数を確保する
- ワックス塗布後の白化クレームを防ぐ。ワックス施工前に洗剤残留ゼロを確認する

## 工程11　乾燥確認

### 作業内容

すすぎ完了後の床面を完全乾燥させ、乾燥状態を確認してから復旧工程に進む。

### 理由

水分が残った状態では利用者の転倒事故が発生する。表面洗浄後にワックス補修・塗布を行う場合、乾燥不足はワックスの白化・密着不良・剥離の原因になる。乾燥確認は安全・品質の両面において最終工程前の必須チェックポイントである。

### 使用工具

| 工具 | 用途 |
|---|---|
| 送風機・ブロワー | 乾燥促進 |
| サーキュレーター | 空気循環・乾燥促進 |
| マイクロファイバークロス | 残水分の拭き取り |

### 使用薬剤

なし

### 作業方法

1. すすぎ後に床全面の水分残留を目視で確認する
2. 壁際・隅部・継ぎ目部分の水分をマイクロファイバークロスで拭き取る
3. 送風機・ブロワーを使用して乾燥を促進する
4. 乾燥状態を目視・手触りで確認する（水分が残っていないこと）
5. 完全乾燥を確認してから復旧工程（カラーコーン・表示板の撤去）に進む

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 乾燥確認前の表示板撤去による転倒 | 乾燥確認後にカラーコーンを撤去する |
| 乾燥中の利用者侵入 | カラーコーンを乾燥完了まで設置し続ける |
| フローリング・天然石への水分残留 | 継ぎ目・端部の水分を確実に除去する |
| ワックス施工前の乾燥不足 | 次工程（ワックス塗布）前に十分乾燥確認する |

### 品質基準

- 床全面・壁際・隅部・継ぎ目に水分が残っていない
- 水滴・水溜まりがない
- 目視・手触りで乾燥が確認できる
- 乾燥確認後にカラーコーンを撤去している

### 床材別注意

| 床材 | 注意事項 |
|---|---|
| フローリング | 継ぎ目・端部の水分を特に徹底拭き取りする。水分放置で膨張リスク高 |
| 天然石 | 水分で輪ジミ・水垢が生じやすい。拭き取りを徹底する |
| Pタイル | 目地・継ぎ目の水分を拭き取る |
| 磁器タイル | 目地の水分を除去する |
| 長尺シート | 継ぎ目への浸水に注意する |
| テラゾー | 水垢が発生しやすい。十分な拭き取りを行う |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 病院 | 車椅子・ストレッチャー通行前に完全乾燥を確認する |
| ホテルロビー | 光沢床は乾燥後に水垢・モップ跡がないか確認する |
| 食品施設 | 乾燥後に食品エリアへの水分・洗剤残留がないことを確認する |
| 商業施設 | 営業開始前に完全乾燥を確認する |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 45001 | 水分残留による転倒リスク管理 |
| ISO 9001 | 乾燥確認チェックリストへの記録 |

### 食品施設への対応

- 乾燥後に食品エリアの床面に水分・洗剤残留がないことを確認する
- 確認結果を衛生管理記録に記載する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 水分残留による転倒 | 中 | 高 | 乾燥確認前の表示板撤去禁止 |
| フローリングへの水分残留による膨張 | 中 | 高 | 継ぎ目・端部の水分拭き取り徹底 |
| ワックス施工前の乾燥不足 | 中（省略時） | 高 | 次工程前の乾燥確認を必須とする |

### 作業時間目安

15〜30分（自然乾燥の場合は面積・環境による）

### 必要人数

1名

### NG例

- 乾燥確認前にカラーコーン・表示板を撤去する
- 壁際・隅部の水分拭き取りを省略する
- フローリングの継ぎ目に水分が残ったまま放置する
- 表面だけ乾燥を確認して内部乾燥を見落とす

### OK例

- 全面乾燥を目視・手触りで確認してから表示板を撤去する
- 壁際・隅部の水分を丁寧にクロスで拭き取る
- 乾燥が遅い場合は送風機を使用して促進する

### よくある失敗

- 乾燥確認を省略して表示板を撤去し、利用者が転倒した
- 乾燥不足のままワックスを塗布して白化・密着不良が発生した

### 改善方法

- 乾燥確認をチェックリストの必須項目として設定し、省略できないようにする

### 写真撮影位置

- 乾燥確認後の床全景（仕上がり状態）

### クレーム防止

- 水分残留による転倒事故クレームを防ぐ。乾燥確認を省略しない
- ワックス塗布後の白化クレームを防ぐ。乾燥を確認してからワックス施工に進む

# 13. よくある失敗と改善方法

| 失敗 | 原因 | 改善方法 |
|---|---|---|
| テスト施工を省略して床材を損傷した | 時間不足・省略習慣 | テスト施工を省略不可の必須工程として標準化する |
| ポリッシャー焼き付き（縦縞状の損傷） | 停止回転・同一箇所への過剰施工 | 「停止回転禁止」を全員に徹底教育する |
| 壁際の黒ずみが残った | ブラッシング省略・ポリッシャーが届かない | ブラッシング担当を配置して並行作業する |
| 洗剤残留によるベタつき | すすぎ不足・バケツ水未交換 | すすぎ回数の基準を設定してチェックリストで管理する |
| 汚水回収不足で汚れが広がった | ウエットバキューム操作不足 | すすぎ前に必ず汚水を完全回収する手順を標準化する |
| 乾燥不足でワックスが白化した | 乾燥確認の省略 | 乾燥確認をチェックリストの必須項目とする |
| 養生テープの糊残り | テープを急いで剥がした | ゆっくり斜め方向に剥がす。残った場合はケレンで除去する |
| パッド選定ミスで床材を傷つけた | 床材確認不足 | パッド選定は床材・汚染度・ワックス状態を確認してから決定する |
| 電源コードへの汚水接触 | コード管理の不備 | コードを肩にかける・床テープ固定を徹底する |
| ポリッシャー騒音のクレーム | 施工時間帯の調整不足 | 事前に施設担当者と施工時間帯を確認・調整する |

## 工程12　復旧（表示・養生撤去・原状回復）

### 作業内容

乾燥確認後、カラーコーン・表示板・養生を撤去し、施工前の状態に現場を戻す。

### 理由

養生・表示物の撤去忘れは施設担当者からの信頼を損なうクレームになる。養生テープの長時間放置は壁・巾木への糊残りの原因となる。表面洗浄は汚水・重い機材を使用するため、復旧時の床への傷・汚れにも注意が必要である。

### 使用工具

- カラーコーン
- 表示板
- 養生テープ除去道具（ケレン・必要時）

### 使用薬剤

なし

### 作業方法

1. 床の完全乾燥を確認してからカラーコーンを撤去する
2. 表示板を撤去する
3. 養生テープをゆっくりと斜め方向に剥がす（糊残りに注意）
4. 養生シートを撤去する
5. 移動させた備品・家具を元の位置に戻す（床を引きずらず持ち上げて移動する）
6. ポリッシャー・ウエットバキュームを搬出する（床面を傷つけないよう注意）
7. カラーコーン・表示板・養生材が全て撤去されていることを確認する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 乾燥前の表示撤去による転倒 | 必ず乾燥確認後に撤去する |
| 養生テープ剥がし時の巾木・壁面傷 | ゆっくりと角度をつけて剥がす |
| 機材搬出時の床面傷 | ポリッシャー・バキュームを持ち上げて移動する |
| 家具・備品を引きずる床面傷 | 持ち上げて移動する。フェルトパッドを使用する |

### 品質基準

- カラーコーン・表示板が全て撤去されている
- 養生テープの糊残りがない
- 家具・備品が元の位置に戻っている
- 機材搬出による床面傷がない
- 現場が施工前の状態に復旧されている

### 床材別注意

| 床材 | 注意事項 |
|---|---|
| 全床材共通 | 機材搬出時に床面を傷つけない。コロや台車を使用する |
| フローリング | 特に傷がつきやすい。機材は必ず持ち上げて移動する |
| 天然石・テラゾー | 高価な床材のため機材接触・引きずりを絶対に避ける |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| オフィス | 机・椅子・備品の位置を元通りにする |
| 商業施設 | 商品陳列・什器の位置を元通りにする |
| ホテル | アメニティ・備品の位置を元通りにする |
| 病院 | 医療機器・備品の配置は施設担当者立会いのもと復旧する |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 復旧確認チェックリストへの記録 |

### 食品施設への対応

- 食品エリアへの機材・養生材の残留がないことを確認する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 機材搬出による床面傷 | 中 | 高 | 持ち上げて移動・コロ使用 |
| 養生糊残りによる巾木損傷 | 中 | 中 | ゆっくり剥がす・残留時はケレン除去 |
| 表示撤去忘れ | 低 | 中 | チェックリストで全項目確認 |

### 作業時間目安

10〜20分

### 必要人数

1〜2名

### NG例

- カラーコーンを設置したまま作業を終了する
- 養生テープを力任せに剥がして巾木を傷める
- ポリッシャーを床に引きずって傷をつける

### OK例

- 乾燥確認後に全ての表示・養生を撤去する
- 養生テープはゆっくりと斜め方向に剥がす
- ポリッシャー・バキュームはコロや台車を使用して搬出する

### よくある失敗

- 表示板を1枚撤去し忘れて施設担当者から指摘を受けた
- 機材を引きずって新しく洗浄した床面に傷をつけた

### 改善方法

- 復旧確認チェックリストで全項目を確認してから施設担当者への引き渡しを行う

### 写真撮影位置

- 復旧完了後の全景（表示・養生が全て撤去された状態）

### クレーム防止

- 表示物・養生材の撤去忘れはクレームの原因。作業完了前に全点確認する
- 機材搬出による床面の傷クレームを防ぐため、機材は必ず持ち上げて移動する

## 工程13　最終品質確認

### 作業内容

作業の全工程が完了した状態で、品質基準に基づき仕上がりを確認する。

### 理由

最終確認で問題を発見し、その場で対応することが施設担当者への引き渡し品質を保証する唯一の機会である。表面洗浄は高額な費用が発生する定期清掃であり、施設担当者の期待品質が高い。確認を省略するとクレームにつながる。

### 使用工具

- チェックリスト
- 懐中電灯（必要時）

### 使用薬剤

なし

### 作業方法

1. 入口側から床全景を目視で確認する（遠景・近景）
2. 窓際・照明下・入口付近を重点確認する（光の角度で洗浄ムラが見えやすい）
3. 壁際・隅部の洗浄品質を近景で確認する
4. 光沢の回復・均一性を確認する
5. 施工前の汚染箇所（黒ずみ・ヒールマーク）が除去されているか確認する
6. 焼き付き・傷・パッドラインがないか確認する
7. 異常箇所（傷・変色・浮き・破損）を確認する
8. チェックリストに全項目記入する
9. 問題があれば即座に対応する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 確認漏れによる品質不良の見落とし | チェックリストを使用して全項目確認する |
| 仕上がり不良の見落とし | 光の角度を変えて目視確認する |

### 品質基準

| 確認項目 | 品質基準 |
|---|---|
| 固着汚れ | 黒ずみ・ヒールマーク・タイヤ痕が除去されている |
| 洗浄均一性 | 洗浄ムラ・パッドライン（縦縞）がない |
| 汚水・洗剤残留 | 汚水・泡・ベタつきが残っていない |
| 水分 | 水滴・水溜まりがない |
| 光沢 | 施工前より光沢が回復・均一になっている |
| 滑り | 滑りやベタつきがない |
| 臭気 | 薬剤臭・異臭が残っていない |
| 傷・焼き付き | 施工による傷・焼き付き・変色がない |
| 壁際 | 壁際・隅部が均一に洗浄されている |
| 周辺設備 | 巾木・壁・コンセントに薬剤・汚水が付着していない |
| 表示撤去 | カラーコーン・表示板が全て撤去されている |
| 養生撤去 | 養生材が全て撤去され糊残りがない |

### 床材別注意

| 床材 | 確認ポイント |
|---|---|
| 長尺シート | 継ぎ目の状態・端部の浮き・洗浄ムラ |
| Pタイル | 目地の洗浄状態・ワックスの状態 |
| 磁器タイル | 目地の洗浄状態・光沢均一性 |
| フローリング | 水分残留・木目に沿った傷・変色 |
| 天然石 | 変色・水垢・輪ジミ・エッチング |
| テラゾー | 光沢均一性・水垢・変色 |

### 場所別注意

| 場所 | 確認ポイント |
|---|---|
| ホテルロビー | 光沢・ゴミ混入・パッドライン（斜め光で確認） |
| 病院 | 感染管理基準での衛生確認 |
| 食品施設 | 洗剤残留・水分残留・異物除去 |
| 工場 | 油汚れ除去状態・滑り確認 |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 品質確認チェックリストへの記録・承認 |
| ISO 14001 | 洗剤残留の確認（環境汚染防止） |

### 食品施設への対応

- 食品エリアの床面に洗剤残留・異物がないことを確認し衛生管理記録に記載する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 品質不良の見落とし | 中（省略時） | 高 | チェックリスト全項目確認 |
| 残汚れ・パッドラインの放置 | 中 | 中 | 照明下で斜め方向から目視確認 |

### 作業時間目安

10〜20分

### 必要人数

1名

### NG例

- 最終確認をせずに作業完了と判断する
- チェックリストを記入せずに施設担当者に引き渡す
- 発見した問題を放置して報告しない

### OK例

- チェックリストを使用して全項目を1つずつ確認する
- 照明下で光の角度を変えながら確認する
- 問題を発見したら即座に対応してから再確認する

### よくある失敗

- 照明が暗い施設で洗浄ムラを見落とし、翌日施設担当者から指摘を受けた

### 改善方法

- 懐中電灯・スマートフォンライトを使用して斜め光で確認する習慣をつける

### 写真撮影位置

- 作業後の床全景（入口側から奥に向けて）
- 壁際・隅部の仕上がり（近景）
- 施工前後の比較写真（汚染箇所の変化）
- 問題が発見された箇所（対応後も撮影）

### クレーム防止

- 最終確認の省略はクレームの直接原因。必ず全項目確認してから施設担当者に引き渡す
- 異常箇所は施設担当者への報告が必要。放置・隠蔽は信頼失墜につながる

## 工程14　写真撮影・報告書作成

### 作業内容

施工記録として写真撮影を行い、作業報告書を作成・提出する。

### 理由

写真・報告書は施工品質の証明であり、クレーム時の証拠資料となる。表面洗浄は定期清掃として施設から費用が発生するため、施工内容・使用薬剤・施工結果の記録が特に重要である。ISO・衛生管理の記録要件を満たすためにも必須である。

### 使用工具

- スマートフォン・デジタルカメラ（800万画素以上推奨）
- 報告書（紙または電子）

### 使用薬剤

なし

### 作業方法

**写真撮影**

1. 作業前写真：施工前の床全景・汚染箇所（黒ずみ・ヒールマーク）・破損箇所を撮影する
2. 作業中写真：除塵・薬剤塗布・ポリッシャー施工・汚水回収・すすぎの状況を撮影する
3. 作業後写真：完了後の床全景・壁際・光沢仕上がりを撮影する
4. 異常箇所写真：傷・浮き・破損・水漏れを発見した場合は必ず撮影する

**撮影ルール**

- 同じ位置・同じ高さ・同じ角度で撮影する
- 日付・時刻の記録機能をONにする
- 施工前後で同じ構図を維持して比較しやすくする
- ピントを合わせてブレを防止する
- 全景（遠景）と汚染箇所（近景）をセットで撮影する

**報告書作成**

1. 基本情報（日時・現場名・作業者・天候）を記入する
2. 作業内容（除塵・薬剤種類・ポリッシャー施工・パッド種類・すすぎ回数）をチェックする
3. 使用薬剤名・希釈率・使用量を記入する
4. 使用機材（ポリッシャー・パッド・ウエットバキューム）を記入する
5. 作業結果（良好・一部改善必要）を記入する
6. 異常箇所（発見した場合は写真と共に記載）を記入する
7. 次回推奨作業を記入する
8. 写真を添付して施設担当者・管理者へ提出する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 個人情報・機密情報の写り込み | 撮影前に不要な情報が映らないか確認する |
| 写真データの紛失 | バックアップを取ってから報告書に添付する |

### 品質基準

- 作業前・中・後の写真が揃っている
- 写真が同じ構図で撮影されている
- 報告書が全項目記入されている
- 使用薬剤・パッド種類が記録されている
- 異常箇所が写真付きで報告されている
- 提出が完了している

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 病院・ホテル | 利用者・患者が映り込まないよう配慮する |
| 食品施設 | 衛生管理記録として専用フォームで記録する |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 品質記録の作成・保管 |
| ISO 45001 | 安全管理記録の作成 |

### 食品施設への対応

- 衛生管理記録として清掃日時・洗剤・施工者・確認結果を記録する
- 記録は施設の衛生管理計画に基づき保管する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 写真・報告書の不備によるクレーム対応不能 | 低（省略時は高） | 高 | 作業前・中・後の写真を必ず撮影する |

### 作業時間目安

10〜20分

### 必要人数

1名

### NG例

- 作業後写真のみ撮影し、作業前写真を省略する
- 異常箇所を発見しても報告書に記載しない
- 使用薬剤・パッド種類を報告書に記載しない

### OK例

- 作業前・中・後を同じ構図で撮影する
- 異常箇所は発見後すぐに撮影し報告書に詳細を記載する
- 使用薬剤名・希釈率・パッド種類を全て記録する

### よくある失敗

- 施工後写真の撮り忘れで施工品質の証明ができなかった
- 報告書の薬剤欄を空欄のまま提出した

### 改善方法

- 作業フローの最後に「写真撮影・報告書作成」を必須工程として位置づけ、完了しないと作業終了にならないルールを設ける

### 写真撮影位置

- 作業前の床全景・汚染箇所（近景）
- ポリッシャー施工状況・使用パッド
- 汚水回収状況
- 作業後の床全景・光沢状態（照明下）
- 施工前後の比較写真

### クレーム防止

- 写真・報告書はクレーム時の唯一の証拠。省略するとクレームへの反証ができなくなる
- 施工前に既存の傷・破損を写真で記録することで「施工中に傷つけた」というクレームを防げる

## 工程15　資機材清掃・後片付け

### 作業内容

使用した全ての資機材を洗浄・整理し、次回使用できる状態にして保管する。

### 理由

使用後の資機材に洗剤・汚れが残ると次回使用時に床面への汚れ再付着・薬剤被害が発生する。ポリッシャー・ウエットバキュームは適切なメンテナンスなしに使用し続けると故障の原因となる。資機材の適切な管理は品質維持と機材寿命の延長に直結する。

### 使用工具

- 水道・ホース
- ブラシ
- 清潔なクロス

### 使用薬剤

なし（清水による洗浄）

### 作業方法

1. モップを清水で3〜5回すすぐ。洗剤成分が残らないまで洗い流す
2. モップを絞り、伸ばした状態で乾燥させる（丸めたまま保管禁止）
3. バケツを清水で洗浄して汚れ・洗剤を除去する
4. スプレーボトルの残液を廃棄し、清水で洗浄する
5. ポリッシャーのパッドを取り外し、清水で洗浄・乾燥させる
6. ポリッシャー本体を清水で拭き取り、汚れ・洗剤を除去する
7. ウエットバキュームのタンクを空にして清水で洗浄する
8. 全資機材を所定の保管場所に収納する
9. 廃液・汚水を現場指定の方法で適切に処理する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 洗浄中の洗剤・汚水の飛散 | 手袋・保護メガネを着用する |
| 廃液の不適切な処理 | 現場指定の排水方法・廃棄方法で処理する |
| 重量物（ポリッシャー・バキューム）の落下 | 重さを確認してから持ち運ぶ。複数名で搬出する |
| ポリッシャー電気系統への水の侵入 | 電気系統に水をかけない。拭き取りで清掃する |

### 品質基準

- 全資機材が清潔に洗浄されている
- モップが伸ばした状態で乾燥保管されている
- パッドが洗浄・乾燥されている
- ポリッシャー・ウエットバキュームが清潔に清掃されている
- 廃液が適切に処理されている
- 全資機材が所定の場所に収納されている

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 食品施設 | 食品施設で使用した資機材は他エリアと区別して保管する |
| 全施設共通 | 廃液処理方法を施設担当者に確認してから処理する |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 14001 | 廃液の適切な処理・排水管理 |
| ISO 9001 | 資機材管理手順の標準化 |

### 食品施設への対応

- 食品施設で使用した資機材は他エリアと区別して保管する
- モップ・クロスは用途別に色分け管理する（現場仕様）

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| ポリッシャー電気系統への水侵入 | 低 | 高 | 電気系統は拭き取りのみ。水をかけない |
| 重機材の落下・怪我 | 中 | 高 | 複数名で搬出・保管する |
| 廃液の不適切処理 | 低 | 中 | 現場指定方法で処理する |

### 作業時間目安

20〜30分

### 必要人数

1〜2名

### NG例

- パッドを洗わずに湿ったまま保管する（カビ・劣化の原因）
- ポリッシャーに水をかけて洗浄する
- ウエットバキュームタンクを空にせず保管する

### OK例

- パッドを清水で洗浄して乾燥させてから保管する
- ポリッシャーは清水で濡らしたクロスで拭き取り清掃する
- ウエットバキュームのタンクを空にして清水ですすいでから保管する

### よくある失敗

- パッドを湿ったまま保管してカビが生え、次回使用時に床面を汚染した
- ウエットバキュームタンクの廃液を処理せずに保管し、翌日異臭が発生した

### 改善方法

- 資機材清掃チェックリストを使用し、全項目を確認してから保管する

### クレーム防止

- 洗浄不足の資機材による次回施工時の汚れ転写クレームを防ぐ
- 廃液の不適切な処理による環境クレーム・法令違反を防ぐ

# 15. クレーム防止

| クレーム事例 | 原因 | 防止策 |
|---|---|---|
| テスト施工なしで床材が変色した | テスト省略 | テスト施工を必須工程として徹底する |
| ポリッシャーで床材に傷・焼き付きが発生した | 停止回転・過剰圧力 | 「停止回転禁止」の徹底・適切な圧力管理 |
| アルカリ洗剤で金属部品が腐食した | 養生不足 | 全金属部品の養生チェックリスト使用 |
| 施工後に洗剤臭・ベタつきが残った | すすぎ不足 | 2〜3回すすぎを標準化する |
| 壁際の黒ずみが残っていた | ブラッシング省略 | ブラッシング担当を配置して徹底する |
| ポリッシャー騒音のクレーム | 時間帯調整不足 | 事前に施設担当者と時間帯を調整する |
| 汚水回収後に汚れが広がった | すすぎ前の汚水回収不足 | 汚水完全回収をすすぎの前提条件とする |
| パッドラインが残った | 重ね幅不足 | 重ね幅1/3の徹底施工 |
| 施工前からの傷を施工でつけたと言われた | 事前写真の未撮影 | 施工前の傷・破損を必ず写真で記録する |
| フローリングが膨れた | 水分過多 | 固絞りモップ・水分拭き取り徹底 |
