# 04_床剥離洗浄 標準作業手順書（SOP）

---

# 1. 作業概要

| 項目 | 内容 |
|---|---|
| 作業名称 | 床剥離洗浄 |
| 目的 | 劣化・蓄積したワックスを剥離剤とポリッシャーで完全除去し、床材の素地を回復させた上で新たなワックス保護膜の再施工に備える |
| 対象施設 | オフィス・商業施設・ホテル・病院・学校・工場・公共施設・マンション共用部・食品施設 |
| 対象床材 | 長尺シート・Pタイル・コンポジションタイル（天然石・テラゾー・フローリングは専用剥離剤またはメーカー確認必須） |
| 作業人数 | 2〜4名（危険薬剤使用・機械操作・汚水管理の同時進行が必要） |
| 作業時間 | 4時間〜8時間（面積・ワックス蓄積量・すすぎ回数による） |
| 推奨施工時間帯 | 営業時間外・夜間・早朝（利用者完全不在時。翌日営業開始前の乾燥完了が必須） |
| 作業頻度 | 年1〜2回（現場仕様・ワックス蓄積状態による） |
| 前工程 | 床日常清掃（AVL-SOP-FLOOR-01）・床表面洗浄（AVL-SOP-FLOOR-02） |
| 後工程 | 床ワックス塗布（AVL-SOP-FLOOR-03）が必須後工程となる |
| 危険度分類 | 高（強アルカリ剥離剤・機械操作・大量汚水・蒸気発生） |

---

## 施工可能条件

| 条件 | 基準 |
|---|---|
| 室温 | 10℃〜35℃（低温は剥離剤効果低下、高温は乾燥不良） |
| 利用者の有無 | 完全不在・翌日営業開始前に乾燥・ワックス再施工完了できること |
| 換気 | 剥離剤（強アルカリ）の蒸気が滞留しないよう換気が確保できること（必須） |
| 電源 | ポリッシャー・ウエットバキューム用電源が2系統以上確保できること |
| 排水 | 大量の汚水（剥離剤・ワックス残渣）の排水先が確保できること |
| 養生 | 什器・壁・電気設備への剥離剤飛散防止養生が実施可能なこと |

## 施工不可条件

| 条件 | 対応 |
|---|---|
| 利用者が残っている | 完全退出後に施工開始 |
| 換気が確保できない密閉空間 | 換気確保後に施工（剥離剤の蒸気中毒リスク） |
| 天然石・テラゾー・フローリングへの一般剥離剤使用 | 専用品またはメーカー確認後のみ施工 |
| 翌朝までにワックス再施工が完了できない | 施工日を変更する |

## 作業中止基準

| 発見内容 | 対応 |
|---|---|
| 薬剤（強アルカリ）が目・皮膚に付着 | 流水で15分以上洗浄・受診 |
| 換気扇が停止・換気不能になった | 作業一時中断・換気回復後に再開 |
| 床材の損傷・変色が発生 | 即時中止・写真撮影・管理者報告 |
| ポリッシャーの異常 | 電源遮断・点検 |
| 施設担当者から中止指示 | 即時中止 |

## 薬剤選択フロー

```
床材とワックス蓄積状態を確認する
　↓
長尺シート・Pタイル（標準蓄積）
→ 剥離剤（標準タイプ）薬剤ラベル記載希釈倍率（通常10〜20倍）
　放置時間：5〜10分→ポリッシャー施工→ウエットバキューム回収
　↓
重度蓄積（5年以上未剥離）
→ 剥離剤（強力タイプ）薬剤ラベル記載希釈倍率（通常5〜10倍）
　放置時間：10〜15分
　↓
天然石・テラゾー・フローリング
→ 専用剥離剤またはメーカー確認後のみ施工
　↓
すすぎ：清水2〜3回→中和（必要時）→完全乾燥確認
→ 後工程：床ワックス塗布（03_床ワックス塗布）へ
```

# 2. 作業目的

床剥離洗浄は、以下の目的を達成するために実施する。

- 劣化・黄ばみ・黒ずみを含むワックス層の完全除去
- 蓄積ワックスによる光沢不均一の解消
- 床材素地の回復（ワックス再施工前の下地リセット）
- 新しいワックス保護膜の密着性向上
- 清潔感・美観の根本的回復
- 床材の長期的な保護と寿命延長
- 衛生管理・ISO衛生管理基準の達成（食品施設）
- 施設資産価値の維持
- クレーム防止

**理由：** ワックスは塗り重ねるにつれて黄ばみ・黒ずみが蓄積し、表面洗浄では除去できない汚染層になる。剥離洗浄でワックスを完全にゼロにしてから新たなワックスを塗布することで、長期的な品質管理コストを最適化し、床材の本来の美観を回復させることができる。

# 5. 放置した場合のリスク

| リスク | 内容 |
|---|---|
| ワックスの黄変固着 | 長期蓄積でワックスが樹脂化し剥離が困難になる |
| 光沢の完全消失 | 汚染ワックス層が増加して美観が回復不能になる |
| 表面洗浄の効果消失 | 蓄積ワックスが厚くなり表面洗浄では改善できなくなる |
| 床材の変色・損傷 | ワックス内に封じ込まれた汚れ・水分が床材を腐食する |
| 剥離困難化 | 蓄積が進むほど剥離に要する時間・薬剤量・工数が増加する |
| クレーム発生 | 美観の著しい低下による利用者・施設担当者からのクレーム |
| 衛生基準違反 | 食品施設での蓄積汚染による衛生基準未達 |

# 12. 詳細作業手順

---

## 工程1　現場確認・KY実施

### 作業内容

作業開始前に施工範囲・床材種類・ワックス蓄積状態・排水計画・養生計画・安全環境を詳細に確認し、KY（危険予知）を実施する。

### 理由

剥離洗浄は強アルカリ剥離剤・ポリッシャー・大量の汚水という三重のリスクを伴う、床清掃の中で最も危険度の高い作業である。床材の誤認や養生計画の不備は取り返しのつかない設備損傷につながる。KYで全員が「剥離洗浄特有の危険」を共有することが事故・クレーム防止の基本となる。

### 使用工具

- チェックリスト
- 図面（あれば）

### 使用薬剤

なし

### 作業方法

1. 施工範囲を目視・メジャーで確認する
2. 床材種類を確認する（長尺シート・Pタイル・フローリング・天然石など）
3. ワックスの蓄積状態（層数・黄変・黒化の程度）を確認する
4. 床材の破損・浮き・剥がれ・亀裂を確認して写真に記録する
5. アルミ・ステンレス・金属部品・木部・ゴム部品の位置を確認して養生計画を立案する
6. 電源位置・給水位置・排水位置を確認する
7. 汚水の排水ルートを施設担当者に確認する
8. 利用者動線・避難経路を確認する
9. 換気扇・窓の位置を確認して換気計画を立案する
10. KYを実施し、本日の危険ポイントを全員で共有する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 床材誤認による剥離剤被害（天然石の損傷） | 目視・担当者確認でメーカー適合を確認する |
| 金属・木部への剥離剤付着による腐食 | 全接触リスク箇所の養生計画を立案する |
| 排水計画不備による汚水拡散 | 施設担当者に排水ルートを確認する |
| 換気不足による剥離剤蒸気の蓄積 | 換気計画を立案して全員に周知する |
| 避難経路遮断 | 作業前に確認・確保する |

### 品質基準

- 床材が正確に識別されている
- ワックス蓄積状態が把握されている

## 工程2　安全確保・表示設置・重点養生

### 作業内容

剥離洗浄の作業区画を設定し、強アルカリ剥離剤から周辺設備・金属部品・木部・ゴム部品を保護するための重点養生を実施する。

### 理由

剥離剤は強アルカリ性のため、アルミ・ステンレス・金属部品に付着すると腐食・変色が発生する。木部に付着すると変色・膨張が起こる。ゴム部品に付着すると劣化・変形が起こる。これらの被害は除去困難で、施設担当者への重大クレームとなる。養生は剥離洗浄において日常清掃・表面洗浄・ワックス塗布よりも格段に重要な工程である。

| TOOL-017 | 養生テープ | 金属・木部・ゴム部品の養生 |
| TOOL-018 | 養生シート（大面積） | 大面積養生 |
| TOOL-019 | コードリール・延長コード | 電源コード固定 |

なし

## 工程3　除塵作業（ドライモップ）

### 作業内容

剥離剤塗布の前に、床面の砂・ホコリ・ゴミを乾式で完全除去する。

### 理由

砂・ゴミが残った状態で剥離剤を塗布すると、砂が泥水状の剥離液と混合してポリッシャー施工時に床材を傷つける。また大きなゴミが残るとポリッシャーパッドの下に入り込み、傷・損傷の原因となる。剥離剤の有効成分が砂・ゴミの除去に消費されないよう、事前の徹底除塵が剥離効果を最大化する。

### 使用工具

| 管理番号 | 工具 | 用途 |
|---|---|---|
| TOOL-008 | ドライモップ（ダスター） | 主要面の除塵 |
| TOOL-010 | マイクロファイバーモップ | 精密除塵・仕上げ |
| TOOL-012 | ハンドブラシ（コーナー用） | 壁際・隅・角部の除塵 |
| TOOL-021 | ゴミ袋 | 回収ゴミの廃棄 |

### 使用薬剤

なし（乾式除塵）

### 作業方法

1. 奥から出口方向へ、一方向にドライモップ（TOOL-008）を施工する
2. ドライモップは床面に密着させ、浮かせずに一定方向へ動かす
3. 往復掛けは行わず、一方向施工を徹底する
4. 壁際・隅・角部はハンドブラシ（TOOL-012）で除塵する
5. 什器・棚・機械の下など、届きにくい場所も必ず除塵する
6. 集めたゴミ・砂を回収してゴミ袋（TOOL-021）に入れる
7. 除塵後に目視でゴミ・砂が残っていないことを確認する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 工場・病院での危険物混入（ガラス・金属片・医療廃棄物） | ゴミ回収時は目視確認してから回収する |
| 除塵中のホコリ吸入 | 防塵マスクを着用する |
| 腰痛（前屈姿勢） | モップ柄の長さを身長に合わせる |

### 品質基準

- 床全面・壁際・隅部のホコリ・砂・ゴミが除去されている
- 目視でゴミ・砂が確認できない状態である
- 剥離剤塗布前に完全除塵が完了している

### 床材別注意

| 床材 | 注意事項 |
|---|---|
| 長尺シート | 継ぎ目・端部に砂が溜まりやすい。重点除塵する |
| Pタイル | 目地に砂が入りやすい。ハンドブラシで除塵する |
| フローリング | 木目・板継ぎ目のゴミを柔らかいモップで除塵する |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 工場 | 金属粉・切粉が混在する。素手で触れない。保護具を使用する |
| 病院 | 医療廃棄物・鋭利物の混在を目視確認してから回収する |
| 食品施設 | 異物の完全除去は衛生管理上必須 |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 除塵完了確認・チェックリスト記録 |
| ISO 14001 | 回収ゴミの適切な分別廃棄 |
| ISO 45001 | 防塵マスク着用・危険物混入確認 |

### 食品施設への対応

- 食品エリアの異物（ゴミ・砂・虫・毛髪）を完全除去する
- 除塵したゴミは食品エリア外へ速やかに搬出する
- 除塵完了を衛生管理記録に記載する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| ゴミ残留でポリッシャー施工時に床材傷 | 高（省略時） | 高 | 完全除塵・目視確認後にポリッシャー施工 |

## 工程4　剥離剤準備・希釈

### 作業内容

床材・ワックス蓄積状態に適した剥離剤を選定し、薬剤ラベルの希釈倍率で安全に希釈する。

### 理由

剥離剤の希釈が不正確な場合、過希釈では剥離効果が得られず施工が無駄になる。高濃度では床材への化学的損傷が発生する。剥離剤は強アルカリ性のため、調製時に皮膚・眼への付着リスクが高い。適切な保護具着用と正確な希釈が施工品質と安全の両方に直結する。

### 使用工具

| 管理番号 | 工具 | 用途 |
|---|---|---|
| TOOL-013 | バケツ2個 | 1個：剥離剤液用、1個：すすぎ水用 |
| TOOL-014 | モップレンチ（絞り器） | 含水率管理 |
| TOOL-022 | スプレーボトル | スポット剥離剤塗布 |

### 使用薬剤

| 管理番号 | 薬剤 | 希釈率 |
|---|---|---|
| CHEM-001 | 剥離剤（標準） | メーカー指定 |
| CHEM-002 | 剥離剤（木床専用） | メーカー指定（フローリングのみ） |

### 作業方法

1. 薬剤ラベルを確認して床材に適した剥離剤（CHEM管理番号）を選定する
2. バケツ（TOOL-013）に薬剤ラベルの希釈倍率で剥離剤液を準備する
3. バケツに「剥離剤液」「すすぎ水」のラベルを貼る
4. スプレーボトル（TOOL-022）にスポット剥離用の希釈液を準備する
5. 希釈後のラベルを確認する
6. 使用薬剤のCHEM管理番号・希釈率を報告書に記録する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 高濃度剥離剤による皮膚・眼への重篤な被害 | 厚手の耐薬品手袋・保護メガネを必ず着用する |
| 酸性洗剤との誤混合による有害ガス発生 | ラベルを必ず確認する。混合絶対禁止 |
| 高濃度による床材損傷 | 薬剤ラベルの希釈倍率を厳守する |
| バケツの誤用（剥離剤と清水の取り違え） | バケツにラベルを必ず貼る |

### 品質基準

- 薬剤ラベルが確認されている
- 床材に適した剥離剤が選定されている
- 薬剤ラベルの希釈倍率で調製されている
- バケツにラベルが貼られている
- CHEM管理番号・希釈率が記録されている

### 床材別注意

| 床材 | 選定剥離剤 |
|---|---|
| 長尺シート・Pタイル | CHEM-001（標準剥離剤） |
| フローリング | CHEM-002（木床専用）のみ使用。CHEM-001禁止 |
| 天然石・テラゾー | 一般剥離剤禁止。本工程に進まない |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 食品施設 | 剥離剤は一般用を使用。食品施設対応洗剤（CHEM-005）はすすぎ後の仕上げ洗浄用 |

### ISO対応

|---|---|
| ISO 9001 | 薬剤選定・希釈の記録・標準化 |
| ISO 14001 | 最小必要量の調製による廃液削減 |

### 食品施設への対応

- 剥離剤は食品施設対応品を施設担当者と確認する
- CHEM管理番号・希釈率を清掃記録に記載する

|---|---|---|---|
| 剥離剤の皮膚・眼への付着 | 中 | 高 | 厚手手袋・保護メガネ着用 |
| 薬剤混合による有害ガス | 低 | 高 | ラベル確認・混合禁止の徹底 |
| 高濃度による床材損傷 | 中 | 高 | 薬剤ラベルの希釈倍率厳守 |

### 作業時間目安

10〜15分

### 必要人数

1名

### NG例

- 薬剤ラベル未確認で剥離剤を使用する
- 「効果を高めたい」と目分量で濃くする
- 酸性洗剤と同じバケツで調製する

### OK例

- 薬剤ラベルを確認してから剥離剤を選定する
- 薬剤ラベルの希釈倍率を厳守して調製する
- バケツに「剥離剤液」「すすぎ水」のラベルを貼って区別する

### よくある失敗

- 剥離剤を濃くすれば効果が高いと思い高濃度で使用して床材が変色した
- フローリングに一般剥離剤（CHEM-001）を使用して損傷した

### 改善方法

- 剥離効果が不十分な場合は濃度を上げるのではなく、作用時間を延ばすかテスト施工で原因を確認する

### 写真撮影位置

- 使用剥離剤・ラベルの確認状態（記録用）

### クレーム防止

- 希釈ミスによる床材損傷クレームを防ぐ。薬剤ラベルの希釈倍率を必ず厳守する

## 工程5　テスト施工

### 作業内容

本施工前に目立たない箇所で剥離剤・ポリッシャー・パッドの床材への適合性と剥離効果を確認するテスト施工を実施する。

### 理由

剥離洗浄は床清掃の中で最も強い化学的・機械的作用を床材に与える作業である。テスト施工で剥離効果・床材への影響・作用時間の適切性を事前確認することで、全面施工後の重大被害・クレームを防止できる。テスト施工の省略は絶対に禁止する。

### 使用工具

| 管理番号 | 工具 | 用途 |
|---|---|---|
| TOOL-001 | ポリッシャー | テスト施工 |
| TOOL-002 または TOOL-003 | 黒パッドまたは剥離パッド | テスト用 |
| TOOL-010 | マイクロファイバーモップ | テスト後拭き取り |

### 使用薬剤

選定済み剥離剤（CHEM-001またはCHEM-002・薬剤ラベルの希釈倍率）

### 作業方法

1. 目立たない場所（入口から見えない隅・棚下など）を選定する
2. 約30cm四方の範囲に剥離剤を塗布する
3. メーカー指定の作用時間を確保する
4. ポリッシャーで数秒間施工する
5. 汚水を回収し、清水で拭き取る
6. 乾燥後に以下を確認する
   - ワックスが適切に剥離できているか
   - 変色・白化・傷・焼き付きがないか
   - 床材の損傷がないか
7. 問題がある場合は施工を中止し、別の希釈率・別のパッドで再テストするか施工を中止する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| テスト施工で問題が出た場合の継続施工 | 問題が発見されたら必ず施工を中止して対策を講じる |
| テスト範囲が小さすぎる | 最低30cm四方で施工する |

### 品質基準

- テスト範囲でワックスが適切に剥離されている
- 変色・白化・傷・焼き付きがない
- 問題がある場合は施工を中止している

### 床材別注意

| 床材 | テスト確認ポイント |

| 長尺シート | 変色・白化・ワックス剥離の均一性 |
| Pタイル | 変色・接着剤への影響・ワックス剥離状態 |
| フローリング | 木材の変色・膨張・光沢変化（CHEM-002使用） |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 全施設 | テスト後に問題がなくても施設担当者に報告してから本施工に進む |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | テスト施工結果の記録・品質確認 |

### 食品施設への対応

- テスト後の剥離剤・汚水を食品エリア外に確実に除去する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| テスト省略による全面損傷 | 高（省略時） | 高 | テスト施工を必須工程とする |
| テスト確認不足による問題見落とし | 中 | 高 | 乾燥後に十分な時間をかけて確認する |

### 作業時間目安

15〜25分（テスト・乾燥確認含む）

### 必要人数

1名

### NG例

- 時間がないからとテスト施工を省略する
- テスト結果に問題があるのに本施工を続行する

### OK例

- 30cm四方以上で剥離剤とポリッシャーを使用してテストする
- 乾燥後に変色・傷・床材損傷がないことを確認してから本施工に進む
- 問題が発見された場合は施工を中止して施設担当者に報告する

### よくある失敗

- テスト施工を省略して全面施工後に天然石の変色が発覚した

## 工程6　剥離剤塗布（区画ごと）

### 作業内容

テスト施工で適合を確認した剥離剤を、乾燥させないために区画ごとにウエットモップで均一に塗布する。

### 理由

剥離剤が乾燥すると除去が極めて困難となり、床材に固着した剥離剤残留物が次工程のワックス塗布に重大な影響を与える。一度に広範囲へ塗布すると、ポリッシャー施工前に乾燥する危険があるため、ポリッシャーで処理できる面積ずつ区画塗布を徹底する。「剥離剤は乾燥させない」が剥離洗浄の最重要原則である。

### 使用工具

| 管理番号 | 工具 | 用途 |
|---|---|---|
| TOOL-009 | ウエットモップ | 剥離剤塗布 |
| TOOL-013 | バケツA（剥離剤液） | 剥離剤の供給 |
| TOOL-014 | モップレンチ（絞り器） | 含水率管理 |
| TOOL-022 | スプレーボトル | スポット・壁際塗布 |

### 使用薬剤

| 管理番号 | 薬剤 | 希釈率 |
|---|---|---|
| CHEM-001 または CHEM-002 | 選定済み剥離剤 | メーカー指定 |

### 作業方法

1. モップ（TOOL-009）をバケツA（剥離剤液）に浸し、モップレンチで適切に絞る
2. ポリッシャーで処理できる区画面積を確認し、その区画のみに塗布する
3. 剥離剤を均一に塗布する（薄すぎると効果が不十分、多すぎると乾燥リスク）
4. 壁際・柱周辺・隅部にも確実に塗布する
5. 塗布後すぐにメーカー指定の作用時間を管理する
6. 塗布した区画が乾燥しそうな場合は追加塗布する（乾燥禁止）
7. ポリッシャー施工後に次の区画へ移動する（区画ごとの繰り返し）

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 剥離剤乾燥による床材固着・除去困難 | 区画を小さく設定して乾燥させない |
| 剥離剤の皮膚・眼への付着 | 厚手手袋・保護メガネ・フェイスシールドを着用する |
| 塗布中の転倒（濡れ床面） | 安全靴を着用・ゆっくり移動する |
| 剥離剤蒸気の吸入 | 換気を確保する。防毒マスクを着用する |

### 品質基準

- 剥離剤が均一に塗布されている
- 乾燥していない
- 区画ごとに施工されている
- 壁際・柱周辺まで確実に塗布されている

### 床材別注意

| 床材 | 注意事項 |
|---|---|
| 長尺シート | 継ぎ目への浸透に注意。過剰塗布禁止 |
| Pタイル | 目地への浸透で接着剤が溶ける可能性あり。50ml/m²以内の塗布量を徹底する |
| フローリング | CHEM-002（木床専用）のみ使用。塗布量はメーカー指定を厳守する |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 広面積施設 | 区画を細分化して乾燥しない面積を管理する |
| 食品施設 | 剥離剤が食品エリアの食品・設備に到達しないよう管理する |
| 換気不十分な場所 | 防毒マスクを着用して塗布作業を行う |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 区画施工の記録・乾燥防止管理 |
| ISO 14001 | 剥離剤使用量の最小化管理 |
| ISO 45001 | 剥離剤蒸気対策・皮膚接触防止 |

### 食品施設への対応

- 剥離剤が食品エリアの設備・食品に到達しないよう区画を管理する
- 塗布量・希釈率を衛生管理記録に記載する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 剥離剤乾燥による固着 | 高（広範囲塗布時） | 高 | 区画塗布・乾燥防止管理 |
| 剥離剤の皮膚・眼への付着 | 中 | 高 | 厚手手袋・保護メガネ着用 |
| 蒸気吸入 | 中 | 高 | 換気確保・防毒マスク着用 |

### 作業時間目安

10〜30分（区画面積による）

### 必要人数

1〜2名

### NG例

- 一度に全面積へ剥離剤を塗布する（乾燥リスク）
- 剥離剤を多量に撒いて水浸しにする
- 保護具を着用せずに剥離剤を取り扱う

### OK例

- ポリッシャーで処理できる面積ずつ区画塗布する
- 均一な薄塗りで塗布する
- 乾燥しそうな場合は追加塗布して湿潤状態を維持する

### よくある失敗

- 広範囲に剥離剤を塗布して一部が乾燥し、除去困難な固着が発生した
- 剥離剤を多量に使用しすぎて汚水処理コストが増大した

### 改善方法

- 施工前に区画面積を計算し「この面積ならポリッシャー施工が完了する時間内に乾燥しない」という区画サイズを決定してから塗布する

### 写真撮影位置

- 剥離剤塗布中の区画施工状況

### クレーム防止

- 剥離剤乾燥による固着・変色クレームを防ぐ。区画施工を徹底する

## 工程7　作用時間確保

### 作業内容

区画ごとに塗布した剥離剤がワックス層に浸透・溶解するためのメーカー指定作用時間を確保する。

### 理由

剥離剤の効果はワックスへの浸透・溶解に必要な化学反応時間によって決まる。作用時間が不十分だとワックスが十分に溶解せず、ポリッシャー施工で物理的に除去できなくなる。一方、作用時間が長すぎると乾燥リスクが増す。メーカー指定の作用時間を正確に管理することが剥離品質の根幹となる。

### 使用工具

なし（時間管理のみ）

### 使用薬剤

なし（前工程で塗布済み）

### 作業方法

1. 剥離剤塗布完了時刻を記録する
2. メーカー指定の作用時間が経過するまで待機する
3. 剥離剤が乾燥していないことを目視で確認する（湿潤状態の維持）
4. 乾燥しそうな箇所があれば追加塗布する
5. 作用時間が経過したらすぐにポリッシャー施工に移行する
6. 作用時間中に次の区画の準備（養生確認・ポリッシャー準備）を行う

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 作用時間中の剥離剤乾燥 | 乾燥しそうな箇所に追加塗布する |
| 作用時間中の利用者侵入 | カラーコーン・表示板を維持する |
| 作用時間短縮による剥離不足 | メーカー指定時間を厳守する |

### 品質基準

- メーカー指定の作用時間が経過している
- 剥離剤が乾燥していない（湿潤状態が維持されている）
- 作用時間が記録されている

### 床材別注意

| 床材 | 注意事項 |
|---|---|
| 長尺シート・Pタイル | 標準作用時間はメーカー指定に従う |
| ワックス蓄積が厚い場合 | 作用時間の延長が必要な場合がある。メーカー確認 |
| フローリング | 木床専用剥離剤（CHEM-002）の作用時間はメーカー指定に従う |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 高温環境 | 剥離剤が乾燥しやすい。区画面積を小さくして対応する |
| 低温環境 | 化学反応が遅くなり作用時間が延長する場合がある。メーカー確認 |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 作用時間の記録・管理 |

### 食品施設への対応

- 作用時間中も剥離剤が食品エリアに流出しないよう管理する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 剥離剤乾燥による固着 | 中 | 高 | 乾燥確認・追加塗布の徹底 |
| 作用時間不足による剥離不良 | 中 | 中 | メーカー指定時間の厳守 |

### 作業時間目安

メーカー指定作用時間

### 必要人数

1名（監視・次区画準備）

### NG例

- 作用時間を短縮してポリッシャー施工に移行する
- 作用時間中の剥離剤乾燥を放置する

### OK例

- 塗布時刻を記録し、メーカー指定時間が経過してからポリッシャー施工に移行する
- 乾燥しそうな箇所には追加塗布して湿潤状態を維持する

### よくある失敗

- 作用時間を短縮してポリッシャー施工したが剥離が不十分で再施工が必要になった

### 改善方法

- 作用時間を時計で管理する。感覚ではなく時刻記録で管理する

### 写真撮影位置

## 工程8　ポリッシャー施工（剥離パッド）

### 作業内容

作用時間を確保した剥離剤が浸透したワックス層をポリッシャーと剥離パッドで機械的に除去する。

### 理由

剥離剤で溶解・浮き上がったワックスをポリッシャーの回転力で物理的に除去することが剥離洗浄の核心工程である。ポリッシャーを停止させたまま回転させると焼き付き・傷が発生する。一定速度・一定方向での施工が剥離ムラを防止する。壁際はポリッシャーが届かないため次工程のブラッシングで対応する。

### 使用工具

| 管理番号 | 工具 | 用途 |
|---|---|---|
| TOOL-001 | ポリッシャー | 機械剥離施工 |
| TOOL-002 または TOOL-003 | 黒パッドまたは剥離パッド | ワックス剥離 |
| TOOL-004 | パッドホルダー | パッドの取り付け |
| TOOL-019 | コードリール・延長コード | 電源供給 |

### 使用薬剤

なし（前工程で塗布済みの剥離剤を使用）

### 作業方法

1. ポリッシャー（TOOL-001）に黒パッドまたは剥離パッド（TOOL-002・TOOL-003）を装着する
2. 電源コードを肩にかけて巻き込みを防止する
3. 両手でポリッシャーをしっかり保持する
4. 塗布した区画を奥から出口方向へ一定速度で施工する
5. 重ね幅を約1/3確保しながら前進する（剥離洗浄ムラ防止）
6. ポリッシャーを停止させたまま回転させない（焼き付き防止の絶対ルール）
7. パッドが汚れたら交換する（汚れたパッドは剥離効果が低下する）
8. 壁際はポリッシャーが届く限り施工し、残った箇所はブラッシング工程で対応する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| ポリッシャー停止による床材焼き付き | 常に移動しながら操作する。停止回転絶対禁止 |
| コードの巻き込みによる転倒・感電 | コードを肩にかけて操作する |
| 剥離汚水の飛散による感電・皮膚被害 | フェイスシールド・防水エプロン着用。電源コードへの汚水接触防止 |
| ポリッシャーの暴走 | 両手でしっかり保持し重心を安定させる |
| 腰痛（長時間操作） | 適切な姿勢・定期的な休憩 |

### 品質基準

- 施工区画のワックスが均一に剥離されている
- 焼き付き・傷・パッドラインがない
- 重ね幅1/3が確保されている
- パッドが適切な状態で使用されている

### 床材別注意

| 床材 | パッド選定・注意事項 |
|---|---|
| 長尺シート | 黒パッドまたは剥離パッドを使用。端部の巻き込みに注意する |
| Pタイル | 黒パッドまたは剥離パッドを使用。目地への圧力に注意する |
| フローリング | 木床専用剥離剤（CHEM-002）使用前提で柔らかめのパッドを使用する |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 病院 | 施工音が医療行為の妨げにならない時間帯に調整する |
| 商業施設 | 広面積では複数台のポリッシャーで分担施工する（現場仕様） |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | ポリッシャー操作手順の標準化・施工記録 |
| ISO 45001 | 機械操作安全・感電防止・転倒防止 |
| ISO 14001 | 使用水量・薬剤量の最小化 |

### 食品施設への対応

- 剥離汚水の飛散が食品管理区域に入らないよう養生を確認する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 床材焼き付き（停止回転） | 低（正常操作時）・高（停止時） | 高 | 常に移動操作を徹底する |
| コード巻き込みによる転倒 | 中 | 高 | コードを肩にかけて操作する |
| 剥離汚水飛散による感電・被害 | 中 | 高 | フェイスシールド着用・コード防水確認 |

### 作業時間目安

30分〜3時間（面積・ワックス蓄積量による）

### 必要人数

1〜2名（操作者1名＋補助者1名が望ましい）

### NG例

- ポリッシャーを停止させたまま回転させ続ける
- コードを床に引きずったまま操作する
- 同じ場所を長時間施工する

### OK例

- 常に移動しながら操作する
- コードを肩にかけて操作する
- 重ね幅1/3を守りながら一定速度で施工する

### よくある失敗

- 狭い箇所でポリッシャーを停止させて床材に焼き付きを起こした
- パッドが汚れたまま施工を続けて剥離効果が低下した

### 改善方法

- 「停止状態での回転は絶対禁止」を施工前に全員で確認する

### 写真撮影位置

- ポリッシャー施工中の全景（施工状況・パッドが分かる角度）
- 剥離進行中の汚水状態（ワックスが溶解している状態）

### クレーム防止

- ポリッシャー焼き付き・傷クレームを防ぐ。「停止回転禁止」を厳守する

## 工程9　壁際・隅部ブラッシング（ハンドブラシ・デッキブラシ）

### 作業内容

ポリッシャーが届かない壁際・柱周辺・隅・角部を、ハンドブラシ・デッキブラシで手作業剥離する。

### 理由

ポリッシャーは壁際10〜15cm程度まで施工できない構造になっている。この未施工箇所を放置すると壁際だけワックスが残留し、新たなワックスを塗布した後に光沢ムラ・密着不良の原因となる。壁際・隅部は汚れとワックスが最も蓄積しやすい場所であり、重点施工が必要である。

### 使用工具

| 管理番号 | 工具 | 用途 |
|---|---|---|
| TOOL-011 | デッキブラシ（硬め） | 壁際の手作業剥離 |
| TOOL-012 | ハンドブラシ（コーナー用） | 隅・角部の剥離 |
| TOOL-009 | ウエットモップ | 壁際への剥離剤追加塗布 |

### 使用薬剤

| 管理番号 | 薬剤 |
|---|---|
| CHEM-001 または CHEM-002 | 壁際・隅部への追加塗布用 |

### 作業方法

1. ポリッシャーが届かなかった壁際・隅・角部を確認する
2. 汚れが残っている場合は剥離剤を追加塗布してから作用時間（5〜10分）を確保する
3. デッキブラシ（TOOL-011）で壁際を前後方向にブラッシングする
4. ハンドブラシ（TOOL-012）で隅・角部をブラッシングする
5. 柱周辺は四方向からブラッシングする
6. 剥離した汚水が広がる場合は誘導してウエットバキュームで回収する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 前屈姿勢による腰痛 | 定期的に姿勢を変える。長時間の前屈禁止 |
| 剥離剤の眼への飛散 | 保護メガネ・フェイスシールドを着用する |
| ハンドブラシで養生した巾木・壁を傷つける | ブラシの向きに注意して施工する |
| 膝関節への負担 | 膝当てを使用する（必要時） |

### 品質基準

- 壁際・隅部・角部・柱周辺のワックスが剥離されている
- ポリッシャー施工箇所と壁際施工箇所で剥離品質が均一である
- 養生した巾木・壁面への剥離剤付着がない

### 床材別注意

| 床材 | 注意事項 |
|---|---|
| 長尺シート | 継ぎ目・端部を傷つけないブラシ硬さを選定する |
| Pタイル | 目地部分を重点的にブラッシングする |
| フローリング | 木目に沿ってブラッシングする。過剰な水分禁止 |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 食品施設 | 壁際の剥離は食品への汚染防止のため衛生管理上最重要箇所 |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 壁際・隅部剥離完了の確認・記録 |
| ISO 45001 | 腰痛防止・保護具着用 |

### 食品施設への対応

- 食品施設の壁際・隅部は汚れが蓄積しやすい衛生管理上の重点箇所。徹底剥離後に記録する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 腰痛（前屈施工） | 中 | 中 | 定期的に姿勢を変える |
| 剥離剤の眼への飛散 | 中 | 高 | フェイスシールド着用 |

### 作業時間目安

15〜40分（壁際延長・隅部の数による）

### 必要人数

1名

### NG例

- 壁際・隅部のブラッシングを省略する
- ポリッシャーを無理に壁に押し当てて施工する

### OK例

- ポリッシャーが届かなかった全箇所をデッキブラシ・ハンドブラシで施工する
- 角部はブラシを回転させながら隅まで施工する

### よくある失敗

## 工程10　汚水回収（ウエットバキューム）

### 作業内容

ポリッシャー施工および壁際ブラッシングで発生した剥離汚水をウエットバキュームで完全回収する。

### 理由

剥離汚水には溶解したワックス・剥離剤が含まれており、そのまま放置するとすすぎ工程で広がり、床面への再付着が起こる。また剥離汚水が残った状態で次のすすぎに移行すると、汚れが広がり複数回のすすぎが必要になり作業効率が著しく低下する。完全回収によりすすぎの効率・品質が大幅に向上する。

### 使用工具

| 管理番号 | 工具 | 用途 |
|---|---|---|
| TOOL-005 | ウエットバキューム | 剥離汚水の機械的回収 |
| TOOL-006 | スクイジー（大型） | 汚水をウエットバキューム吸引口へ誘導 |
| TOOL-007 | スクイジー（小型） | 壁際・隅部の汚水誘導 |

### 使用薬剤

なし

### 作業方法

1. スクイジー（TOOL-006）で剥離汚水を一か所に集める
2. ウエットバキューム（TOOL-005）で汚水を回収する
3. 壁際・隅部はスクイジー（TOOL-007）で汚水を誘導してからウエットバキュームで回収する
4. ウエットバキュームのタンクが満水になる前に排水する
5. 排水は施設担当者に確認した方法で適切に処理する
6. 汚水が残っていないことを目視で確認する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 剥離汚水残留による転倒（滑り） | 安全靴着用。汚水を完全回収する |
| ウエットバキュームタンク満水による溢れ | 定期的にタンク残量を確認する |
| 剥離汚水の電源コードへの接触による感電 | コードへの汚水接触を防ぐ |
| 剥離汚水の不適切排出 | 施設指定の排水方法で処理する |

### 品質基準

- 床全面・壁際・隅部の剥離汚水が回収されている
- 目視で汚水・水溜まりが確認できない状態である
- タンクが満水でない
- 排水が適切に処理されている

### 床材別注意

| 床材 | 注意事項 |
|---|---|
| 長尺シート | 継ぎ目への汚水浸透を防ぐ。速やかに回収する |
| Pタイル | 目地の汚水を確実に回収する |
| フローリング | 汚水の木材への浸透を防ぐため速やかに回収する |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 食品施設 | 剥離汚水が食品管理区域に流出しないよう区画管理する |
| 工場 | 排水基準を施設担当者に確認して処理する |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 汚水回収完了の確認・記録 |
| ISO 14001 | 剥離汚水の適切な排水処理・環境管理 |
| ISO 45001 | 汚水による転倒・感電リスク管理 |

### 食品施設への対応

- 剥離汚水が食品エリアに流出しないよう区画管理を徹底する
- 汚水処理方法を衛生管理記録に記載する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 剥離汚水残留による転倒 | 中 | 高 | 完全回収・目視確認 |
| タンク満水による溢れ | 中 | 中 | 定期的なタンク確認 |
| 感電（汚水とコードの接触） | 低 | 高 | コード管理の徹底 |

### 作業時間目安

15〜35分（面積による）

### 必要人数

1〜2名

### NG例

- 剥離汚水を残したままですすぎに移行する
- タンクが満水のまま使用し続ける

### OK例

- スクイジーで汚水を誘導してからウエットバキュームで回収する
- 回収後に目視で汚水残留がないことを確認する

### よくある失敗

### 改善方法

- すすぎ前に汚水を完全回収することを手順書の必須ステップとして標準化する

### 写真撮影位置

- ウエットバキューム施工状況（全景）
- 汚水回収後の床状態（汚水がないことの確認）

### クレーム防止

- 剥離汚水回収不足による次工程品質不良クレームを防ぐ

## 工程11　すすぎ洗浄（第1回・清水）

### 作業内容

剥離汚水回収後の床面を清水で第1回のすすぎを実施し、剥離剤・溶解ワックスを除去する。

### 理由

剥離剤は強アルカリ性のため、床面に残留すると次工程のワックス塗布の密着不良・白化の原因になる。また利用者の皮膚・靴底への刺激・損傷の原因にもなる。第1回すすぎで剥離剤の大部分を除去し、続く第2回以降のすすぎで完全除去する。第1回すすぎの徹底が後工程の品質を決定する。

### 使用工具

| 管理番号 | 工具 | 用途 |
|---|---|---|
| TOOL-009 | ウエットモップ | 清水すすぎ |
| TOOL-013 | バケツB（清水） | すすぎ水供給 |
| TOOL-010 | マイクロファイバーモップ | 壁際・精密すすぎ |
| TOOL-005 | ウエットバキューム | すすぎ後の汚水回収 |
| TOOL-006 | スクイジー（大型） | すすぎ水誘導 |

### 使用薬剤

なし（清水のみ）

### 作業方法

1. バケツB（TOOL-013）に清水を準備する
2. モップ（TOOL-009）を清水に浸し、適切に絞る
3. 奥から出口方向へ「コの字」を描きながら清水ですすぐ
4. モップが汚れたら清水で洗い、清水ですすいでから再使用する
5. バケツの水が黄色・茶色に汚れたら新しい清水に交換する
6. 第1回すすぎ完了後にウエットバキュームで汚水を完全回収する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 剥離剤残留による皮膚・眼への被害 | 手袋・保護メガネを着用してすすぎ作業を行う |
| すすぎ後の床面での転倒 | 安全靴着用 |
| フローリングへの水分過多 | モップを固く絞る |

### 品質基準

- 剥離剤・溶解ワックスの大部分が除去されている
- バケツのすすぎ水が茶色から薄い色になっている
- 第1回すすぎ後に汚水回収が完了している

### 床材別注意

| 床材 | 注意事項 |
|---|---|
| 長尺シート | 継ぎ目への清水浸入に注意。速やかにすすいで回収する |
| フローリング | モップは固く絞る。水分の木材浸透を防ぐ |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 食品施設 | 第1回すすぎ水も食品エリアに流出しないよう管理する |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | すすぎ回数・完了確認の記録 |
| ISO 14001 | 最小限の清水使用 |

### 食品施設への対応

- 食品エリアは特に徹底したすすぎを実施する
- すすぎ完了を衛生管理記録に記載する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 剥離剤残留による健康被害 | 中（すすぎ不足時） | 高 | 徹底したすすぎ回数の確保 |
| すすぎ後の転倒 | 中 | 高 | 安全靴着用 |

### 作業時間目安

15〜40分（面積による）

### 必要人数

1〜2名

### NG例

- すすぎを1回で終了する（剥離剤が残留する）
- バケツの水を交換せずに使い続ける

### OK例

- バケツの水が汚れたら交換してから継続する
- 第1回すすぎ後に汚水を完全回収する

### よくある失敗

- すすぎが不十分でワックス塗布後に密着不良が発生した

### 改善方法

- すすぎの完了基準を「バケツの水が比較的透明になること」として定める

### 写真撮影位置

- 第1回すすぎ作業の状況（全景）

### クレーム防止

- 剥離剤残留による密着不良クレームを防ぐ。十分なすすぎ回数を確保する

## 工程12　すすぎ洗浄（第2回・必要時第3回）

### 作業内容

第1回すすぎ・汚水回収後に第2回（アルカリ感・ぬめりが残る場合は第3回）のすすぎを実施し、剥離剤残留をゼロにする。

### 理由

剥離洗浄では1回のすすぎでは剥離剤の完全除去は困難である。2〜3回のすすぎにより剥離剤残留を限りなくゼロに近づけることが、次工程のワックス塗布の密着品質と利用者の安全を保証する。特に食品施設では剥離剤残留ゼロが必達であり、すすぎ回数の増加が必要な場合がある。

### 使用工具

| 管理番号 | 工具 | 用途 |
|---|---|---|
| TOOL-009 | ウエットモップ | 清水すすぎ |
| TOOL-013 | バケツB（清水） | すすぎ水供給 |
| TOOL-010 | マイクロファイバーモップ | 壁際・精密すすぎ |
| TOOL-005 | ウエットバキューム | すすぎ後の汚水完全回収 |

### 使用薬剤

| 管理番号 | 薬剤 | 用途 | 希釈率 |
|---|---|---|---|
| CHEM-004 | 中性床用洗剤 | 最終回のすすぎ仕上げ（必要時） | メーカー指定 |
| CHEM-005 | 食品施設対応洗剤 | 食品施設の最終仕上げ洗浄 | 現場確認 |

### 作業方法

1. バケツBに新しい清水を準備する
2. 第1回と同様の手順で全面をすすぐ
3. すすぎ水・バケツの水の濁り具合を確認する
4. 手触りでぬめり・アルカリ感が残る場合は第3回のすすぎを実施する
5. 最終回のすすぎ後にウエットバキュームで汚水を完全回収する
6. ぬめりが取れない場合はCHEM-004（中性洗剤）を使用して仕上げ洗浄を行い、清水で再すすぎする

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| すすぎ不足による剥離剤残留 | バケツの水が透明に近くなるまですすぎを繰り返す |
| すすぎ後の床面での転倒 | 安全靴着用・表示板を維持する |

### 品質基準

- すすぎ水が透明に近い状態になっている
- 床面にベタつき・アルカリ感がない（手触り確認）
- 泡・洗剤残留がない
- 壁際・隅部のすすぎが完了している

### 床材別注意

| 床材 | 注意事項 |
|---|---|
| 長尺シート・Pタイル | 目地のすすぎを徹底する |
| フローリング | モップは固く絞る。水分最小限 |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 食品施設 | 剥離剤残留ゼロを必達とする。最低3回のすすぎを実施する |
| 病院 | 剥離剤残留が医療行為・患者に影響する。徹底すすぎ |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | すすぎ回数・完了確認の記録 |
| ISO 14001 | 最小限の清水使用で効率的なすすぎ |

### 食品施設への対応

- 食品エリアは最低3回のすすぎを実施する
- 最終すすぎにCHEM-005（食品施設対応洗剤）での仕上げ洗浄後、清水で再すすぎする
- すすぎ完了を衛生管理記録に記載する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 剥離剤残留によるワックス密着不良 | 中（すすぎ不足時） | 高 | 透明水確認まですすぎを継続する |

### 作業時間目安

20〜60分（すすぎ回数・面積による）

### 必要人数

1〜2名

### NG例

- すすぎを2回で打ち切る（剥離剤が残留している可能性がある）
- バケツの水を交換せずに使い続ける

### OK例

- すすぎ水が透明に近くなるまで繰り返す
- 食品施設では最低3回のすすぎを実施する
- 最終すすぎ後に汚水を完全回収する

## 工程13　中和確認

### 作業内容

すすぎ完了後の床面に剥離剤のアルカリ成分が残留していないことを確認する。

### 理由

剥離剤のアルカリ成分が床面に残留すると、次工程のワックス塗布の密着不良・白化が発生する。また利用者の皮膚・靴底へのアルカリ被害も起こる。手触りでぬめり感・アルカリ感がないことを確認し、ぬめり感が取れない場合は中和剤（CHEM-003）を使用して確実に中和状態を確認する。

### 使用工具

| 管理番号 | 工具 | 用途 |
|---|---|---|
| TOOL-010 | マイクロファイバークロス | 中和確認用拭き取り |

### 使用薬剤

| 管理番号 | 薬剤 | 用途 | 希釈率 |
|---|---|---|---|
| CHEM-003 | 中和剤 | 必要時の中和処理 | 現場確認 |

### 作業方法

1. すすぎ完了後、床全面の手触りを確認する（ぬめり感・アルカリ感がないこと）
2. 壁際・隅部も手触りで確認する
3. ぬめり感・アルカリ感がある場合は追加すすぎを実施する
4. 追加すすぎ後も改善しない場合は中和剤（CHEM-003）を使用して中和処理を行う
5. 中和剤使用後は清水で再すすぎを実施する
6. 中和確認の結果を記録する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 中和剤の皮膚・眼への付着 | 手袋・保護メガネを着用する |
| 中和確認省略による剥離剤残留 | 全面を手触りで確認する。省略禁止 |

### 品質基準

- 床全面の手触りでぬめり感・アルカリ感がない
- 壁際・隅部も同様に確認されている
- 中和確認結果が記録されている

### 床材別注意

| 床材 | 注意事項 |
|---|---|
| 長尺シート・Pタイル | 目地部分の中和確認も実施する |
| フローリング | 剥離剤残留は木材変色の原因。特に徹底確認する |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 食品施設 | 剥離剤残留ゼロを確認して衛生管理記録に記載する |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 中和確認の記録 |
| ISO 14001 | 中和剤使用時の廃液適切処理 |

### 食品施設への対応

- 剥離剤残留ゼロを確認してから衛生管理適合洗剤（CHEM-005）での仕上げ洗浄を行う
- 中和確認結果を衛生管理記録に記載する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 剥離剤残留によるワックス密着不良 | 中（確認省略時） | 高 | 全面手触り確認の徹底 |
| 中和剤の皮膚・眼への付着 | 低 | 中 | 手袋・保護メガネ着用 |

### 作業時間目安

5〜15分

### 必要人数

1名

### NG例

- 中和確認を省略してワックス塗布に進む
- 壁際・隅部の確認を省略する

### OK例

- 全面を手触りでぬめり感がないことを確認する
- ぬめり感がある場合は追加すすぎ・中和処理を行う

### よくある失敗

- 中和確認を省略してワックスを塗布し、白化・密着不良が発生した

### 改善方法

- 中和確認をチェックリストの必須項目として設定し、省略できないようにする

### 写真撮影位置

### クレーム防止

- 剥離剤残留によるワックス密着不良クレームを防ぐ。中和確認を省略しない

## 工程14　完全乾燥確認

### 作業内容

すすぎ・中和確認が完了した床面を完全乾燥させ、乾燥状態を確認してから復旧工程に進む。

### 理由

剥離洗浄完了後の床面は大量の水分を含んでいる。水分が残った状態では利用者転倒事故が発生する。また後工程でワックスを塗布する場合、乾燥不足は白化・密着不良の直接原因になる。完全乾燥確認は安全・品質の両面で剥離洗浄の最終チェックポイントである。

### 使用工具

| 管理番号 | 工具 | 用途 |
|---|---|---|
| TOOL-020 | 送風機・ブロワー | 乾燥促進 |
| TOOL-010 | マイクロファイバーモップ | 残水分の拭き取り |

### 使用薬剤

なし

### 作業方法

1. すすぎ・汚水回収後に床全面の水分残留を目視で確認する
2. 壁際・隅部・継ぎ目部分の水分をマイクロファイバーモップで拭き取る
3. 送風機・ブロワー（TOOL-020）を使用して乾燥を促進する
4. 乾燥状態を目視・手触りで確認する（水分が残っていないこと）
5. 完全乾燥を確認してから復旧工程（カラーコーン・表示板の撤去）に進む

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 乾燥確認前の表示板撤去による転倒 | 乾燥確認後にカラーコーンを撤去する |
| フローリングへの水分残留による膨張 | 継ぎ目・端部の水分を特に拭き取る |
| 乾燥不足でワックスを塗布する | 次工程（ワックス塗布）前に乾燥確認を必ず実施する |

### 品質基準

- 床全面・壁際・隅部・継ぎ目に水分が残っていない
- 水滴・水溜まりがない
- 目視・手触りで乾燥が確認できる

### 床材別注意

| 床材 | 注意事項 |
|---|---|
| フローリング | 継ぎ目・端部の水分を特に徹底拭き取りする |
| 長尺シート | 継ぎ目への浸水に注意する |
| Pタイル | 目地・継ぎ目の水分を拭き取る |

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 換気不十分な場所 | 送風機を十分活用して乾燥を促進する |
| 商業施設 | 翌日営業開始前に完全乾燥・ワックス塗布が完了するよう時間を管理する |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 45001 | 水分残留による転倒リスク管理 |
| ISO 9001 | 乾燥確認チェックリストへの記録 |

### 食品施設への対応

- 乾燥後に食品エリアの床面に水分・剥離剤残留がないことを確認する
- 確認結果を衛生管理記録に記載する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 水分残留による転倒 | 中 | 高 | 乾燥確認前の表示板撤去禁止 |
| 乾燥不足でワックス塗布 | 中（省略時） | 高 | 乾燥確認をチェックリスト必須項目とする |

### 作業時間目安

20〜60分（自然乾燥・送風機使用・面積による）

### 必要人数

1名

### NG例

- 乾燥確認前にカラーコーン・表示板を撤去する
- 壁際・隅部の水分拭き取りを省略する

### OK例

- 全面乾燥を目視・手触りで確認してから表示板を撤去する
- 壁際・隅部の水分を丁寧に拭き取る

### よくある失敗

- 乾燥確認を省略してワックスを塗布し、白化が発生した

### 改善方法

- 乾燥確認をチェックリストの必須項目として、確認なしでは次工程に進めないルールを設ける

### 写真撮影位置

- 乾燥確認後の床状態（全景）

### クレーム防止

- 水分残留による転倒クレームを防ぐ。乾燥確認を省略しない
- 乾燥不足でのワックス塗布による白化クレームを防ぐ

## 工程15　復旧（表示・養生撤去・原状回復）

### 作業内容

乾燥確認後、カラーコーン・表示板・養生を撤去し、施工前の状態に現場を戻す。

### 理由

養生・表示物の撤去忘れは施設担当者からのクレームになる。養生テープの長時間放置は巾木への糊残りの原因となる。剥離洗浄では大型機材（ポリッシャー・ウエットバキューム）を搬出するため、乾燥した床面への傷に特に注意が必要である。

### 使用工具

- カラーコーン（TOOL-015）
- 表示板（TOOL-016）
- 養生テープ除去道具（ケレン・必要時）

### 使用薬剤

なし

### 作業方法

1. 床の完全乾燥を確認してからカラーコーン（TOOL-015）を撤去する
2. 表示板（TOOL-016）を撤去する
3. 養生テープをゆっくりと斜め方向に剥がす（巾木・壁を傷つけないよう注意）
4. 養生シート（TOOL-018）を撤去する
5. ポリッシャー（TOOL-001）・ウエットバキューム（TOOL-005）をコロ・台車を使用して搬出する
6. 移動させた備品・家具を元の位置に戻す（床を引きずらず持ち上げて移動）
7. 全ての表示物・養生材・機材が撤去されていることを確認する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 機材搬出時の乾燥床面への傷 | コロ・台車を使用して搬出する |
| 養生テープ剥がし時の巾木損傷 | ゆっくりと角度をつけて剥がす |
| 乾燥確認前の表示撤去 | 乾燥確認後に撤去する |

### 品質基準

- カラーコーン・表示板が全て撤去されている
- 養生テープの糊残りがない
- 機材搬出による床面傷がない
- 家具・備品が元の位置に戻っている

### 場所別注意

| 場所 | 注意事項 |
|---|---|
| 病院 | 医療機器・備品は担当者立会いのもと復旧する |
| 商業施設 | 商品陳列・什器の位置を元通りにする |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 復旧確認チェックリストへの記録 |

### 食品施設への対応

- 食品エリアへの養生材・機材の残留がないことを確認する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 機材搬出による床面傷 | 中 | 高 | コロ・台車を使用して搬出する |
| 養生糊残りによる巾木損傷 | 中 | 中 | ゆっくり斜め方向に剥がす |

### 作業時間目安

15〜30分

### 必要人数

1〜2名

### NG例

- ポリッシャー・バキュームを床に引きずって搬出する
- 養生テープを力任せに剥がして巾木を傷める

### OK例

- ポリッシャー・バキュームはコロ・台車を使用して搬出する
- 養生テープはゆっくり斜め方向に剥がす

### よくある失敗

- 機材を引きずって搬出し、剥離後の清潔な床面に傷をつけた

### 改善方法

- 機材搬出計画（コロ・台車の使用）を施工前に立案する

### 写真撮影位置

- 復旧完了後の全景（表示・養生が全て撤去された状態）

### クレーム防止

- 機材搬出による床面傷クレームを防ぐ。必ずコロ・台車を使用する

## 工程16　最終品質確認

### 作業内容

剥離洗浄の全工程が完了した状態で、品質基準に基づき仕上がりを確認し、施設担当者への引き渡し品質を保証する。

### 理由

最終品質確認は施設担当者への引き渡し前の唯一のチェックポイントである。剥離洗浄はワックス塗布（後工程）の前処理であり、剥離が不完全な状態でワックスを塗布すると品質不良が連鎖する。特にワックス残留・剥離ムラ・洗剤残留の確認が重要である。

### 使用工具

- チェックリスト
- 懐中電灯（必要時）

### 使用薬剤

なし

### 作業方法

1. 入口側から床全景を目視で確認する（遠景・近景）
2. 照明下・窓際で光の角度を変えながら確認する（剥離ムラが見えやすい）
3. ワックスが完全に除去されているか確認する（黄変・光沢ムラがないか）
4. 剥離ムラがないか確認する
5. 洗剤残留・ベタつき・アルカリ感がないか手触りで確認する
6. 水分が残っていないか確認する
7. 床材の破損・変色がないか確認する
8. チェックリストに全項目を記入する
9. 問題があれば即座に対応する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 確認漏れによる品質不良の引き渡し | チェックリストで全項目確認する |
| 照明が暗くて剥離ムラを見落とす | 照明・懐中電灯を活用する |

### 品質基準

| 確認項目 | 品質基準 |
|---|---|
| ワックス除去 | 全面のワックスが除去されている（黄変・光沢ムラがない） |
| 剥離均一性 | 剥離ムラ・未剥離箇所がない |
| 洗剤残留 | 剥離剤・洗剤・ベタつきが残っていない |
| 水分 | 水滴・水溜まりがない |
| 中和確認 | ぬめり感・アルカリ感がない |
| 床材保護 | 施工による傷・変色・焼き付きがない |
| 壁際 | 壁際・隅部の剥離が完了している |
| 設備保護 | 巾木・壁・コンセントに剥離剤・汚水が付着していない |
| 養生撤去 | 養生材が全て撤去されている |
| 異常報告 | 発見した異常箇所が記録されている |

### 床材別注意

| 床材 | 確認ポイント |
|---|---|
| 長尺シート | 継ぎ目の状態・剥離ムラ |
| Pタイル | 目地の剥離状態・ワックス残留 |
| フローリング | 木目への損傷・変色 |

### 場所別注意

| 場所 | 確認ポイント |
|---|---|
| ホテルロビー | 剥離ムラ・床材変色（斜め光で確認） |
| 食品施設 | 洗剤残留・水分残留 |

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 品質確認チェックリストへの記録・承認 |
| ISO 14001 | 洗剤残留の確認（環境汚染防止） |

### 食品施設への対応

- 食品エリアの剥離剤残留・異物がないことを確認し衛生管理記録に記載する

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| 品質不良の見落とし | 中（省略時） | 高 | チェックリスト全項目確認 |

### 作業時間目安

10〜20分

### 必要人数

1名

### NG例

- 最終確認をせずに施設担当者に引き渡す
- 壁際・隅部の確認を省略する

### OK例

- チェックリストで全項目を確認する
- 照明下で斜め光を使い剥離ムラを確認する

### よくある失敗

- 壁際の剥離ムラを見落とし、後工程のワックス塗布後に品質不良が発覚した

### 改善方法

- 壁際・隅部を最終確認の必須項目としてチェックリストに明記する

### 写真撮影位置

- 作業後の床全景（入口側から奥に向けて）
- 壁際・隅部の剥離状態（近景）
- 施工前後の比較写真

## 工程17　写真撮影・報告書作成

### 作業内容

施工記録として写真撮影を行い、作業報告書を作成・提出する。

### 理由

剥離洗浄は強アルカリ剥離剤を使用する高リスク作業であり、写真・報告書は施工品質の証明・クレーム対応の証拠・次回施工計画の参考資料として不可欠である。また後工程（ワックス塗布）の担当者への引き継ぎ資料としても重要である。ISO・衛生管理の記録要件を満たすためにも必須である。

### 使用工具

- スマートフォン・デジタルカメラ（800万画素以上推奨）
- 報告書（紙または電子）

### 使用薬剤

なし

### 作業方法

**写真撮影**

1. 作業前写真：施工前の床全景・ワックス劣化状態・汚染箇所・床材破損を撮影する
2. 作業中写真：養生実施状況・剥離剤塗布・ポリッシャー施工・汚水回収・すすぎを撮影する
3. 作業後写真：剥離完了後の床全景・壁際・素地状態を撮影する
4. 異常箇所写真：床材破損・変色・浮きを発見した場合は必ず撮影する

**撮影ルール**

- 同じ位置・同じ高さ・同じ方向から撮影する
- 日付・時刻の記録機能をONにする
- 施工前後で同じ構図を維持して比較しやすくする
- 照明を活用して剥離状態が分かりやすい角度で撮影する

**報告書作成**

1. 基本情報（日時・現場名・作業者・天候・温度）を記入する
2. 使用剥離剤（CHEM管理番号・希釈率・使用量）を記入する
3. 施工内容（区画数・すすぎ回数・中和処理の有無）を記入する
4. 作業結果（良好・一部改善必要）を記入する
5. 異常箇所（写真と共に記載）を記入する
6. 後工程推奨（ワックス塗布の推奨時期・ワックス種類）を記入する
7. 写真を添付して施設担当者・管理者へ提出する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 個人情報・機密情報の写り込み | 撮影前に確認する |

### 品質基準

- 作業前・中・後の写真が揃っている
- 使用剥離剤のCHEM管理番号・希釈率が記録されている
- すすぎ回数・中和処理の有無が記録されている
- 報告書が全項目記入されている
- 提出が完了している

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 9001 | 品質記録の作成・保管 |
| ISO 14001 | 使用薬剤・廃液処理の記録 |
| ISO 45001 | 安全管理記録の作成 |

### 食品施設への対応

## 工程18　資機材清掃・後片付け

### 作業内容

使用した全ての資機材を洗浄・整理し、次回使用できる状態にして保管する。

### 理由

使用後の資機材に剥離剤・汚れが残ると、次回使用時に床面への汚染・薬剤被害が発生する。特にポリッシャー（TOOL-001）・ウエットバキューム（TOOL-005）は適切なメンテナンスなしに使用し続けると故障の原因になる。剥離パッドは洗浄・乾燥保管で次回も使用可能になる。廃液の適切な処理は法令遵守・環境管理上必須である。

### 使用工具

- 水道・ホース
- ブラシ
- 清潔なクロス

### 使用薬剤

なし（清水による洗浄）

### 作業方法

1. モップ（TOOL-009・010）を清水で3〜5回すすぐ
2. モップを絞り、伸ばした状態で乾燥させる
3. バケツ（TOOL-013）を清水で洗浄して剥離剤を完全除去する
4. 剥離パッド（TOOL-003）・黒パッド（TOOL-002）を清水で洗浄・乾燥させる
5. ポリッシャー（TOOL-001）本体を清水で拭き取り清掃する（電気系統に水をかけない）
6. ウエットバキューム（TOOL-005）のタンクを空にして清水で洗浄する
7. スクイジー（TOOL-006・007）を清水で洗浄する
8. カラーコーン（TOOL-015）・表示板（TOOL-016）を清水で拭き取る
9. 全資機材を所定の保管場所に収納する
10. 廃液・汚水を施設指定の方法で適切に処理する

### KY（危険予知）

| 危険 | 対策 |
|---|---|
| 洗浄中の剥離剤・汚水の飛散 | 手袋・保護メガネを着用する |
| ポリッシャー電気系統への水侵入 | 電気系統は拭き取りのみ。水をかけない |
| 廃液の不適切排出による環境汚染 | 施設指定方法で処理する |
| 重量機材の落下・怪我 | 複数名で搬出・保管する |

### 品質基準

- 全資機材が清潔に洗浄されている
- 剥離パッドが洗浄・乾燥保管されている
- ポリッシャー・ウエットバキュームが清潔に清掃されている
- 廃液が適切に処理されている
- 全資機材が所定の場所に収納されている

### ISO対応

| 規格 | 対応内容 |
|---|---|
| ISO 14001 | 剥離廃液の適切な処理・排水管理 |
| ISO 9001 | 資機材管理手順の標準化 |

### 食品施設への対応

- 食品施設で使用した資機材は他エリアと区別して保管する
- モップ・クロスは用途別に色分け管理する（現場仕様）

### リスクアセスメント

| リスク | 発生確率 | 重大度 | 対策 |
|---|---|---|---|
| ポリッシャー電気系統への水侵入 | 低 | 高 | 電気系統は拭き取りのみ |
| 廃液不適切処理による環境汚染 | 低 | 高 | 施設指定方法で処理する |
| 剥離剤残留による次回施工時の被害 | 中（洗浄不備時） | 高 | 全資機材の徹底洗浄 |

### 作業時間目安

20〜35分

### 必要人数

1〜2名

### NG例

- 剥離パッドを洗わずに湿ったまま保管する
- ポリッシャーに水をかけて洗浄する
- ウエットバキュームタンクの廃液を処理せず保管する

### OK例

- 剥離パッドを清水で洗浄して乾燥させてから保管する
- ポリッシャーは拭き取り清掃のみ行う
- 廃液を施設指定の方法で適切に処理する

### よくある失敗

- 剥離剤が付着したモップを洗わずに保管し、次回に持ち込んで床面を汚染した
- ウエットバキュームの廃液を排水溝に無処理で流し、施設担当者から指摘を受けた

### 改善方法

- 資機材清掃チェックリストを使用し、全項目を確認してから保管する

### クレーム防止

- 廃液の不適切処理による環境クレーム・法令違反を防ぐ

# 17. よくある失敗と改善方法

| 失敗 | 原因 | 改善方法 |
