# 業務用エアコン（天井カセット4方向）清掃 SOP

**対象：業務用天井カセット4方向エアコン**

---

# 1. 適用範囲

## 対象施設

- オフィス / 商業施設 / 飲食店 / 病院 / 学校 / ホテル / 福祉施設 / 工場 / 公共施設

## 対象設備

- 天井カセット4方向エアコン（天井埋込型4方向吹出しタイプ）

※家庭用壁掛けエアコンは対象外（AVL-SOP-AC-001を参照）。

## 対象作業

- 化粧パネル・フィルター・ルーバー・ドレンパン・送風ファン・熱交換器の分解洗浄
- ドレンポンプ点検・ドレンホース洗浄
- 消臭・防カビ施工 / 試運転・動作確認

## 施工可能条件

| 条件 | 基準 |
|------|------|
| 天井高さ | 2.5m〜4m（3段脚立対応範囲）。4m超は足場が必要 |
| 室内気温 | 5℃〜40℃（凍結・熱変形リスク回避） |
| 湿度 | 85%以下 |
| 雨天・強風・直射日光 | 室内作業のため天候不問 |
| 凍結 | 室内気温5℃以上であれば施工可。凍結時は室温を上げてから施工 |
| 感電リスク対策 | ブレーカーをOFFにできること。電装部の二重養生が可能なこと |
| 高所作業 | 脚立が水平に設置できる床面・スペースがあること（天井高4m超は足場必須） |
| 電源（作業用） | 高圧洗浄機の電源コンセントが使用可能であること |
| 水道 | 清水が使用可能であること |
| 排水先 | バケツ・排水口のいずれかを確保できること |
| 養生 | 電装部の二重養生・洗浄シート設置が実施可能なこと |

## 施工不可条件

| 条件 | 理由 |
|------|------|
| 天井高さ4m超（足場なし） | 転落リスク。足場設置後に施工 |
| 電装部の養生が不可能な機種 | 感電・基板損傷リスク |
| 水道が使用不可の現場 | 洗浄不可 |
| 排水先が確保できない現場 | 漏水リスク |
| 施工前からエラーコードが表示されている | 既存故障の可能性。担当者へ報告し指示を仰ぐ |
| ドレンポンプが故障・停止している | 施工後に排水不能になるリスク |
| 高圧洗浄機が使用できない環境 | 洗浄品質を確保できない |

## 作業中止基準

以下を発見した場合は即時作業を停止し、担当者へ報告する。

| 発見内容 | 対応 |
|------|------|
| 感電症状（しびれ・スパーク・焦げ臭） | 電源遮断・119番通報 |
| 配線の被覆損傷・焦げ跡 | 作業中止・電気工事業者へ連絡 |
| 冷媒ガス漏れ（甘い臭い・白い霧） | 換気・電気使用禁止・冷媒回収業者へ連絡 |
| ドレンポンプの異常音・停止 | 作業中止・ポンプ修理後に再開 |
| 水漏れが養生範囲を超えた | 作業中止・養生追加後に再開 |
| 天井材の損傷・たわみを発見 | 作業中止・施設担当者へ報告 |
| 担当者から中止指示 | 即時中止 |

# 2. 用語の定義

| 用語 | 内容 |
|------|------|
| 熱交換器 | アルミフィン部。冷暖房効率に直結する最重要部位。 |
| 送風ファン（シロッコファン） | 風を送るファン。羽根裏側にカビ・油汚れが最も付着しやすい。 |
| ドレンパン | 熱交換器下の結露水受け皿。スライム・カビが最も発生しやすい部位。 |
| ドレンポンプ | 結露水を強制的に排水するポンプ。業務用特有の装置。故障すると漏水の原因になる。 |
| フロートスイッチ | ドレンパンの水位を検知するセンサー。変形・破損禁止。 |
| ドレンホース | 結露水を屋外・排水口へ送るホース。詰まると逆流・漏水の原因。 |
| 化粧パネル | 天井に取り付けられた外装パネル。ABS樹脂製が多い。重量5〜8kg。 |
| 洗浄シート | 天井カセット専用の汚水回収バッグ。エアコン本体を包み、汚水をバケツへ誘導する。 |
| ルーバーモーター | ルーバー（風向き板）を動かすモーター。コネクター接続忘れに注意。 |
| 電装部 | 基板・配線・モーター・コネクターなど、水・洗剤が触れると故障する部品。 |
| KY活動 | 危険予知活動。作業前に危険を洗い出し事故を防ぐ。 |

# 4. 施工前確認

## 設置環境確認

1. 天井高さを確認する。3段脚立の最上段作業位置がエアコン本体に届くか確認する。
2. 脚立設置スペース（エアコン直下）に障害物がないか確認する。
3. 周辺の机・OA機器・家具を確認する。移動可能なものは移動する。
4. 排水先（バケツ設置場所または排水口）を確認する。

## 機種確認

1. 型式ラベルを確認・撮影する（化粧パネルを開けた内側または本体側面にある）。
2. ドレンポンプの有無・位置を確認する（ほぼ全機種に搭載）。
3. ルーバーモーターのコネクター数を確認する（4方向＝4枚＝コネクター4本が基本）。

**【写真①：型式ラベル】**

## 試運転（施工前）

1. リモコンで冷房運転を起動する。
2. 以下を確認・記録する。

| 確認項目 | 正常 | 異常 |
|---------|------|------|
| 冷暖房能力 | 設定温度に向かって変化する | 変化しない |
| 風量 | 4方向から均一に出る | 一部方向が弱い・出ない |
| ルーバー動作 | 4枚全て動く | 動かない・途中で止まる |
| ドレン排水 | 排水口から排水される | 排水がない・逆流する |
| 異音 | なし | ガタガタ・キーキー・ゴーゴー |
| 異臭 | なし | カビ臭・焦げ臭 |
| 水漏れ | なし | 化粧パネルから水が垂れる |
| エラー表示 | なし | エラーコード点灯 |

3. 異常がある場合は施工前に担当者・お客様へ報告し、指示を受けてから施工する。
4. 試運転を停止し、ブレーカーをOFFにする（電源プラグは対象外—ブレーカー必須）。

**【写真②：エアコン全景（作業前）】**

**【写真③：フィルター（汚れ状況）】**

**【写真④：吹出口・ルーバー状態】**

**【写真⑤：キズ・破損箇所（ある場合のみ）】**

## お客様・担当者への事前説明

施工開始前に必ず以下を伝える。

| 説明項目 | 説明内容の例 |
|---------|------------|
| 施工内容 | 「本日はエアコンを分解し、内部を高圧洗浄でお掃除します」 |
| 所要時間 | 「汚れの程度により2.5〜5時間かかります。飲食店の油汚れは最大6時間かかります」 |
| 水の使用 | 「水道水を使用します。排水は〇〇へ流します」 |
| 家具・OA機器 | 「作業範囲内の家具・機器を養生または移動します」 |
| 騒音 | 「高圧洗浄機の音がします。施工中は騒音が発生します」 |
| 施工後の汚水 | 「施工直後、ドレンから一時的に黒い汚水が流れる場合がありますが正常です」 |
| ドレンポンプ | 「排水ポンプを確認します。故障があれば施工前にご報告します」 |
| 異常発見時 | 「施工中に故障・異常を発見した場合はすぐにご報告します」 |

# 9. 詳細作業手順

---

## 工程1　事前確認・試運転・お客様説明

**目安時間：約10〜15分　必要人数：1名**

### 使用道具

TOOL-024（温度計）/ TOOL-025（LEDライト）/ リモコン / チェックシート

### 手順

1. 型式ラベルを確認・撮影する。ラベルは化粧パネルを開けた内側または本体側面にある。
2. ドレンポンプの有無・位置を確認する。ほぼ全機種に搭載されている。
3. ルーバーモーターのコネクター数を確認する（4方向＝4本が基本）。
4. リモコンで冷房運転を起動し、以下を確認する。
   - 4方向から均一に冷風が出るか
   - ルーバー4枚が全て動くか
   - 異音・異臭がないか
   - 水漏れ・エラー表示がないか
   - ドレン排水が正常か
5. 異常がある場合は施工前に担当者・お客様へ報告する。エラーコードは必ず記録する。
6. 試運転を停止し、ブレーカーをOFFにする。
7. 作業前写真を撮影する（写真①〜⑤）。

## 工程2　周辺養生・電装部養生・洗浄シート設置

## 工程3　本体分解

**目安時間：約30〜50分　必要人数：2名推奨（化粧パネル・ドレンパンは重量物）**

### 使用道具

TOOL-004（プラスドライバー）/ TOOL-005（六角レンチ）/ TOOL-006（内張りはがし）/ TOOL-007（コネクター抜き）/ TOOL-023（部品ケース）/ TOOL-024（LEDライト）

### 手順

**吸込グリル・フィルター取外し**

1. 吸込グリルの固定フックを押しながら、下から上へ押し上げ手前に引いて開ける。
2. フィルターを下に向けながら取り外す（ホコリが落下しないよう下にビニール袋を当てる）。

**化粧パネル取外し（重量5〜8kg）**

3. 化粧パネルの固定ビスを確認する（中央1〜2本＋四隅付近）。LEDライトで確認する。
4. ビスを全て外す。部品ケースに保管する。
5. ルーバーモーターのコネクターを外す（4本）。コネクター抜き（TOOL-007）を使い、ロックを押しながら水平方向へ引き抜く。
6. **2名で化粧パネルを支えながら取り外す。1名が脚立で支え、1名が受け取る。**（1名の場合は脚立上で一時固定してから降ろす）
7. 化粧パネルを床の養生シート上に安全に置く。

**ドレンパン取外し（重量3〜5kg）**

8. ドレンパンの固定ビスを外す。ドレンポンプの電源コネクターを外す（TOOL-007使用）。
9. **ドレンパン内に残水がある場合はウエスで吸い取ってから取り外す。**（残水がこぼれると漏水の原因）
10. **2名でドレンパンを支えながら取り外す。**（1名の場合はゆっくり降ろす）
11. ドレンポンプをドレンパンから取り外す（必要時）。フロートスイッチを曲げないよう注意する。

**送風ファン・熱交換器露出**

12. ファンモーターの固定ボルトを六角レンチで外す（サイズ4〜6mm・機種により異なる）。
13. 送風ファン（シロッコファン）を取り外す。
14. 熱交換器が露出したことを確認する。

**分解後の記録**

15. **分解後の内部状態・配線位置・コネクター配置を写真撮影する（必須）。**

**【写真⑦：分解後の内部状態・配線位置】**

**【写真⑧：ドレンパン・ドレンポンプ取外し後】**

### 注意事項

- 化粧パネル（5〜8kg）・ドレンパン（3〜5kg）は高所からの落下で重大事故になる。必ず2名で取り外す。
- コネクターはロックを解除してから引き抜く。引っ張るとコネクターが断線する。
- フロートスイッチは曲げると動作不良になる。取り扱いは丁寧に行う。
- ドレンパン内の残水は先に除去する。残水があると取り外し時に漏水する。
- 分解前に配線写真を必ず撮影する。組立時に参照する。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 化粧パネル | 2名で安全に取り外し・傷なし | 1名で無理に取り外し → 落下リスク |
| コネクター | ロック解除後に引き抜き・損傷なし | 引っ張って外した → 断線リスク |
| フロートスイッチ | 変形なし | 曲がっている → 動作不良 → 報告 |
| ビス管理 | 部品ケースで位置別に管理 | 床にバラバラに置いている |

### プロのコツ

- 化粧パネルは「重量物」として扱う。脚立の上で無理な体勢で持つと落下する。必ず2名で作業する。
- ドレンパンの残水は「ウエスを数枚敷いて吸わせる」と素早く除去できる。
- ファン固定ボルトは六角レンチのサイズが合わないと潰れる。必ずサイズを確認してから差し込む。

### 次工程へ進む判断

✅ 分解後の内部状態・配線位置の写真撮影完了（写真⑦⑧）

✅ 化粧パネル・ドレンパン・送風ファンの取外し完了

✅ 部品ケースにビスを種類別・位置別に保管済み

✅ フロートスイッチに変形がないことを確認済み

→ 工程4へ進む

## 工程4　部品洗浄

**目安時間：約20〜30分　必要人数：1名**

### 使用道具

TOOL-012（スポンジ）/ TOOL-010（Jブラシ）/ TOOL-014（ウエス）/ TOOL-013（マイクロファイバークロス）/ バケツ

### 使用薬剤・薬剤を選ぶ理由

| 対象部品 | 薬剤 | 選ぶ理由 |
|---|---|---|
| フィルター・樹脂部品 | CHEM-003（中性洗剤）50〜100倍 | 樹脂素材への影響が最も少ない。ホコリ・軽い汚れには中性洗剤で十分 |
| 化粧パネル・ルーバー（ABS樹脂） | CHEM-002（弱アルカリ性洗剤）50〜100倍 | 弱アルカリが皮脂汚れ・軽度カビを落とす。強アルカリ（CHEM-001）はABS樹脂を変色させるため使用禁止 |

### 手順

**フィルター**

1. バケツに水を張り、CHEM-003を50〜100倍希釈する。
2. フィルターを水に浸し、スポンジで撫でるように洗浄する（力は約200〜300g程度。絶対に擦らない）。
3. 細部はJブラシで3〜5往復する。
4. 水洗いして洗剤を完全に流す（すすぎ水が透明になるまで）。
5. ウエスで水気を拭き取り、自然乾燥させる。

**化粧パネル・ルーバー**

6. CHEM-002を50〜100倍希釈した液をスプレーボトルに入れ、全面に吹きかける。放置時間：2〜3分。
7. スポンジで全体を拭き取る（力は約300〜400g程度）。
8. 水で濡らしたウエスで洗剤を拭き取る。
9. 乾いたマイクロファイバークロスで仕上げ拭きをする。

**ルーバー（4枚）**

10. 各ルーバーを同様に洗浄する。可動軸・モーター取付部に負荷をかけない。
11. 水気を拭き取り、乾燥させる。

**【写真⑨：部品洗浄状況】**

### 注意事項

- 化粧パネル・ルーバーはABS樹脂製。強アルカリ洗剤（CHEM-001）の使用禁止。変色・変形の原因。
- フィルターを強く擦ると目詰まりまたは破損する。
- 高温乾燥禁止（変形の原因）。自然乾燥または常温ドライヤーのみ使用。
- 洗浄は熱交換器洗浄（工程5）の薬剤放置時間中に並行して行うと時間短縮できる。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| フィルター | ホコリなし・破損なし・洗剤残りなし・光に透かして均一 | 破れている・洗剤が残っている |
| 化粧パネル | 拭きムラなし・乾燥している | 水滴が残っている・洗剤ムラあり |
| ルーバー | 可動軸が無傷・全ての面が洗浄されている | 軸が変形している → 報告 |

### プロのコツ

- 化粧パネルは「4方向全ての面」を洗浄する。裏面のカビ・ホコリを見落とさない。
- ルーバーはモーター取付部の向きを確認してから洗浄する。向きを間違えると組立時に取り付けられない。

### 次工程へ進む判断

✅ フィルター：ホコリなし・破損なし・洗剤残りなし（光に透かして均一）

✅ 化粧パネル：拭きムラなし・乾燥している

✅ ルーバー4枚：可動軸が無傷・全面洗浄済み・乾燥している

→ 工程5へ進む（工程5の薬剤放置時間中に工程4を並行実施すると時間短縮できる）

## 工程5　熱交換器（アルミフィン）洗浄

**目安時間：約30〜45分　必要人数：1〜2名**

### 使用道具

TOOL-001（高圧洗浄機）/ TOOL-008（噴霧器）/ TOOL-024（LEDライト）

### 使用薬剤・薬剤を選ぶ理由

**CHEM-001（業務用エアコン専用アルカリ洗剤）を使う理由**：アルカリ成分がアルミフィンに付着したカビ・油汚れ・ヤニを鹸化（乳化）して浮かせる。アルミフィン対応品を使用することで、アルミ素材へのダメージを最小限に抑えながら洗浄できる。飲食店の油汚れは濃度を高め・放置時間を長くすることで分解効率を上げる。

| 汚れの程度 | 希釈倍率 | 使用量 | 放置時間 |
|----------|---------|--------|--------|
| 通常（ホコリ・軽度カビ） | 30〜50倍 | 約80〜100ml | 3〜5分 |
| 重度（カビ多・ヤニ） | 10〜20倍 | 約100〜150ml | 5〜10分 |
| 飲食店（油汚れ） | 10〜20倍 | 約120〜150ml | 10〜15分 |

### 手順

**洗剤塗布**

1. 噴霧器にCHEM-001希釈液を入れる。
2. 熱交換器の上部から下部へ向けて均一に噴霧する。ノズルを熱交換器から15〜20cm離す。泡立つまで全体にかける。
3. 放置時間を守る（上表参照）。放置中は部品洗浄（工程4）を並行して進める。

**高圧洗浄**

4. 高圧洗浄機の水圧を3〜5MPaに設定する。
5. ノズルをアルミフィンから15〜20cm離す。
6. ノズル角度はアルミフィンに対して90度（垂直）。斜めにするとフィンが倒れる。
7. 上部から下部へ向けて一定速度（約10〜15cm/秒）で移動しながら洗浄する。
8. 洗浄水が透明になるまで繰り返す。
9. フィンの変形がないかLEDライトで確認する。

**【写真⑩：熱交換器洗浄前（汚れ状態）】**

**【写真⑪：熱交換器洗浄後（汚れ除去確認）】**

### 注意事項

- 水圧は5MPaを超えない（フィン変形・電装部浸水の原因）。
- ノズルは15cm未満に近づけない。
- 電装部・ドレンポンプ・ルーバーモーターに向けて噴射しない。
- ノズルをフィンに対して斜めにしない（フィンが倒れる）。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| フィン | 変形なし・均一に洗浄・洗剤残りなし | フィンが1箇所以上曲がっている → フィン起こし必要 |
| 洗浄水 | 透明 | 茶色・黒い汚水が出続ける → すすぎを継続 |
| 電装部 | 濡れていない | 濡れている → 即電源確認・乾燥処置 |

### プロのコツ

- 飲食店の油汚れは「2回洗浄（1回目洗剤→すすぎ→2回目洗剤→最終すすぎ）」が効果的。1回では落ちないことが多い。
- 洗剤噴霧後、全面が泡立つ程度が適切。泡立たない場合は濃度が薄すぎる。
- フィン変形が起きた場合は、フィンコームまたは指で慎重に起こす。完全に起こせない場合はお客様へ報告する。

### 次工程へ進む判断

✅ 熱交換器全面の汚れ除去完了（LEDライトで確認）

✅ 洗浄水が透明になっている

✅ フィンに変形がない（変形がある場合は報告済み）

✅ 電装部が濡れていない

→ 工程6へ進む

## 工程6　ドレンパン・ドレンポンプ洗浄

**目安時間：約20〜30分　必要人数：1名**

### 使用道具

TOOL-008（噴霧器）/ TOOL-010（Jブラシ）/ TOOL-012（スポンジ）/ TOOL-017（ドレンホースクリーナー）/ TOOL-024（LEDライト）

### 使用薬剤・薬剤を選ぶ理由

| 汚れ状態 | 薬剤 | 選ぶ理由 |
|---|---|---|
| 通常のスライム・ぬめり | CHEM-002（弱アルカリ性洗剤）50〜100倍 | 弱アルカリがスライムのタンパク質・菌を分解する。ドレンポンプ周辺の素材への影響がCHEM-001より少ない |
| 重度スライム・カビ多 | CHEM-001（アルカリ洗剤）30〜50倍 | スライムの菌糸を強力に分解する必要がある場合に使用。ドレンポンプ本体への噴霧は禁止 |

### 手順

**ドレンパン洗浄**

1. LEDライトでドレンパンの状態を確認する。スライム（黒・ピンク・白色の粘液）・カビ・ゴミの有無を確認する。

**【写真⑫：ドレンパン洗浄前の状態（スライム・カビ）】**

2. CHEM-002（50〜100倍希釈）を噴霧器でドレンパン全体に噴霧する。放置時間：2〜3分（スライムが多い場合は5分）。
3. スポンジで底面・壁面・排水口周辺を撫でるように洗浄する（約300〜400g程度の力）。
4. Jブラシで排水口・角・フロートスイッチ周辺を3〜5往復する。フロートスイッチを曲げない。
5. 高圧すすぎ（工程8）で同時に洗い流す。

**ドレンポンプ確認・洗浄**

6. ドレンポンプ本体・フロートスイッチの状態を目視確認する。破損・異物詰まりがないか確認する。
7. ドレンポンプ本体への高圧洗浄は禁止。スポンジまたはウエスで外面を拭く。
8. ドレンポンプの吸込口周辺のゴミ・スライムをJブラシで除去する（低圧水または手で洗浄）。

**ドレンホース洗浄**

9. ドレンホースの出口（排水先）を確認する。ゴミ・詰まりがないか確認する。
10. ドレンホースクリーナー（TOOL-017）をホース取り付け口から差し込む。ゆっくり押し引きを5〜10回繰り返す。無理に押し込まない。
11. バケツに水を流してドレンパンへ注ぎ、ドレンポンプが作動して排水されるか確認する。

**【写真⑬：ドレンパン洗浄後の状態】**

### 注意事項

- ドレンポンプ本体に高圧洗浄機を向けない。ポンプ内部に水が浸水して故障する。
- フロートスイッチを曲げると動作不良（排水エラー）の原因になる。
- ドレンホースクリーナーを無理に押し込まない。ホースに穴が開く可能性がある。
- フロートスイッチの動作確認（水位が上がると動作するか）は試運転時に確認する。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| ドレンパン | スライムなし・カビなし・排水口清通 | スライムが残っている → 再洗浄 |
| ドレンポンプ | 外面清潔・フロートスイッチ変形なし | フロートスイッチが曲がっている → 報告 |
| ドレンホース | 水を流すとスムーズに排水される | 逆流する・流れない → 詰まり除去を継続 |

### プロのコツ

- ドレンパンのスライムは「先にCHEM-002で5分浸透させる」と高圧洗浄で楽に除去できる。
- ドレンポンプが正常かどうかは「ドレンパンに水を注いでポンプが作動するか」で確認できる。組立後より先に確認しておくと安心。

### 次工程へ進む判断

✅ ドレンパン：スライムなし・カビなし・排水口清通

✅ ドレンポンプ：外面清潔・フロートスイッチに変形なし

✅ ドレンホース：水を流してスムーズに排水されることを確認済み

→ 工程7へ進む

## 工程7　送風ファン（シロッコファン）洗浄

**目安時間：約20〜30分　必要人数：1名**

### 使用道具

TOOL-001（高圧洗浄機）/ TOOL-008（噴霧器）/ TOOL-011（洗浄ブラシ）/ TOOL-010（Jブラシ）

### 使用薬剤・薬剤を選ぶ理由

**CHEM-001（業務用エアコン専用アルカリ洗剤）を使う理由**：送風ファン（金属製）の羽根内側に蓄積したカビ・油汚れはアルカリ洗剤が最も効果的。飲食店では油汚れが羽根内部に固着しているため、高濃度・長い放置時間で油分を鹸化してから除去する。

| 汚れの程度 | 希釈倍率 | 使用量 | 放置時間 |
|----------|---------|--------|--------|
| 通常 | 30〜50倍 | 約50〜80ml | 3〜5分 |
| 重度カビ・飲食店油汚れ | 10〜20倍 | 約80〜100ml | 5〜10分 |

### 手順

**洗剤塗布**

1. 噴霧器にCHEM-001希釈液を入れる。
2. 送風ファンの羽根全体に均一に噴霧する。
3. 羽根の裏側（汚れが最も多い面）にも必ず噴霧する。
4. 放置時間を守る（上表参照）。

**ブラッシング（目視でカビ・油汚れが残っている場合）**

5. 洗浄ブラシ（TOOL-011）をファンの羽根に対して平行に当て、約500g程度の力で3〜5往復する。
6. Jブラシで羽根の隙間・根元部分を3〜5往復する。

**高圧すすぎ**

7. 高圧洗浄機（3〜5MPa）でファン全体をすすぎ洗浄する。
8. ファンモーターの軸受け部分・電線に直接噴射しない。
9. 汚水が透明になるまですすぎを繰り返す。

**【写真⑭：送風ファン洗浄前（カビ・油汚れ状態）】**

**【写真⑮：送風ファン洗浄後】**

### 注意事項

- ファンモーター本体への直接高圧洗浄禁止。モーターに水が入ると故障する。
- 羽根を変形させない。変形するとバランスが崩れて振動・騒音が発生する。
- 羽根の裏側は最も汚れが多い。洗浄後にLEDライトで裏面を確認する。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 羽根 | カビなし・油汚れなし・裏面まで洗浄済み | 羽根の裏側にカビが残っている → 再洗浄 |
| ファンバランス | 均一洗浄（片側だけ洗浄しない） | 片側だけ洗浄 → バランス崩れ・振動 |
| すすぎ水 | 透明 | 色付きの汚水が出続ける → 再洗浄 |

### プロのコツ

- 天井カセットのシロッコファンは「羽根の内側（ドラム内部）」に油汚れが蓄積しやすい。内部にJブラシを差し込んで確認する。
- 飲食店の油汚れは浸透時間が重要。10分以上放置してからブラッシングすると除去効率が上がる。

### 次工程へ進む判断

✅ 羽根の裏面までカビ・油汚れなし（LEDライトで裏面を確認）

✅ すすぎ水が透明

✅ ファンモーター本体が濡れていない

→ 工程8へ進む

## 工程8　高圧すすぎ洗浄

**目安時間：約20〜30分　必要人数：1名**

### 使用道具

TOOL-001（高圧洗浄機）

### 手順

1. 高圧洗浄機の水圧を設定する（熱交換器：3〜5MPa / ドレンパン：2〜3MPa）。
2. 熱交換器全体を上から下へ向けて洗浄する。ノズル距離：15〜20cm。ノズル角度：フィンに対して90度。
3. ドレンパンを低圧（2〜3MPa）で洗浄する。フロートスイッチ・ドレンポンプへは向けない。
4. 送風ファンを洗浄する。ファンモーター軸受け・電線には向けない。
5. ドレンポンプが作動してバケツへ排水されていることを確認する。
6. 洗浄水の色を確認する。透明になるまで繰り返す。
7. 天井・壁で水漏れが発生していないか確認する。

**【写真⑯：高圧すすぎ中の状態・排水状況】**

### 注意事項

- 電装部・ドレンポンプ・ルーバーモーターに絶対に水を向けない。
- アルミフィンに対してノズルを斜めにしない（フィン変形の原因）。
- ドレンポンプが止まるとドレンパンから溢れる。バケツの水量を定期的に確認し、満杯になる前に捨てる。
- すすぎ不足は臭い再発・洗剤残留・フィン腐食の原因。汚水が透明になるまで必ず継続する。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| すすぎ水 | 透明・泡なし | 茶色・黒・泡が残っている → 継続 |
| 排水 | ドレンポンプが作動しバケツへ排水 | 排水音がしない → ドレンポンプ確認 |
| 漏水 | 天井・壁からの漏水なし | 漏水あり → 即停止・養生確認 |

### プロのコツ

- バケツの水が満杯になる前に捨てる習慣をつける。洗浄中に確認を怠るとバケツから溢れる。
- すすぎの最後は洗浄シートの内側を水で洗い流す。洗浄シート内に残った汚水が後から漏れる場合がある。

### 次工程へ進む判断

✅ 全部位の洗浄水が透明・泡なし

✅ ドレンポンプが作動してバケツへ正常排水されている

✅ 天井・壁からの漏水がない

✅ 電装部が濡れていない

→ 工程9へ進む

## 工程9　乾燥・消臭・防カビ処理

**目安時間：約15〜20分　必要人数：1名**

### 使用道具

TOOL-015（ブロワー）/ TOOL-016（ドライヤー）/ TOOL-013（マイクロファイバークロス）/ TOOL-009（スプレーボトル）

### 使用薬剤・薬剤を選ぶ理由

| 薬剤 | 使う場面 | 選ぶ理由 |
|---|---|---|
| CHEM-004（消臭剤） | カビ臭・タバコ臭・油臭がある場合 | 臭気の原因物質を化学的に分解・中和する。洗浄後の乾燥した状態で使うことで効果を発揮する |
| CHEM-005（防カビ剤） | カビが多かった・定期メンテナンス時 | カビの再発を抑制する成分を内部に定着させる。洗浄・乾燥後に施工しないと効果がない |

### 手順

**乾燥**

1. マイクロファイバークロスで手が届く内部の水滴を拭き取る。
2. ブロワー（TOOL-015）を熱交換器・送風ファン・吹出口内部へ当てる。出口を対象から20〜30cm離し、約10分間乾燥させる。電装部・ドレンポンプへ直接当てない。
3. ブロワー後も水滴が残っている箇所はドライヤー（TOOL-016）を弱温風設定・20cm以上離して当てる。電装部・モーターに温風を集中させない。
4. 乾燥完了の確認：手で内部に触れて水気がなく、LEDライトで内部の水滴が確認できない状態。

**消臭施工（カビ臭・タバコ臭・油臭がある場合）**

5. CHEM-004をスプレーボトルに入れる（原液または2〜5倍希釈）。
6. 吹出口内部・送風ファン・熱交換器へ各3〜5回スプレーする。
7. 乾燥させる（拭き取り不要）。

**防カビ施工（カビが多かった場合・定期メンテナンス時）**

8. CHEM-005をスプレーボトルに入れる（原液または2〜3倍希釈）。
9. 熱交換器・送風ファン・ドレンパン・吹出口内部へ各2〜3回スプレーする。
10. 乾燥させる（拭き取り不要）。

**【写真⑰：乾燥完了後の内部状態】**

### 注意事項

- 内部が湿ったまま組み立てると短期間でカビが再発する。乾燥を省略しない。
- ドライヤーの温風を電装部・モーターに集中させると熱損傷する。
- 消臭剤・防カビ剤は洗浄・乾燥後に施工する。洗浄前に使用しても効果がない。
- CHEM-004とCHEM-005は混合しない。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 乾燥 | 手で触れて水気なし・LEDで水滴なし | 内部に水滴が残っている → ブロワー継続 |
| 防カビ剤 | 全部位に均一に施工 | 熱交換器のみ施工・ドレンパンを忘れた |

### プロのコツ

- 飲食店は油分が多いため、乾燥後に消臭剤を念入りに施工する。施工直後は消臭剤の香りが出るがお客様に事前説明しておく。
- 乾燥が不十分な状態で組み立てると、試運転後1〜2週間でカビが再発する。丁寧に乾燥させる。

### 次工程へ進む判断

✅ 手で内部に触れて水気がない

✅ LEDライトで内部に水滴が確認できない

✅ 消臭剤・防カビ剤の施工完了（対象箇所全て乾燥させた）

→ 工程10へ進む

## 工程10　組立・復旧

**目安時間：約30〜45分　必要人数：2名推奨（化粧パネル・ドレンパンは重量物）**

### 使用道具

TOOL-004（プラスドライバー）/ TOOL-005（六角レンチ）/ TOOL-007（コネクター抜き）/ TOOL-023（部品ケース）/ TOOL-024（LEDライト）

### 手順

**分解の逆順で組み立てる。工程3で撮影した配線写真を参照しながら施工する。**

1. 送風ファンをファンモーターに取り付ける。六角レンチで固定ボルトを締め付ける。ボルトの締め過ぎはモーター破損の原因（手で締め込んだ後に180度（半回転）締める程度）。
2. ドレンポンプをドレンパンに取り付ける（取り外した場合）。フロートスイッチが正しい位置にあることを確認する。
3. ドレンパンを取り付ける。固定ビスを締め付ける。**2名で支えながら取り付ける。**
4. ドレンポンプの電源コネクターを接続する（「カチッ」と音がするまで押し込む）。
5. 撮影した写真と照合しながら全コネクターを接続する。ルーバーモーターコネクター4本を全て接続する。
6. **化粧パネルを2名で取り付ける。**（脚立上の1名が保持し、もう1名が受けながら固定する）
7. 化粧パネルの固定ビスを締め付ける。
8. フィルターを正しい向きで取り付ける。
9. 吸込グリルを取り付ける。固定フックが全て掛かっていることを確認する。
10. 部品ケースのビスが残っていないことを確認する（残っていれば付け忘れ）。

**【写真⑱：組立完了状態】**

### 注意事項

- 化粧パネル（5〜8kg）・ドレンパン（3〜5kg）は高所からの落下で重大事故になる。必ず2名で取り付ける。
- コネクターの接続忘れは動作不良・エラーの直接原因。全コネクターを写真と照合して確認する。
- ルーバーモーターコネクターが4本全て接続されているか必ず確認する。1本でも外れると試運転時にエラーになる。
- ドレンパン固定ビスの締め忘れは水漏れの原因になる。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| コネクター | 全接続確認・「カチッ」音あり | 1本でも未接続 → エラー・水漏れ |
| ドレンポンプコネクター | 接続済み・「カチッ」音あり | 未接続 → 排水できない・漏水 |
| 化粧パネル | 2名で安全に取り付け・ビス全締め | 浮いている・ビスが残っている |
| フィルター | 正しい向き・しっかり固定 | 逆向き・浮いている |

### プロのコツ

- 「部品ケースが空になったら組立完了」というルールで管理すると付け忘れを防げる。
- ルーバーモーターコネクターは「4方向・4本」と口に出して確認する（指差呼称）。
- 組立後に全コネクターを約2〜3kgの力で引っ張り、抜けないことを確認する習慣をつける。

### 次工程へ進む判断

✅ 部品ケースが空になっている（ビスの付け忘れなし）

✅ ルーバーモーターコネクター4本すべて接続済み（指差呼称確認）

✅ ドレンポンプコネクター接続済み（カチッと音がした）

✅ 化粧パネルのビスが全て締め付け済み

✅ フィルター・吸込グリルが正しく取り付けられている

→ 工程11へ進む

## 工程11　試運転・最終確認

**目安時間：約15〜20分　必要人数：1名**

### 使用道具

リモコン / TOOL-025（温度計）/ TOOL-013（マイクロファイバークロス）/ チェックシート / カメラ

### 手順

**試運転**

1. ブレーカーをONにする。
2. リモコンで冷房運転を起動する。
3. 以下を10〜15分間確認する。

| 確認項目 | OK基準 |
|---------|--------|
| 冷風 | 4方向から均一に冷たい風が出る |
| 風量 | 設定通り |

| 異臭 | なし |
| 水漏れ | 化粧パネルから水が垂れない |
| エラー表示 | なし |

5. 化粧パネル全体をマイクロファイバークロスで乾拭きする。一方向に拭き、拭きムラをなくす。
6. 吹出口の縁・ルーバー周辺の拭き残しを確認する。

**最終写真撮影**

**【写真⑲：エアコン全景（作業後）】**

**【写真⑳：熱交換器（洗浄後）】**

**【写真㉑：送風ファン（洗浄後）】**

**【写真㉒：ドレンパン（洗浄後）】**

**【写真㉓：吹出口・ルーバー（作業後）】**

**【写真㉔：試運転状況】**

### 注意事項

- 試運転は10〜15分以上行う。短すぎると異常を見落とす。
- ドレンポンプの作動確認は試運転中に必ず行う（排水音が聞こえるか確認）。
- エラー表示が出た場合は即座に電源を切り、コネクターの接続を全て確認する。
- ルーバーが動かない場合はルーバーモーターコネクターの接続を確認する。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 試運転 | 4方向均一冷風・ルーバー全動作・エラーなし | 動かない・異音あり・エラー → コネクター確認 |
| ドレンポンプ | 作動音あり・正常排水 | 作動しない・排水されない → 接続確認 |
| 外装 | 拭きムラなし・水滴なし | 水滴・拭きムラあり |

### プロのコツ

- 施工前後の吹出口温度を温度計で比較する。施工後に冷気温度が改善していればお客様へ具体的な効果を伝えられる。
- 試運転中に「4方向全ての吹出口に手をかざして風量を確認する」。均一でない場合はルーバーまたはファンの問題がある可能性がある。

### 次工程へ進む判断

✅ 冷房正常（4方向から均一に冷風・設定温度±3℃以内）

✅ ルーバー4枚全て正常動作

✅ ドレンポンプ正常作動（排水音確認）

✅ 異音・異臭・水漏れ・エラー表示なし

✅ 作業後写真撮影完了（写真⑲〜㉔）

→ 工程12へ進む

## 工程12　養生撤去・現場復旧・お客様説明

**目安時間：約10〜15分　必要人数：1〜2名**

### 手順

**養生撤去**

1. 試運転が正常であることを確認してから養生を撤去する。
2. 洗浄シートを取り外す。汚水がこぼれないよう下に向けながら外す。残水はバケツへ捨てる。
3. 電装部の養生テープを剥がす（剥がし忘れがないよう全箇所確認する）。
4. マスカー・養生テープを丁寧に剥がす。壁紙・設備が剥がれないよう壁と平行方向（横方向）にゆっくり剥がす。
5. 養生シートを折り畳んでゴミ袋に入れる。

**現場復旧**

6. 移動した机・OA機器・家具を元の位置に戻す。
7. 床・壁に水滴・汚れが残っていないか確認し、残っていれば拭き取る。
8. 自分の工具・資材を全て確認する。忘れ物がないか確認する。

**お客様・担当者への最終説明**

| 説明項目 | 内容 |
|---------|------|
| 施工完了 | 「本日の作業が完了しました」 |
| 施工内容の報告 | 分解洗浄した部位・使用薬剤・特記事項（重度汚染・ドレン詰まり等） |
| 状態の報告 | 作業前後の写真を見せる「洗浄前はこの状態でした。洗浄後はこの状態です」 |
| 異常の報告 | 施工中に発見した異常（フィン変形・ドレンポンプ劣化・水漏れ跡等）を伝える |
| 次回目安 | 施設の種類に応じた次回推奨時期を伝える（第13章参照） |
| 施工後の注意 | 「施工直後1〜2分はドレンから黒い汚水が出る場合がありますが正常です」 |

### 注意事項

- 養生テープを急いで剥がすと壁紙・設備の塗装が剥がれる。必ずゆっくり横方向へ剥がす。

# 14. 安全管理

## 感電防止

- 作業前にブレーカーをOFFにする（電源プラグは対象外—ブレーカー必須）
- ブレーカーOFF後に電装部を防水二重養生する
- 濡れた手で電装部・コネクターに触れない
- 試運転時は養生が全て撤去されてから通電する

## 転落防止（高所作業）

- 脚立は水平な床に設置する
- 天板に乗らない
- 3点支持（両手1足または両足1手）を守る
- 脚立上で無理な体勢を取らない
- 重量物（化粧パネル・ドレンパン）は脚立上で単独で持たない。必ず2名で作業する

## 薬剤管理

- 薬剤ラベルの注意事項を確認してから使用する
- 推奨希釈倍率を厳守する
- 酸性薬剤とアルカリ性薬剤を混合しない

## 感染対策

- 手袋・マスク着用
- 作業後の手洗い・工具洗浄

## 緊急時対応

| 事故 | 対応 |
|------|------|
| 感電 | ブレーカーを遮断してから対応。感電者に直接触れない。119番通報。 |
| 転落 | 応急処置→動かさない→救急要請（119番）→責任者へ報告。 |
| 漏水（天井・設備） | 洗浄を即停止。電源を切る。養生を補強してから対応。担当者へ即座に報告。 |
| 薬剤が目に入った | その場で15分以上水洗眼。医療機関を受診。 |
| 薬剤が皮膚に付いた | 流水で15分以上洗浄。 |
| 化粧パネル落下 | けが人確認→応急処置→担当者へ報告。パネルの損傷状況を記録する。 |
