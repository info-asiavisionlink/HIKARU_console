# ガラス・窓まわり清掃 SOP

**対象：窓ガラス・サッシ・網戸・鏡・ガラス建具**

---

# 1. 適用範囲

## 対象施設

- ホテル / オフィス / 商業施設 / マンション / 病院 / 学校 / 公共施設 / 一般住宅 / 飲食店

## 対象設備・作業範囲

- 窓ガラス（内側・外側）/ FIXガラス / ガラス扉 / ガラスパーテーション
- ショーウィンドウ / 自動ドアガラス / 鏡 / サッシ / 窓枠 / 網戸 / レール / 水切り

## 施工可能条件

| 条件 | 基準 |
|------|------|
| 天候（外側） | 晴れ・曇り。雨天・強風（目安：風速5m/s以上）は外側施工不可。施工後2時間以内に雨の予報がある場合は施工延期 |
| 気温 | 5℃〜40℃（5℃未満は洗浄液が凍結リスクあり。40℃超はガラスが急乾燥し拭きムラが出やすい） |
| 凍結 | 気温5℃以上かつガラス表面が凍結していないこと。凍結時は室温が上がるまで施工延期 |
| 直射日光 | 直射日光が当たるガラスは洗浄液が急速乾燥するため避ける。早朝・日陰面・曇天から施工する |
| 高所作業 | 2m超は脚立・足場が必要。5m超はフルハーネス必須。ロープ作業は有資格者のみ |
| 感電リスク対策 | 電気設備（コンセント・スイッチ・照明）周辺は養生し、水が直接かからないようにすること |
| 作業スペース | スクイジー・シャンパーが使える最低40cmの作業空間があること |
| 養生 | 床・家具・電気設備への水滴防止養生が実施可能なこと |

## 施工不可条件

| 条件 | 理由 |
|------|------|
| ヒビ・欠けのあるガラス | 清掃中に割れる可能性がある。施工前にお客様へ報告 |
| コーティング・フィルムの種類が不明なガラス | 素材不適合による損傷リスク |
| 雨天・強風（目安：風速5m/s以上）時の高所外側施工 | 転落・転倒リスク |
| 5m超の高所（資格なし・足場なし） | 重大事故リスク |
| テスト施工で白化・変色が確認されたガラス | 素材適合不可 |

## 作業中止基準

以下を発見した場合は即時作業を停止し、お客様・担当者へ報告する。

| 発見内容 | 対応 |
|------|------|
| ガラスにヒビ・欠けを発見（施工中） | 即時中止・写真撮影・報告 |
| 高所作業中に強風が急変（目安：体に当たる風を感じる5m/s以上） | 即時降下・作業中止 |
| 薬剤が目・皮膚に付着 | 流水で15分以上洗浄・受診 |
| フィルム・コーティングの剥がれを発見 | 中止・写真撮影・報告 |
| 雷・落雷の兆候（高所外側作業中） | 即時降下・屋内退避 |

# 2. 用語の定義

| 用語 | 内容 |
|------|------|
| シャンパー（ウォッシャー） | ガラスに洗浄液を塗布する道具。スポンジカバー付きのT型ホルダー。 |
| スクイジー | ゴムブレードでガラス面の水・洗浄液・汚れを一方向に掻き取る道具。仕上がり品質を左右する最重要工具。 |
| 替えゴム | スクイジーのゴムブレード。摩耗・切れが生じたら交換。施工前に必ず確認する。 |
| スクレーパー | 刃を使ってガラス面のシール跡・固着した汚れを削り取る道具。使用可能なガラスが限られる。 |
| フロートガラス | 一般的な透明ガラス。建築用に最も多く使われる。 |
| Low-Eガラス | 熱反射コーティングが施されたガラス。コーティングを傷付けるスクレーパー・メラミンスポンジ・強アルカリ・強酸禁止。 |
| フィルム施工ガラス | 飛散防止・遮熱等のフィルムが貼られたガラス。フィルムを傷付ける道具・薬剤は使用禁止。 |
| テスト施工 | 目立たない小範囲で薬剤・道具の適合を確認する作業。本施工前に必ず実施する。 |
| 水垢（スケール） | 雨水・水道水のカルシウム・ミネラル分が固着した白い汚れ。中性洗剤では除去できず酸性洗剤が必要。 |

- ガラス扉・自動ドア・エントランスガラス・鏡の指紋・手垢・水滴除去

## 週次清掃

- 内側窓ガラス / サッシ / レール / 窓枠 / 網戸

## 月次清掃

- 外側ガラス全面 / 外部サッシ / 水切り / FIXガラス

## 半年・年次清掃

- 高所ガラス / 水垢除去 / 特殊汚れ除去 / コーティング・シーリング確認

# 4. 施工前確認

## ガラス種類の確認（最重要）

施工開始前に必ずガラス種類を確認する。種類によって使用できる薬剤・道具が異なる。

| ガラスの種類 | 見分け方 | 使用可否のポイント |
|------------|---------|-----------------|
| フロートガラス（一般） | 透明・反射なし | 基本的に全薬剤・道具が使用可 |
| 強化ガラス | 端部に「強化」刻印あり・透明度高い | スクレーパーは浅い角度のみ。端部衝撃禁止 |
| 網入りガラス | 内部に金属網が見える | 中性洗剤のみ。サビ・割れ確認 |
| Low-Eガラス | 反射色がわずかに着色（青・緑等） | スクレーパー・メラミン・強アルカリ・強酸禁止 |
| フィルム施工ガラス | 端部にフィルムの縁が見える | スクレーパー・メラミン・溶剤系禁止 |
| コーティングガラス | 虹色反射・マット感 | メーカー確認後のみ施工可 |

## 汚れの確認

1. ガラス全体を外光に当てて確認する（斜めから見ると汚れが見えやすい）。
2. 水垢（白い固着）・油膜（虹色の膜）・シール跡・鳥害汚れ（白い斑点）の有無を確認する。
3. ヒビ・欠け・フィルムの浮き・シーリングの劣化を確認する。

## テスト施工の実施

1. 目立たない箇所（下隅・端部）に薬剤を約5ml（コイン大）塗布する。
2. 30秒〜1分後に白化・変色・コーティング剥がれがないか確認する。
3. 異常があれば即座に水で洗い流し、施工を中止してお客様へ報告する。

**【写真①：ガラス状態（汚れ・異常確認）】**

## お客様への事前説明

| 説明項目 | 説明内容の例 |
|---------|------------|
| 施工内容 | 「本日は窓ガラス・サッシ・網戸を清掃します」 |
| 施工範囲 | 「今回は〇〇の窓を対象とします」 |
| 水の使用 | 「水道水を使用します。床に養生シートを敷きます」 |
| 異常発見時 | 「ヒビ・傷・コーティング剥がれを発見した場合はすぐにご報告します」 |
| 水垢・油膜 | 「頑固な水垢や油膜は通常清掃とは別に専用作業が必要な場合があります」 |
| 施工不可箇所 | 「フィルム・コーティングの種類によっては施工できない場合があります」 |

# 9. 詳細作業手順

---

## 工程1　ガラス確認・テスト施工・養生

**目安時間：約10〜15分　必要人数：1〜2名**

### 使用道具

TOOL-007（マイクロファイバークロス）/ TOOL-016（養生シート）/ TOOL-017（養生テープ）/ TOOL-009（ウエス）

### 手順

**ガラス確認**

1. 全対象ガラスを外光（斜め方向）で確認する。水垢・油膜・シール跡・ヒビ・欠けの有無を記録する。
2. ガラスの種類を確認する（第4章「施工前確認」参照）。Low-E・フィルム・コーティングは必ず判別する。
3. ヒビ・欠けがある場合は施工前にお客様へ報告し、指示を受けてから施工する。

**テスト施工**

4. 目立たない箇所（窓の下隅）にCHEM-001を約5ml（コイン大）塗布し、30秒〜1分後に白化・変色がないか確認する。
5. 水垢がある場合は同様の箇所でCHEM-003のテスト施工を行う（異常があれば即水洗いして施工中止）。

**養生**

6. 床全面に養生シートを敷く。サッシ下部にウエスを敷く（水滴が室内に落下しないよう受ける）。
7. 窓ガラス周辺の電気設備・壁コンセントを確認し、濡れないよう養生する。

**【写真①：ガラス状態（汚れ・異常確認）】**

**【写真②：作業前全景】**

### 注意事項

- ガラス種類の確認を省略しない。Low-Eガラスに酸性洗剤やスクレーパーを使うと即座に損傷する。
- テスト施工を飛ばして本施工を始めない。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| ガラス確認 | 全面を外光で確認・ガラス種類を判別済み | 「たぶんフロートガラス」で施工開始 → 損傷リスク |
| テスト施工 | 下隅で確認・異常なしを確認後に本施工 | テスト省略で本施工 → コーティング剥がれリスク |
| 養生 | 床全面・電気設備を養生済み | 床に水滴が直接落ちている → 床材汚損 |

### プロのコツ

- 斜め45度から光を当てると水垢・油膜・傷が見えやすい。作業前に外光・蛍光灯を使って必ず確認する。
- 「フロートガラス」と「Low-Eガラス」の見分けは難しい場合がある。わずかに青・緑・茶系に見えたらLow-Eを疑い、管理会社またはお客様に確認する。

## 工程2　網戸清掃

**目安時間：1枚あたり約5〜10分　必要人数：1名**

### 使用道具

TOOL-001（シャンパー）/ TOOL-011（サッシブラシ）/ TOOL-007（マイクロファイバークロス）/ TOOL-006（バケツ）

### 使用薬剤

CHEM-001（中性ガラス用洗剤）100〜200倍希釈 / または清水のみ（軽い汚れの場合）

### 手順

1. 網戸を取り外せる場合は取り外して地面または床の養生シート上で洗浄する。
2. シャンパーに洗浄液を十分含ませ、絞らずに網戸へ当てる（水分が多いほどホコリが浮きやすい）。
3. 上部から下部へ向けて、サッシブラシを網に対して平行に動かしてブラッシングする（網を押し込まない）。
4. 裏面も同様に施工する（両面施工が基本）。
5. 清水をシャンパーに含ませてすすぎ洗浄する。
6. クロスで縁（フレーム部分）の水気を拭き取る。
7. 自然乾燥させてから取り付ける（取り付け後の水滴落下を防ぐ）。

**【写真③：網戸洗浄前（汚れ状況）】**

**【写真④：網戸洗浄後】**

### 注意事項

- 網戸は必ずガラス洗浄より先に施工する。先に洗ったガラスに網戸の水・ホコリが落ちることを防ぐ。
- ブラシを網に対して垂直に押し込まない。網が変形する。
- 網戸が破れている場合は施工前にお客様へ報告する。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 網戸 | ホコリなし・虫なし・両面洗浄・破損なし | ホコリが片面に残っている・破れを見落とした |
| 乾燥 | 取り付け前に乾燥させた | 濡れたまま取り付け → 水滴がガラスに落下 |

### プロのコツ

- 網戸が汚れていても水で濡らすだけで8割のホコリが除去できる。ブラシよりも「水量」が重要。
- サッシブラシは「網の目に直角方向」ではなく「網の面と平行に寝かせて」動かすと網が変形しない。

## 工程3　外側ガラス洗浄・スクイジー施工

**目安時間：1面あたり約5〜15分（大きさにより変動）　必要人数：1〜2名**

### 使用道具

TOOL-001（シャンパー）/ TOOL-002（T型スクイジー）/ TOOL-007（マイクロファイバークロス）/ TOOL-009（ウエス）/ TOOL-006（バケツ）

### 使用薬剤

CHEM-001（中性ガラス用洗剤）100〜200倍希釈
油膜・排気ガスが多い場合：CHEM-002（弱アルカリ性ガラス洗剤）30〜50倍希釈

### 手順

**シャンパー施工（洗浄液塗布）**

1. バケツにCHEM-001希釈液を作る（10Lに対して洗剤50〜100ml）。
2. シャンパーを洗浄液に浸し、1〜2回絞る（シャンパーを持ち上げたとき水がしたたる程度が目安。絞りすぎると塗布量が不足する）。
3. ガラス上部から下部へ向けて、円を描くように全面へ均一に洗浄液を塗布する（力は約200〜300g程度）。
4. ガラス全面を洗浄液で均一に濡らす（乾いた部分を残さない）。
5. **水分が乾く前にすぐにスクイジー施工に移る（乾燥すると拭きムラの原因になる）。**

**スクイジー施工（水切り・仕上げ）**

6. スクイジーゴムに砂・汚れが付いていないか確認する。あれば水で洗ってから使用する。
7. ガラスの**左上端**からスクイジーを当てる。ゴムの角度はガラス面に対して**30〜45度**。
8. **横引き施工（新人向け）：** 左から右へ一直線に水平移動する。右端まで来たらウエスでゴムを拭く。約5cm下へ移動して同じ動作を繰り返す。最後に縦一本で端を仕上げる。
9. **半円施工（習熟者向け）：** 左上から右方向へ一直線に引き、下方向へ半円を描いて左端に戻る。この動作を繰り返しながら徐々に下へ移動する。最下部は横一直線で仕上げる。
10. **毎回のストロークの後、ウエスでゴムの水分を拭き取る（拭かないとスジが残る）。**
11. 施工後にクロスでガラス四隅の水滴を拭き取る。

**【写真⑤：外側ガラス洗浄前（汚れ状態）】**

**【写真⑥：外側ガラス施工後（仕上がり確認）】**

### スクイジーの角度と速度の基準

| 設定 | 基準値 | 影響 |
|------|--------|------|
| ゴム角度 | 30〜45度 | 立ちすぎ（60度超）→ ビビり・水残り / 寝すぎ（15度以下）→ ゴムが滑る・水切れ不良 |
| 移動速度 | 約30〜50cm/秒（一定速度） | 速すぎ → 水残り / 遅すぎ → スジが出やすい |
| ゴム拭き | 毎ストロークごと | 拭かない → スジが残る |

### 注意事項

- 水分が乾く前にスクイジーを動かす。乾燥が始まると水跡が残り除去できなくなる。
- ゴムに砂・ゴミが付着したまま施工するとガラスに傷が付く。
- スクイジーをガラス端で急に止めない。滑らかに引き抜く。
- 直射日光が当たる面は洗浄液が急速に乾燥する。日陰面から施工するか、早朝に施工する。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 仕上がり | 水滴なし・スジなし・光を反射してもムラなし | スジが残っている → ゴム確認・再施工 |
| ゴム管理 | 毎ストロークごとに拭く | 拭かない → スジが必ず残る |
| 水分管理 | 全面が濡れた状態でスクイジー施工 | 一部が乾いた状態で施工 → 水垢跡が残る |

### プロのコツ

- スクイジーの「切れ味」はゴムの状態で決まる。ゴムに1箇所でも切れ目があればすぐ交換する。
- 水が乾きそうになったら、シャンパーで水を追加してから施工する。焦らず追加水で対応する。
- 仕上がり確認は「光を斜めから当てる」。正面から見るだけではスジ・水滴を見落とす。

## 工程4　窓枠清掃

**目安時間：1窓あたり約3〜5分　必要人数：1名**

### 使用道具

TOOL-007（マイクロファイバークロス）/ TOOL-011（サッシブラシ）/ TOOL-010（スポンジ）

### 使用薬剤

CHEM-001（中性ガラス用洗剤）100〜200倍希釈

### 手順

1. サッシブラシで窓枠の角・溝のホコリを払い落とす。
2. スポンジにCHEM-001希釈液を含ませ、窓枠全体を上から下へ拭く。力は約300〜400g程度。
3. 角部・シーリング周辺を重点的に施工する。
4. 水で濡らしたクロスで洗剤を拭き取る。
5. 乾いたクロスで仕上げ拭きをする。

### 注意事項

- 塗装面を強く擦らない。変色・塗装剥がれの原因になる。
- シーリング（コーキング）を傷付けない。シーリングに傷が入ると雨漏りの原因になる。
- アルミ枠はヘアライン（縦方向の線）に沿って拭く。横方向に擦るとヘアラインに洗剤・汚れが入り込む。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 窓枠 | 黒ずみなし・ホコリなし・水滴なし | 角部に黒ずみが残っている → 再施工 |
| シーリング | 損傷なし | 擦って傷が入った → 報告 |

### プロのコツ

- 窓枠の黒ずみは「スポンジを縦にして角に押し当てる」と効率よく除去できる。
- 水分が残ると新たな水垢の原因になる。乾拭きを丁寧に行う。

## 工程5　サッシ清掃

**目安時間：1窓あたり約5〜10分　必要人数：1名**

### 使用道具

TOOL-011（サッシブラシ）/ TOOL-007（マイクロファイバークロス）/ TOOL-010（スポンジ）/ TOOL-019（掃除機）

### 使用薬剤

CHEM-001（中性ガラス用洗剤）100〜200倍希釈

### 手順

1. 掃除機でサッシの大きなゴミ・砂を先に吸引する（水洗い前に除去することで洗浄効率が上がる）。
2. CHEM-001希釈液をスポンジに含ませ、サッシ全体に塗布する。放置時間：1〜2分。
3. サッシブラシをサッシの溝方向（縦方向）に動かしてブラッシングする（横方向に動かすとゴミが詰まる）。
4. 細部・コーナーはブラシの毛先を使って施工する。
5. 水で濡らしたクロスで洗剤・汚れを拭き取る。
6. 乾いたクロスで仕上げ拭きをする。
7. サッシの排水穴が塞がっていないか確認する（塞がっていれば爪楊枝や細いブラシで開通させる）。

### 注意事項

- アルミサッシに金属ブラシ（ワイヤーブラシ等）を使用しない。傷がつく。
- 強アルカリ洗剤・強酸性洗剤をアルミサッシに直接塗布しない（変色・腐食の原因）。
- 排水穴を塞いだまま放置しない（サッシに水が溜まり腐食の原因になる）。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| サッシ | 泥なし・虫なし・排水穴清通 | 排水穴が詰まっている → 開通作業必要 |
| アルミ面 | 傷なし・水滴なし | 金属ブラシで傷がついた → 報告 |

### プロのコツ

- サッシの排水穴は「ブラシの毛先でゴミを掻き出す→掃除機で吸引」の順番が効率的。
- 飲食店・店舗のサッシは油分が固着していることが多い。CHEM-002（弱アルカリ）に切り替えると効果的。

## 工程6　レール清掃

## 工程7　内側ガラス洗浄・スクイジー施工

**目安時間：1面あたり約5〜10分　必要人数：1名**

### 使用道具

TOOL-001（シャンパー）/ TOOL-002（T型スクイジー）/ TOOL-007（マイクロファイバークロス）/ TOOL-009（ウエス）

### 使用薬剤

CHEM-001（中性ガラス用洗剤）100〜200倍希釈（外側より希薄でもよい）

### 手順

1. サッシ部分にウエスを敷く（内側は水滴が室内に落ちないよう特に注意する）。
2. シャンパーを洗浄液に浸し、外側より多めに絞る（室内は水分が少ないほうが安全）。
3. ガラス全面を上から下へ均一に洗浄液で拭く。
4. スクイジーで上から下へ水切りをする（工程3と同じ要領）。角度：30〜45度。速度：約30〜50cm/秒。
5. 毎ストロークごとにゴムをクロスで拭く。
6. 施工後にクロスでガラス四隅の水滴を拭き取る。
7. サッシ・窓枠に落ちた水滴を拭き取る。

### 注意事項

- 内側は室内の壁紙・床材・家具に水滴が落下しないよう特に注意する。
- 水分は外側より少なめに使用する。
- スクイジー施工後の余分な水は即座にクロスで拭き取る。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 内側ガラス | 手垢なし・水滴なし・ムラなし | 室内の壁や床に水が落ちた → 即座に拭き取り・報告 |
| 使用水量 | 最小限 | 水が垂れるほど使用 → 室内への漏水リスク |

### プロのコツ

- 内側ガラスの手垢・指紋は「シャンパーで濡らしてすぐスクイジー」より「クロスに洗浄液を約3〜5ml含ませて拭く→乾拭き」の方が仕上がりが良いことがある。汚れ量に応じて使い分ける。

## 工程9　頑固な汚れ除去（水垢・油膜・シール跡）※必要時

**目安時間：箇所により約10〜30分　必要人数：1名**

### 使用道具

TOOL-004（スクレーパー）/ TOOL-010（スポンジ）/ TOOL-007（マイクロファイバークロス）

### 使用薬剤

水垢：CHEM-003（酸性水垢除去剤）5〜20倍希釈
シール跡：CHEM-004（粘着剤除去剤）原液

### 手順

**水垢除去（CHEM-003使用）**

1. 対象ガラスの種類を確認する（Low-E・フィルム・コーティングには使用禁止）。
2. テスト施工を行う（目立たない箇所で白化・変色がないか確認。異常があれば即水洗いして中止）。
3. CHEM-003希釈液をスポンジに含ませ、水垢部分に塗布する。
4. 放置時間を守る（軽度：3〜5分 / 重度：5〜10分）。乾燥しないよう途中で追加塗布する。
5. スポンジで円を描くように施工する（力は約500g程度）。
6. 水をかけながら3〜5回拭き取り完全に洗い流す（酸性洗剤の残留は素材を傷める）。
7. 乾拭きして仕上げを確認する。1回で除去できない場合は2〜3回繰り返す。

**シール跡・粘着剤除去（CHEM-004使用）**

8. テスト施工を行う（目立たない箇所で確認）。
9. クロスにCHEM-004を2〜3プッシュ含ませ、シール跡へ当てる。放置時間：1〜2分。
10. クロスで円を描くように拭き取る。
11. 残りがある場合はスクレーパー（角度約20〜30度）を使用する。表面全体が均一に濡れる程度（約10〜20ml）水を塗布してから施工する。
12. 水拭き→乾拭きで仕上げる。

**【写真⑧：水垢・シール跡（除去前）】**

**【写真⑨：水垢・シール跡（除去後）】**

### 注意事項

- CHEM-003（酸性）は必ずテスト施工後に本施工する。アルミサッシへの直接塗布禁止。
- スクレーパーは乾いたガラスに使用禁止（傷が付く）。必ず水を含ませた状態で使用する。
- スクレーパーの角度を20〜30度より立てると（60度超）ガラスに傷が付く。
- Low-Eガラス・フィルム施工ガラスにはスクレーパー・CHEM-003・メラミンスポンジを使用しない。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 水垢除去 | テスト後に本施工・十分な放置時間・水洗い完了 | テスト省略・施工後の水洗い不十分 → 素材腐食 |
| スクレーパー | 水含み・20〜30度・フロートガラスのみ | 乾いたガラスに使用・角度が急 → 傷 |

### プロのコツ

- 重度の水垢は「CHEM-003を2〜3回繰り返す」のが効果的。1回で無理に落とそうとするより、放置→施工→水洗いを繰り返す。
- スクレーパーは「刃の全面をガラスに密着させる」感覚で使う。刃を浮かせて角で施工すると必ず傷がつく。

## 工程10　最終仕上げ・品質確認

**目安時間：約5〜15分　必要人数：1名**

### 使用道具

TOOL-007（マイクロファイバークロス）/ TOOL-008（ガラス用クロス）

### 手順

1. 乾いたマイクロファイバークロスでガラス四隅・サッシ境界の水滴を拭き取る。
2. 光を斜めから当てて（窓を斜め方向から見る）、スジ・水滴・拭きムラを確認する。
3. 発見した場合は乾いたクロスで再拭きする。
4. 室内側・室外側の両面を確認する。
5. サッシ・窓枠・レール・網戸の状態を最終確認する。

**【写真⑩：仕上がり確認（外側・斜め方向）】**

**【写真⑪：仕上がり確認（内側）】**

### 品質確認の方法

| 確認方法 | 何を見る |
|---------|---------|
| 斜め方向から光を当てる | スジ・水滴・拭きムラ |
| 反射を利用する（蛍光灯・外光） | 水垢・油膜の残り |
| 四隅を乾拭きクロスで拭いて確認 | クロスに汚れが付けば汚れ残りあり |
| 室内外両面を確認 | 片面見落とし防止 |

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 仕上がり | 光を当ててもスジ・水滴・ムラなし | 蛍光灯を反射させるとスジが見える → 再施工 |
| 四隅 | 水滴なし・洗剤残りなし | 四隅に水滴が残っている |

### プロのコツ

- 品質確認は「外光が差し込む時間帯」に行うと最もわかりやすい。
- 「お客様目線」（ガラス越しに外を見る位置に立つ）で確認すると、施工者目線では気づかない不具合に気づける。

## 工程11　養生撤去・現場復旧・お客様説明

**目安時間：約5〜10分　必要人数：1名**

### 手順

1. 養生シート・ウエスを取り外す。床に水滴・汚れが落ちていれば拭き取る。
2. 養生テープをゆっくり横方向に剥がす（壁紙・塗装が剥がれないよう注意）。
3. 移動した家具・備品を元の位置に戻す。
4. 工具・資材を全て確認する。忘れ物がないか確認する。
5. お客様・担当者へ最終説明を行う。

| 説明項目 | 内容 |
|---------|------|
| 施工完了 | 「本日の作業が完了しました」 |
| 施工範囲の確認 | 施工した箇所を一緒に確認する |
| 異常の報告 | ヒビ・コーティング剥がれ・シーリング劣化など発見した異常を報告する |
| 水垢・頑固汚れ | 除去できなかった汚れがある場合は状況を説明する |

# 11. 汚れ別除去方法

| 汚れ | 使用薬剤 | 希釈倍率 | 施工方法 | 放置時間 |
|------|---------|---------|---------|--------|
| ホコリ・花粉 | 中性洗剤（CHEM-001） | 100〜200倍 | シャンパー→スクイジー | 乾燥させない |
| 手垢・指紋 | 中性洗剤（CHEM-001） | 100〜200倍 | クロス拭き→乾拭き | 1〜2分 |
| 排気ガス・軽度油膜 | 中性洗剤（CHEM-001） | 100〜200倍 | シャンパー→スクイジー | 乾燥させない |
| 重度油膜・ヤニ | 弱アルカリ洗剤（CHEM-002） | 30〜50倍 | スプレー→スポンジ→水洗い | 1〜3分 |
| 水垢（スケール） | 酸性水垢除去剤（CHEM-003） | 5〜20倍 | スポンジ塗布→放置→水洗い | 3〜10分 |
| シール跡・粘着剤 | 粘着剤除去剤（CHEM-004） | 原液 | クロス→スクレーパー（適合ガラスのみ） | 1〜2分 |
| 鳥害汚れ（フン） | 中性洗剤（CHEM-001）＋水で浸透 | 100倍 | 水で浸透させてからクロスで除去 | 2〜5分（浸透させる） |

# 12. よくある失敗と対策

| 失敗 | 原因 | 改善方法 | 防止策 |
|------|------|---------|--------|
| スジが残る | ゴム摩耗・ゴムに汚れ | ゴム交換・クロスで拭いて再施工 | 毎回ゴムを拭く。施工前にゴム確認 |
| 水滴が残る | スクイジー角度不良 | 30〜45度に調整して再施工 | 角度を常に意識する |
| 白く曇る | 洗剤残留 | 清水シャンパーですすぎ→乾拭き | 洗剤希釈率を守る。乾拭きを徹底する |
| 拭きムラになる | 水分不足・シャンパーの絞りすぎ | 水分を追加して再施工 | シャンパーは十分な水分を保持する |
| ガラスに傷が付く | 砂を巻き込んだ・スクレーパー角度不良 | 傷は修復不可→報告 | 施工前に異物を除去。スクレーパーは20〜30度厳守 |
| 水垢が残る | 放置時間不足・薬剤濃度不足 | 濃度を上げて再施工 | CHEM-003の放置時間を守る |
| シール跡が残る | 薬剤の浸透不足 | 放置時間を延ばして再施工 | 1〜2分の浸透時間を確保する |
| 室内が濡れた | 水分が多すぎた・養生不足 | 即座に拭き取り | 内側は水分を少なく使う。ウエスを敷く |
| コーティングが剥がれた | 素材確認不足・禁止薬剤使用 | 修復不可→報告 | テスト施工必須 |

# 14. 安全管理

## 切創防止

- 耐切創手袋を必ず着用する
- スクレーパーは使用後すぐに刃をしまう
- 割れたガラスに素手で触れない

## 転倒防止

- 床に養生シートを敷いた後、滑り止めとしてテープで固定する
- 床の水滴をこまめに拭く
- 滑り止め安全靴を着用する

## 高所作業

- 2m超：脚立の3点支持を守る・天板に乗らない
- 5m超：フルハーネス型安全帯を着用する
- ロープアクセス・高所作業車：有資格者のみ

## 薬剤管理

- 薬剤ラベルを確認してから使用する
- 酸性洗剤（CHEM-003）と中性・アルカリ洗剤を混合しない
- 薬剤は風下で使用する

## 緊急時対応

| 事故 | 対応 |
|------|------|
| 切創 | 出血を止め、受診。ガラス片が残っていない確認。 |
| 転倒 | 応急処置→担当者へ報告→必要に応じ受診。 |
| 高所からの転落 | 動かさない→119番→担当者へ報告。 |
| 薬剤が目に入った | 15分以上水洗眼→医療機関受診。 |
| ガラス破損 | 周囲に近づかない→ガラス片を除去→担当者へ報告。 |

# 19. 教育ポイント（新人向け）

## 最初に覚えること（優先順）

1. ガラス種類の見分け方（特にLow-E・フィルムの識別）

5. 水分が乾く前にスクイジーを動かす感覚

## 新人が失敗しやすいポイント

| 失敗 | 防止策 |
|------|--------|

| スクレーパーで傷をつける | 角度20〜30度・水を含ませた状態のみ使用 |

## 一人施工を許可する判断基準

以下を全て満たしていること（現場責任者が確認・許可）：

- ガラス種類を正確に識別できる
- テスト施工を実施できる

- 品質確認（斜め光）ができる
- 高所作業時の安全手順を理解している
