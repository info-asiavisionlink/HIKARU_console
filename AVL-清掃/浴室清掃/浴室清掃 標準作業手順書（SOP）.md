# 浴室清掃 SOP

**対象：浴室全般（日常・週次・定期清掃）**

---

# 1. 適用範囲

## 対象施設

- ホテル / マンション / アパート / 一般住宅 / 宿泊施設 / 介護施設 / 商業施設

## 対象設備・作業範囲

- 天井 / 換気扇 / 壁 / 鏡 / 蛇口 / シャワー / カウンター
- 浴槽 / 浴槽エプロン / エプロン内部 / 床 / 排水口 / 排水トラップ
- ドア / レール / パッキン / シーリング / 照明 / 窓 / 小物棚 / タオル掛け

## 施工可能条件

| 条件 | 基準 |
|------|------|
| 換気 | 換気扇稼働 または 窓開放により換気が確保できること |
| 水道 | 清水での洗浄・すすぎができること |
| 電源 | 換気扇・照明の電源確認ができること |

## 施工不可条件

| 条件 | 理由・対応 |
|------|----------|
| 浴槽・壁に著しい割れ・欠けがある | 施工前にお客様へ報告。修理後に施工 |
| 換気ができない密閉空間 | 塩素系洗剤・酸性洗剤の蒸気が滞留し中毒リスク |
| 排水が完全閉塞している | 無理に薬剤を使用しない。管理者へ報告 |
| コーティング鏡・特殊素材で仕様不明 | メーカー確認後のみ施工 |

# 2. 基本施工原則

**浴室清掃の基本：「強く擦る」のではなく「汚れに合った薬剤を作用させてから除去する」**

## 施工順序（必ず守る）

```text
天井（最高所から）
    ↓
換気扇
    ↓
壁
    ↓
鏡・蛇口・金属部
    ↓
浴槽
    ↓
エプロン内部（脱着可能な場合）
    ↓
床
    ↓
排水口・排水トラップ
    ↓
ドア・レール
    ↓
防カビ・抗菌施工
    ↓
乾拭き・最終確認
```

**上から下への理由：上部の汚れ・薬剤・水滴が下へ落ちるため。下から施工すると再汚染になる。**

## 汚れ別薬剤選定の原則

| 汚れ | 使用薬剤 | 理由 |
|------|---------|------|
| 皮脂・石鹸カス・黒ずみ | CHEM-002（アルカリ性） | 油性汚れはアルカリで分解 |
| 水垢・ウロコ・シリカスケール | CHEM-003（酸性） | ミネラル固着は酸で溶解 |
| 黒カビ・ピンクぬめり | CHEM-004（塩素系） | 菌は塩素で除菌・漂白 |
| 軽い汚れ・日常清掃 | CHEM-001（中性） | 素材への影響が最小 |

**絶対禁止：CHEM-003（酸性）とCHEM-004（塩素系）を同時・連続使用しない→有毒ガス発生**

# 3. 対象素材と主な汚れ

## 主な汚れの種類

| 汚れ | 主な発生箇所 | 対応薬剤 |
|------|------------|---------|
| 水垢（ミネラル固着） | 鏡・蛇口・シャワー・壁 | CHEM-003 |
| シリカスケール（通常水垢より硬い固着） | 鏡・ガラス面 | CHEM-003＋ダイヤモンドパッド |
| 石鹸カス | 壁・床・カウンター | CHEM-002 |
| 皮脂汚れ | 浴槽・壁・床 | CHEM-002 |
| 黒カビ（Cladosporium等） | 天井・パッキン・シーリング・エプロン内部 | CHEM-004 |
| ピンクぬめり（ロドトルラ菌） | 排水口・カウンター・床 | CHEM-004 |
| 髪の毛・排水汚れ | 排水口・排水トラップ | 手回収＋CHEM-001 |
| サビ（もらいサビ） | 金属部・排水口 | CHEM-003（テスト施工後） |

# 4. 施工前確認

## 素材確認（最重要）

素材によって使用できる薬剤・道具が異なる。作業前に必ず確認する。

| 素材 | 主な使用箇所 | 使用禁止 |
|------|------------|---------|
| FRP | 浴槽・壁・天井 | 金属たわし・粗い研磨材・強アルカリ長時間接触 |
| 人工大理石 | 浴槽・カウンター | 強酸・強アルカリ・ダイヤモンドパッド |
| ホーロー | 浴槽 | 金属ブラシ・強い研磨・酸性の長時間接触 |
| タイル | 壁・床 | 特になし（目地は酸性洗剤が効果的） |
| ガラス・鏡 | 鏡・窓 | 乾いた状態でのダイヤモンドパッド施工 / コーティング鏡は要確認 |
| ゴムパッキン | ドア周辺・配管 | 長時間の強アルカリ・強酸接触 |
| ステンレス | 蛇口・シャワー | 塩酸系薬剤（変色・腐食） |
| 樹脂・ABS | ドア・小物棚 | シンナー・ベンジン・アセトン・溶剤系 |

## キズ・破損確認

1. 浴槽・壁・ドアのキズ・割れ・欠けを確認する。
2. シーリング（コーキング）の劣化・剥がれを確認する。
3. 排水口の詰まり・破損を確認する。
4. 異常があれば施工前にお客様へ報告し、写真に残す。

**【写真①：浴室全景（作業前）】**

**【写真②：浴槽・壁（汚れ状況）】**

**【写真③：鏡・蛇口（水垢・ウロコ状況）】**

**【写真④：排水口・床（汚れ状況）】**

**【写真⑤：キズ・破損箇所（ある場合のみ）】**

## お客様への事前説明

| 説明項目 | 説明内容の例 |
|---------|------------|
| 施工内容 | 「本日は浴室全体をクリーニングします（天井・壁・浴槽・床・鏡・排水口）」 |
| 所要時間 | 「エプロン内部洗浄含む場合は3〜4時間、通常は2〜3時間かかります」 |
| 薬剤使用 | 「専用洗剤を使用します。換気をお願いします」 |
| 水の使用 | 「水道水を使用します」 |
| 鏡・水垢 | 「長年の水垢・シリカスケールは完全除去できない場合があります」 |
| エプロン | 「エプロンが脱着可能な場合は内部も洗浄します（追加時間が必要です）」 |
| 異常発見時 | 「キズ・カビ・設備破損を発見した場合はすぐにご報告します」 |

# 5. 使用保護具

## 必須

□ 耐薬品ゴム手袋（酸性・塩素系薬剤から手を保護）

□ 保護メガネ（薬剤飛散防止。酸性・塩素系使用時は特に必須）

□ 防水エプロン（薬剤・汚水から衣類を保護）

□ 滑り止め付き安全靴・長靴（浴室床の転倒防止）

□ マスク（薬剤蒸気・カビ胞子の吸入防止）

□ 作業服（長袖推奨）

## 必要時

□ フェイスシールド（高圧洗浄・塩素系薬剤使用時）

□ 防毒マスク（密閉空間での強い薬剤使用時）

□ 耐切創手袋（エプロン脱着・鋭利な部品取り扱い時）

# 9. 詳細作業手順

---

## 工程1　事前点検・養生・お客様説明

**目安時間：約10分　必要人数：1名**

### 使用道具

TOOL-009（LEDライト）/ 養生シート / 養生テープ

### 手順

1. 浴室全体をLEDライトで確認する（天井カビ・エプロン脱着可否・排水口詰まりの有無）。
2. 素材を確認する（FRP・人工大理石・ホーロー・タイル・ガラス）。
3. キズ・割れ・シーリング劣化・破損箇所を確認し、写真撮影する。
4. 電源スイッチ・照明・換気扇の位置と状態を確認する。
5. 作業前写真を撮影する（写真①〜⑤）。
6. お客様へ事前説明を行う（第4章参照）。
7. 電気設備（照明・コンセント）を養生する（薬剤・水が入らないよう）。
8. 換気扇を起動し、窓があれば開放して換気を確保する。

### 注意事項

- 素材確認をせずに薬剤を使用しない。
- コーティング鏡・特殊鏡はメーカー仕様を確認してから施工する。
- キズ・破損は施工前にお客様へ必ず報告する（施工中に破損したと思われないため）。

### 完了基準

□ 素材確認完了（FRP / 人工大理石 / ホーロー / タイル / ガラス を特定した）

□ 作業前写真撮影完了

□ 換気確保・電装部養生完了

---

## 工程2　天井清掃

**目安時間：約10〜15分　必要人数：1名（高所は2名推奨）**

### 使用道具

TOOL-001（マイクロファイバークロス）/ TOOL-002（スポンジ）/ TOOL-010（脚立）

### 使用薬剤

ホコリのみ：CHEM-001（中性洗剤）50〜100倍希釈 / 放置時間：1〜2分
黒カビがある場合：CHEM-004（塩素系漂白剤）10〜50倍希釈 / 放置時間：5〜10分

### 手順

1. 脚立を設置する（水平確認・滑り止め確認）。
2. 乾いたクロスで天井全体のホコリを先に払い取る（濡らす前に乾式除塵）。
3. 黒カビがある場合：CHEM-004（10〜50倍希釈）をクロスに含ませ、カビ箇所に密着させる。放置時間：5〜10分（クロスを当てたまま放置するとゴミ袋との組み合わせで効果が高まる）。
4. カビがない場合：CHEM-001（50〜100倍希釈）をクロスに含ませ、天井全体を一方向に拭く。
5. 奥から入口方向へ施工する（カビ胞子が入口側に落ちてくるのを防ぐ）。
6. 清水をクロスに含ませてすすぎ拭きする。
7. 乾拭きで仕上げる。

**【写真⑥：天井（清掃後・カビ除去確認）】**

### 注意事項

- 照明カバーに薬剤を直接かけない（感電リスク）。
- カビ胞子を壁・床に落とさないよう静かに作業する。
- 脚立の天板には乗らない。高所作業は補助者を配置する。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| カビ | 放置時間を守り・クロスで除去・黒い跡なし | すぐに擦る → カビが広がる |
| ホコリ | 乾式除塵→湿式拭きの順 | 濡らしたクロスで先に拭く → ホコリが泥状になる |

### プロのコツ

- 天井カビはCHEM-004をクロスに含ませて「パック」する（クロスを密着させて5〜10分放置）と擦らずに除去できる。
- カビが多い場合は防カビ施工（工程11）を重点的に行うことで再発を防げる。

## 工程3　換気扇清掃

**目安時間：約15〜20分　必要人数：1名**

### 使用道具

プラスドライバー / TOOL-005（ハンドブラシ）/ TOOL-001（クロス）/ TOOL-002（スポンジ）/ バケツ

### 使用薬剤

CHEM-001（中性洗剤）50〜100倍希釈 / 放置時間：2〜3分

### 手順

1. **換気扇の電源を停止する（スイッチOFFを目視確認）。感電防止のため必須。**
2. 換気扇カバーを取り外す（ドライバーまたは手で固定部を外す。機種に応じる）。
3. カバーをバケツに入れてCHEM-001（50〜100倍）で2〜3分つけ置きする。
4. ハンドブラシでカバーのホコリ・汚れを除去する（毛流れに沿って施工）。
5. 水洗いして洗剤を流す（泡が出なくなるまで30秒以上すすぎ）。
6. カバー内部（本体側）をクロスでホコリ・汚れを除去する（**モーター部への水・薬剤厳禁**）。
7. カバーを完全乾燥させる（濡れたまま取り付けない）。
8. カバーを正しい位置へ取り付ける。
9. 電源を入れて動作確認する（異音・振動・回転不良がないか確認）。

### 注意事項

- **感電防止のため電源OFFを必ず確認してから作業する。**
- モーター部・電装部に水・薬剤を絶対にかけない。
- カバーが濡れたまま取り付けると漏電の原因になる。必ず完全乾燥してから取り付ける。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 電源 | OFFを目視確認してから作業開始 | 「たぶんOFF」で作業 → 感電リスク |
| カバー | 完全乾燥後に取り付け・動作確認 | 濡れたまま取り付け → 漏電リスク |

### プロのコツ

- 換気扇のホコリが多い場合は、取り外す前に乾いたブラシで先にホコリを払うと作業が楽になる（取り外しの際にホコリが落ちにくくなる）。
- 換気扇を清掃すると換気効率が大幅に向上し、カビ再発を防ぐ効果が高い。

## 工程4　壁清掃

**目安時間：約20〜30分　必要人数：1名**

### 使用道具

TOOL-002（スポンジ）/ TOOL-001（マイクロファイバークロス）/ TOOL-005（ハンドブラシ）

### 使用薬剤

| 汚れ状況 | 使用薬剤 | 希釈倍率 | 放置時間 |
|---------|---------|---------|---------|
| 軽い汚れ（日常） | CHEM-001（中性） | 50〜100倍 | 1〜2分 |
| 石鹸カス・皮脂（通常） | CHEM-002（アルカリ） | 10〜30倍 | 3〜5分 |
| 頑固な石鹸カス | CHEM-002（アルカリ） | 5〜10倍 | 5〜10分 |
| 黒カビ | CHEM-004（塩素系） | 10〜50倍 | 5〜10分 |

### 手順

1. シャワーで壁全体を予洗いする（洗剤を塗布しやすくするため）。
2. 汚れの状況を確認し薬剤を選定する。
3. 上部から下部へ向けてCHEM-002（または選定した薬剤）をスポンジに含ませ、全面に塗布する。**一度に全壁に塗布せず、1m²ずつ施工する（乾燥防止）。**
4. 放置時間を守る（上表参照）。
5. スポンジで上から下へ一方向に洗浄する（力は約300〜400g程度）。
6. 目地・角部はハンドブラシで3〜5往復する（毛先を立てて施工）。
7. シャワーで30秒以上すすぐ（洗剤が完全に流れるまで）。
8. クロスで水滴を上から下へ一方向に除去する。

**【写真⑦：壁（清掃後確認）】**

### 注意事項

- **CHEM-003（酸性）とCHEM-004（塩素系）を同時・連続で使用しない（必ず十分すすいでから次の薬剤へ切り替える）。**
- FRP壁は力を入れて擦らない（コーティング剥がれの原因）。
- 壁のシーリング（コーキング）をブラシで傷付けない。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 施工単位 | 1m²ずつ施工（乾燥防止） | 全壁に一度に塗布 → 乾燥してしまう → 効果なし |
| すすぎ | 30秒以上シャワーで流す | 少量の水だけかける → 洗剤残留 → 滑り・白残り |
| 施工方向 | 上から下へ一方向 | 下から上へ → 汚れが上に広がる |

### プロのコツ

- 「壁の石鹸カスはアルカリ洗剤を塗布して5分放置→スポンジで約200〜300gの力で撫でるだけで落ちる」。最初から擦ると素材を傷める。
- カビは「CHEM-004を塗布してキッチンペーパー等で密着させる（パック）→10分後に水洗い」が最も効果的。

## 工程5　鏡・蛇口・金属部清掃（ウロコ除去）

**目安時間：約20〜30分（ウロコの重さによる）　必要人数：1名**

### 使用道具

TOOL-003（ダイヤモンドパッド）/ TOOL-001（マイクロファイバークロス）/ TOOL-002（スポンジ）

### 使用薬剤

CHEM-003（酸性洗剤）原液〜5倍希釈（ウロコ度合いによる）/ 放置時間：3〜10分

### 手順

**テスト施工（必須）**

1. コーティング鏡かどうか確認する（コーティング鏡にはダイヤモンドパッドを使用しない）。
2. 鏡の端部（目立たない箇所）にCHEM-003を約3〜5ml塗布し、30秒後に白化・変色がないか確認する。

**鏡のウロコ除去**

3. 鏡全面をシャワーで濡らす（必ず湿潤状態で施工）。
4. CHEM-003（原液〜5倍希釈）をスポンジに含ませ、鏡全面に塗布する。放置時間：3〜10分（ウロコの固さによる）。
5. ダイヤモンドパッド（TOOL-003）を水で湿らせ、鏡に当てる。
6. **一方向（上から下または左から右）へ約200〜300gの力で均一に研磨する**（円を描かない。一部分だけ研磨すると仕上がりに差が出る）。
7. 全面を均一に同じ回数研磨する（鏡の下半分だけ光沢が出ないよう注意）。
8. シャワーで30秒以上すすぐ。
9. 乾いたマイクロファイバークロスで一方向に乾拭きする（光沢確認）。

**蛇口・シャワー・金属部**

10. CHEM-003（5〜10倍希釈）をクロスに含ませ、蛇口・シャワーヘッドに当てて放置する（3〜5分）。
11. スポンジで水垢を除去する。
12. 根元・細部はハンドブラシで3〜5往復する。
13. シャワーで30秒以上すすぐ。
14. マイクロファイバークロスで乾拭きして光沢を確認する。

**【写真⑧：鏡・蛇口（ウロコ除去後）】**

### 注意事項

- コーティング鏡・特殊鏡にダイヤモンドパッドを使用しない（コーティング剥がれ）。
- ダイヤモンドパッドを**乾いた状態で使用しない**（傷が深く入る）。
- 酸性洗剤をステンレス・金属部に長時間放置しない（変色・腐食）。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| パッドの状態 | 水で湿らせてから使用 | 乾いた状態で使用 → 深い傷 |
| 研磨方向 | 一方向・全面均一に研磨 | 円を描く・部分研磨 → ムラになる |
| すすぎ | 酸性洗剤を30秒以上すすぐ | すすぎ不足 → 金属部腐食・白く残る |

### プロのコツ

- 「鏡の仕上がり確認は乾拭き後に光を斜め方向から当てる」と研磨ムラが一目でわかる。
- 重度のシリカスケールは「CHEM-003パック（クロスを密着させて10分放置）→パッドで研磨」の2段階が効果的。1回で焦らず2〜3回繰り返す。

## 工程6　浴槽清掃

**目安時間：約20〜30分　必要人数：1名**

### 使用道具

TOOL-002（スポンジ）/ TOOL-001（マイクロファイバークロス）/ TOOL-005（ハンドブラシ）

### 使用薬剤

| 汚れ状況 | 使用薬剤 | 希釈倍率 | 放置時間 |
|---------|---------|---------|---------|
| 日常汚れ | CHEM-001（中性） | 50〜100倍 | 1〜2分 |
| 石鹸カス・皮脂（通常） | CHEM-002（アルカリ） | 10〜20倍 | 3〜5分 |
| 頑固な皮脂・湯垢 | CHEM-002（アルカリ） | 5〜10倍 | 5〜10分 |
| 水垢（水面線） | CHEM-003（酸性） | 5〜10倍 | 3〜5分（CHEM-002を完全すすぎ後） |

### 手順

1. 浴槽全体をシャワーで予洗いする。
2. CHEM-002（10〜20倍希釈）をスポンジに含ませ、浴槽内面全体に均一に塗布する。放置時間：3〜5分。
3. スポンジで浴槽内面を縦横両方向に洗浄する（力は約300〜400g。FRP・人工大理石は柔らかいスポンジを使用）。
4. オーバーフロー部（排水穴）はハンドブラシで3〜5往復する。
5. 浴槽の縁・外側もスポンジで洗浄する（縁は汚れが溜まりやすい）。
6. シャワーで30秒以上すすぐ（洗剤残留ゼロになるまで）。
7. 水面線に水垢が残っている場合はCHEM-003（5〜10倍）で追加施工する（CHEM-002を完全にすすいでから使用）。
8. マイクロファイバークロスで乾拭きして光沢を確認する。

**【写真⑨：浴槽（清掃後・光沢確認）】**

### 注意事項

- FRPは力を入れて擦らない（光沢が落ちる）。
- 人工大理石にダイヤモンドパッド・強い研磨材を使用しない（傷・変色）。
- ホーローに金属たわしを使用しない（傷から錆が発生する）。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| FRP浴槽 | 柔らかいスポンジ・約300g程度の力 | 研磨スポンジで強く擦る → 光沢が落ちる |
| 水面線水垢 | CHEM-002→完全すすぎ→CHEM-003の順序 | CHEM-002とCHEM-003を同時に使用 → 効果が相殺 |
| 乾拭き | 光を当てて水滴・拭きムラなし | 乾拭き省略 → 水垢跡が残る |

### プロのコツ

- 浴槽の水面線（浴槽の水位線）は皮脂・石鹸カスが最も固着する箇所。ここをCHEM-002で重点施工すると仕上がりが大きく変わる。
- 「浴槽を拭く際は、乾拭きクロスを換えながら施工」する。一枚のクロスで全面拭くと洗剤・水分を引き伸ばす。

## 工程7　浴槽エプロン脱着・内部清掃

**目安時間：約30〜45分　必要人数：1〜2名（エプロン脱着・大型浴槽は2名推奨）**

### 目的

浴槽エプロン内部は悪臭・黒カビ・ぬめりの最大の原因箇所。日常清掃では届かない内部を洗浄し、臭気・カビの根本原因を除去する。

### 使用道具

TOOL-009（LEDライト）/ TOOL-008（高圧洗浄機）/ TOOL-005（ハンドブラシ）/ TOOL-001（クロス）/ バケツ

### 使用薬剤

CHEM-002（アルカリ洗剤）10〜20倍希釈 / 放置時間：5〜10分
CHEM-004（塩素系漂白剤）10〜50倍希釈 / 放置時間：10〜15分（カビが多い場合）

### 手順

**エプロン取り外し**

1. エプロン下部のネジ・固定部を確認する（脱着不可の場合は無理に外さない）。
2. 取り外し方法を確認してからゆっくり外す（固定部を把握してから取り外す）。

**【写真⑩：エプロン取り外し後・内部状態（黒カビ・汚れ確認）】**

3. LEDライトで内部全体を確認する（カビの範囲・ぬめり・ゴミの状況）。
4. 髪の毛・ゴミをトングまたは手袋を着用した手で回収する。

**内部洗浄**

5. カビがある場合：CHEM-004（10〜50倍希釈）を内部全体に散布する。放置時間：10〜15分。
6. 皮脂・石鹸カスがある場合：CHEM-002（10〜20倍希釈）を塗布する。放置時間：5〜10分。
7. ハンドブラシで上から下へ施工する（奥から手前へ向かって施工する）。
8. 高圧洗浄機（TOOL-008）でノズルを対象から**20〜30cm離し、角度30〜45度**で内部全体を洗浄する（上から下へ）。
9. 配管・電装部にノズルを直接当てない。
10. バケツで汚水を回収する（床へ流さない）。
11. LEDライトで内部を再確認する（カビ・汚れが残っていないか）。
12. エプロンを洗浄する（外側・内側両面）。

**エプロン復旧**

13. エプロンを乾燥させてから正しい位置・向きで取り付ける（ガタつきがないか確認する）。

**【写真⑪：エプロン内部洗浄後】**

### 注意事項

- 固定式エプロン（ネジで固定されていない・脱着不可の記載がある）は無理に外さない。
- 高圧洗浄機を配管・電装部・断熱材に直接当てない（破損リスク）。
- 復旧後に必ずガタつきがないか前後に各2〜3kgの力で動かして確認する。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 確認 | LEDライトで内部全体を施工前後に確認 | 目視のみ → 奥のカビを見落とし |
| 高圧洗浄 | 20〜30cm離す・30〜45度の角度 | 近距離で直接当てる → 配管・断熱材破損 |
| 復旧 | ガタつきなし確認 | 確認省略 → エプロンが外れる |

### プロのコツ

- 「悪臭の原因はほぼエプロン内部」。外見がきれいでも臭いが残る場合はここを確認する。
- 黒カビのひどい場合は「CHEM-004を散布してキッチンペーパーで密着（パック）→15分放置→高圧洗浄」の手順が最も効果的。

## 工程8　床清掃

**目安時間：約20〜30分　必要人数：1名**

### 使用道具

TOOL-002（スポンジ）/ TOOL-007（デッキブラシ）/ TOOL-005（ハンドブラシ）/ TOOL-001（マイクロファイバークロス）

### 使用薬剤

| 汚れ状況 | 使用薬剤 | 希釈倍率 | 放置時間 |
|---------|---------|---------|---------|
| 軽い汚れ | CHEM-001（中性） | 50〜100倍 | 1〜2分 |
| 石鹸カス・黒ずみ | CHEM-002（アルカリ） | 10〜20倍 | 3〜5分 |
| 床目地カビ | CHEM-004（塩素系） | 10〜50倍 | 5〜10分 |
| ピンクぬめり | CHEM-004（塩素系） | 50〜100倍 | 3〜5分 |

### 手順

1. 床全体をシャワーで予洗いする。
2. 汚れ状況に合わせた薬剤を選定し、床全面に均一に塗布する（**奥から手前（入口方向）へ塗布し始める**）。
3. 放置時間を守る（上表参照）。
4. デッキブラシで縦横両方向に洗浄する（力は約400〜600g程度。床面に密着させて施工）。
5. 床目地はハンドブラシを立てて目地に沿って3〜5往復する。
6. 浴槽周辺・壁際・排水口周辺を重点施工する（汚れが集中する箇所）。
7. シャワーで30秒以上すすぐ。
8. 水切りをする（床面の水を排水口方向へ掻き集める）。
9. **奥から入口方向へ後退しながら**クロスで水滴を除去する（清掃済みの床を踏まない）。

**【写真⑫：床（清掃後・黒ずみ除去確認）】**

### 注意事項

- 床に洗剤を長時間放置しない（床材が変色・劣化する可能性）。
- 洗剤残留は転倒の原因になる。必ずシャワーで30秒以上すすぐ。
- 清掃中の床はすべりやすい。滑り止め靴を着用して移動に注意する。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 施工順 | 奥から手前へ後退しながら施工 | 手前から奥へ → 清掃済みの床を踏む |
| すすぎ | 30秒以上シャワーで流す | すすぎ不足 → 洗剤残留 → 転倒リスク |
| 目地 | ブラシを立てて目地に沿って施工 | ブラシを寝かせるだけ → 目地の汚れが残る |

### プロのコツ

- 「床目地の黒ずみはブラシで縦・横それぞれ施工する」。縦方向だけでは目地の横ラインに残りやすい。
- 浴室床は滑り止め加工で汚れが入り込みやすい。「薬剤を十分放置してから施工」するだけで擦る力が半分以下になる。

## 工程9　排水口・排水トラップ清掃

**目安時間：約15〜20分　必要人数：1名**

### 使用道具

TOOL-005（ハンドブラシ）/ TOOL-006（ボトルブラシ）/ ピンセット / バケツ

### 使用薬剤

CHEM-001（中性洗剤）50〜100倍希釈：一般洗浄 / 放置時間：1〜2分
CHEM-004（塩素系漂白剤）50〜100倍希釈：ぬめり除去 / 放置時間：5〜10分

### 手順

1. 排水口カバーを外す。
2. ピンセットまたは手袋を着用した手で髪の毛・ゴミを回収する（排水管には流さない）。
3. 排水トラップを分解する（向きをメモまたは写真撮影する）。
4. CHEM-004（50〜100倍希釈）を排水口内部・トラップ各部品に散布する。放置時間：5〜10分。
5. ハンドブラシで排水口内壁・トラップ各部品を洗浄する（3〜5往復）。
6. ボトルブラシで排水管入口の内部まで施工する（差し込んで回転させながら引き抜く）。
7. トラップ各部品の裏側を重点洗浄する（臭いの原因が最も多い箇所）。
8. 清水で30秒以上すすぐ。
9. 正しい向きでトラップを復旧する（写真・メモと照合）。
10. 排水口カバーを取り付けて、水を流して排水確認をする。

**【写真⑬：排水口・トラップ清掃後】**

### 注意事項

- 部品を紛失しない（床に直接置かず、バケツの縁に掛けるか小皿に集める）。
- 向きを間違えて復旧すると排水不良・臭気の原因になる（必ず撮影してから分解する）。
- ボトルブラシを無理に深く差し込まない（ホースが折れる）。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 部品管理 | 分解前に写真撮影・向き確認 | 感覚で分解・復旧 → 向き間違い → 臭気 |
| 裏側 | トラップ裏側を重点洗浄 | 表面だけ洗浄 → 臭いが残る |
| 排水確認 | 水を流してスムーズに流れることを確認 | 確認省略 → 復旧ミスを見落とし |

### プロのコツ

- 排水トラップの「臭いの原因は裏側」。特に封水トラップの裏面にぬめりが固着していることが多い。
- 「分解前に写真撮影→復旧時に写真と照合」の習慣で復旧ミスを防げる。

## 工程10　ドア・レール・パッキン清掃

**目安時間：約15〜20分　必要人数：1名**

### 使用道具

TOOL-001（クロス）/ TOOL-005（ハンドブラシ）/ TOOL-006（ボトルブラシ）/ スポンジ

### 使用薬剤

ドア面（水垢）：CHEM-003（酸性洗剤）5〜10倍希釈 / 放置時間：3〜5分
レール（石鹸カス・ホコリ）：CHEM-001（中性洗剤）50〜100倍希釈 / 放置時間：1〜2分
パッキンカビ：CHEM-004（塩素系漂白剤）10〜50倍希釈 / 放置時間：5〜10分

### 手順

**ドア面**

1. ドア全体にシャワーで予洗いする。
2. 水垢がある場合はCHEM-003（5〜10倍希釈）をクロスに含ませ、水垢部分に塗布する。放置時間：3〜5分。
3. スポンジで全面を洗浄する。
4. シャワーで30秒以上すすぐ。
5. クロスで乾拭きする。

**レール**

6. ホコリ・ゴミをブラシで払い出す。
7. CHEM-001（50〜100倍希釈）をレール内部に散布する。放置時間：1〜2分。
8. ハンドブラシをレール角部に当て、レール方向へ3〜5往復する。
9. ボトルブラシでレール内部の深部を施工する。
10. 清水で洗い流す。
11. ドアの開閉確認をする（スムーズに動くか）。

**パッキン**

12. パッキンカビにCHEM-004（10〜50倍希釈）を直接塗布する。放置時間：5〜10分（クロスで密着させるとより効果的）。
13. クロスで拭き取る（強く擦らない）。
14. シャワーでよくすすぐ。

**【写真⑭：ドア・レール・パッキン清掃後】**

### 注意事項

- パッキンを傷付けない（引っかかったまま擦ると裂ける）。
- 換気口はホコリを先に乾式除去してから湿式清掃する。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| パッキン | 薬剤放置後に優しく拭き取る | 最初から擦る → パッキン損傷 |
| レール | ブラシを縦（レール方向）に動かす | 横方向に動かす → ゴミが詰まる |

### プロのコツ

- レールは「ボトルブラシを入れてクルクル回しながら引き出す」と深部の汚れも除去しやすい。
- パッキンカビは「CHEM-004を染み込ませたペーパータオルを密着させて10分パック」すると、擦らなくても漂白できる。

## 工程11　防カビ・抗菌コーティング

**目安時間：約10分　必要人数：1名**

**この工程は浴室が完全に乾燥してから実施する（濡れた状態では効果がない）。**

### 使用道具

スプレーボトル / TOOL-001（マイクロファイバークロス）

### 使用薬剤

CHEM-005（防カビ剤）原液または2〜5倍希釈
CHEM-006（抗菌剤）原液または2〜5倍希釈

### 手順

1. 浴室全体が乾燥していることを確認する（手で触れて水気がない状態）。
2. CHEM-005（防カビ剤）を壁・天井・パッキン・シーリングに均一にスプレーする（各面5〜10回スプレー）。液だれしないよう均一に塗布する。
3. 乾燥させる（拭き取らない）。乾燥時間：自然乾燥（約5〜10分）。
4. CHEM-006（抗菌剤）を排水口周辺・床・浴槽に均一にスプレーする（各3〜5回）。
5. 乾燥させる（拭き取らない）。

### 注意事項

- 濡れた状態では効果がない。必ず乾燥後に施工する。
- 液だれすると乾燥後に白い跡が残る。約10ml/回を均一にスプレーする。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| タイミング | 完全乾燥後に施工 | 濡れた状態で施工 → 効果なし |
| 塗布量 | 均一に・液だれしない量（約10ml/回） | 30ml以上一度に噴霧 → 液だれ → 白い跡 |

### プロのコツ

- 防カビ施工の重点箇所は「天井・パッキン・シーリング」。ここを重点施工するとカビの再発が大幅に遅くなる。
- 防カビ剤はブロワーや換気扇で乾燥させると効果が早く発揮される。

# 12. よくある失敗と対策

| 失敗 | 原因 | 改善方法 | 防止策 |
|------|------|---------|--------|
| 水垢が残る | 酸性洗剤の放置時間不足 | 濃度を上げて再施工 | 放置時間を必ず守る（最低3〜5分） |
| カビが再発する | 乾燥不足で防カビ施工した / 換気不足 | 完全乾燥後に防カビ再施工 | 防カビ施工前に乾燥を確認する |
| 浴槽が曇る | 洗剤残留 | 清水で30秒以上再すすぎ | 使用量を減らし・すすぎを徹底する |
| 鏡にキズが入った | 乾いた状態でパッド施工 / 圧が強い | 傷は修復不可→報告 | パッド使用前に必ず水で湿らせる |
| 床が滑る | 洗剤残留 | 清水で30秒以上再すすぎ | すすぎ後に手で触れて確認する |
| 悪臭が残る | 排水口トラップ裏側未施工 | トラップ分解→裏側重点洗浄 | トラップは必ず分解して裏側まで洗浄 |
| 有毒ガスが発生した | 酸性洗剤と塩素系を混合 | 即座に換気・退避→119番 | 薬剤切り替え前に必ず十分すすぐ |
| エプロン内部が臭う | 高圧洗浄不足 / 放置時間不足 | 再度分解して高圧洗浄 | 放置時間10〜15分・ライトで確認する |
| パッキンが傷んだ | 薬剤長時間放置 / 強く擦った | 管理者へ報告 | 放置時間を守り・優しく拭き取る |
| ダイヤモンドパッドで傷が入った | コーティング鏡への使用 / 乾燥状態での使用 | 修復不可→報告 | コーティング確認後のみ使用 |

# 14. 安全管理

## 転倒防止

- 滑り止め付き安全靴・長靴を着用する
- 床面に水・洗剤を放置しない
- 作業中は床の濡れ具合を常に確認する

## 薬剤安全

- **CHEM-003（酸性）とCHEM-004（塩素系）を絶対に混合しない**（有毒ガス発生・最高リスク）
- 換気を確保した状態で薬剤を使用する（換気なしの密閉空間での強い薬剤使用禁止）
- 保護メガネ・耐薬品手袋を着用する

## 感電防止

- 換気扇清掃前に電源OFFを目視確認する
- 電装部・照明・コンセントに薬剤・水をかけない
- 電源コードの損傷を確認する

## 高所作業

- 脚立の滑り止めを確認する（浴室内は特に床が濡れやすい）
- 天板に乗らない
- 高所作業は補助者を配置する

## 緊急時対応

| 事故 | 対応 |
|------|------|
| 薬剤が目に入った | 即座に15分以上水洗眼→受診。 |
| 薬剤が皮膚に付いた | 流水で15分以上洗浄。 |
| 有毒ガス（薬剤混合） | 即座に退避・換気→119番→管理者報告。 |
| 転倒 | 応急処置→管理者報告→必要に応じ受診。 |
| 感電 | 電源遮断→119番→管理者報告。 |

# 19. お客様への維持管理アドバイス

清掃後の状態を長く維持するために以下を案内する。

| 行動 | 頻度 | 効果 |
|------|------|------|
| 入浴後に壁・床の水滴をスクイジー・タオルで除去する | 毎回 | 水垢・カビ予防 |
| 換気扇を入浴後2〜4時間以上運転する | 毎回 | カビ予防 |
| 排水口の髪の毛を除去する | 毎日 | 悪臭・詰まり予防 |
| ボトル類を浮かせて収納する（シャンプー棚等） | 常時 | 底のぬめり予防 |
| 浴室全体を月1回軽度清掃する | 月1回 | 水垢・カビ固着防止 |
| プロクリーニングを依頼する | 6〜12ヶ月毎 | 清潔状態の維持 |

# 20. 教育ポイント（新人向け）

## 最初に覚えること（優先順）

1. **上から下への施工順序**（天井→換気扇→壁→鏡→浴槽→床の順序の理由）
2. **酸性洗剤と塩素系洗剤の混合禁止**（有毒ガス発生の危険）
3. **素材確認と薬剤の使い分け**（FRP・人工大理石・ホーローは強い研磨・強い薬剤禁止）
4. **薬剤放置時間の重要性**（擦る前に浸透させる）
5. **換気扇清掃前の電源OFFの確認**

## 新人が失敗しやすいポイント

| 失敗 | 防止策 |
|------|--------|
| 酸性と塩素系を混合 | 「切り替え前に必ず30秒以上すすぐ」を徹底する |
| ダイヤモンドパッドで鏡に傷 | 「湿潤状態のみ・コーティング確認後」を必ず守る |
| 水垢が残る | 「薬剤を塗布して3〜5分以上待つ」→「すぐ擦らない」 |
| FRPを傷付ける | 「柔らかいスポンジのみ」→「力を入れない」 |
| 換気扇で感電 | 「電源OFFを目視確認してから取り外す」を指差呼称 |

## 一人作業を許可する判断基準

以下を全て満たしていること（現場責任者が確認・許可）：

- 施工順序（上から下）を説明できる
- 素材別の使用可能薬剤・禁止事項を理解している
- 酸性洗剤と塩素系漂白剤を混合しないことを徹底できる
- ダイヤモンドパッドの正しい使い方を理解している（湿潤状態・コーティング確認）
- 品質確認方法（目視・触診・臭気）を実施できる
