# トイレ清掃 SOP

**対象：トイレ清掃全般（日常・巡回・週次・定期）**

---

# 1. 適用範囲

## 対象施設

- 飲食店 / ホテル / オフィス / 商業施設 / 病院 / 学校 / 公共施設 / 集合住宅共用部

## 対象設備・作業範囲

- 天井 / 換気口 / 照明器具 / 壁 / 間仕切り / 扉 / ドアノブ / 鍵 / 手すり
- 操作ボタン / ペーパーホルダー / 棚 / 手洗い器 / 洗面ボウル / 鏡 / 水栓 / 石けん容器
- 大便器 / 小便器 / 温水洗浄便座 / 便座ノズル / タンク / フラッシュバルブ
- 便器周辺床 / 巾木 / 床 / 排水口 / 汚物入れ / サニタリーボックス / ゴミ箱
- ベビーチェア / おむつ交換台 / 消耗品補充

## 施工可能条件

| 条件 | 基準 |
|------|------|
| 利用者の有無 | 利用者が退出してから作業開始 |
| 換気 | 換気扇稼働・窓開放で換気が確保できること（塩素系・酸性薬剤使用時は必須） |
| 床の状態 | 水溜まり・著しい漏水がないこと |
| 設備 | 便器・便座の割れ・欠けが確認済みであること |
| 感電リスク対策 | 電装部（温水洗浄便座・操作パネル）周辺に薬剤・水が直接かからないよう養生すること |
| 高所作業 | 天井・換気口清掃で脚立が必要な場合、安全に設置できるスペースがあること |
| 養生 | コンセント・操作パネルへの水・薬剤飛散防止養生が実施可能なこと |
| 雨天・強風・直射日光 | 室内作業のため天候不問 |
| 凍結 | 室内で水道・温水洗浄便座が使用できる状態であれば施工可 |

## 施工不可条件（通常清掃を中止し別対応へ切り替える）

| 条件 | 対応 |
|------|------|
| 血液・嘔吐物・大量の排泄物汚染 | 感染症・汚物処理手順へ切り替える。周囲を立入禁止にする |
| 排水が完全閉塞している | 管理者へ報告。無理に薬剤を追加しない |
| 便器・便座に著しい割れ・欠けがある | 使用中止表示→管理者へ報告→修理後に施工 |
| 注射針・刃物等の鋭利物がある | 素手で触らない。トング使用・管理者報告 |
| 漏電の疑い（焦げ臭・異音） | 電源へ近づかない。管理者・施設担当へ報告 |

## 作業中止基準

以下を発見した場合は即時作業を停止し、管理者へ報告する。

| 発見内容 | 対応 |
|------|------|
| 塩素臭・刺激臭が急に強くなった | 即時退避・換気・原因薬剤を確認 |
| 薬剤が目・皮膚に付着 | 流水で15分以上洗浄・受診 |
| 便器・タンクから漏水が起きた | 作業中止・止水栓を閉める・管理者へ報告 |
| 温水洗浄便座からスパーク・煙 | 電源遮断・119番通報 |
| 感染性汚染物を発見（血液・体液） | 通常清掃を中止・感染対策手順へ切り替え |

# 2. 基本施工原則

**これだけ守れば品質は揃う。全員が守る。**

```text
① 上から下へ施工する
② 奥から手前へ施工する
③ きれいな箇所から汚れた箇所へ進む
④ 一度拭いた清潔部へ汚れたクロスで戻らない
⑤ 床は必ず最後に施工する
```

## クロスの色分けルール（必須）

| 色 | 用途 | 使用箇所 |
|---|---|---|
| 赤 | 洗剤拭き | 便器外側・便座裏・汚れた壁 |
| 黄 | 仕上げ水拭き | 洗剤使用後の仕上げ |
| 白 | 清潔部の水拭き | 便座表面・操作部・手洗い器・鏡 |
| 緑 | ノズル専用 | 温水洗浄便座のノズルのみ |

**色を間違えない。他の箇所で使用した色は同じ場所に戻さない。**

## 道具の区分けルール（必須）

- 大便器用ブラシ ≠ 小便器用ブラシ（共用禁止）
- ノズル専用クロス（緑）≠ 他の箇所のクロス（共用禁止）
- トイレ用資機材 ≠ 他の清掃区域（持ち出し禁止）

## 清潔部・汚染部の区分け

清潔部（先に施工）→ 汚染部（後に施工）の順番を守る。

| 清潔部（先） | 汚染部（後） |
|------------|------------|
| ドアノブ・鍵・操作部・手すり | 便座裏面・便器内部・小便器・排水口 |
| 手洗い器・鏡 | 便器外側・床接合部 |
| 換気口・天井 | 床 |

# 3. 対象設備と主な汚れ

## 汚れの種類と対応薬剤

| 汚れ | 発生しやすい箇所 | 対応薬剤 |
|------|----------------|---------|
| 尿汚れ（飛散） | 便座裏・便器外側・小便器・壁・床 | CHEM-001（中性洗剤） |
| 尿石（固着） | 便器リム裏・排水口・小便器目皿 | CHEM-006（酸性洗剤）※定期清掃 |
| 便汚れ | 便器ボウル・便座裏・リム裏 | CHEM-002（便器用洗剤） |
| 水垢 | 手洗い器・水栓・鏡・便器水面 | CHEM-001（通常）/ CHEM-006（固着時） |
| 手垢・皮脂 | ドアノブ・鍵・操作ボタン・手すり | CHEM-001・CHEM-003 |
| ホコリ | 換気口・照明・棚・間仕切り上部 | 乾式除塵→CHEM-001 |
| カビ・ぬめり | 排水口・床目地・タンク周辺 | CHEM-007（塩素系漂白剤） |
| 石けんカス | 手洗い器・水栓 | CHEM-001 |

## 悪臭の原因箇所（清掃で除去する。芳香剤で隠さない）

- 便器外側（尿飛散） / 便器と床の接合部 / 小便器下部 / 壁・床への尿飛散
- 排水口 / 汚物入れ・サニタリーボックス / 換気不足 / 尿石 / 清掃用具自体の汚染

# 4. 施工前確認

## 設備確認（作業開始前に必ず確認する）

1. 便器・便座の割れ・欠け・ひびを確認する。異常があれば使用中止表示→管理者報告。
2. 温水洗浄便座の機種を確認する。初めて扱う機種は取扱説明書を確認してから作業する。
3. 床の漏水・異常な濡れを確認する。
4. 異常な臭気（ガス臭・異常な腐敗臭）がないか確認する。
5. 血液・嘔吐物・大量の排泄物汚染がないか確認する（あれば別手順へ切り替え）。
6. 作業前写真を撮影する。

**【写真①：トイレ全景（作業前）】**

**【写真②：便器・小便器（汚れ状況）】**

**【写真③：手洗い器・鏡（状況）】**

**【写真④：床（状況）】**

**【写真⑤：破損・異常箇所（ある場合のみ）】**

## 利用者への対応

1. 入口へ「清掃中」表示を設置する。
2. 利用者がいない状態で作業を開始する。利用中の場合は退出を待ってから入る。
3. 利用者が来た場合は「清掃中です。少々お待ちください」と声をかけ、退出後に作業を再開する。

# 5. 使用保護具

## 必須

□ 使い捨て手袋（便・尿・薬剤への接触防止）

□ トイレ清掃専用作業着（他の清掃区域と分ける）

□ マスク（飛沫・臭気の低減）

□ 保護メガネ（薬剤飛散・汚水飛散防止）

□ 滑り止め付き作業靴

## 必要時

□ 耐薬品手袋（尿石除去剤・塩素系漂白剤使用時）

□ 防水エプロン（床機械洗浄・高水圧施工時）

□ フェイスシールド（大量飛散対策）

□ 長靴（大量漏水対応時）

## 手袋の正しい外し方（必ず守る）

1. 片方の手袋外側を反対の手でつまむ（汚染面を内側にして裏返す）。
2. 外した手袋を、まだ着用している手で握る。
3. 素手の指を残った手袋の手首内側へ差し込む。
4. 外側に触れないよう裏返して外す。
5. 廃棄容器へ廃棄する。
6. 石けんと流水で20秒以上手洗いする。

**手袋を外した後は素手で便器・床に触れない。必ず手洗いしてから次の作業へ進む。**

# 7. 使用薬剤一覧（AVL Facilities 推奨基準）

## CHEM-001　中性洗剤（トイレ全般用）

| 項目 | 内容 |
|------|------|
| 液性 | 中性（pH 6〜8） |
| 対象汚れ | 手垢・皮脂・尿飛散（軽度）・ホコリ・石けんカス・水垢（軽度） |
| 対象部位 | 便器外側・便座表面・壁・ドアノブ・手すり・手洗い器・水栓 |
| 推奨希釈倍率 | 50〜100倍希釈 |
| 使用量目安 | クロスに2〜3プッシュ / スプレーボトルで対象から10〜15cm離して3〜5回 |
| 放置時間 | 1〜2分（乾燥させない）→ 黄色クロスで水拭き仕上げ |
| 使用不可素材 | 電装部・操作部への直接噴霧禁止（クロスに含ませて使用） |
| 注意事項 | 洗剤使用後は黄色クロスで仕上げ水拭きする（残留防止） |

---

## CHEM-002　便器用洗剤（弱アルカリ性〜中性）

| 項目 | 内容 |
|------|------|
| 液性 | 弱アルカリ性〜中性（pH 7〜10） |
| 対象汚れ | 便汚れ・尿汚れ・水面線汚れ・軽度尿石 |
| 対象部位 | 便器ボウル内部・リム裏・封水部 |
| 推奨希釈倍率 | 原液または5〜10倍希釈 |
| 使用量目安 | 柄付きスポンジに5〜10ml（スポンジ全面に均一に含ませる） |
| 放置時間 | 30秒〜3分以内（長時間放置禁止。金属部品の腐食・劣化の原因） |
| 使用不可素材 | 温水洗浄便座・ノズル・金属部・便器外側への長時間放置禁止 |
| 注意事項 | CHEM-007（塩素系）との混合禁止。一度に30ml以上投入しない（過剰投入は素材劣化の原因）。 |

## CHEM-008　消臭剤

| 項目 | 内容 |
|------|------|
| 液性 | 中性〜弱アルカリ性 |
| 用途 | 清掃後の残臭調整（原因汚れ除去の後に使用） |
| 対象部位 | 汚物入れ周辺・排水口周辺・トイレ全体 |
| 推奨希釈倍率 | 原液または2〜5倍希釈 |
| 使用量目安 | スプレー3〜5回/箇所 |
| 放置時間 | 乾燥させる（拭き取り不要） |
| 注意事項 | 臭気を消臭剤で隠さない。原因汚れを除去してから使用する。 |

## 工程1　作業表示・立入管理・換気

**目安時間：約2〜3分　必要人数：1名**

### 手順

1. トイレ入口へ「清掃中」表示を、入口から見える位置に設置する。
2. トイレ内に利用者がいないことを声かけして確認する（「清掃に入ります」）。
3. 換気扇を起動する。窓がある場合は開放する。
4. 照明を全灯にする。
5. 床の水分・障害物を確認し、滑り止め靴着用を確認する。

### 注意事項

- 利用中の場合は退出を待ってから入る。
- 作業用具を通路中央へ置かない（転倒リスク）。
- 多目的トイレでは代替トイレの案内が出ているか確認する。

### 完了基準

□ 作業表示を正しい位置に設置した

□ 利用者不在を確認した

□ 換気・照明が正常である

## 工程2　ゴミ回収・汚物入れ・消耗品確認

**目安時間：約3〜5分　必要人数：1名**

### 使用道具

TOOL-020（トング）/ TOOL-021（ゴミ回収袋）/ 使い捨て手袋

### 使用薬剤

CHEM-003（除菌清拭剤）→ 汚物入れ内外の清拭に使用

### 手順

1. ゴミ箱の内容物をトングを使って確認する（鋭利物・異物がないか）。
2. ゴミ袋の口を利用者側へ向けず、静かに取り外す（振ったり圧縮しない）。袋を密閉して廃棄する。
3. サニタリーボックスを開けて内容物を回収する。
4. 汚物入れの内外をCHEM-003（除菌清拭剤）で清拭する。
5. 新しい袋を取り付ける。
6. トイレットペーパー・ハンドソープ・ペーパータオル等を確認し、残量が30%以下の場合は補充する（補充時は新しい手袋で触る）。
7. **手袋を交換する。**

**【写真⑥：消耗品補充状態（作業後）】**

### 注意事項

- 注射針・刃物・不明な鋭利物を素手で触らない。トングを使用し、管理者へ報告する。
- ゴミ袋へ顔を近づけない（感染リスク）。
- 清潔な消耗品に汚染手袋で触らない。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| ゴミ袋の取り外し | 静かに・振らず・密閉して廃棄 | 振って圧縮する・顔を近づける |
| 消耗品補充 | 手袋交換後に清潔な手で補充 | 汚染手袋のままで補充 → 交差汚染 |

### プロのコツ

- ゴミ箱交換のタイミングで残量・種類を記録しておくと次回の補充が効率的になる。
- サニタリーボックスは「外側→内側→新袋設置」の順番で施工すると再汚染しない。

## 工程3　天井・換気口・照明・上部除塵

**目安時間：約3〜10分　必要人数：1〜2名（脚立使用時は2名推奨）**

### 使用道具

TOOL-010（ドライモップ・ダスター）/ TOOL-019（脚立）/ クロス

### 手順

1. 奥から入口方向へ向かいながら、ドライモップで天井・換気口・照明・棚上部のホコリを静かに払い取る。
2. 換気口の表面ホコリを除去する（換気扇内部には直接薬剤を噴霧しない）。
3. 照明カバーの外側を乾いたクロスで拭き取る（内部・電球には触れない）。
4. 棚・間仕切り上部をクロスで拭き取る。
5. 落下したホコリは後工程（床清掃）で回収する。

### 注意事項

- ホコリを舞い上げないようゆっくり動かす（水拭きの前に必ず乾式除塵を行う）。
- 照明・換気扇内部へ直接薬剤を噴霧しない（感電・故障リスク）。
- 脚立使用時は必ず補助者を配置する。

### 完了基準

□ 目視できるホコリなし　□ クモの巣なし　□ 換気口詰まりなし

## 工程4　壁・扉・高頻度接触部清掃

**目安時間：約5〜10分　必要人数：1名**

### 使用道具

TOOL-001（赤色クロス）/ TOOL-002（黄色クロス）/ TOOL-003（白色クロス）/ TOOL-008（隙間ブラシ）

### 使用薬剤

CHEM-001（中性洗剤）50〜100倍希釈：壁・扉全般
CHEM-003（除菌清拭剤）原液：ドアノブ・鍵・手すり・操作ボタン

### 手順

1. 壁・扉のホコリを乾式で先に払い取る。
2. 上部から下部へ向けて、CHEM-001を含ませた赤色クロスで清拭する。一方向（往復させない）。
3. クロス面が汚れたら新しい面へ替える。
4. **ドアノブ・鍵・手すりをCHEM-003（除菌清拭剤）を含ませた白色クロスで清拭する（高頻度接触部を重点施工）。**
5. ペーパーホルダー・操作ボタン・リモコンをCHEM-001（赤色クロスに含ませて）清拭する。電装部には直接スプレーしない。
6. 洗剤使用箇所は黄色クロスで仕上げ水拭きする。

### 注意事項

- 便器周辺を拭いたクロスでドアノブ等の清潔部を拭かない（再汚染）。
- 電装部（操作ボタン・リモコン）にスプレーを直接噴霧しない。
- 往復拭きは汚れを広げる。必ず一方向で拭く。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 施工方向 | 上から下へ一方向 | 往復拭き → 汚れを広げる |
| ドアノブ | 除菌清拭剤で重点施工・白色クロス使用 | 便器を拭いた赤色クロスで施工 → 再汚染 |

### プロのコツ

- ドアノブは最も手垢が付きやすい。クロスを畳み直して清潔な面を必ず使う。
- 壁の高い位置から始めると、下に落ちたホコリを後で床清掃でまとめて回収できる。

## 工程5　手洗い器・水栓・鏡清掃

**目安時間：1台 約3〜5分　必要人数：1名**

### 使用道具

TOOL-003（白色クロス）/ TOOL-001（赤色クロス）/ TOOL-002（黄色クロス）/ スポンジ / TOOL-008（隙間ブラシ）

### 使用薬剤

CHEM-001（中性洗剤）50〜100倍希釈：洗面ボウル・水栓・石けん容器
CHEM-004（ガラス・鏡用洗剤）30〜100倍希釈：鏡

### 手順

**手洗い器・水栓**

1. 髪の毛・ゴミをトングまたは手袋を着用した手で回収する。
2. CHEM-001（50〜100倍希釈）をスポンジに含ませ、洗面ボウル全体を洗浄する（力は約300〜400g程度。円を描かず上から下へ一方向）。
3. 排水口周辺・オーバーフロー穴を隙間ブラシで3〜5往復する。
4. 水で流すか白色クロスで水拭きする。
5. 水栓をCHEM-001（クロスに含ませて）清拭する（クロムメッキを傷付けない柔らかいクロスを使用）。
6. 水栓根元の石けんカス・水垢を重点清掃する。

**鏡**

7. CHEM-004（クロスに2〜3プッシュ）を白色クロスに含ませ、鏡を上から下へ拭く（一方向）。
8. 乾いた白色クロスで仕上げ拭きをする。光を斜めから当てて拭きムラがないか確認する。

**【写真⑦：手洗い器・鏡（清掃後）】**

### 注意事項

- 自動水栓のセンサー部に直接スプレーしない。
- 鏡端部を長時間濡らさない（腐食リスク）。
- 石けん容器の補充を忘れない。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 鏡 | 光を当てて確認・拭きムラなし・端部乾燥 | 拭きムラあり・端部が濡れたまま |
| 水栓 | 根元まで洗浄・水垢なし | 根元の石けんカスを見落とし |

### プロのコツ

- 鏡は「斜め方向から蛍光灯の光を反射させて確認」する。正面からでは拭きムラが見えにくい。
- 手洗い器は利用者の目に入りやすく、施設の印象に直結する。仕上がりを特に丁寧に確認する。

## 工程6　温水洗浄便座ノズル清掃（日常）

**目安時間：1台 約2〜3分　必要人数：1名**

### 使用道具

TOOL-004（緑色ノズル専用クロス）/ 使い捨て手袋

### 使用薬剤

**清水のみ**（メーカーが水拭き以外を指定している場合のみCHEM-001）

温水洗浄便座・ノズルには酸性洗剤・強アルカリ・塩素系・研磨剤入り洗剤を使用禁止。

### 手順

1. 対象機種の取扱説明書でノズルの出し方・戻し方を確認する。
2. リモコンや操作部に白色クロスを添える（水分が入らないよう保護）。
3. ノズル洗浄ボタンを操作してノズルを出す。
4. ノズルへ片手を添える（ノズルを固定するため）。
5. 緑色ノズル専用クロス（水に浸けた後、水滴が垂れない程度に絞った状態）で、**根元から先端へ向けて一方向**に清拭する（3〜5往復）。
6. ノズルの孔（穴）を強く擦らない。
7. ノズルを所定の方法で戻す。
8. 動作・収納状態を確認する。

### 注意事項

- 便器用ブラシや研磨材でノズルを絶対に洗浄しない（破損・故障の原因）。
- ノズルを引っ張らない・曲げない・回転させない。
- 洗剤を直接ノズルに噴霧しない。
- 緑色クロスを他の箇所（便器・床等）に使用しない。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 方向 | 根元から先端へ一方向 | 往復拭き・先端から根元方向 |
| 使用道具 | 緑色専用クロス・水拭きのみ | 便器用ブラシで洗浄 → 破損 |
| 収納確認 | 所定の方法で戻し・動作確認 | 無理に押し込む → 破損 |

### プロのコツ

- ノズルを出すときに「手を添えてゆっくり支える」習慣をつけると破損事故を防げる。
- 機種によってノズルの形状・数が異なる。初めての機種は取扱説明書を必ず確認する。

## 工程7　便座・便ふた・操作部清掃

**目安時間：1台 約3〜5分　必要人数：1名**

### 使用道具

TOOL-003（白色クロス）/ TOOL-001（赤色クロス）/ TOOL-002（黄色クロス）/ 使い捨て手袋

### 使用薬剤

CHEM-001（中性洗剤）50〜100倍希釈：クロスに2〜3プッシュ含ませて使用
CHEM-003（除菌清拭剤）：操作部・リモコン

便座・便ふた・操作部に酸性洗剤・強アルカリ・研磨剤入り洗剤を使用禁止。

### 手順

**清潔な部分から汚れた部分へ順番に施工する（以下の順序を厳守）：**

```
便座表面（最も清潔）
    ↓
便ふた表面
    ↓
便ふた裏面
    ↓
便座本体ケース上部
    ↓
操作部・リモコン
（ここまでが比較的清潔な箇所）
```

1. 便座・便ふたの破損・ひび・ガタつきを確認する。異常があれば管理者へ報告する。
2. 白色クロスをCHEM-001（50〜100倍希釈）で湿らせ（80〜90%絞る）、便座表面を一方向に清拭する（力は約200〜300g程度）。
3. 便ふた表面・裏面を同様に清拭する。
4. 便座本体ケース上部を清拭する。
5. 操作部・リモコンはCHEM-003（クロスに含ませて）清拭する。直接スプレーしない。
6. 洗剤使用箇所は黄色クロスで仕上げ水拭きをする。
7. 水滴・洗剤残留を確認する。

### 注意事項

- 便器内・床を拭いたクロスで便座表面へ戻らない（再汚染）。
- 電装部（操作部・リモコン）への直接スプレー禁止（故障・漏電リスク）。
- 汚れが固着していても強く擦らない。CHEM-001を1〜2分作用させてから施工する。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 施工順 | 便座表面→ふた→裏面→操作部の順 | 汚れた箇所を先に施工して清潔部へ戻る |
| 操作部 | クロスに含ませて清拭・直接スプレーなし | 直接スプレー → 内部への水分侵入 → 故障 |
| 仕上げ | 黄色クロスで洗剤残留を除去 | 洗剤拭きだけで終了 → 残留 → ベタつき |

### プロのコツ

- 便座表面は「傷付けない素材で」「乾いた布・ペーパーを使わない」のが基本。傷がつくと汚れが入り込みやすくなる。
- 操作部は「クロスを固く絞ってから施工」する。水分が入ると設定変更・故障の原因になる。

## 工程8　便器ボウル・封水部清掃

**目安時間：1台 約3〜5分　必要人数：1名**

### 使用道具

TOOL-005（柄付き便器用スポンジ）/ TOOL-006（便器用ブラシ）/ 使い捨て手袋

### 使用薬剤

CHEM-002（便器用洗剤）原液または5〜10倍希釈：スポンジに5〜10ml（スポンジ全面へ均一に）

### 手順

1. 便座と便ふたを上げる。
2. 白色クロスを操作部に添えてから便器洗浄を行う（内部を確認する）。
3. 便器内の異物・大量汚染の有無を確認する（大量汚染があれば別手順へ）。
4. 柄付きスポンジのスポンジ部分にCHEM-002を5〜10ml含ませ、スポンジ全面に均一に行き渡らせる。
5. 以下の順序で便器内を洗浄する（飛沫が出ないよう約5〜10cm/秒の速度で動かす）：

```
リム裏（手前から奥へ3〜5往復）
    ↓
水面上部
    ↓
ボウル側面（全周）
    ↓
水面線（輪状の汚れが残りやすい）
    ↓
封水部（飛沫を出さないよう、ゆっくり洗浄）
    ↓
排水方向
```

6. 便器洗浄を行いながら、洗剤と汚れを洗い流す（放置は最大3分以内）。
7. 汚れ残り・洗剤残留・排水状態を確認する。

### 注意事項

- 便器用洗剤を温水洗浄便座・ノズル・金属部に付着させない。
- 洗剤を長時間放置しない（最大3分以内に流す）。放置すると金属部品の腐食・変色の原因になる。
- 金属ブラシ・研磨剤入りたわしで便器表面を擦らない（傷・コーティング剥がれ）。
- ブラシを速く動かさない（汚水・洗剤の飛沫が顔・衣服に付着する）。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 施工順 | リム裏→水面上部→側面→水面線→封水部の順 | いきなり封水部から施工 → 汚れが上に広がる |
| 洗剤放置 | 30秒〜3分以内に洗い流す | 長時間放置 → 金属部品の腐食 |
| 飛沫管理 | 約5〜10cm/秒のゆっくりした速度 | 速く動かす → 汚水が顔に飛ぶ |

### プロのコツ

- リム裏は便器用ブラシのブラシ先端を使い、「奥から手前へ向けて引く」動作が汚れを落としやすい。
- 水面線（便器のガラスコートが弱くなりやすい箇所）は特に丁寧に施工する。ここが残ると「便器が汚い」印象になる。

**【写真⑧：便器洗浄後の状態確認】**

## 工程9　便座裏面・便器外側・床接合部清掃

**目安時間：1台 約4〜6分　必要人数：1名**

### 使用道具

TOOL-001（赤色クロス）/ TOOL-002（黄色クロス）/ TOOL-008（隙間ブラシ）/ 使い捨て手袋

### 使用薬剤

CHEM-001（中性洗剤）50〜100倍希釈：クロスに2〜3プッシュ

### 手順

1. 便座を上げる。
2. CHEM-001（赤色クロスに2〜3プッシュ）を含ませ、80〜90%絞ってから施工する。
3. 以下の順序で施工する：

```
便座裏面（尿飛散が最も多い）
    ↓
便座本体ケース下部
    ↓
便器リム外周
    ↓
便器側面（上から下へ）
    ↓
便器背面・給水管周辺
    ↓
便器と床の接合部（臭気の原因箇所。隙間ブラシで重点施工）
```

4. 便器と床の接合部は隙間ブラシを差し込み、左右に3〜5往復する（尿が染み込みやすい最重要箇所）。
5. 黄色クロスで仕上げ水拭きをする。
6. 尿臭・汚れ残り・水滴を確認する。

### 注意事項

- 電源プラグ・給水ホースを強く引かない（断線・漏水リスク）。
- 強く擦って樹脂・陶器を傷付けない。
- 汚染したクロスで便座表面や操作部へ戻らない。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 接合部 | 隙間ブラシで奥まで施工 | 目視だけで完了と判断 → 臭気が残る |
| 便座裏面 | 赤色クロスで全面施工 | 表面だけ施工・裏面を忘れる → 尿臭の原因 |

### プロのコツ

- 「便器と床の接合部」はトイレ臭の最大原因。ここを丁寧に施工するだけで臭気が大幅に改善する。
- 便器背面・給水管周辺は「ほこりが溜まりやすく・見落とされやすい」。クロスを回し込むように施工する。

## 工程10　小便器清掃

**目安時間：1台 約3〜5分（尿石除去含む場合：10〜20分）　必要人数：1名**

### 使用道具

TOOL-007（小便器用ブラシ）/ TOOL-001（赤色クロス）/ TOOL-002（黄色クロス）/ TOOL-008（隙間ブラシ）/ TOOL-020（トング）/ 使い捨て手袋

### 使用薬剤

日常清掃：CHEM-001（中性洗剤）50〜100倍希釈 / CHEM-002（便器用洗剤）
尿石除去（定期）：CHEM-006（酸性洗剤）原液〜5倍希釈（耐薬品手袋・保護メガネ必須）

### 手順

1. トングで小便器内の異物を回収する。
2. 洗浄水を流し、排水状態を確認する。
3. CHEM-002を小便器内に適量（5〜10ml）塗布する。
4. 小便器用ブラシでリム→内壁→目皿→排水口の順にブラシ洗浄する（3〜5往復）。大便器用ブラシと共用しない。
5. センサー部をCHEM-001（赤色クロスに含ませて）清拭する（センサーへ直接スプレーしない）。
6. 小便器外側・側面・下部を赤色クロスで洗剤拭きする。
7. 洗浄水ボタンを2〜3回押して完全に洗い流す。
8. 黄色クロスで仕上げ水拭きする。
9. 小便器下部・床接合部を赤色クロスで清拭する（臭気が最も残りやすい箇所）。
10. 臭気・排水・自動洗浄の動作を確認する。

**【写真⑨：小便器清掃後】**

### 注意事項

- 尿石除去剤（CHEM-006・酸性）は塩素系漂白剤（CHEM-007）と絶対に混合しない。
- センサーへ直接薬剤を噴霧しない（故障リスク）。
- 詰まりがある場合は薬剤を追加しない（溢れる可能性）。管理者へ報告。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| ブラシ | 小便器専用ブラシを使用 | 大便器用ブラシと共用 → 交差汚染 |
| 下部・接合部 | 赤色クロスで重点施工 | 目視確認だけで省略 → 尿臭の原因 |

### プロのコツ

- 小便器下部と壁面の尿飛散は「臭気の主な原因」。外側だけでなく、便器と床・便器と壁の接合部を必ず施工する。
- 目皿を外せる場合は取り外して裏側まで洗浄する。目皿の裏側に尿石が固着していることが多い。

## 工程11　床・巾木・排水口清掃（必ず最後に施工）

**目安時間：小規模 約5〜10分 / 中規模 約10〜20分　必要人数：1名**

### 使用道具

TOOL-010（ドライモップ）/ TOOL-011（ウエットモップ）/ TOOL-012（スクイジー）/ TOOL-009（ハンドブラシ）/ TOOL-020（トング）

### 使用薬剤

CHEM-005（床用中性洗剤）50〜100倍希釈（バケツ10Lに対して100〜200ml）

### 手順

1. 床の紙くず・髪の毛・異物をトングで回収する。
2. **奥から入口方向へ**ドライモップで乾式除塵する（先にホコリを除去してから水拭きする）。
3. 便器周辺・小便器下部・巾木・壁際の尿飛散を確認する。
4. CHEM-005（50〜100倍希釈）をウエットモップに含ませ、奥から入口方向へ「コの字型または一方向」で清拭する。
5. 便器周辺・小便器下部を重点施工する（尿飛散が最も多い箇所）。
6. 巾木・角部はハンドブラシまたはクロスで施工する。
7. 排水口がある場合はゴミを回収し、ハンドブラシで3〜5往復洗浄する。
8. 必要に応じてスクイジーで水切りをする（ゴム全面を床に密着させて一方向へ引く）。
9. 洗剤残留・水滴を確認する（残留は転倒の原因）。
10. **清掃済みの床を踏まないよう、入口方向へ後退しながら施工を完了する。**

**【写真⑩：床・排水口清掃後】**

### 注意事項

- 床は必ず最後に施工する（上部の汚れが落下するため）。
- 清掃済みの床を踏まない（奥から手前へ施工する理由）。
- トイレ用モップを他の清掃区域へ使用しない。
- 利用再開前に完全乾燥を確認する（濡れた床は転倒の原因）。
- 排水口へ固形物を流さない。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 施工順 | 奥から入口方向へ後退しながら施工 | 入口から奥へ向かって施工 → 清掃済みを踏む |
| 乾燥確認 | 利用再開前に完全乾燥確認 | 濡れたまま表示撤去 → 利用者が転倒 |
| 便器周辺 | 重点施工（尿飛散が多い） | 通路だけ清掃して便器周辺を省略 |

### プロのコツ

- モップは「コの字型」で動かすと、一方向ずつ清掃済みの面に重ならず効率的。
- 「洗浄水がすぐに濁る」場合は早めに交換する。汚れた水で床を拭くと汚れを広げる。

## 工程12　温水洗浄便座 脱着清掃（週次）

**目安時間：1台 約15〜25分　必要人数：1名（初回・大型機種は2名推奨）**

### 使用道具

TOOL-001（赤色クロス）/ TOOL-002（黄色クロス）/ TOOL-003（白色クロス）/ TOOL-008（隙間ブラシ）/ メーカー取扱説明書

### 使用薬剤

CHEM-001（中性洗剤）50〜100倍希釈：便器上面・便座本体底面

### 手順（脱着前の確認が最重要）

1. 対象機種の品番を確認し、取扱説明書で脱着方法・取り外しボタン・レバーの位置を確認する。
2. 運転ランプが正常に点灯していることを確認する。
3. **手袋の水分を完全に拭き取ってから電源プラグを抜く**（濡れた手袋でプラグ操作は感電リスク）。
4. 給水ホース・電源コードの位置を確認する（引っ張らないように注意）。
5. 本体取り外しボタンまたはレバーを操作し、温水洗浄便座を**無理に引っ張らず**取り外す。

**【写真⑪：温水洗浄便座取り外し前（向き・設置位置確認）】**

6. 便器上面（温水洗浄便座が乗っていた面）を赤色クロス（CHEM-001含ませて）で清拭する。
7. 便座本体底面を確認し、クロスで清拭する（クロスに薬剤を含ませてから拭く。直接噴霧しない）。
8. 隙間ブラシで接続部・細部を3〜5往復する。
9. クロス面が汚れたら新しい面へ替える。
10. 黄色クロスで仕上げ水拭きをする。
11. 脱臭フィルターを取り外し、黄色クロスで清拭する（フィルターを水没させない）。フィルターを所定の位置へ戻す。
12. ベースプレートと便座本体の中心を合わせて、「カチッ」と音がするまで確実に装着する。
13. 前後左右に各2〜3kgの力で押してガタつきがないことを確認する（ガタつきは転倒事故の原因）。
14. **手袋の水分を拭き取ってから電源プラグを差し込む。**
15. 運転ランプ・ノズル・洗浄機能を確認する。

**【写真⑫：便器上面・便座底面清掃後】**

**【写真⑬：復旧後の固定確認・動作確認】**

### 注意事項

- 取扱説明書を確認できない場合は取り外さない。
- 便器から取り外しできない機種は脱着工程を省略する（メーカー確認）。
- 濡れた手袋で電源プラグを操作しない（感電リスク）。
- 電源コード・給水ホースを傷付けない。
- 脱臭フィルターを水没させない。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| プラグ操作 | 手袋の水分を完全に拭き取ってから操作 | 濡れた手袋でプラグ操作 → 感電リスク |
| 装着確認 | 「カチッ」音確認・ガタつきなし | 音がしない・ガタつく → 再装着 |
| 動作確認 | 電源ON・運転ランプ・ノズル・洗浄機能を全確認 | 電源だけ確認して終了 |

### プロのコツ

- 装着時に「中心を合わせてから押し込む」のが確実な固定のコツ。ずれた状態で押し込むと正しく固定されない。
- 復旧後に「前後左右に各2〜3kgの力で押して確認する」を習慣化する。ガタつきが残ると転倒事故の直接原因になる。

# 12. よくある失敗と対策

| 失敗 | 原因 | 改善方法 | 防止策 |
|------|------|---------|--------|
| 尿臭が残る | 便器外側・床接合部・小便器下部の清掃不足 | 臭気発生箇所を特定し再清掃 | 接合部を必ず隙間ブラシで施工する |
| 便器に汚れが残る | リム裏・封水部の洗浄不足 | 施工順序を守り全面施工 | リム裏から始める順序を徹底する |
| 便座に拭きムラ | クロスの水分過多・面交換不足 | 固く絞り清潔な面で仕上げ | 黄色クロスで必ず仕上げる |
| 洗剤残留（ベタつき） | 仕上げ水拭き不足 | 黄色クロスで再水拭き | 「洗剤拭き（赤）→水拭き（黄）」の2工程を守る |
| 便座樹脂に傷 | 研磨材・乾いた布使用 | 傷は修復不可→管理者報告 | マイクロファイバークロスと中性洗剤のみ使用 |
| 操作部が故障 | 直接スプレー・水分侵入 | 管理者・メーカーへ報告 | クロスに含ませて清拭。直接スプレー禁止 |
| ノズルが変形 | 強く引く・ブラシ使用 | 使用中止→管理者・メーカー報告 | 緑色クロスで約100〜200gの力で拭く・引っ張らない |
| 便座ガタつき | 脱着後の装着不良 | 「カチッ」音確認まで再装着 | 装着後に前後左右の押し確認を習慣化 |
| 床が滑る | 洗剤・水滴残留 | 仕上げ水拭き・乾燥確認 | 利用再開前に乾燥確認 |
| 汚れを広げる | 往復拭き・同一クロスの連続使用 | 一方向拭きで再施工 | 「一方向・クロス面交換」の2ルールを徹底 |
| 清潔部を再汚染 | 便器清掃後にドアノブへ戻る | 再清掃 | 施工順序（清潔部→汚染部）を守る |
| 感電事故 | 濡れた手袋でプラグ操作 | 電源遮断・119番・管理者報告 | プラグ操作前に手袋の水分を完全に拭き取る |
| 薬剤臭が残る | 過剰使用・換気不足 | 5〜10ml使用・水拭き・換気 | 規定使用量を守り・換気を維持する |

# 14. 安全管理

## 転倒防止

- 清掃中表示を設置する
- 床の水滴を直ちに除去する
- 床洗浄後は完全乾燥確認をしてから表示を撤去する

## 感電防止

- 濡れた手袋でプラグを操作しない
- 電装部へ直接スプレーしない
- 電源コード・プラグの損傷を使用前に確認する

## 薬剤安全

- **CHEM-006（酸性）とCHEM-007（塩素系）を絶対に混合しない**
- 換気を確保した状態で薬剤を使用する
- 使い捨て手袋・保護メガネを着用する
- 薬剤が目に入ったら即座に15分以上水洗眼→医療機関受診

## 感染・交差汚染防止

- トイレ専用資機材を他の区域で使用しない
- クロスを色分けして用途を守る
- 清潔部から汚染部への順序を守る
- 作業後に石けんと流水で20秒以上手洗いする
- 厨房用エプロン・帽子等を外してからトイレ清掃を行う

## 血液・嘔吐物・大量排泄物汚染

通常清掃で対応しない。以下を守る：

1. 周囲を立入禁止にする
2. 通常清掃用具を使用しない（汚染拡大の原因）
3. 感染症・汚物処理手順へ切り替える
4. 管理者・施設担当へ即座に報告する

## 緊急時対応

| 事故 | 対応 |
|------|------|
| 薬剤が目に入った | 即座に15分以上水洗眼→受診。使用薬剤名を記録する。 |
| 薬剤が皮膚に付いた | 大量の水で15分以上洗い流す。 |
| 感電の疑い | 電源に触れない。安全な場合のみ電源遮断。119番→管理者報告。 |
| 転倒・負傷 | 作業区域を立入禁止→応急処置→119番→管理者報告。 |
| 設備破損・漏水 | 利用中止→立入禁止表示→管理者・設備担当・メーカーへ連絡。 |

# 19. 教育ポイント（新人向け）

## 最初に覚えること（優先順）

1. **クロスの4色管理（赤・黄・白・緑）と使用箇所**
2. **清潔部から汚染部への施工順序**（逆にすると再汚染になる）
3. **床は必ず最後・奥から手前へ**
4. **電装部へ直接スプレーしない**（操作部・リモコン・センサー）
5. **CHEM-006（酸性）とCHEM-007（塩素系）を混合しない**（有毒ガス発生）
6. **温水洗浄便座は取扱説明書を確認してから作業する**
7. **濡れた手袋でプラグ操作しない**
8. **作業後は必ず手洗い（石けん・流水・20秒以上）**

## 新人が失敗しやすいポイント

| 失敗 | 防止策 |
|------|--------|
| 同じクロスで全箇所を拭く | 「色を見て判断」する習慣。赤・黄・白・緑を使い分ける |
| 便器清掃後にドアノブへ戻る | 「便器は最後の方」「清潔部へ戻らない」を徹底 |
| 洗剤を操作部へ直接スプレー | 「クロスに含ませてから拭く」のルールを守る |
| 便器用と小便器用ブラシを共用 | 「ブラシの置き場を分ける」で物理的に共用を防ぐ |
| 仕上げ水拭きを忘れる | 「洗剤拭き（赤）→水拭き（黄）」は必ずセットで行う |
| 床に水滴を残したまま表示撤去 | 「乾燥確認してから表示撤去」のルールを守る |
| 濡れた手袋でプラグ操作 | 「プラグ操作前に手袋の水分を拭く」を指差呼称で確認 |

## 一人作業を許可する判断基準

以下を全て満たしていること（現場責任者が確認・許可）：

- 施工順序（上から下・清潔部から汚染部・床は最後）を説明できる
- クロスの4色管理を正しく実施できる
- 便器用・小便器用・ノズル用道具を正しく区別できる
- 中性洗剤を正しく希釈できる
- 電装部へ直接噴霧しない・洗剤拭き後に仕上げ水拭きを行える
- 温水洗浄便座の脱着前に取扱説明書を確認できる
- 作業後の手洗いを必ず実施できる

## 一人作業を許可しない作業（必ず複数名で対応）

- 血液・嘔吐物・大量排泄物処理
- 初めて扱う機種の温水洗浄便座脱着
- 尿石除去剤（強酸性・CHEM-006）の使用
- 床機械洗浄
- 高所作業
