# ベランダ清掃 標準作業手順書（SOP）

**対象：一般住宅・マンション・アパート・社宅・寮のベランダ・バルコニー**

---

# 1. 適用範囲

## 対象施設・設備

| 区分 | 対象 |
|---|---|
| 対象施設 | 一般住宅・マンション・アパート・社宅・寮・マンスリーマンション・低層集合住宅 |
| 対象部位 | ベランダ床・排水口・排水溝・手すり・笠木・室外機・室外機架台・窓ガラス（外側）・サッシ・網戸（外側）・物干し竿・物干し金具・壁面 |

## 対象作業

- ゴミ・落葉回収
- 鳥のフン除去
- 排水口・排水溝清掃
- ベランダ床清掃
- 手すり・室外機・設備清掃
- 窓ガラス外側・サッシ清掃

## 施工可能条件

| 条件 | 基準 |
|---|---|
| 天候 | 晴れ〜曇り（施工後1時間以内に雨の予報がある場合は延期） |
| 気温 | 5℃〜35℃（5℃未満は凍結・薬剤効果低下リスク） |
| 凍結 | 外気温5℃以上かつ床面・手すりが凍結していないこと |
| 強風 | 風速5m/s以下（旗が軽くなびく程度が目安）。高所手すり清掃は3m/s以下 |
| 直射日光 | 気温35℃超の直射日光下は薬剤乾燥が速いため、早朝・曇天を優先する |
| 近隣への配慮 | 隣接住戸に洗濯物がないことを確認してから湿式作業を開始 |
| 排水経路 | 排水口・排水溝が確保できること |
| 水使用 | マンション・集合住宅：一度に2〜3L以内で使用（管理規約確認） |
| 感電リスク対策 | 室外機の電装部・コンセント・屋外照明への水・薬剤飛散を養生で防ぐこと |
| 高所作業 | 手すり清掃時は身を乗り出さないこと。脚立が必要な場合は安全に設置できること |
| 養生 | 隣接住戸・植栽・窓への薬剤飛散防止養生が実施可能なこと |

## 施工不可条件

| 条件 | 対応 |
|---|---|
| 強風（目安：風速5m/s超。旗が激しくなびく状態） | 作業中止。ゴミ・薬剤が隣接住戸へ飛散する |
| 豪雨・雷 | 作業中止・延期 |
| 防水層に亀裂・破損が見える | 高圧洗浄・散水は禁止。報告して指示を仰ぐ |
| 手すりが緩んでいる・腐食している | 手すりに体重をかけない。報告 |
| 排水が完全に詰まっている | 詰まり除去後に清掃開始 |
| 電気設備の養生が不可能 | 室外機の電装部周辺には水を使用しない |

## 作業中止基準

以下を発見した場合は即時作業を停止し、お客様・管理者へ報告する。

| 発見内容 | 対応 |
|---|---|
| 風速が急変・強くなった | 作業中止・室内退避 |
| 防水層のひび割れ・浮きを発見 | 散水中止・報告 |
| 手すりのぐらつきを発見 | 即時中止・使用禁止表示・報告 |
| 薬剤が目・皮膚に付着 | 流水で15分以上洗浄・受診 |
| 隣接住戸への汚水飛散 | 作業中止・謝罪・清掃対応・報告 |

# 2. 汚れ別攻略表

**まずこの表で汚れを特定してから薬剤・工具を選ぶこと。**

| 汚れ | 見た目の特徴 | 発生場所 | 使用薬剤 | 道具 | 処置方法 | 注意点 |
|---|---|---|---|---|---|---|
| ゴミ・落葉・砂埃 | 乾いた固形物 | 床全体 | 不要 | ほうき・ちり取り | 濡れ新聞紙で吸着してから掃く | 乾いたまま掃くと周囲に飛散する |
| 鳥のフン | 白〜黄色のかたまり | 手すり・床・室外機 | 鳥害除去剤（CHEM-005）または中性洗剤 | スプレー・ペーパータオル | 湿潤3〜5分→回収→洗浄→除菌 | **乾燥したまま擦り取り禁止（病原菌飛散）** |
| 黒ずみ（コンクリート・タイル） | 灰〜黒色の面汚れ | 床全体 | 重曹水（CHEM-002） | デッキブラシ | 重曹水散布→5〜10分放置→ブラッシング | ウッドデッキへの重曹禁止 |
| コケ・藻 | 緑〜黒の生物汚染 | 北側・日陰の床 | 弱アルカリ洗剤（CHEM-003） | デッキブラシ | 薬剤散布→5〜10分放置→ブラッシング | テスト施工必須 |
| 排水口の詰まり汚れ | 泥・落葉の蓄積 | 排水口内部 | クエン酸水（CHEM-004） | 排水口ブラシ | ゴミ除去→クエン酸水散布→ブラッシング→バケツ1杯（1〜2L）の水で流れを確認 | ゴミを排水口に流し込まない |
| 手すりの汚れ（皮脂・排気ガス） | 灰〜茶色の薄い汚れ | 手すり全体 | 中性洗剤（CHEM-001） | クロス | 湿拭き→水拭き→乾拭き | アルミはヘアライン方向に拭く |
| 窓の汚れ（水垢・花粉・土埃） | 白い輪状・薄い膜 | ガラス外面 | ガラス用中性洗剤（CHEM-001） | ガラスクロス・スクイジー | 水拭き→洗剤→スクイジー→乾拭き | 研磨剤禁止 |
| サッシの泥・砂 | 茶〜灰色の固まった汚れ | サッシレール | 中性洗剤（CHEM-001） | サッシブラシ・綿棒 | 乾いたブラシで除去→湿拭き→乾拭き | 一度に100ml以上流し込まない（室内浸水リスク） |
| 室外機の外面ホコリ | 灰色のふわふわした汚れ | 天板・前面・側面 | 中性洗剤（CHEM-001） | 柔らかいクロス・柔らかいブラシ | 乾式除塵→湿拭き→乾拭き | **フィン・電装部に水を掛けない** |

# 3. 床素材別施工方法

| 床素材 | 見分け方 | 使用可能薬剤 | 使用禁止薬剤 | 施工方法 |
|---|---|---|---|---|
| コンクリート | 灰色・ザラザラした質感 | 中性洗剤・重曹水 | 強酸・強アルカリ | デッキブラシで前後方向にブラッシング |
| 防水シート（FRP・ウレタン） | 滑らかな塗膜・弾力あり | 中性洗剤 | 重曹（素材劣化の恐れ）・研磨材・金属ブラシ | マイクロファイバークロスで撫でる |
| タイル | 四角形のパネル状 | 中性洗剤・重曹水 | 強酸性（目地を傷める） | デッキブラシ＋目地は専用ブラシ |
| **ウッドデッキ（天然木・樹脂木）** | 木目・板状 | 中性洗剤（50〜100倍希釈液をスポット使用）・専用クリーナー | **重曹（アルカリで木材を傷める）・漂白剤** | 木目方向に沿って柔らかいブラシで施工 |
| 塩ビシート | 薄い弾力性のシート | 中性洗剤 | 研磨材・シンナー・メラミンスポンジ | マイクロファイバークロスで撫でる |

# 6. 使用薬剤一覧（AVL Facilities 推奨基準）

## CHEM-001　中性洗剤

| 項目 | 内容 |
|---|---|
| 液性 | 中性（pH 6〜8） |
| 使う理由 | 全素材に使用可能。床・手すり・設備の日常汚れ（皮脂・ホコリ・軽度の黒ずみ）の基本薬剤 |
| 対象汚れ | 皮脂・ホコリ・軽度の黒ずみ・花粉・水垢（軽度） |
| 対象部位 | 手すり・室外機外装・窓ガラス・サッシ・物干し竿・床（全素材） |
| 推奨希釈倍率 | 50〜100倍（水500mlに対し5〜10ml） |
| 使用量目安 | 床：約100〜200ml/5m² / 手すり：クロスに含ませる量（約10〜20ml） |
| 放置時間 | 1〜3分 |
| 使用できない素材 | 特になし（最も安全な洗剤） |
| 注意事項 | 汚れが落ちない場合はCHEM-002または重曹水へ切り替える |

---

## CHEM-002　重曹水（床の黒ずみ・コケ用）

| 項目 | 内容 |
|---|---|
| 液性 | 弱アルカリ性（pH 8〜9） |
| 使う理由 | 弱アルカリが床の黒ずみ・コケ・藻を分解する。中性洗剤より強い洗浄力で、コンクリート・タイルの頑固な汚れに効果的 |
| 対象汚れ | 黒ずみ・コケ・藻・排気ガス汚れ |
| 対象部位 | コンクリート床・タイル床・排水口周辺 |
| 推奨希釈倍率 | 水500mlに対して重曹約10g（大さじ1）= 約50倍 |
| 使用量目安 | 約100〜200ml/5m² |
| 放置時間 | 3〜10分（コケ・藻は10分） |
| 使用できない素材 | **ウッドデッキ（アルカリで木材が傷む）・防水シート（劣化の恐れあり。テスト施工必須）** |
| 注意事項 | 使用後は必ず水拭き（洗剤残りは白いムラになる）。クエン酸と同時に混合禁止 |

---

## CHEM-003　弱アルカリ洗剤（コケ・頑固汚れ用）

| 項目 | 内容 |
|---|---|
| 液性 | 弱〜中アルカリ性（pH 9〜11） |
| 使う理由 | コケ・藻の細胞壁を分解する成分を含む。重曹水で落ちない頑固なコケに使用する |
| 対象汚れ | コケ・藻・長期固着した黒ずみ |
| 対象部位 | コンクリート床・タイル床（テスト施工必須） |
| 推奨希釈倍率 | 30〜50倍 |
| 使用量目安 | 約100〜200ml/5m² |
| 放置時間 | 5〜10分 |
| 使用できない素材 | **ウッドデッキ・防水シート・アルミ手すり（テスト施工必須）** |
| 注意事項 | 必ずテスト施工を実施。植栽への飛散注意 |

---

## CHEM-004　クエン酸水（排水口・水垢用）

| 項目 | 内容 |
|---|---|
| 液性 | 弱酸性（pH 4〜6） |
| 使う理由 | 酸がミネラル成分（水垢・石鹸カス・排水口のスライム）を溶解する。排水口の詰まり防止に効果的 |
| 対象汚れ | 水垢・排水口のぬめり・石鹸カス・ミネラル汚れ |
| 対象部位 | 排水口内部・排水溝 |
| 推奨希釈倍率 | 水200mlに対してクエン酸約4g（小さじ1）= 約50倍 |
| 使用量目安 | 排水口1箇所あたり約50〜100ml |
| 放置時間 | 5〜10分 |
| 使用できない素材 | **アルミ手すり（腐食の原因）・大理石・金属部品（錆の原因）** |
| 注意事項 | 重曹と同時使用禁止（発泡して効果が相殺される）。重曹使用後はクロスで2〜3回水拭きしてからクエン酸を使用 |

---

## CHEM-005　鳥害除去剤（または中性洗剤＋除菌剤）

| 項目 | 内容 |
|---|---|
| 液性 | 中性〜弱アルカリ性（pH 7〜9） |
| 使う理由 | 鳥のフンに含まれるタンパク質・尿酸を分解・除去する。除菌成分により感染リスクを低減する |
| 対象汚れ | 鳥のフン・鳥害汚染 |
| 対象部位 | 手すり・床・室外機・笠木 |
| 推奨希釈倍率 | 10〜20倍（または中性洗剤50倍＋除菌剤を別途使用） |
| 使用量目安 | 汚染箇所が完全に湿る量（約10〜30ml/箇所） |
| 放置時間 | 3〜5分湿潤後に除去 |
| 使用できない素材 | テスト施工推奨（素材により変色リスクあり） |
| 注意事項 | **乾燥したフンへの直接除去禁止（病原菌飛散）。必ず湿潤させてから除去。除去後は必ず手洗い** |

## 薬剤選択フロー

```
汚れを確認する
　↓
ゴミ・落葉・砂埃（乾いた固形物）
→ 乾式回収のみ（ほうき・ちり取り。薬剤不要）
　↓
鳥のフン（白〜黄色のかたまり）
→ CHEM-005（鳥害除去剤）10〜20倍 / 3〜5分湿潤→ペーパータオルで包んで回収
　※乾燥したまま擦り取り禁止（病原菌飛散）
　↓
手垢・皮脂・花粉・軽度汚れ（皮脂・ホコリ）
→ CHEM-001（中性洗剤）50〜100倍 / 放置1〜3分
　↓
落ちない場合（床の黒ずみ・コケ）
→ CHEM-002（重曹水）50倍 / 放置3〜10分
　※ウッドデッキ・防水シートに使用禁止
　↓
重曹水でも落ちない（頑固なコケ・藻）
→ CHEM-003（弱アルカリ洗剤）30〜50倍 / 放置5〜10分
　※テスト施工必須。ウッドデッキ・アルミ手すりに使用禁止
　↓
排水口のぬめり・水垢
→ CHEM-004（クエン酸水）50倍 / 放置5〜10分
　※アルミ・金属部・大理石に使用禁止。重曹と同時使用禁止
　↓
素材確認（アルミ手すり・防水シート・ウッドデッキ）
→ CHEM-001のみ使用可能。強アルカリ・強酸禁止
　↓
施工開始
```

# 7. 作業前確認

## 現場・安全確認

| 確認項目 | 確認方法 | 対応 |
|---|---|---|
| 管理規約（マンション） | 施設管理者・看板・管理組合への確認 | 水使用量・高圧洗浄の可否を確認 |
| 排水口の位置・状態 | 目視 | 詰まっている場合は工程4を最初に実施 |
| 隣接住戸の洗濯物 | 目視確認 | 湿式清掃前に隣戸の洗濯物がないことを確認 |
| 手すりの固定状態 | 揺らして確認 | 緩みがある場合は報告。手すりに体重をかけない |
| 防水層の状態 | 目視（亀裂・膨れ・剥がれ） | 発見時は写真撮影して報告。高圧洗浄は禁止 |
| 天候・風向き | 体感 | 強風時は飛散リスクあり。作業中止の判断 |
| 電気設備の位置 | 目視（室外機・照明・インターホン） | 電装部への水の飛散を防ぐ位置で施工 |

```text
工程2　ゴミ・落葉回収（約5〜10分）
　↓
工程3　鳥のフン除去（フンがある場合のみ）（約5〜10分）
　↓
工程4　排水口・排水溝清掃（約10〜15分）
　↓
工程5　ベランダ床清掃（約15〜30分）
　↓
工程6　手すり・室外機・設備清掃（約10〜15分）
　↓
工程7　窓ガラス・サッシ清掃（約10〜15分）
　↓
工程8　最終確認・作業後写真撮影（約5分）
　↓
養生撤去・現場復旧
　↓
作業完了
```

## 基本原則

1. **上から下へ**：ヘッドから始め、設備→床→排水口の順で汚れを下へ流す
2. **水は最小限に**：マンション・集合住宅では大量散水禁止。バケツ2〜3Lで施工する
3. **汚れは回収する**：排水口へゴミ・泥を流し込まない。ちり取り・ペーパーで回収する
4. **鳥のフンは必ず湿潤させてから除去**：乾燥したまま除去すると病原菌が飛散する

## 工程1　作業前確認・写真撮影・KY

**目安時間：約3〜5分　必要人数：1名**

### 何を行うか

管理規約・排水状況・近隣状況を確認し、施工前の状態を写真記録する。**施工前に破損を記録することで、作業中の破損と区別できる。**

### 施工順序

1. 管理規約を確認する（マンション：大量散水・高圧洗浄の可否）。
2. 排水口の位置と詰まり状況を確認する。詰まりがひどい場合は工程4を最初に実施する。
3. 隣接住戸の洗濯物を確認する。
4. 手すりを揺らして固定状態を確認する（緩みがあれば報告）。
5. 防水層に亀裂・膨れ・剥がれがないか目視確認する（発見時は写真撮影して報告）。
6. 作業前写真を撮影する（全景・汚染箇所・異常箇所）。
7. KY活動を実施する（転落・感染・感電・漏水リスクを口頭確認）。

**【写真①：ベランダ全景（作業前）】**

**【写真②：排水口・汚染箇所・異常箇所（発見時）】**

### ⚠ 失敗しやすいポイント

- **管理規約確認を省略する** → マンションで大量散水や高圧洗浄を行うとトラブルになる。必ず最初に確認する。
- **写真撮影を省略する** → 施工中に「このヒビは最初からあったのか」でトラブルになる。必ず最初に撮影する。
- **手すりに寄りかかって作業する** → 手すりが固定されていない場合は転落する。必ず固定確認後に使用する。

### 【プロのコツ】

- 排水口の詰まり状況を最初に確認する。詰まっている場合は「床清掃の前に排水口を先に清掃する」段取りに切り替えると効率的。
- 風向きを確認してから施工順序を決める。下風側から施工すると汚れが戻ってくる。

### 次工程へ進む判断

✅ 管理規約確認完了

✅ 安全確認完了（手すり・防水層・排水口）

✅ 隣接住戸の洗濯物確認完了

✅ 作業前写真撮影完了

✅ KY実施完了

→ 工程2へ進む

## 工程2　ゴミ・落葉回収

**目安時間：約5〜10分/箇所　必要人数：1名**

### 何を行うか

ベランダ全体の落葉・砂・土・ホコリ・ゴミを回収し、排水口へ流れ込まないよう除去する。**ホコリが残った状態で濡らすと泥状になり床に固着する。必ず乾式回収を先に行う。**

### 施工順序

1. 大きなゴミ（空き缶・袋など）を手で拾いゴミ袋に入れる。
2. 新聞紙を軽く湿らせて手でちぎり（約5cm角）、床全体に撒く（床1m²あたり新聞紙1〜2枚分程度）。
3. 新聞紙が砂・ホコリを吸着するのを20〜30秒待つ。
4. ほうきで排水口を背にして手前方向に掃き集める（排水口へ向けて掃かない）。
5. ちり取りでゴミをすくいゴミ袋に入れる。
6. 落葉・土砂の残りを確認する。残りがあれば再度掃く。

### 使用工具

TOOL-001（ほうき）/ TOOL-002（ちり取り）/ TOOL-014（ゴミ袋）

### ⚠ 失敗しやすいポイント

- **乾いた状態でそのまま掃く** → ホコリが舞い上がり周囲に飛散・再付着する。必ず濡れ新聞紙を使う。
- **排水口に向かって掃く** → ゴミが排水口に詰まる。排水口を背にして施工する。
- **強風時に新聞紙を使う** → 新聞紙が飛ぶ。強風時は新聞紙を使わず、掃くだけにする。
- **隣のベランダへゴミを飛ばす** → 風向きを確認してから施工する。

### 【プロのコツ】

- 濡れ新聞紙法は「マンションで水を大量に使えない現場でのプロの技」。砂やホコリを舞わせずに効率よく回収できる。
- ほうきの角度：床に対して約30°（寝かせ気味に）当てると砂がすくいやすい。垂直に立てると砂が弾ける。

### 次工程へ進む判断

✅ ゴミ・落葉なし

✅ 砂・土埃なし

✅ 排水口周辺にゴミがない

→ 工程3へ進む（鳥のフンがある場合）/ 工程4へ進む（フンがない場合）

## 工程3　鳥のフン除去

**目安時間：約5〜10分/箇所　必要人数：1名（大量汚染時は2名推奨）**

### 何を行うか

鳥のフンを安全に除去し、病原菌・臭気・金属腐食を防止する。**乾燥したフンには病原菌が含まれる。必ず湿潤させてから除去する。**

### 薬剤を選ぶ理由

**CHEM-005（鳥害除去剤）または中性洗剤を使う理由**：鳥のフンに含まれるタンパク質・尿酸を湿潤・分解させることで、除去しやすくなる。除去後に除菌することで感染リスクを低減する。

### 施工順序

1. **必ずマスク・手袋・保護メガネを着用してから開始する。**
2. スプレーボトルで鳥のフンが完全に湿るまで水または鳥害除去剤を噴霧する（約2〜3プッシュ/箇所）。
3. 3〜5分放置して軟化させる。
4. ペーパータオルで「包み取る」ように回収する（擦らない）。
5. ゴミ袋に密閉して廃棄する。
6. 中性洗剤（CHEM-001、50倍希釈）を噴霧し、クロスで拭き取る。
7. 水拭きで洗剤を拭き取る。
8. 除菌剤を噴霧し、乾燥させる（拭き取り不要）。
9. 金属部（手すり・室外機）はフンが接触していた箇所を確認する（腐食がある場合は報告）。

### 使用工具

TOOL-009（スプレーボトル）/ TOOL-011（ペーパータオル）/ TOOL-005（マイクロファイバークロス）/ TOOL-014（ゴミ袋）

### ⚠ 失敗しやすいポイント

- **乾いたまま擦る** → 病原菌を含む粉塵が空気中に舞う。必ず湿潤させてから除去する。
- **素手で触れる** → 感染リスク。必ず手袋着用。作業後は手洗い必須。
- **高圧洗浄でフンを吹き飛ばす** → 周囲に病原菌が飛散する。マンションでは高圧洗浄は原則禁止。
- **金属部のフンを放置する** → 鳥のフンの酸性成分が金属を腐食させる。発見したら早急に除去する。

### 【プロのコツ】

- 鳥のフンは「時間が経つほど固着して落ちにくくなる」。湿潤後に3〜5分待つと柔らかくなって取れやすい。
- 除去後の金属部（手すり・室外機天板）はクロスで乾拭きしてから除菌する。水分が残ると錆びやすくなる。

### 次工程へ進む判断

✅ 鳥のフンが完全に除去されている

✅ 臭気がない

✅ 金属腐食がないことを確認済み（腐食ある場合は報告済み）

✅ 使用した手袋・ペーパータオルを廃棄済み

→ 工程4へ進む

## 工程4　排水口・排水溝清掃

**目安時間：約10〜15分/箇所　必要人数：1名**

### 何を行うか

排水口・排水溝の詰まりを解消し、排水機能を回復する。**排水が詰まった状態でベランダを洗浄すると水があふれ、下階へ漏水する。床清掃の前に必ず実施する。**

### 薬剤を選ぶ理由

| 薬剤 | 選ぶ理由 |
|---|---|
| 重曹水（CHEM-002） | 排水口の有機汚れ（泥・葉の腐敗物）を分解する |
| クエン酸水（CHEM-004） | ミネラル汚れ（水垢・石鹸カス）を溶解する。重曹と組み合わせると発泡してスライムを浮かせる |

### 施工順序

1. 排水口のカバー（ヘアキャッチャー）を外す。
2. 中のゴミ・落葉・土砂をペーパーまたは手で取り出し、ゴミ袋に入れる（水で流し込まない）。
3. 重曹水（CHEM-002）を排水口内部に約50〜100mlかける。
4. 3〜5分放置する。
5. 排水口ブラシを差し込み、上下に5〜10回押し引きする（無理に押し込まない）。
6. クエン酸水（CHEM-004）を約50mlかける（発泡して有機物を浮かせる）。
7. 3〜5分放置後、バケツの水（約1〜2L）で流す。
8. 排水口カバーを戻す。
9. バケツに水（約500ml）を注いで排水スピードを確認する（ゆっくり流れる場合は詰まりが残っている）。

### 使用工具

TOOL-004（排水口ブラシ）/ TOOL-010（バケツ）/ TOOL-009（スプレーボトル）/ TOOL-014（ゴミ袋）

### ⚠ 失敗しやすいポイント

- **ゴミを排水口に流し込む** → 下水管が詰まる。必ずゴミ袋に回収する。
- **床を洗浄してから排水口を清掃する** → 床の汚水が流れず溢れる。排水口清掃を必ず先にする。
- **重曹とクエン酸を同時に混ぜる** → 効果が相殺される。重曹→放置→クエン酸の順番を守る。
- **排水口ブラシを無理に押し込む** → 排水管を傷つける。入らなければ無理に押し込まない。

### 【プロのコツ】

- 排水確認は「バケツ500mlを排水口から離れた場所（約1m）で流す」と本来の排水スピードがわかる。排水口の真上で流すと詰まりを隠してしまう。
- 重曹→放置→クエン酸→発泡 の組み合わせは「ベランダの生物汚れ・スライムに最も効果的なプロの方法」。

### 次工程へ進む判断

✅ 排水口内のゴミなし

✅ 水を流してスムーズに排水される（500ml流して5秒以内に排水されれば正常）

✅ 排水口カバーが正しく設置されている

→ 工程5へ進む

## 工程5　ベランダ床清掃

**目安時間：約15〜30分/5m²　必要人数：1名（大型は2名）**

### 何を行うか

ベランダ床面の土砂・黒ずみ・コケ・泥汚れを除去し、安全で美観のある状態に仕上げる。

### 薬剤を選ぶ理由

| 汚れ・素材 | 薬剤 | 選ぶ理由 |
|---|---|---|
| 軽度の汚れ・全素材 | CHEM-001（中性洗剤）50〜100倍 | 全素材に安全。まず最初に試す |
| コンクリート・タイルの黒ずみ | CHEM-002（重曹水）50倍 | 弱アルカリが黒ずみ・有機汚れを分解する |
| コケ・藻（緑色・黒の生物汚染） | CHEM-003（弱アルカリ洗剤）30〜50倍 | コケの細胞壁を分解する成分を含む |

### 床素材別の施工方法

**コンクリート・タイル**

1. 重曹水（CHEM-002）をバケツで希釈する（水500mlに重曹10g）。
2. スプレーボトルで床全体に均一に噴霧する（約100〜200ml/5m²）。
3. 3〜10分放置する（コケ・藻は10分）。
4. デッキブラシで前後方向に約300〜500gの力でブラッシングする（ストローク：約30〜50cm）。
5. 黒ずみが残る箇所は重点的に追加施工する。
6. 固く絞ったクロスで汚れを回収する（大量の水で流さない）。
7. 乾拭きで水分を除去する。

**防水シート（FRP・ウレタン）**

1. 中性洗剤（CHEM-001）を50〜100倍希釈してスプレーボトルに入れる。
2. 全体に均一に噴霧する（約100〜150ml/5m²）。
3. 1〜3分放置する。
4. マイクロファイバークロスで撫でるように拭き取る（力：約200〜300g）。
5. 固く絞ったクロスで水拭きする。
6. 乾拭きで仕上げる。

**ウッドデッキ（天然木・樹脂木）**

1. 中性洗剤（CHEM-001）を100倍希釈してスプレーボトルに入れる。
2. 木目方向に沿って全面に噴霧する。
3. 柔らかいブラシ（TOOL-012）で木目方向に沿って約200〜300gの力でブラッシングする。
4. 固く絞ったクロスで拭き取る。
5. 水気が残らないよう乾拭きで仕上げる。

### ⚠ 失敗しやすいポイント

- **マンションで大量の水を流す** → 下階への漏水・近隣トラブルの原因。バケツ2〜3L以内で施工する。
- **ウッドデッキに重曹を使う** → アルカリで木材が傷む。ウッドデッキには中性洗剤のみ使用。
- **汚水を排水口に向けて流す** → 排水口が詰まる原因。クロスで回収する。
- **隣のベランダへ汚水が流れる** → 近隣トラブルの原因。隣接方向へ水を流さない。

### 【プロのコツ】

- 重曹は「乾いた状態でまく→水を約20〜30mlかけて湿らせる」と濃度が上がって黒ずみに効果的。水を先に流すと薄まる。
- デッキブラシは「床に対して約45°の角度に持つ」と力が伝わりやすく、腰への負担も少ない。
- コケは「薬剤をかけて放置するだけで半分以上除去できる」。力で擦るより時間を長くとるほうが効果的。

### 次工程へ進む判断

✅ 黒ずみ・土砂・コケなし

✅ 水たまりなし

✅ 滑りなし

✅ 隣戸への汚水流出なし

→ 工程6へ進む

## 工程6　手すり・室外機・設備清掃

**目安時間：約10〜15分/箇所　必要人数：1名**

### 何を行うか

手すり・物干し竿・室外機・壁面などの設備を清掃し、ホコリ・鳥のフン・排気ガス汚れを除去する。

### 薬剤を選ぶ理由

| 対象部位 | 薬剤 | 選ぶ理由 |
|---|---|---|
| 手すり・笠木（アルミ・ステンレス） | CHEM-001（中性洗剤）50〜100倍 | アルミ・ステンレスへのダメージなし。皮脂・排気ガス汚れに効果的 |
| 物干し竿 | CHEM-001（中性洗剤）50〜100倍 | 洗濯物が直接触れる部位のため安全な中性洗剤のみ使用 |
| 室外機外装 | CHEM-001（中性洗剤）50〜100倍 | 電装部への影響がない中性洗剤を使用 |
| 壁面 | CHEM-001（中性洗剤）50〜100倍 | テスト施工後に使用 |

### 施工順序

**手すり・笠木**

1. クロスに中性洗剤液（50〜100倍希釈）を含ませる。
2. 手すりの外面・内面・上面を上から下へ拭く（力：約200〜300g）。
3. アルミ製はヘアライン（髪の毛のような目）の方向に沿って拭く。
4. 笠木の上面・側面を同様に拭く。
5. 水拭きして洗剤を除去する。
6. 乾拭きで仕上げる。

**物干し竿・物干し金具**

7. 同様に湿拭き→水拭き→乾拭きの順で施工する。

**室外機（外装のみ）**

8. 室外機の電源状態を確認する（運転中でも外装清掃は可能）。
9. 天板・前面・側面の表面ホコリを柔らかいブラシで払う（乾式除塵から始める）。
10. クロスに中性洗剤液を含ませて外装を拭く（力：約200〜300g）。
11. **吸気口（格子状の部分）・排気口・フィン（金属の羽根部分）には水を一切かけない。**
12. 水拭き→乾拭きで仕上げる。
13. 室外機周辺の床を清掃する。

### ⚠ 失敗しやすいポイント

- **室外機のフィンをブラシで擦る** → フィンが変形して冷暖房効率が低下する。フィンには絶対に触れない。
- **室外機の電装部・吸気口に水をかける** → 感電・故障の原因。外装のみ拭く。
- **手すりに体重をかけながら清掃する** → 固定状態を確認済みでも、体重をかけながら身を乗り出さない。
- **ステンレス・アルミを横方向に拭く** → ヘアラインに逆らった傷が目立つ。必ずヘアライン方向に拭く。

### 【プロのコツ】

- 手すりは「内面（室内側）が最も汚れやすい」。外面だけ拭いて内面を忘れがち。内面は特に重点的に確認する。
- 室外機裏側（壁と室外機の隙間）は手が届きにくいが汚れが溜まりやすい。細い柄付きブラシや折り畳んだクロスを使って届く範囲を拭く。

### 次工程へ進む判断

✅ 手すり：指紋・鳥害・ホコリなし・乾燥している

✅ 物干し竿：汚れなし

✅ 室外機：外装清掃完了・フィン変形なし

✅ 壁面に異常なし

→ 工程7へ進む

## 工程7　窓ガラス・サッシ清掃

**目安時間：約10〜15分/箇所　必要人数：1名**

### 何を行うか

ベランダ側窓ガラスの外面・サッシ・網戸外側を清掃し、透明感と美観を回復する。

### 薬剤を選ぶ理由

**CHEM-001（中性洗剤）を使う理由**：ガラス面の花粉・排気ガス・土埃・水垢を除去する。中性洗剤はガラス・アルミサッシ・樹脂サッシのいずれにも安全で、すすぎ残しがあっても白化リスクが低い。

### 施工順序

**窓ガラス（外面）**

1. クロスを固く絞り、ガラス全体を水拭きして表面のホコリを除去する。
2. 中性洗剤液（100倍希釈）をガラスクロスに含ませ、ガラス全体に均一に塗布する。
3. スクイジー（TOOL-007）を使い、上から下へ一定速度（約20〜30cm/秒）で水切りする。各ストロークは10cm重ねる。
4. スクイジーで取れない四隅・縁をガラスクロスで拭き取る。
5. 乾いたガラスクロスで仕上げ拭きをする。

**サッシレール**

6. 乾いたサッシブラシでレール内の砂・土を掃き出す。
7. 綿棒（TOOL-013）でレールの隅（特に四隅）の残汚れを除去する。
8. 固く絞ったクロスでレール内を拭く。
9. 乾拭きする。

**網戸（外側）**

10. ハンディモップまたは乾いたクロスで表面のホコリを払う。
11. 固く絞ったクロスで拭く（強く押し付けると網目が歪む）。

### ⚠ 失敗しやすいポイント

- **乾いたガラスに洗剤を直接噴霧して拭く** → 拭きムラ・白いスジが残る。必ず水拭きで表面のホコリを先に除去する。
- **スクイジーを止めたまま横方向に動かす** → 力がかかってゴムが傷む。必ず「上から下へ」一方向に動かす。
- **サッシレールに一度に100ml以上の水を流す** → 室内側に水が浸入することがある。固く絞ったクロスでの施工のみ使用。
- **網戸を強く押さえる** → 網目が歪んで変形する。軽く当てながら拭く。

### 【プロのコツ】

- 曇り天気のほうがガラス清掃がしやすい。晴天・直射日光下では洗剤が乾燥してすぐにムラになる。
- スクイジーは「刃の全面を均一にガラスに当てる」ことが重要。端が浮いているとスジが残る。

### 次工程へ進む判断

✅ ガラス：拭きムラなし・水滴なし・透明

✅ サッシ：砂・土汚れなし

✅ 網戸：ホコリなし・変形なし

→ 工程8へ進む

# 11. よくある失敗と対策

| 失敗 | 原因 | 対処法 | 防止策 |
|---|---|---|---|
| 排水が流れない | 排水口清掃が不十分 | 排水口ブラシで再清掃 | 床清掃の前に必ず排水口清掃を実施 |
| 床の黒ずみが残る | ブラッシングが弱い・放置時間が短い | 重曹水を再散布して放置時間を延ばす（最大10分） | 薬剤の放置時間を守る。力より放置時間を長くとる |
| ホコリが舞い上がる | 乾いたまま掃いた | 掃き取り後に再度クロスで回収 | 濡れ新聞紙を使って吸着させてから掃く |
| 鳥のフンが広がる | 乾いたまま擦った | 水で再度湿潤させてから回収 | 必ず湿潤3〜5分→包み取るように回収 |
| ガラスに白いムラ | 洗剤が乾燥した・水拭きが不十分 | 水拭き→乾拭きを再度実施 | 曇り天気を選ぶ。乾燥前にスクイジー・乾拭きを行う |
| 隣へ汚水が流れた | 風向きを考慮せず大量散水した | 隣戸へ謝罪・清掃対応 | 少量散水を徹底。施工前に風向きを確認 |
| 室外機フィンが変形した | 硬いブラシで擦った | 報告。修理費が発生する可能性あり | 室外機フィンには絶対に触れない |
| 防水シートに傷がついた | 金属ブラシ・強研磨 | 報告。防水機能に問題がある場合は修理が必要 | 防水シートには柔らかいクロスのみ使用 |
| ウッドデッキが変色・反った | 重曹を使った・大量の水を流した | 乾燥させる。改善しない場合は報告 | ウッドデッキには中性洗剤のみ。水は最小限 |

# 12. 安全管理

## 転落・転倒防止（最重要）

- 手すりに体重をかけない・乗らない
- 身を乗り出してガラスや窓の外を拭かない（必要な場合は足場や脚立を使用）
- 床が濡れている間は滑りやすい。滑り止め靴を着用する
- 養生シートはテープで固定する（めくれると転倒の原因）

## 感染防止（鳥のフン）

- 鳥のフン除去時はマスク・手袋・保護メガネを必ず着用する
- 作業後は必ず手洗いをする（石鹸で20秒以上）
- 鳥のフンに使ったクロス・ペーパーは他の清掃に転用しない
- 使い捨て手袋は廃棄袋に入れてから廃棄する

## 感電防止

- 室外機の電装部・吸気口・フィンに水をかけない
- 濡れた手でコンセント・電気設備に触れない
- 電気設備の近くで大量散水しない

## 漏水防止

- マンション・集合住宅での大量散水禁止（管理規約を確認）
- 床清掃前に排水口が通水していることを確認する
- 隣戸へ汚水が流れないよう施工方向を意識する

## 薬剤管理

- 薬剤ラベルの注意事項を確認してから使用する
- 重曹とクエン酸の混合禁止（効果が相殺される）
- 酸性・アルカリ性の混合禁止（有害ガス発生のリスク）
- 薬剤が目に入った場合：その場で15分以上流水で洗眼。医療機関を受診

## 緊急時対応

| 事故 | 対応 |
|---|---|
| 転落・転倒 | 動かさない。119番通報。責任者へ報告 |
| 感染の疑い（鳥のフン接触） | 石鹸で15分以上手洗い。体調不良が出たら医療機関を受診 |
| 薬剤が目に入った | 15分以上流水で洗眼。医療機関を受診 |
| 漏水発見（防水層破損・排水逆流） | 施工を中止。写真撮影。管理者・担当者へ即報告 |
| 手すりが破損した | 作業停止。立入禁止にする。責任者へ報告 |

## KYリスクアセスメント（作業開始前に確認）

| 危険要因 | 想定される事故 | リスク | 予防対策 |
|---|---|---|---|
| 手すり・ベランダ端部 | 転落・墜落 | 高 | 手すりに体重をかけない。身を乗り出さない |
| 濡れた床面 | 転倒 | 中 | 滑り止め靴着用 |
| 鳥のフン | 感染症 | 高 | マスク・手袋・保護メガネ着用必須 |
| 大量散水 | 下階漏水・近隣トラブル | 高 | バケツ2〜3L以内。管理規約遵守 |
| 室外機電装部 | 感電 | 高 | 電装部への水・薬剤は使用しない |

# 15. 新人教育ポイント

## 最初に覚えること（優先順）

| 優先度 | 覚えること | なぜ重要か |
|---|---|---|
| 1 | マンションでは大量散水禁止（バケツ2〜3L以内） | 下階への漏水・近隣トラブルの直接原因 |
| 2 | 鳥のフンは必ず湿潤させてから除去する | 乾燥フンの粉塵には病原菌が含まれる |
| 3 | 床清掃の前に排水口を先に清掃する | 排水が詰まった状態で洗浄すると水があふれる |
| 4 | 室外機のフィン・電装部に水をかけない | 感電・フィン変形・冷暖房効率低下 |
| 5 | ウッドデッキに重曹を使わない | アルカリで木材が傷む |
| 6 | 手すりに体重をかけない・乗らない | 転落事故の最多原因 |

## 新人が間違えやすいポイントと正しい対応

| 間違い | 正しい対応 | なぜそうするか |
|---|---|---|
| 排水口へゴミを流す | ゴミ袋に回収する | 下水管が詰まる |
| 水を大量に使う | バケツ2〜3Lで施工する | マンションでの漏水・近隣トラブル |
| 鳥のフンを乾いたまま擦る | 必ず湿潤3〜5分後に除去 | 病原菌が空気中に飛散する |
| 室外機へ水をかける | 外装のみ乾拭き→湿拭き→乾拭き | 感電・故障の原因 |
| ウッドデッキに重曹を使う | 中性洗剤のみ使用 | 木材が傷む・変色する |
| 防水シートをデッキブラシで強く擦る | クロスで撫でるように施工 | 防水層を傷つけると漏水の原因 |
| ガラスに直接洗剤を噴霧して拭く | 先に水拭きでホコリを除去 | 洗剤がムラになりスジが残る |

## 独立施工を許可する基準（自己確認）

以下を全て自己確認できること：

- 管理規約に従った水使用量を管理できる
- 床素材の種類を見分けて適切な薬剤を選択できる
- 排水口清掃→床清掃の正しい順番で施工できる
- 鳥のフンを安全に（PPE着用・湿潤後）除去できる
- 室外機の電装部・フィンへの水の使用禁止を徹底できる

## 早めの施工を推奨するケース

- 排水口が詰まっている（次の雨で漏水リスク）
- コケ・藻が発生している（放置すると床が滑りやすくなる）
- 鳥の巣の形跡がある（鳥のフン大量発生の前兆）
- 防水層に亀裂・膨れを発見した（漏水の危険）
