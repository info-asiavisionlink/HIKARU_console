# 家庭用エアコンクリーニング SOP

**対象：家庭用壁掛けエアコン**

---

# 1. 適用範囲

## 対象施設

- 一般住宅 / マンション / アパート / 分譲住宅 / 賃貸住宅
- 社宅 / 寮 / ホテル客室 / 民泊施設 / 福祉施設 / 小規模事務所

## 対象作業

家庭用壁掛けエアコンの分解洗浄

- スタンダードエアコン
- お掃除機能付きエアコン

※業務用天井カセットエアコンは対象外。

## 対象設備

- 前面パネル / エアフィルター / ダストボックス（お掃除機能付き）/ ルーバー
- 熱交換器（アルミフィン）/ シロッコファン / 吹出口
- ドレンパン / ドレンホース / 本体カバー / 外装パネル / リモコン

## 施工可能条件

| 条件 | 基準 |
|------|------|
| 室内気温 | 5℃〜40℃（凍結・熱による変形リスク回避） |
| 湿度 | 85%以下 |
| 雨天・強風・直射日光 | 室内作業のため天候不問（屋外の排水口確認は必要） |
| 凍結 | 室内気温5℃以上であれば施工可。凍結している場合は室温を上げてから施工 |
| 感電リスク対策 | ブレーカーOFF または 電源プラグを抜けること。電装部の二重養生が可能なこと |
| 高所作業 | 脚立（3段以上）が水平に設置できる床面・スペースがあること |
| 電源（作業用） | 高圧洗浄機の電源コンセントが使用可能であること |
| 水道 | 清水が使用可能であること |
| 排水先 | バケツ・洗面台・屋外排水のいずれかを確保できること |
| 養生 | 電装部の二重養生・床養生・洗浄カバー設置が実施可能なこと |

## 施工不可条件

| 条件 | 理由 |
|------|------|
| 電装部の養生が物理的に不可能な機種 | 感電・基板損傷リスク |
| 水道が使用不可の現場 | 洗浄不可 |
| 排水先が確保できない現場 | 漏水リスク |
| 施工前からエラーコードが表示されている | 既存故障の可能性。お客様へ報告し指示を仰ぐ |
| 本体に目視でわかる亀裂・損傷がある | 分解時の破損リスク |
| 高圧洗浄機が使用できない環境 | 洗浄品質を確保できない |

## 作業中止基準

以下を発見した場合は即時作業を停止し、お客様へ報告する。

| 発見内容 | 対応 |
|------|------|
| 感電症状（しびれ・スパーク・異臭） | 電源遮断・119番通報 |
| 配線の被覆損傷・焦げ跡 | 作業中止・電気工事業者へ連絡 |
| 冷媒ガス漏れ（甘い臭い・白い霧） | 換気・電気使用禁止・冷媒回収業者へ連絡 |
| 水漏れが養生範囲を超えた | 作業中止・養生追加後に再開 |
| お客様から中止指示 | 即時中止 |

# 2. 用語の定義

| 用語 | 内容 |
|------|------|
| 熱交換器 | アルミフィン部。冷暖房効率に直結する最重要部位。 |
| シロッコファン | 送風ファン。カビ・ホコリが最も付着しやすく洗浄が必要な部位。 |
| ドレンパン | 熱交換器下の結露水受け皿。スライム・カビが発生しやすい。 |
| ドレンホース | ドレンパンから屋外へ排水するホース。詰まると水漏れの原因になる。 |
| 養生 | 周囲の家具・壁・電装部を保護し、水漏れ・薬剤飛散を防ぐ作業。 |
| 高圧洗浄 | 高圧洗浄機を使用して汚れを洗い流す作業。 |
| 電装部 | 基板・配線・モーター・コネクターなど、水・洗剤が触れると故障する部品。 |
| お掃除ユニット | 自動フィルター清掃機能を持つ付加ユニット。分解・復旧が複雑になる。 |
| KY活動 | 危険予知活動。作業前に危険を洗い出し事故を防ぐ。 |

# 4. 施工前確認

## 機種確認

1. 型式ラベルを確認・撮影する（前面パネル内側または本体側面にある）。
2. スタンダード機 または お掃除機能付き機種を判別する。
3. お掃除機能付きは分解・復旧に約30〜50分追加される。

**【写真①：型式ラベル】**

## 動作確認

1. リモコンで冷房運転を起動する。
2. 以下を確認・記録する。

| 確認項目 | 正常 | 異常 |
|---------|------|------|
| 風量 | 設定通り出る | 弱い・出ない |
| ルーバー動作 | 上下に動く | 動かない・途中で止まる |
| 異音 | なし | キーキー・ガタガタ・カタカタ |
| 異臭 | なし | カビ臭・焦げ臭 |
| 水漏れ | なし | 前面・横から水が垂れる |
| エラー表示 | なし | エラーコード点灯 |

3. 異常がある場合は施工前にお客様へ報告し、指示を受けてから施工する。
4. 確認後、冷房運転を停止し、電源プラグを抜く または ブレーカーをOFFにする。

**【写真②：エアコン全景（作業前）】**

**【写真③：吹出口内部（カビ状況）】**

**【写真④：フィルター（汚れ状況）】**

**【写真⑤：キズ・破損箇所（ある場合のみ）】**

## お客様への事前説明

施工開始前に必ず以下を伝える。

| 説明項目 | 説明内容の例 |
|---------|------------|
| 施工内容 | 「本日はエアコンを分解し、内部を高圧洗浄でお掃除します」 |
| 所要時間 | 「スタンダード機で約1〜1.5時間、お掃除機能付きで約2〜3時間かかります」 |
| 水の使用 | 「水道水を使用します。排水は〇〇へ流します」 |
| 騒音 | 「高圧洗浄機の音がします」 |
| 施工後の汚水 | 「施工直後、ドレンから一時的に黒い汚水が流れる場合がありますが正常です」 |
| 立会い | 「最初と最後にご確認をお願いします。途中は不要です」 |
| 異常発見時 | 「施工中に故障や異常を発見した場合はすぐにご報告します」 |

# 9. 詳細作業手順

---

## 工程1　作業前確認・動作確認

**目安時間：約10〜15分　必要人数：1名**

### 使用道具

TOOL-025（LEDライト）/ リモコン / チェックシート

### 手順

1. エアコンの型式ラベルを確認・撮影する。ラベルは前面パネルを開けた内側または本体側面にある。
2. お掃除機能の有無を確認する。ダストボックス・集じんユニットがある＝お掃除機能付き。
3. リモコンで冷房運転を起動し、以下を確認する。
   - 風量・風向が正常か
   - ルーバーが正常に動くか
   - 異音・異臭がないか
   - 水漏れ・エラー表示がないか
4. 異常がある場合は施工前にお客様へ報告し、確認を取ってから施工する。エラーコードは必ず記録する。
5. 冷房運転を停止し、電源プラグを抜く または ブレーカーをOFFにする。
6. 作業前写真を撮影する（写真①〜⑤）。
7. お客様への事前説明を行う（第4章参照）。

**【写真①：型式ラベル】**

**【写真②：エアコン全景（作業前・正面）】**

**【写真③：吹出口内部（カビ状況）】**

**【写真④：フィルター（汚れ状況）】**

**【写真⑤：キズ・破損箇所（ある場合のみ）】**

### 注意事項

- 施工前から異常がある場合は無断で分解しない。必ずお客様へ報告する。
- 型式ラベルは後日のトラブル対応に必要。必ず撮影する。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 動作確認 | 冷風正常・ルーバー動作・異音なし | エラーコード点灯・異音あり → 施工前に報告 |
| 写真 | ピントが合い汚れが確認できる距離 | ブレている・暗くて見えない |

### プロのコツ

- 施工前の水漏れ・異音は「施工前から存在していた」証拠として写真に残す。後日のトラブル防止になる。
- 試運転中にLEDライトで吹出口を照らすとカビの状態が確認しやすい。お客様への説明材料になる。

## 工程2　周辺養生・電装部養生

**目安時間：約10〜15分　必要人数：1名（大型家具移動時は2名）**

### 使用道具

TOOL-002（エアコン洗浄カバー）/ TOOL-020（養生シート）/ TOOL-021（マスカー）/ TOOL-022（養生テープ）/ TOOL-023（絶縁テープ）/ ビニール袋

### 手順

**床・壁の養生**

1. エアコン下の家具・家電を移動する。移動できないものは養生シートで覆う。
2. 床全面に養生シートを敷き、重なり部分はテープで固定する。
3. 壁面・カーテンをマスカーで保護する。粘着面を壁に密着させ、シートを広げる。

**電装部の養生（最重要）**

4. LEDライトでエアコン内部の電装部（基板・コネクター・配線・モーター）の位置を確認する。
5. 電装部を絶縁テープで一重に包む。
6. その上からビニール袋で覆い、養生テープで固定する（二重養生）。
7. テープの端が浮いていないか全周確認する。

**洗浄カバーの取り付け**

8. エアコン洗浄カバーをエアコン本体の上から被せる。
9. 洗浄カバーの排水口がドレンパンの排水位置に合うよう調整する。
10. 洗浄カバーの上端・両端を養生テープで壁に固定し、「コの字型」に貼って隙間を作らない。
11. 洗浄カバーの排水ホースを排水先（バケツ・洗面台・屋外）へ誘導する。
12. 排水ホースが折れていないことを確認する。バケツは倒れないよう壁や脚立に固定する。

**【写真⑥：養生完了状態（電装部・洗浄カバー含む）】**

### 注意事項

- 電装部の養生は必ず二重にする。一重では洗浄水が侵入する可能性がある。
- 洗浄カバーと壁の隙間は必ず塞ぐ。隙間があると水が壁・床へ直接流れる。
- ドレンホースが折れると排水されず逆流する。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 電装部養生 | テープが全面密着・二重養生 | テープの端が浮いている・一重のみ |
| 洗浄カバー | 壁との隙間ゼロ・排水ホース折れなし | 隙間あり・ホース折れ |
| 排水先 | バケツ等に誘導済み・転倒防止固定 | 床に垂れ流し |

### プロのコツ

- 養生後にコップ1杯の水を洗浄カバー内に流し、水漏れがないか確認してから本洗浄に入ると安心。
- 電装部の位置はメーカーにより異なる。パネルを外す前にLEDライトで確認する習慣をつける。

## 工程3　本体分解

**目安時間：スタンダード 約20〜30分 / お掃除機能付き 約30〜50分　必要人数：1名**

### 使用道具

TOOL-004（プラスドライバー）/ TOOL-005（マイナスドライバー）/ TOOL-006（内張りはがし）/ TOOL-007（ピックツール）/ TOOL-008（コネクター抜き）/ TOOL-024（部品ケース）/ TOOL-025（LEDライト）

### 手順（スタンダード機共通）

1. 電源プラグが抜かれている または ブレーカーがOFFであることを再確認する。
2. 前面パネルを開け、左右の爪を外しながらパネルを取り外す。爪は「下から上へ起こす方向」に外す。
3. フィルターを左右それぞれ外方向へスライドさせて取り外す。
4. ルーバー（風向き板）の両端の軸を押しながら手前へ引き出す。軸を折らないよう根元を支えながら外す。
5. 外装カバーのビスを確認する。ビスは本体上部・左右・下部にある（機種により異なる）。
6. ビスを外し、部品ケースへ取外し位置ごとに分けて保管する。
7. 外張りはがしを使い、爪の位置を移動しながら均等に外装カバーを外す。一箇所に力を集中させない。
8. **分解後の配線・コネクターの位置を写真撮影する（必須）。**

**【写真⑦：分解後の内部状態・配線位置】**

### お掃除機能付き機種の追加手順

9. お掃除ユニット（集じんユニット）のカバーを外す。固定ビスの位置はLEDライトで確認する。
10. お掃除ユニットのコネクターをコネクター抜き（TOOL-008）で外す。ロックを押しながら水平方向へ引き抜く。上下に力をかけない。
11. お掃除ユニット本体を取り外す。配線に引っかかっていないか確認しながら外す。
12. ダストボックスを取り外し、ゴミを廃棄する。

**【写真⑧：お掃除ユニット取外し後の状態・コネクター位置】**

### 注意事項

- ツメ（爪）は横方向に力をかけると折れる。必ず「起こす方向（垂直方向）」に外す。
- コネクターは絶対に引っ張らない。ロックを解除してから引き抜く。
- ビスの紛失は組立不可の原因。部品ケースで必ず管理する。
- 分解前に配線の写真を必ず撮影する。組立時に参照する。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 爪外し | 爪が全て無傷で外れた | 爪が1箇所でも折れた → 即座に報告 |
| コネクター | ロック解除後に引き抜き・損傷なし | 引っ張って外した → 断線リスク |
| ビス管理 | 部品ケースで位置別に管理 | 床にバラバラに置いている |
| 配線記録 | 写真撮影済み | 撮影なし → 組立時に配線ミスのリスク |

### プロのコツ

- 外装カバーは「全体を少しずつ浮かせる」イメージで外す。一箇所だけ強く引くと爪が必ず折れる。
- ビスの本数は機種ごとに異なる。「もうビスがない」と思っても、カバー内側や端に隠れていることがある。LEDライトで必ず確認する。
- お掃除機能付き機種は焦らない。配線を傷つけると部品代が発生する。

## 工程4　部品洗浄

**目安時間：約20〜30分　必要人数：1名**

### 使用道具

TOOL-013（スポンジ）/ TOOL-011（Jブラシ）/ TOOL-015（ウエス）/ TOOL-014（マイクロファイバークロス）/ バケツ

### 使用薬剤

- フィルター・樹脂部品：CHEM-003（中性洗剤）50〜100倍希釈
- 外装パネル・前面パネル・ルーバー：CHEM-002（弱アルカリ性洗剤）50〜100倍希釈

### 手順

**フィルター**

1. バケツに水を張り、CHEM-003を50〜100倍希釈する。
2. フィルターを水に浸し、スポンジで撫でるように洗浄する（力は約200〜300g程度。絶対に擦らない）。
3. 細部はJブラシで3〜5往復する。
4. 水洗いして洗剤を完全に流す（すすぎ水が透明になるまで）。
5. ウエスで水気を拭き取り、自然乾燥させる。

**外装パネル・前面パネル・ルーバー**

6. CHEM-002を50〜100倍希釈した液をスプレーボトルに入れ、全面に吹きかける。放置時間：1〜2分。
7. スポンジで全体を拭き取る（力は約300〜400g程度）。
8. 水で濡らしたウエスで洗剤を拭き取る。
9. 乾いたマイクロファイバークロスで仕上げ拭きをする。一方向に拭き、拭きムラをなくす。

**ダストボックス（お掃除機能付き）**

10. ダストボックス内のゴミを廃棄する。
11. 水洗い後、自然乾燥または常温ドライヤーで乾燥させる。

**【写真⑨：部品洗浄状況】**

### 注意事項

- フィルターを強く擦ると目詰まりまたは破損する。約200〜300gの力（スポンジを指先でわずかに押す程度）で撫でること。
- ルーバーの軸（細い棒状の部分）は折れやすい。根元を支えながら洗浄する。
- 高温乾燥禁止（変形の原因）。自然乾燥または常温ドライヤーのみ使用。
- 塗装部にCHEM-001（強アルカリ）を使用しない。変色・剥がれの原因になる。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| フィルター | ホコリなし・破損なし・洗剤残りなし・光に透かして均一に光が通る | 破れている・洗剤が残っている |
| 外装パネル | 拭きムラなし・乾燥している | 水滴が残っている・洗剤ムラあり |
| ルーバー | 全ての軸・爪が無傷で可動する | 軸が折れている → 報告 |

### プロのコツ

- フィルターは洗浄後に光に透かして確認する。光が均一に通ればOK。光が通らない部分は再洗浄。
- 部品洗浄は熱交換器洗浄（工程6）の薬剤放置時間中に並行して行うと時間短縮できる。

## 工程5　ドレンパン・ドレンホース洗浄

**目安時間：約10〜20分　必要人数：1名**

### 使用道具

TOOL-009（噴霧器）/ TOOL-011（Jブラシ）/ TOOL-013（スポンジ）/ TOOL-018（ドレンホースクリーナー）/ TOOL-025（LEDライト）

### 使用薬剤

- ドレンパン：CHEM-001（エアコン専用アルカリ洗剤）30〜50倍希釈
- ※スライムが少ない場合はCHEM-003（中性洗剤）50〜100倍希釈でも可

### 手順

**ドレンパン洗浄**

1. LEDライトでドレンパンの状態を確認する。スライム（黒・ピンク・白色の粘液）・カビ・ゴミの有無を確認する。

**【写真⑩：ドレンパン洗浄前の状態（スライム・カビ）】**

2. CHEM-001（30〜50倍希釈）を噴霧器でドレンパン全体に噴霧する。放置時間：3〜5分（スライムが多い場合は5〜10分）。
3. スポンジで底面・壁面を撫でるように洗浄する（約300〜400g程度の力）。
4. Jブラシで排水口周辺・角の細部を3〜5往復する。
5. 高圧すすぎ（工程8）で同時に洗浄水を洗い流す。

**ドレンホース洗浄**

6. ドレンホースの屋外出口を確認する。ゴミ・虫の巣・詰まりがないか確認する。
7. ドレンホースクリーナー（TOOL-018）を屋内のドレンホース取り付け口から差し込む。ゆっくり押し引きを5〜10回繰り返す。無理に押し込まない。
8. バケツに水を入れてドレンパンへゆっくり流し、屋外へスムーズに排水されるか確認する。

**【写真⑪：ドレンパン洗浄後の状態】**

### 注意事項

- ドレンホースクリーナーを無理に押し込まない。ホースに穴が開く可能性がある。
- ドレンパンが分解できない機種は、高圧すすぎ（工程8）で同時に洗浄する。
- スライムは放置時間を長くとるほど除去しやすい。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| ドレンパン | スライムなし・カビなし・洗剤残りなし | スライムが残っている → 再洗浄 |
| ドレンホース | 水をかけるとスムーズに流れる | 水を流すと逆流する・流れない → 詰まり除去を継続 |

### プロのコツ

- ドレンパンのスライムは「先にアルカリ洗剤で5〜10分浸透させる」と高圧洗浄での除去が格段に楽になる。
- ドレンホースの詰まりは屋外側から見ると原因がわかりやすい。屋外に出てホース出口を確認する。

## 工程6　熱交換器（アルミフィン）洗浄

**目安時間：約20〜40分　必要人数：1名**

### 使用道具

TOOL-001（高圧洗浄機）/ TOOL-009（噴霧器）/ TOOL-025（LEDライト）

### 使用薬剤

CHEM-001（エアコン専用アルカリ洗剤）

| 汚れの程度 | 希釈倍率 | 使用量 | 放置時間 |
|----------|---------|--------|--------|
| 通常（ホコリ・軽度カビ） | 30〜50倍 | 約50〜80ml | 3〜5分 |
| 重度（カビ多・ヤニ・油汚れ） | 10〜20倍 | 約80〜100ml | 5〜10分 |

### 手順

**洗剤塗布**

1. 噴霧器にCHEM-001希釈液を入れる。
2. 熱交換器の上部から下部へ向けて均一に噴霧する。ノズルを熱交換器から15〜20cm離す。泡立つまで全体にかける。
3. 放置時間を守る（上表参照）。放置中は部品洗浄（工程4）を並行して進める。

**高圧洗浄**

4. 高圧洗浄機の水圧を3〜5MPaに設定する。
5. ノズルをアルミフィンから15〜20cm離す。
6. ノズル角度はアルミフィンに対して90度（垂直）。斜めにするとフィンが倒れる。
7. 上部から下部へ向けて一定速度（約10〜15cm/秒）で移動しながら洗浄する。
8. 洗浄水が透明になるまで繰り返す。
9. フィンの変形がないかLEDライトで確認する。

**【写真⑫：熱交換器洗浄前（汚れ状態）】**

**【写真⑬：熱交換器洗浄後（汚れ除去確認）】**

### 注意事項

- 水圧は5MPaを超えない（フィン変形・基板浸水の原因）。
- ノズルは15cm未満に近づけない。
- 電装部（配線・基板）に向けて噴射しない。
- ノズルをフィンに対して斜めにしない（フィンが倒れる）。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| フィン | 変形なし・均一に洗浄・洗剤残りなし | フィンが1箇所以上曲がっている → フィン起こし必要 |
| 洗浄水 | 透明 | 茶色・黒い汚水が出続ける → すすぎを継続 |
| 電装部 | 濡れていない | 濡れている → すぐに電源確認・乾燥処置 |

### プロのコツ

- 洗剤噴霧後、フィン全面が白い泡で均一に覆われた状態（泡の厚さ約1〜2cm）が適切。泡立ちが薄い場合は濃度が薄すぎる。
- 重度汚染の場合は2回洗浄（1回目洗剤→すすぎ→2回目洗剤→最終すすぎ）が効果的。
- フィン変形が起きた場合は、フィンコームまたは指で慎重に起こす。完全に起こせない場合はお客様へ報告する。

## 工程7　シロッコファン・吹出口内部洗浄

**目安時間：約20〜40分　必要人数：1名**

### 使用道具

TOOL-001（高圧洗浄機）/ TOOL-009（噴霧器）/ TOOL-012（洗浄ブラシ）/ TOOL-011（Jブラシ）/ TOOL-014（マイクロファイバークロス）

### 使用薬剤

CHEM-001（エアコン専用アルカリ洗剤）

| 汚れの程度 | 希釈倍率 | 使用量 | 放置時間 |
|----------|---------|--------|--------|
| 通常 | 30〜50倍 | 約30〜50ml | 3〜5分 |
| 重度カビ | 10〜20倍 | 約50〜80ml | 5〜10分 |

### 手順

**洗剤塗布**

1. 噴霧器にCHEM-001希釈液を入れる。
2. 吹出口からノズルをシロッコファンの中央へ向けて差し込む（約5〜10cm）。
3. 片手でシロッコファンをゆっくり回す（1周を約10〜15秒かけて回す）。もう一方の手で噴霧器を持ち、全周に均一に噴霧する。
4. 吹出口内壁・内部壁面全体にも噴霧する。
5. 放置時間を守る（上表参照）。

**ブラッシング（目視でカビ・油汚れが残っている場合のみ）**

6. 洗浄ブラシ（TOOL-012）をファンの羽根に対して平行に当て、約500g程度の力で3〜5往復する。
7. Jブラシで吹出口の奥・内壁の隅を3〜5往復する。

**高圧すすぎ（仮）**

8. 高圧洗浄機を吹出口に向け、片手でシロッコファンを固定した状態ですすぎ洗浄する。
   ※ファンを固定しないと水圧で逆回転しモーター・軸受の故障原因になる。
9. 汚水が透明になるまですすぎを繰り返す。

**【写真⑭：シロッコファン洗浄前（カビ状態）】**

**【写真⑮：シロッコファン洗浄後】**

### 注意事項

- 高圧洗浄時は必ずファンを手で固定する。水圧によるファンの逆回転はモーター・軸受の故障原因。
- ブラシをファンの羽根に対して無理に押し込まない。羽根が変形する。
- Jブラシを吹出口へ差し込む際は、根元を支えながら差し込む。折れやすい。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| ファン | カビなし・油汚れなし・全周均一に洗浄 | 片側だけ洗浄・カビが残っている → 再洗浄 |
| 吹出口奥 | 汚れなし | カビ・黒ずみが見える → 再洗浄 |
| すすぎ水 | 透明 | 色付きの汚水が出続ける → 再洗浄 |

### プロのコツ

- ファンを「時計回りにゆっくり回しながら噴霧」→「逆時計回りにゆっくり回しながらすすぎ」の順番が効率的。
- シロッコファンのカビは「羽根の裏側」に最も多い。吹出口から覗いて羽根の裏面を確認する。

## 工程8　高圧すすぎ洗浄

**目安時間：約20〜30分　必要人数：1名**

### 使用道具

TOOL-001（高圧洗浄機）

### 手順

1. 高圧洗浄機の水圧を3〜5MPaに設定する。
2. 熱交換器全体を上から下へ向けて洗浄する。ノズル距離：15〜20cm。ノズル角度：フィンに対して90度。
3. シロッコファン・吹出口内部を洗浄する（ファンを手で固定したまま）。
4. ドレンパンへ水が流れ、ドレンホースへ排水されていることを確認する。
5. 洗浄水の色を確認する。透明になるまで繰り返す。
6. 室内・室外で水漏れが発生していないか確認する。
7. 電装部の養生が剥がれていないか確認する。

**【写真⑯：高圧すすぎ中の状態・排水状況】**

### 注意事項

- 電装部に絶対に水を向けない。
- アルミフィンに対してノズルを斜めにしない（フィン変形の原因）。
- すすぎ不足は臭い再発・洗剤残留の原因。汚水が透明になるまで必ず継続する。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| すすぎ水 | 透明・泡なし | 茶色・黒・泡が残っている → 継続 |
| 漏水 | 室内・室外ともになし | 壁や天井から水が染み出す → 即停止・養生確認 |
| 電装部 | 乾燥・養生intact | 養生が剥がれ濡れている → 即電源確認・乾燥処置 |

### プロのコツ

- バケツに排水された水の色で確認する。透明になれば洗剤・汚れの除去が完了している。
- 最後にすすぎ水を止め、ドレンからの排水が止まるのを待ってから終了する。

## 工程9　乾燥・消臭・防カビ処理

**目安時間：約15〜20分　必要人数：1名**

### 使用道具

TOOL-016（ブロワー）/ TOOL-017（ドライヤー）/ TOOL-014（マイクロファイバークロス）/ TOOL-010（スプレーボトル）

### 使用薬剤

CHEM-004（消臭剤）/ CHEM-005（防カビ剤）

### 手順

**乾燥**

1. マイクロファイバークロスで手が届く内部の水滴を拭き取る。
2. ブロワー（TOOL-016）を吹出口から内部全体へ当てる。出口を対象から20〜30cm離し、約10分間乾燥させる。電装部へ直接当てない。
3. ブロワー後も水滴が残っている箇所は、ドライヤー（TOOL-017）を弱温風設定・20cm以上離して当てる。電装部に温風を集中させない。
4. 乾燥完了の確認：手で内部に触れて水気がなく、LEDライトで内部の水滴が確認できない状態。

**消臭施工（カビ臭・タバコ臭がある場合）**

5. CHEM-004をスプレーボトルに入れる（原液または2〜5倍希釈）。
6. 吹出口内部・シロッコファン全体・熱交換器へ各3〜5回スプレーする。
7. 乾燥させる（拭き取り不要）。

**防カビ施工（カビが多かった場合・お客様希望時）**

8. CHEM-005をスプレーボトルに入れる（原液または2〜3倍希釈）。
9. 熱交換器・シロッコファン・吹出口内部へ各2〜3回スプレーする。
10. 乾燥させる（拭き取り不要）。

**【写真⑰：乾燥完了後の内部状態】**

### 注意事項

- 内部が湿ったまま組み立てると短期間でカビが再発する。乾燥を省略しない。
- ドライヤーの温風を電装部に集中させると基板・コネクターが熱損傷する。
- 消臭剤・防カビ剤は洗浄・乾燥後に施工する。洗浄前に使用しても効果がない。
- CHEM-004とCHEM-005は混合しない。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 乾燥 | 手で触れて水気なし・LEDで水滴なし | 内部に水滴が残っている → ブロワー継続 |
| 消臭剤 | 全周均一に施工・乾燥させた | 片側だけ施工・洗浄前に使用した |

### プロのコツ

- ブロワーをエアコンの吹出口から当てると内部全体に風が通り乾燥が早い。
- 乾燥が不十分な状態で組み立てると試運転時に臭いが出る。お客様クレームの主な原因。乾燥を徹底する。

## 工程10　組立・復旧

**目安時間：スタンダード 約15〜20分 / お掃除機能付き 約30〜45分　必要人数：1名**

### 使用道具

TOOL-004（プラスドライバー）/ TOOL-006（内張りはがし）/ TOOL-008（コネクター抜き）/ TOOL-024（部品ケース）/ TOOL-025（LEDライト）

### 手順

**分解の逆順で組み立てる。工程3で撮影した配線写真を参照しながら施工する。**

1. 熱交換器・シロッコファンの状態を最終確認する（洗浄残り・異物がないか）。
2. お掃除ユニットを取り付ける（搭載機種）。撮影した写真と照合しながらコネクターを接続する。コネクターは「カチッ」と音がするまで押し込む。
3. 外装カバーを取り付ける。爪の位置を全て合わせてから均等に押し込む。ビスを元の位置に締め付ける（締め過ぎると樹脂が割れる。「手で締め込んだ後に90度（1/4回転）締める」程度）。
4. ルーバーを取り付ける。両端の軸を穴に合わせ、「カチッ」と音がするまで押し込む。手で動かして可動することを確認する。
5. フィルターを正しい向きで取り付ける。左右スライドして装着し、浮いていないか確認する。
6. 前面パネルを取り付ける。爪を全て合わせてから均等に押し込む。

**【写真⑱：組立完了状態】**

### 注意事項

- 必ず工程3の写真と照合しながら組み立てる。
- コネクターの接続忘れは動作不良・エラーの原因。全接続を確認してから次に進む。
- ネジの締め過ぎは樹脂割れの原因。
- 部品ケースのビスが残っていたら付け忘れ。全て使い切る。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| コネクター | 全接続確認・「カチッ」音あり | 途中まで差し込み・フワッとした感触 → 再接続 |
| ビス | 全て取り付け済み（部品ケースが空） | 部品ケースにビスが残っている → 付け忘れ |
| ルーバー | 手で動かしてスムーズに可動 | 途中で引っかかる → 取り付け直し |
| フィルター | 正しい向き・しっかり固定・浮きなし | 逆向き・浮いている |

### プロのコツ

- 「部品ケースが空になったら組立完了」というルールで管理すると付け忘れを防げる。
- 組立後にコネクターを約2〜3kgの力で引っ張り、抜けないことを確認する習慣をつける。

## 工程11　動作確認・外装仕上げ・最終確認

**目安時間：約15〜20分　必要人数：1名**

### 使用道具

リモコン / TOOL-014（マイクロファイバークロス）/ TOOL-011（Jブラシ）/ チェックシート / カメラ

### 手順

**動作確認（試運転）**

1. 電源プラグを挿す または ブレーカーをONにする。
2. リモコンで冷房運転を起動する。
3. 以下を10〜15分間確認する。

| 確認項目 | OK基準 |
|---------|--------|
| 冷風 | 冷たい風が出る |
| 風量 | 設定通り |
| ルーバー | 上下に正常動作 |
| 異音 | なし |
| 異臭 | なし（最初の1〜2分は消臭剤のわずかな香りが出る場合あり。正常） |
| 水漏れ | 前面・横からの水垂れなし |
| ドレン排水 | 屋外でドレンから排水が出る |
| エラー表示 | なし |
| お掃除ユニット | 正常動作（搭載機種） |

4. 施工直後にドレンから一時的に黒い汚水が流れる場合がある。2〜3分で透明になれば正常。

**リモコン清掃**

5. 乾いたマイクロファイバークロスでリモコン全体を拭く。
6. ボタンの隙間はJブラシで約100〜200gの力でなぞる。
7. 電池蓋・液晶部分の汚れを確認する。

**外装仕上げ**

8. 前面パネル・外装全体をマイクロファイバークロスで乾拭きする。一方向に拭き、拭きムラをなくす。
9. 吹出口の縁・ルーバー周辺を確認し、拭き残しがないか確認する。

**最終写真撮影**

**【写真⑲：エアコン全景（作業後）】**

**【写真⑳：熱交換器（洗浄後）】**

**【写真㉑：シロッコファン（洗浄後）】**

**【写真㉒：吹出口（洗浄後）】**

**【写真㉓：試運転状況】**

### 注意事項

- 試運転は10〜15分以上行う。短すぎると異常を見落とす。
- ドレン排水の確認は必ず屋外でも行う。
- エラー表示が出た場合は即座に電源を切り、コネクターの接続を全て確認する。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 試運転 | 冷風・静音・水漏れなし・エラーなし | 動かない・異音あり・エラー → コネクター確認 |
| 外装 | 拭きムラなし・水滴なし・光沢あり | 水滴・手垢・拭きムラあり |
| ドレン排水 | 屋外でスムーズに排水 | 排水されない → ドレンホース詰まり再確認 |

### プロのコツ

- 試運転中に前面パネルに顔を近づけて内部の風を嗅ぐとカビ臭の残りを確認できる。
- 作業前後の写真を並べてお客様に見せると「きれいになった」と実感してもらえ、次回依頼につながる。

## 工程12　養生撤去・現場復旧・お客様説明

**目安時間：約10〜15分　必要人数：1名**

### 手順

**養生撤去**

1. 試運転が正常であることを確認してから養生を撤去する。
2. 洗浄カバーを取り外す。汚水がこぼれないよう下に向けながら外す。
3. マスカー・養生テープを丁寧に剥がす。壁紙が剥がれないよう壁と平行方向（横方向）にゆっくり剥がす。
4. 養生シートを折り畳んでゴミ袋に入れる。

**現場復旧**

5. 移動した家具・家電を元の位置に戻す。
6. 床・壁に水滴・汚れが残っていないか確認し、残っていれば拭き取る。
7. 自分の工具・資材を全て確認する。忘れ物がないか確認する。

**お客様への最終説明**

| 説明項目 | 内容 |
|---------|------|
| 施工完了の報告 | 「本日の作業が完了しました」 |
| 施工内容の報告 | 分解洗浄した部位・使用薬剤・特記事項（重度汚染・ドレン詰まり等） |
| 状態の報告 | 作業前後の写真を見せる「洗浄前はこの状態でした。洗浄後はこの状態です」 |
| 異常の報告 | 施工中に発見した異常（コネクター劣化・フィン変形・水漏れ跡等）を伝える |
| 次回目安 | 「次回は約1年後を目安にご依頼ください」 |
| 施工後の注意 | 「施工直後1〜2分はドレンから黒い汚水が出る場合がありますが正常です」 |

### 注意事項

- 養生テープを急いで剥がすと壁紙・塗装が剥がれる。必ずゆっくり横方向へ剥がす。
- 汚水入りのバケツは倒さないよう注意して運ぶ。

# 14. 安全管理

## 感電防止

- 作業前にブレーカーOFFまたは電源プラグを抜く
- 電装部を防水二重養生する
- 濡れた手で電装部・コンセントに触れない

## 転倒防止

- 脚立は水平な床に設置する
- 脚立の天板に乗らない
- 床の水滴をこまめに拭く
- 3点支持（両手1足または両足1手）を守る

## 薬剤管理

- 薬剤ラベルを確認してから使用する
- 推奨希釈倍率を厳守する
- 酸性薬剤とアルカリ性薬剤を混合しない

## 高所作業

- 脚立から身を乗り出さない
- 無理な姿勢で作業しない

## 緊急時対応

| 事故 | 対応 |
|------|------|
| 感電 | 電源を遮断してから対応。感電者に直接触れない。119番通報。 |
| 漏水 | 洗浄を止め、電源を切る。養生を強化してから再施工。 |
| 薬剤が目に入った | その場で15分以上水洗眼。医療機関を受診。 |
| 薬剤が皮膚に付いた | 流水で15分以上洗浄。 |
| 転倒・負傷 | 応急処置→責任者へ報告→医療機関を受診。 |

# 19. 教育ポイント（新人向け）

## 最初に覚えること（優先順）

1. 電装部の位置と防水二重養生の方法
2. 洗浄カバーの取り付けと排水経路の確保
3. 外装パネル・爪の外し方（爪は起こす方向に外す）
4. アルミフィンを変形させない水圧（3〜5MPa）・距離（15〜20cm）・角度（90度）
5. シロッコファンを手で固定しながら洗浄する方法

## 新人が失敗しやすいポイント

| 失敗 | 防止策 |
|------|--------|
| コネクター接続忘れ | 「部品ケースが空になったら組立完了」を徹底 |
| ネジ紛失 | 部品ケースを必ず使用する |
| フィン変形 | 水圧・距離・角度を数値で覚える |
| ルーバー破損 | 軸の方向を確認してから外す |
| 養生不足による水漏れ | 養生後にコップ1杯の水で漏れ確認をする |

## 一人施工を許可する判断基準

以下を全て自己確認できること：

- 外装分解・組立を一人で正確に完了できる
- 電装部の防水二重養生を一人で正しく行える
- 薬剤の希釈を一人で正しく行える（CHEM-001〜003の使い分けを理解）
- 試運転まで問題なく完了できる
- 品質基準・安全管理を理解している
