# キッチンクリーニング SOP

**対象：家庭用キッチン全般**

---

# 1. 適用範囲

## 対象施設

- 戸建住宅 / マンション / アパート / 賃貸物件（空室・退去後）
- 分譲住宅 / ホテル / マンスリーマンション / 社宅 / 福祉施設 / 社員寮

## 対象設備・作業範囲

- ガスコンロ・IHクッキングヒーター / 五徳・受け皿・バーナーキャップ
- 魚焼きグリル（取り外し可能部品）/ 壁面 / レンジフード表面
- 戸棚表面 / 照明 / スイッチ・コンセントプレート
- 作業台 / シンク / 排水口・排水トラップ / 蛇口・シャワーヘッド
- 冷蔵庫表面 / 電子レンジ表面

## 施工可能条件

| 条件 | 基準 |
|------|------|
| コンロ温度 | 完全に冷えていること（前回調理から最低30分以上経過。手をかざして熱さを感じない状態） |
| ガス確認 | ガス元栓がOFFにできること |
| 換気 | 窓・換気扇で換気ができること（アルカリ・塩素系薬剤使用時は必須） |
| 水道 | 水道が使用できること |
| 感電リスク対策 | コンセント・スイッチ周辺は養生し、水・薬剤が直接かからないようにすること |
| 高所作業 | 照明・戸棚上部清掃で脚立が必要な場合、安全に設置できるスペースがあること |
| 養生 | 床・家電・食器棚内部への薬剤・水の飛散防止養生が実施可能なこと |
| 雨天・強風・直射日光 | 室内作業のため天候不問 |
| 凍結 | 室内で水道が使用できる状態であれば施工可 |

## 施工不可条件

| 条件 | 理由 |
|------|------|
| コンロが熱い状態（手をかざして温かさを感じる） | 熱傷リスク・薬剤が急速に蒸発し有害ガスが発生する |
| ガス漏れが疑われる（ガス臭がする） | 爆発・中毒リスク。即座に元栓を閉め換気し退避する |
| 換気ができない密閉空間 | 薬剤蒸気が滞留し中毒リスク |
| IHガラストッププレートにヒビ・欠けがある | 感電・破損リスク。施工前にお客様へ報告 |
| 水道が使用できない | 洗浄・すすぎ不可 |

## 作業中止基準

以下を発見した場合は即時作業を停止し、お客様へ報告する。

| 発見内容 | 対応 |
|------|------|
| ガス臭がする | 作業中止・元栓を閉める・換気・退避・ガス会社へ連絡 |
| コンロ・配線から焦げ臭・煙が出る | 作業中止・電源遮断・119番通報 |
| 薬剤が目・皮膚に付着 | 流水で15分以上洗浄・受診 |
| IHガラスのヒビを発見（施工中） | 即時中止・写真撮影・お客様へ報告 |
| 異常な発熱・スパーク | 電源遮断・119番通報 |

# 2. 用語の定義

| 用語 | 内容 |
|------|------|
| 油汚れ | 調理油・油煙などが固着した汚れ。アルカリ性洗剤で分解する。 |
| 焦げ付き | 加熱により炭化した汚れ。つけ置き→ラストラーレスポンジ→一枚刃の順で除去する。 |
| 水アカ（スケール） | 水道水のカルシウム・マグネシウムが固着した白い汚れ。酸性洗剤で溶かす。 |
| カルキ | 塩素・ミネラルが白く固着した汚れ。水アカと同様に酸性洗剤を使用する。 |
| 石鹸カス | 洗剤成分とミネラルが固着した汚れ。白：酸性洗剤 / 黒：アルカリ性洗剤で除去する。 |
| ぬめり | 排水口・排水トラップに発生する細菌・バイオフィルム。塩素系漂白剤で除去する。 |
| つけ置き | 部品を薬剤液に浸漬し、汚れを軟化・分解させる洗浄方法。汚れを削る前に必ず実施する。 |
| 養生 | 床・家具・家電に薬剤・水が付着しないよう保護する作業。 |
| KY活動 | 危険予知活動。作業前に危険を洗い出し事故を防ぐ。 |

# 3. 作業区分

## 日常清掃

軽度な油汚れ・水滴・食品汚れを除去し衛生状態を維持する清掃。

## 定期清掃

日常清掃では除去できない油汚れ・水アカ・石鹸カス・軽度の焦げ付きまで除去する清掃。

## 特別清掃

長期間蓄積した油汚れ・重度焦げ付き・カビ・水アカ等を専用薬剤・専用工具で除去する清掃。

# 4. 施工前確認

## コンロ・ガス確認

1. コンロ本体に手を近づけて「熱くないこと」を確認する（完全に冷えていること）。
2. ガス元栓がOFFになっていることを確認する。
3. 換気扇を起動し、窓を開けて換気を開始する。

## 素材確認

施工前に対象素材を確認する。素材によって使用できる洗剤・道具が異なる。

| 素材 | 見分け方 | 禁止事項 |
|------|---------|---------|
| ステンレス | 金属光沢・磁石が付かない | 金属たわし・塩素の長時間放置 |
| ガラストップIH | ガラス状の滑らかな黒い面 | 一枚刃の使用・衝撃 |
| ホーロー（コンロ天板等） | 白・黒のつやのある金属面 | 強い研磨・一枚刃 |
| 人工大理石（シンク・作業台） | 白または石目柄の人工素材 | 強酸性・強アルカリ長時間接触 |
| 樹脂（戸棚・カバー） | プラスチック系 | 強アルカリ・シンナー・強い研磨 |
| アルミ（換気扇部品等） | 軽い金属 | 強アルカリ洗剤 |
| 木部・化粧板（戸棚） | 木目模様または木目シート | 過剰な水分・酸性洗剤 |

## キズ・破損確認

1. コンロ・シンク・IHガラス・戸棚のキズ・欠け・割れを確認する。
2. 異常がある場合は施工前にお客様へ報告し、写真に残す。

**【写真①：キッチン全景（作業前）】**

**【写真②：コンロ（作業前・汚れ状況）】**

**【写真③：シンク（作業前・水アカ状況）】**

**【写真④：キズ・破損箇所（ある場合のみ）】**

## お客様への事前説明

| 説明項目 | 説明内容の例 |
|---------|------------|
| 施工内容 | 「本日はキッチン全体を専用洗剤・専用工具でクリーニングします」 |
| 所要時間 | 「汚れの程度により2〜4時間かかります」 |
| 食品・食器 | 「カウンター上の食品・食器をシンク内またはダイニングへ移動します」 |
| 水の使用 | 「水道水を使用します。床に養生シートを敷きます」 |
| 換気 | 「薬剤使用のため、施工中は換気をお願いします」 |
| 焦げ・水垢 | 「長年の焦げ付き・水垢は1回の施工では完全に除去できない場合があります」 |
| 異常発見時 | 「施工中にキズ・故障を発見した場合はすぐにご報告します」 |

# 6. 必要資機材・工具の使い方

|---------|--------|------|----------------|

| TOOL-002 | 掃除機 | 除塵 | 養生前に床・コンロ周辺のホコリ・粉末汚れを先に吸引する。水で洗う前に乾いた汚れを除去することで洗浄効率が上がる。 |
| TOOL-003 | ネットスポンジ | 油汚れ・一般洗浄 | 薬剤を含ませ約300〜500g程度の力で施工。傷が付きにくい。コンロ・壁面・戸棚の一般的な油汚れに使用。 |
| TOOL-004 | メラミンスポンジ | 軽度水アカ・手垢 | 水を含ませて約200〜300g程度の力で施工。鏡面ステンレスや光沢のある樹脂面は最小限の使用にとどめる（細かい傷が入る）。 |

| TOOL-006 | Jブラシ | 排水口・蛇口・隙間洗浄 | 根元を支えながら差し込む。3〜5往復。排水口の底まで届かせる。 |
| TOOL-007 | 五徳ブラシ | 五徳の凹部・細部洗浄 | 毛先を五徳の凹部に当て、前後に3〜5往復する。強く押し付けない。 |
| TOOL-008 | 歯ブラシ | 蛇口根元・細部仕上げ | 毛先を対象に当て、小さく円を描くように動かす。5〜10往復。 |
| TOOL-009 | サッシヘラ | コンロ隙間・シンクパッキン周辺 | ウエスを1〜2枚巻いてから差し込む（素材に傷が付かないよう）。一方向に動かし、汚れを掻き出す。横方向に力をかけない（折れやすい）。 |
| TOOL-010 | 樹脂ヘラ | 樹脂・ガラス面の汚れ除去 | 約30〜45度の角度で当て、一方向に動かす。ガラストップIHの焦げ付き除去に使用可。 |
| TOOL-011 | 一枚刃スクレーパー | コンロ・五徳の焦げ付き除去 | 刃を約20〜30度に寝かせる（立てすぎると傷が付く）。水または薬剤を塗布した湿った状態のみ使用。乾いた面には使用禁止。一方向のみ動かす（往復禁止）。ガラス面・ホーロー・塗装面・IHガラスには使用禁止。 |
| TOOL-012 | マイクロファイバークロス | 水拭き・乾拭き・仕上げ | 水拭き用・乾拭き用を別々に用意する。乾拭きは常に乾いた面を使用する。折り返して清潔な面を使う。 |
| TOOL-013 | ウエス | 水拭き・養生補助 | サッシヘラに巻いて使用。洗剤拭き取り・粗拭きに使用。 |
| TOOL-014 | スプレーボトル | 薬剤散布 | 対象から10〜15cm離してスプレー。コンロのセンサー・点火部・通電部には直接スプレーしない。 |
| TOOL-015 | バケツ（大：10L以上） | つけ置き / 洗浄液調製 | つけ置き用は60℃のお湯を使用。温度計で確認する。 |
| TOOL-016 | 計量カップ | 薬剤希釈 | 薬剤量を正確に計量する。目盛りを正面から読む。 |
| TOOL-017 | 温度計 | つけ置き温度管理 | つけ置き液は55〜65℃（60℃が最適）。70℃超えは禁止（部品変形・火傷リスク）。 |

# 7. 使用薬剤一覧（AVL Facilities 推奨基準）

| 項目 | 内容 |
|------|------|
| 液性 | 中性（pH 6〜8） |
| 対象汚れ | 食品汚れ・軽い手垢・日常的な汚れ |

| 使用不可素材 | 特になし（最も安全な洗剤） |

## 薬剤選択フロー

```
汚れを確認する
    ↓
食品汚れ・日常的な汚れ → CHEM-001
    ↓
油汚れ・油煙（通常） → CHEM-002
    ↓
固着した油汚れ・焦げ付き → CHEM-003（スプレー）または CHEM-004（つけ置き）
    ↓
白い固着（水垢・カルキ） → CHEM-005
```

## 工程1　事前準備・養生

**目安時間：約10〜15分　必要人数：1名**

### 使用道具

TOOL-002（掃除機）/ TOOL-001（養生シート）/ 養生テープ / カメラ

1. 作業範囲を最終確認する。お客様に施工箇所・所要時間を説明する（第4章参照）。
2. カウンター上の食品・食器・調味料を移動する（シンク内またはダイニングへ）。
3. コンロが完全に冷えていることを確認する（手を近づけて温もりがないこと）。
4. ガス元栓をOFFにする。
5. 換気扇を起動し、窓を開けて換気を開始する。
6. 床のゴミ・ホコリを掃除機で除去する（養生前に必ず除塵する）。
7. 床全面に養生シートを敷き、テープで固定する（浮きがないことを確認する）。
8. 水が掛かる可能性がある床には防水シートを養生シートの上に重ねる。

**【写真①：キッチン全景（作業前）】**

**【写真②：コンロ（汚れ状況）】**

**【写真③：シンク（汚れ状況）】**

**【写真④：キズ・破損箇所（ある場合のみ）】**

### 注意事項

- 養生シートの下に砂・ゴミが残った状態で敷くと、歩行時にフローリングが傷つく。必ず掃除機で除塵してから敷く。
- 養生テープを塗装面・壁紙に長時間（1時間以上）貼らない。剥がすときに塗装・壁紙が剥がれる。
- ガス元栓OFFを目視で確認する（「たぶんOFF」で作業開始しない）。

| | OK | NG |

| 養生 | 床全面・浮きなし・テープ固定 | 一部だけ養生・養生シートが浮いている |

## 工程2　コンロ部品取り外し・つけ置き開始

**目安時間：約10〜20分（つけ置き：30〜120分）　必要人数：1名**

### 使用道具

TOOL-015（バケツ大）/ TOOL-016（計量カップ）/ TOOL-017（温度計）/ TOOL-018（保温器具）/ TOOL-007（五徳ブラシ）/ ゴミ袋

### 使用薬剤

CHEM-004（アルカリ性つけ置き洗浄剤）1〜1.5%濃度（お湯10Lに対して100〜150ml）+ お湯55〜65℃

### 手順

1. ガス元栓がOFFであることを再確認する。
2. 五徳を手で持ち上げて取り外す。ゴミ・大きな焦げくずはゴミ袋へ捨てる。
3. バーナーキャップを取り外す（ガスコンロのみ）。
4. 受け皿を取り外す。
5. グリル扉を開け、グリル網・グリル受け皿を取り外す。
6. バケツにお湯を入れる。温度計で55〜65℃であることを確認する。
7. 計量カップでCHEM-004を量り、バケツに添加する（10Lのお湯に対して100〜150ml）。
8. 取り外した部品をバケツに浸ける（全て完全に沈めること）。
9. 保温器具でお湯の温度を維持する。

**つけ置き時間の目安**

| 汚れの程度 | 放置時間 |
|----------|---------|
| 軽度（最近の汚れ） | 30〜60分 |
| 通常（1〜3ヶ月分の汚れ） | 60〜90分 |
| 重度（半年以上の固着汚れ） | 90〜120分 |
| 飲食店レベルの超重度 | 120〜180分 |

10. バケツをコンロ近くに設置し、他の工程（工程3〜8）を進める。

**【写真⑤：部品取り外し・つけ置き開始状態】**

### 注意事項

- バーナーキャップは穴が多く、アルカリ洗剤の長時間つけ置きで変色することがある。アルミ製バーナーキャップは30分以内を目安にする。
- お湯の温度が70℃を超えると部品が変形する可能性がある。必ず温度計で確認する。
- バケツに全部品が完全に沈んでいること（一部が水面上に出ているとつけ置き効果が低下する）。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| お湯温度 | 55〜65℃（温度計確認） | 体感だけで判断・70℃超え → 部品変形リスク |
| 薬剤量 | 計量カップで正確に計量 | 「だいたいこのくらい」で添加 → 濃度不明・効果不安定 |
| 部品の浸漬 | 全部品が完全に沈んでいる | 一部が水面より上に出ている |

### プロのコツ

- つけ置き中は他の工程（照明→壁面→戸棚→コンロ本体）を進める。時間を無駄にしない。
- 超重度の焦げ付きは「つけ置き開始→1時間後に取り出して一度ブラッシング→再度つけ置き60分」の2段階が効果的。

## 工程3　照明・戸棚上部清掃

**目安時間：約10〜15分　必要人数：1名**

### 使用道具

TOOL-012（マイクロファイバークロス）/ TOOL-008（歯ブラシ）/ 脚立（必要時）

### 使用薬剤

照明カバー（プラスチック製）：CHEM-001（中性洗剤）50倍希釈
油汚れがある場合：CHEM-002（弱アルカリ性洗剤）20倍希釈

### 手順

1. 照明カバーを取り外せる場合は取り外す（カバーの取り付け方を確認してから外す）。
2. カバーを洗浄液（CHEM-001、50倍希釈）に浸けるか、全面に塗布して1〜2分放置する。
3. クロスで拭き取る。歯ブラシで隙間の汚れを除去する。
4. 水拭き→乾拭きで仕上げる。カバーは完全に乾燥させてから取り付ける。
5. 戸棚上部のホコリ・油煙をクロスで拭き取る。

### 注意事項

- 照明カバーは必ず電源OFFを確認してから取り外す。
- 照明本体（電球・LED）に水・洗剤が付着しないよう注意する。直接スプレーしない。
- 割れたカバーは素手で触らない（切創リスク）。耐切創手袋を着用する。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 照明 | 電源OFFを確認後に取り外し・油汚れなし | 電源確認せずに作業・電球に水がかかった |
| カバー取り付け | 完全に乾燥してから取り付け | 濡れたまま取り付け → 漏電リスク |

### プロのコツ

- 照明カバーはつけ置き（CHEM-001希釈液に浸ける）してから他の部分を施工し、戻ってきたときに洗うと効率的。

## 工程4　壁面・レンジフード表面清掃

**目安時間：約20〜30分　必要人数：1名**

### 使用道具

TOOL-003（ネットスポンジ）/ TOOL-012（マイクロファイバークロス）/ TOOL-009（サッシヘラ）

### 使用薬剤

CHEM-002（弱アルカリ性洗剤）20倍希釈（通常）/ 10倍希釈（重度油汚れ）

### 手順

1. クロスにCHEM-002希釈液を含ませ、壁面上部から下部へ向けて均一に塗布する。放置時間：2〜3分。
2. ネットスポンジで上から下へ縦方向に拭く（円を描いて拭かない。拭き筋が残る）。力は約300〜400g程度。
3. 隙間・角部はサッシヘラにウエスを巻いて除去する。
4. レンジフード表面に同様に施工する（フィルターは対象外。フィルターは換気扇・レンジフード清掃SOPを参照）。
5. 水で濡らしたクロスで洗剤を拭き取る（水拭き2〜3回）。
6. 乾拭きで仕上げる。光を当てて拭き筋・油膜の残りがないか確認する。

### 注意事項

- 壁紙・クロスは過度に濡らさない（剥がれ・変色の原因）。
- 電気スイッチ・コンセントに直接スプレーしない。
- 塗装壁は目立たない箇所でテスト施工を行う（CHEM-002でも変色する塗装がある）。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 壁面 | 油膜なし・拭き筋なし・上から下へ一方向施工 | 円を描いて施工 → 拭き筋が残る |
| 水拭き | 洗剤が残らないよう2〜3回水拭き | 1回だけ水拭き → 洗剤残留・白く曇る |

### プロのコツ

- 壁面の油汚れは「上から下へ一方向で拭く」が基本。円を描くと逆に汚れが広がる。
- 重度の油汚れは「洗剤を塗布して5分放置→スポンジで拭く→再度洗剤→水拭き」の2回施工が効果的。

## 工程5　戸棚表面・スイッチ・コンセント清掃

**目安時間：約15〜20分　必要人数：1名**

### 使用道具

TOOL-012（マイクロファイバークロス）/ TOOL-003（ネットスポンジ）/ TOOL-009（サッシヘラ）/ TOOL-008（歯ブラシ）

### 使用薬剤

CHEM-002（弱アルカリ性洗剤）20倍希釈

### 手順

**戸棚表面**

1. 乾いたクロスでホコリを先に払い取る（ホコリを濡らすと汚れが広がる）。
2. クロスにCHEM-002（20倍希釈）を含ませ、戸棚扉全面を上から下へ拭く。放置時間：2〜3分。
3. 取手周辺・取手裏面を歯ブラシで3〜5往復する（手垢が最も多い箇所）。
4. 角・木口はサッシヘラにウエスを巻いて差し込み、汚れを掻き出す。
5. 水で濡らしたクロスで洗剤を拭き取る。木口へ水が入らないよう素早く拭く。
6. 乾拭きで仕上げる。

**スイッチ・コンセントプレート**

7. クロスにCHEM-002（20倍希釈）を約3〜5ml含ませ（クロスが湿る程度。スプレーしない）、スイッチ・コンセントを拭く。
8. サッシヘラにウエスを巻いてスイッチの隙間を清掃する。
9. 乾拭きで仕上げる。

### 注意事項

- 木製戸棚・化粧板に酸性洗剤を使用しない（変色・変形の原因）。
- 木口（木の断面）に水分を長時間接触させない。木部が膨張・変形する。
- スイッチ・コンセントに洗剤を直接スプレーしない（クロスに含ませて使用する）。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 戸棚 | 手垢なし・取手裏まで洗浄・木口乾燥 | 取手の裏面を見落とし・木口に水が残っている |
| スイッチ | クロスで施工・乾拭き完了 | 直接スプレーして水が侵入 → 漏電リスク |

### プロのコツ

- 取手の裏面は「ここまで洗ってくれた」とお客様に最も気づいてもらえる箇所。必ず施工する。
- 戸棚は「上段→中段→下段」の順で施工する。洗剤が下に垂れるため。

## 工程6　ガスコンロ・IH本体洗浄

**目安時間：約40〜90分（汚れ程度により変動）　必要人数：1名**

### 使用道具

TOOL-003（ネットスポンジ）/ TOOL-005（ラストラーレスポンジ）/ TOOL-010（樹脂ヘラ）/ TOOL-011（一枚刃スクレーパー）/ TOOL-009（サッシヘラ）/ TOOL-012（マイクロファイバークロス）/ TOOL-014（スプレーボトル）

### 使用薬剤

| 汚れ状況 | 使用薬剤 | 希釈倍率 | 放置時間 |
|---------|---------|---------|---------|
| 通常の油汚れ | CHEM-002（弱アルカリ性） | 10倍希釈 | 3〜5分 |
| 重度の油汚れ・焦げ付き | CHEM-003（アルカリ性） | 10〜20倍希釈 | 5〜10分 |

### 手順

**ガスコンロ本体**

1. コンロが完全に冷えていることを再確認する。
2. バーナー周辺の粉末状のゴミ・焦げくずを乾いたクロスで先に払い取る。
3. CHEM-003（10〜20倍希釈）をスプレーボトルに入れ、コンロ全体に塗布する。センサー・点火部にはかからないようにする。放置時間：5〜10分。
4. ネットスポンジで全体を洗浄する（力は約300〜500g程度）。
5. 焦げ付きはラストラーレスポンジで一方向に施工する（約500〜700g程度の力）。
6. ラストラーレで落ちない焦げは一枚刃スクレーパーを使用する。刃を20〜30度に寝かせ、一方向のみ動かす（往復禁止）。水または薬剤で濡れた状態で使用する。
7. コンロの隙間はサッシヘラにウエスを巻いて掻き出す。
8. 水で濡らしたクロスで洗剤を拭き取る（2〜3回繰り返す）。
9. 乾拭きで仕上げる。

**IHクッキングヒーター**

10. ガラストップが完全に冷えていることを確認する。
11. CHEM-002（10倍希釈）を塗布する。放置時間：3〜5分。
12. ネットスポンジで汚れを除去する（約200〜300g程度の力）。
13. 固着した食品・焦げは樹脂ヘラ（TOOL-010）を30〜45度に当てて除去する。一枚刃スクレーパーはIHガラスには使用禁止。
14. 水拭き→乾拭きで仕上げる。

**【写真⑥：コンロ洗浄前（汚れ状況）】**

**【写真⑦：コンロ洗浄後】**

### 注意事項

- コンロが熱い状態で薬剤を使用すると急激に蒸発し、有害ガスが発生する。必ず冷えてから作業する。
- センサー・点火部（イグナイター）・電装部に薬剤を直接かけない。故障の原因。
- IHガラストップに一枚刃スクレーパーを使用しない（ガラスが割れる）。
- 一枚刃は乾いた面に使用禁止（傷が付く）。必ず水・薬剤で濡らしてから使用する。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 温度確認 | 触れて完全に冷えていることを確認 | 触れずに作業開始 → 熱傷リスク |
| 一枚刃 | 20〜30度・湿潤状態・一方向 | 乾いた状態・立てすぎ・往復 → 傷 |
| センサー | 薬剤・水が付着していない | センサーが濡れている → 故障リスク |

### プロのコツ

- 重度の焦げ付きは「薬剤を塗布して10分放置→ラストラーレ→残りを一枚刃」の順番で。焦らず薬剤を浸透させることが傷を防ぐ最大のポイント。
- 「洗剤で汚れを浮かせてから除去する」順番を必ず守る。最初から削ると素材に傷が付く。

## 工程7　五徳・グリル部品洗浄（つけ置き完了後）

**目安時間：約20〜40分　必要人数：1名**

### 使用道具

TOOL-007（五徳ブラシ）/ TOOL-005（ラストラーレスポンジ）/ TOOL-011（一枚刃スクレーパー）/ TOOL-012（マイクロファイバークロス）

### 使用薬剤

CHEM-003（アルカリ性洗剤）20〜30倍希釈（ブラッシング時の追加塗布用）

### 手順

1. バケツからつけ置き完了した部品を取り出す（素手ではなくゴム手袋を着用）。
2. つけ置き液はバケツに残したままにする。
3. 五徳を五徳ブラシで洗浄する。凹部・溝に毛先を当て、前後に3〜5往復する（約400〜600g程度の力）。
4. 焦げ付きが残る場合はラストラーレスポンジを使用する。一方向に5〜10往復する。
5. まだ焦げ付きが残る場合は一枚刃を20〜30度に寝かせて除去する（塗装がある部品への使用は禁止）。
6. 受け皿はスポンジで全面を洗浄する。
7. グリル網はブラシで全面を洗浄する。油汚れが残る場合はCHEM-003（20倍希釈）を追加塗布して3〜5分放置後、再度ブラッシングする。
8. 全部品を流水で30秒以上すすぐ（洗剤が残らないまで）。
9. クロスで水気を拭き取り、完全乾燥させる（水分が残ったまま取り付けると焦げの原因になる）。

**【写真⑧：五徳・部品洗浄後】**

### 注意事項

- 塗装が施された五徳・部品に一枚刃を使用しない（塗装が剥がれる）。
- 水洗いは流水で30秒以上行う。洗剤が残ったまま取り付けると、次回加熱時に有害ガスが発生する。
- アルミ製バーナーキャップは強アルカリ洗剤での長時間洗浄後に変色することがある。白い粉が付いている場合は水洗いのみとする。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 焦げ除去 | つけ置き→ブラシ→スポンジ→一枚刃の順で施工 | 最初から一枚刃で削る → 傷・塗装剥がれ |
| 水洗い | 洗剤の泡が出なくなるまですすぐ | 1〜2回だけすすぎ → 洗剤残留 |
| 乾燥 | 完全乾燥してから取り付け | 濡れたまま取り付け → 焦げ付きの原因 |

### プロのコツ

- 五徳の凹部（丸い溝部分）はブラシの毛先を溝に押し込むように当てると汚れが取れやすい。
- 焦げ付きは「黒い層だけを除去する」意識で施工する。素材まで削ろうとしない。

## 工程8　作業台・冷蔵庫・電子レンジ表面清掃

**目安時間：約20〜30分　必要人数：1名**

### 使用道具

TOOL-003（ネットスポンジ）/ TOOL-012（マイクロファイバークロス）/ TOOL-009（サッシヘラ）/ TOOL-004（メラミンスポンジ）

### 使用薬剤

食品接触面（作業台）：CHEM-001（中性洗剤）50〜100倍希釈
油汚れのある面：CHEM-002（弱アルカリ性洗剤）20倍希釈

### 手順

**作業台（カウンター）**

1. 台面のゴミ・食品残渣を先に乾いたクロスで除去する。
2. CHEM-001（50〜100倍希釈）をクロスに含ませ、台面全体を拭く。放置時間：1〜2分。
3. ネットスポンジで油汚れ・ベタつきを除去する（約300〜400g程度の力）。
4. 固く絞ったクロスで2〜3回水拭きして洗剤を完全に除去する（食品接触面は特に徹底する）。
5. 乾拭きで仕上げる。

**冷蔵庫表面**

6. CHEM-002（20倍希釈）をクロスに含ませ、冷蔵庫の扉・側面・上部を上から下へ拭く。
7. 取手・取手裏面を歯ブラシで3〜5往復する（手垢が最も多い箇所）。
8. 水拭き→乾拭きで仕上げる。

**電子レンジ表面**

9. CHEM-001（50倍希釈）をクロスに含ませ、電子レンジの扉・側面・上部を拭く。
10. 操作パネル周辺はクロスを絞ってから施工する（水分が入ると故障する）。
11. 乾拭きで仕上げる。

### 注意事項

- 作業台は食品が直接触れるため、洗剤残留を絶対に残さない。水拭きを2〜3回繰り返す。
- 木製天板に過剰な水分を与えない（膨張・反りの原因）。
- 電子レンジの操作パネル・ボタン隙間に水が入らないよう注意する。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 作業台 | 食品接触面はCHEM-001使用・水拭き2〜3回・ベタつきなし | 強アルカリ洗剤使用・水拭き1回 → 洗剤残留 |
| 冷蔵庫 | 取手裏まで洗浄・乾拭き仕上げ | 取手の表面だけ施工 |

### プロのコツ

- 冷蔵庫上部のホコリ・油汚れは「最後に仕上げ」ではなく「工程4（壁面清掃）の流れで先に施工」すると上から落ちる汚れを再拭きしなくて済む。

## 工程9　シンク・排水口・蛇口清掃

**目安時間：約30〜60分　必要人数：1名**

### 使用道具

TOOL-003（ネットスポンジ）/ TOOL-006（Jブラシ）/ TOOL-008（歯ブラシ）/ TOOL-005（ラストラーレスポンジ）/ TOOL-009（サッシヘラ）/ TOOL-012（マイクロファイバークロス）

### 使用薬剤

| 汚れ | 薬剤 | 希釈倍率 | 放置時間 |
|------|------|---------|---------|
| ぬめり・カビ（排水口） | CHEM-006（塩素系漂白剤） | 50〜100倍 | 5〜10分 |
| 水アカ・カルキ（シンク・蛇口） | CHEM-005（酸性洗剤） | 5〜20倍 | 3〜10分 |
| 一般油汚れ（シンク全体） | CHEM-002（弱アルカリ性洗剤） | 20倍 | 2〜3分 |
| 研磨仕上げ | CHEM-007（クリームクレンザー） | 原液 | 不要 |
| 光沢仕上げ | CHEM-008（金属磨き剤） | 原液 | 不要 |

### 手順

**CHEM-006とCHEM-005は絶対に混合しない。排水口のCHEM-006が完全に流れてからCHEM-005を使用する。**

**Step1：排水口・排水トラップ（最初に実施）**

1. 排水口カバー・排水トラップを取り外す。
2. CHEM-006（50〜100倍希釈）を排水口内部・排水トラップに直接塗布する（約20〜30ml）。
3. 放置時間：5〜10分（この間にシンク・蛇口の洗浄を進める）。

**Step2：シンク全体洗浄（排水口放置中に並行して実施）**

4. CHEM-002（20倍希釈）をネットスポンジに含ませ、シンク全体を洗浄する（約300〜500g程度の力）。
5. カルキ・水アカが白く固着している箇所はCHEM-005（5〜20倍希釈）をスポンジに含ませて塗布する。放置時間：3〜10分。
6. ラストラーレスポンジで一方向（ヘアライン方向）に研磨する（約500g程度の力）。

**Step3：蛇口・シャワーヘッド洗浄**

7. CHEM-002（20倍希釈）をクロスに含ませ、蛇口全体を拭く。
8. 蛇口根元の水アカ・カルキはCHEM-005（5〜10倍希釈）をクロスに含ませて巻き付け、5〜10分放置する。
9. 歯ブラシで蛇口根元・ジョイント部を3〜5往復する。
10. シャワーヘッドのノズル穴詰まりはCHEM-005に5〜10分浸けてから歯ブラシで除去する。

**Step4：排水口の仕上げ**

11. CHEM-006の放置時間が完了したら、Jブラシで排水口内部を3〜5往復する。
12. 流水で30秒以上洗い流す（塩素系漂白剤が完全に流れたことを白い泡が出なくなるまで確認してから次の薬剤を使用する）。
13. 排水トラップを洗浄してから取り付ける。

**Step5：研磨仕上げ（ステンレスシンクのみ）**

14. CHEM-007（原液）をスポンジに2〜3g（パール粒1〜2個程度）付け、シンク全体をヘアライン方向に研磨する。
15. 流水で30秒以上洗い流す。
16. CHEM-008（原液）をクロスに1〜2ml含ませ、ヘアライン方向に拭く。
17. 水拭き→乾拭きで仕上げる。

**【写真⑨：シンク・蛇口洗浄前（水アカ・ぬめり状況）】**

**【写真⑩：シンク・蛇口洗浄後】**

### 注意事項

- **CHEM-005（酸性）とCHEM-006（塩素系）を混合しない。有毒ガス（塩素ガス）が発生し重大事故になる。**
- CHEM-005（酸性洗剤）をシンク全体に長時間放置しない（ステンレスの変色・腐食の原因）。
- 研磨は必ずステンレスのヘアライン方向（縦方向）で行う。円を描いて研磨すると研磨ムラが目立つ。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 薬剤の順序 | 塩素系→水洗い→酸性の順序を守る | 塩素系と酸性を同時に使用 → 有毒ガス発生 |
| ステンレス研磨 | ヘアライン方向（縦一方向）で研磨 | 円を描いて研磨 → 研磨ムラ・光沢不均一 |
| 仕上がり | 水滴なし・光沢均一・ぬめりなし | 水滴が残っている・ぬめりが残っている |

### プロのコツ

- 「排水口にCHEM-006を入れて放置する→その間にシンク・蛇口を洗う」の並行作業で時間を節約する。
- 蛇口根元の水アカは「CHEM-005を含ませたキッチンペーパーを巻き付けてパック」する方法が効果的（薬剤が乾かず長時間接触できる）。

# 12. よくある失敗と対策

| 失敗 | 原因 | 改善方法 | 防止策 |
|------|------|---------|--------|
| 油汚れが残る | 放置時間不足・薬剤濃度不足 | 濃度を上げて再塗布・放置時間を延ばす | 通常3〜5分・重度5〜10分の放置を守る |

# 14. 安全管理

## 転倒防止

- 床の水滴をこまめに拭く
- 養生シートはテープで確実に固定する
- 床が濡れているときは移動を最小限にする

## 感電防止

- スイッチ・コンセントに直接スプレーしない（クロスに含ませて使用）
- 照明カバーは電源OFFを確認してから取り外す
- 電子レンジ・冷蔵庫の周辺は水分を最小限にする

## 薬剤管理

- 酸性洗剤（CHEM-005）と塩素系漂白剤（CHEM-006）を絶対に混合しない
- 薬剤使用中は換気を維持する
- 薬剤ラベルを確認してから使用する

## 火傷・熱傷防止

- コンロが熱い状態では作業しない（触れて冷えていることを確認）
- つけ置きのお湯は70℃超えにしない（沸騰直後の湯を使用しない）

## 緊急時対応

| 事故 | 対応 |
|------|------|
| 薬剤が目に入った | その場で15分以上水洗眼。医療機関受診。 |
| 薬剤が皮膚に付いた | 流水で15分以上洗浄。 |
| 有毒ガス発生（塩素混合） | 即座に換気・退避。全員に知らせる。119番。 |
| ガス漏れ | 元栓を閉める→窓を開けて換気→点火源（電気スイッチ含む）に触れない→屋外に退避→119番。 |
| コンロが点火しない（施工後） | ガス漏れではないことを確認→点火部の水分を乾燥させてから再試験。 |
| 切創（一枚刃・金属部品） | 出血を止める→応急処置→責任者へ報告→医療機関受診。 |
| 転倒 | 応急処置→責任者へ報告→必要に応じ受診。 |

# 20. 教育ポイント（新人向け）

## 最初に覚えること（優先順）

1. **ガス元栓OFFと薬剤混合禁止**（最重要安全事項）
2. 「上から下へ・奥から手前へ」の施工順序の理由
3. 薬剤の種類と汚れの対応（油汚れ→アルカリ / 水垢→酸性 / ぬめり→塩素）
4. つけ置きを最初に開始して並行作業する時間管理
5. 一枚刃の正しい使い方（角度・湿潤状態・一方向・使用禁止素材）

## 新人が失敗しやすいポイント

| 失敗 | 防止策 |
|------|--------|
| 酸性と塩素を混合 | 「使う前に必ず確認する。CHEM-005とCHEM-006は絶対に同時に使わない」を徹底 |
| IHガラスに一枚刃で傷 | 使用前に「これはIHか？ガスコンロか？」を必ず確認する |
| 洗剤残留 | 食品接触面は水拭きを2〜3回繰り返す |
| 五徳の塗装剥がし | 「削るのは最後の手段。つけ置き→ブラシの順番を守る」を意識する |
| コンロが点火しない | 点火部・センサーに薬剤が入らないよう施工範囲を意識する |

## 一人作業を許可する判断基準

以下を全て満たしていること（現場責任者が確認・許可）：

- 薬剤の種類・汚れの対応を正しく理解している
- 酸性洗剤と塩素系漂白剤を混合しないことを徹底できている
- 一枚刃の使用可能素材・禁止素材を理解している
- つけ置きと並行して他の工程を進められる時間管理ができる
- 品質確認方法（光・手触り・臭気）を理解している
