# グリストラップ清掃 詳細作業手順②〜⑤

**対象：日常・週次清掃の詳細手順（グリストラップ清掃 SOP 工程②〜⑤）**

---

## 工程②　浮上油回収（日常清掃）

**目安時間：約5〜10分　必要人数：1名　頻度：毎日**

### 目的

第2槽の水面に浮遊する油脂（スカム）を回収し、油脂層の蓄積を防ぐ。油脂を放置すると腐敗して悪臭・害虫発生の原因となり、仕切板やトラップ管に固着して排水機能を低下させる。

### 使用道具

TOOL-002（油回収ひしゃく）/ TOOL-012（吸油シート）/ TOOL-001（産業廃棄物用バケツ）/ TOOL-013（産業廃棄物用ゴミ袋）

### 使用薬剤

通常は使用しない。固着油脂がある場合のみCHEM-001（アルカリ性洗剤・50倍希釈）を使用。

### 手順

1. 第2槽の蓋を開放する。
2. 投光器（TOOL-016）で槽内の浮上油の量・状態を確認する。
3. 油回収ひしゃくを水面に対して**水平**に差し込む。水面より約1〜2cm深い位置でひしゃくを水平に保ちながらゆっくり前方へ移動させ、油脂層だけをすくい取る（水は一緒にすくわない）。
4. ひしゃくを産業廃棄物用バケツの上に持ってきてゆっくり傾け、油脂を回収する。
5. 手順3〜4を繰り返し、水面の油脂を全て回収する。
6. ひしゃくで回収できない薄い油膜には吸油シートを水面に広げ、10〜15秒後に引き上げて油脂を吸収させる。
7. 固着した油脂がある場合は、スクレーパーを約30〜45度に当ててゆっくり剥離し回収する。
8. 回収した油脂は産業廃棄物として適正処理する（排水管・ゴミ箱への廃棄は法律違反）。
9. 周辺の床・蓋に油が飛散した場合は直ちにウエスで拭き取る（転倒リスク）。

**【写真⑤：浮上油回収前（油脂量確認）】**

**【写真⑥：浮上油回収後（油脂なし確認）】**

### 注意事項

- 油脂を排水に流さない（環境汚染・下水道法違反）。
- 槽内を大きくかき混ぜない（油脂が水中へ混入し回収が困難になる）。
- 回収した油脂は産業廃棄物として処理する（一般ゴミへの混入禁止）。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| ひしゃく操作 | 水平に差し込み・水をすくわず油脂層のみ回収 | 縦に差し込む・水ごとすくう → 回収量が少ない |
| 油膜 | 吸油シートで処理済み・水面に油膜なし | 薄い油膜が残っている → 悪臭・害虫の原因 |
| 廃棄物 | 産業廃棄物として適正処理 | 排水管へ流した → 環境汚染・法令違反 |

### プロのコツ

- 「ひしゃくを水面に浮かせるように静かに操作する」のが基本。力任せに動かすと油脂が水中へ混ざってしまい回収できなくなる。
- 油脂量が多い日（揚げ物が多い日の翌日など）は、回収回数を増やす（1日2〜3回）と蓄積を防げる。

## 工程③　沈殿物回収（週次清掃）

**目安時間：約15〜20分　必要人数：1〜2名　頻度：週1回以上**

### 目的

底部に蓄積した食品残渣・ヘドロ・汚泥を回収する。沈殿物が蓄積すると腐敗・悪臭・排水詰まりの原因となる。ヘドロは重さで底部全体に広がるため、放置するほど除去に時間がかかる。

### 使用道具

TOOL-003（汚泥スコップ・長柄）/ TOOL-005（ケレン棒・長柄）/ TOOL-001（産業廃棄物用バケツ）/ TOOL-016（投光器）

### 使用薬剤

通常は使用しない。固着汚泥がある場合のみCHEM-001（30〜50倍希釈）を塗布して5〜10分放置後に除去する。

### 手順

1. 工程②の浮上油回収を先に完了させてから実施する（浮上油回収が先）。
2. 投光器で槽内の底部を照らし、沈殿物の量・場所を確認する。
3. スコップを底面に対して平行に差し込み、底面から2〜3cm浮かせながら手前（出口方向）へゆっくり5〜10cm/秒の速度で移動させてヘドロを掻き集める。
4. 掻き集めたヘドロをスコップで掬い上げ、産業廃棄物用バケツへ回収する。
5. 底部四隅（角の部分）は汚泥が最も多い。角から中央へ寄せるように回収する。
6. バッフル（仕切板）の下側も汚泥が蓄積しやすい。スコップをバッフルの下に差し込んで回収する。
7. 排水口周辺は特に重点的に回収する（詰まりの原因になりやすい）。
8. 全ての沈殿物が回収されていることを投光器で確認する。
9. 回収した汚泥は産業廃棄物として適正処理する。

**【写真⑦：底部沈殿物（回収前）】**

**【写真⑧：底部（回収後・清掃状態確認）】**

### 注意事項

- 汚泥を排水管に流さない（詰まりの原因・環境汚染）。
- スコップで底面・壁面・仕切板を強く叩かない（FRP・ステンレスの損傷原因）。
- 槽内の水量を70%以上一度に除去しない（トラップ管のシール水が消えると悪臭が漏れる）。

### OK例 / NG例

| | OK | NG |
|---|───|---|
| スコップ操作 | 底面から2〜3cm浮かせて移動・5〜10cm/秒 | 底面を強く擦る → FRP傷・底面損傷 |
| 四隅 | 四隅・仕切板下・排水口周辺を重点回収 | 中央だけ回収・四隅を見落とし |
| 完了確認 | 投光器で底部全体に残留なし | 目視のみ・暗い部分を見落とし |

### プロのコツ

- スコップは「押す」より「引く」操作の方が汚泥を効率よく回収できる。
- ヘドロが蓄積して除去しにくい場合は、CHEM-001（30倍希釈）を底部に塗布して10分放置すると軟化して回収しやすくなる。

## 工程④　仕切板（バッフル）洗浄（週次清掃）

**目安時間：約10〜15分　必要人数：1名　頻度：週1回以上**

### 目的

仕切板に付着した油脂・ぬめり・食品残渣を除去する。仕切板は油脂が流れ出ないよう分離する設備なので、油脂が付着したまま放置すると分離機能が低下する。

### 使用道具

TOOL-007（ハンドブラシ）/ TOOL-006（ナイロンブラシ）/ TOOL-009（スポンジ）/ TOOL-010（クロス）/ TOOL-001（バケツ）

### 使用薬剤

CHEM-001（アルカリ性洗剤）30〜50倍希釈

| 汚れ | 希釈倍率 | 放置時間 |
|------|---------|---------|
| 軽度（ぬめり・薄い油脂） | 50〜100倍 | 3〜5分 |
| 通常（固着油脂） | 30〜50倍 | 5〜10分 |
| 重度（長期固着） | 10〜20倍 | 10〜20分 |

### 手順

1. 仕切板の取り外し方向を確認する（向きを写真撮影してから外す）。

**【写真⑨：仕切板取り外し前（向き・設置位置確認）】**

2. 仕切板をゆっくり引き上げて取り外す。急に引き上げると汚水が飛散する。
3. CHEM-001希釈液を仕切板全面に散布する。
4. 放置時間を守る（上表参照）。
5. ハンドブラシで**表裏両面**を洗浄する。上下方向・左右方向を交互に動かす（円を描かない）。力は約400〜500g程度。
6. 溝・継ぎ目・下端部を重点的にブラッシングする（油脂が最も固着しやすい箇所）。
7. 清水で30秒以上すすぐ（泡が出なくなるまで）。
8. 破損・変形・腐食がないか確認する。異常があれば報告する。
9. 正しい向きで確実に設置する（取り外し前の写真と照合する）。

**【写真⑩：仕切板洗浄後】**

### 注意事項

- 無理に曲げない（変形すると設置できなくなる）。
- 向きを間違えて設置しない（正しい向きでないと油脂分離機能が働かない）。
- 復旧を忘れない（仕切板なしで使用すると第1槽の食品残渣が直接排水へ流れる）。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 洗浄 | 表裏両面・溝・下端まで洗浄済み | 表面だけ洗浄・裏面を見落とし |
| すすぎ | 泡が出なくなるまで30秒以上すすぎ | 1〜2回だけすすぎ → 洗剤残留 |
| 設置 | 写真と照合して正しい向きで設置 | 向きが逆 → 油脂分離機能が低下 |

### プロのコツ

- 仕切板の下端は特に油脂が固着しやすい。ブラシの毛先を下端に押し付けるように当てると除去しやすい。
- 重度の固着油脂はバケツのCHEM-002希釈液に15〜30分つけ置きしてからブラッシングすると効率的。

## 工程⑤　トラップ管洗浄（週次清掃）

**目安時間：約10〜15分　必要人数：1名　頻度：週1回以上**

### 目的

トラップ管内部の油脂・汚泥を除去し、排水能力を維持する。トラップ管は第2槽から清浄な水だけを第3槽へ送る仕組み（下から水が出て油脂は通らない構造）。詰まると排水不良・逆流の原因になる。

### 使用道具

TOOL-007（ハンドブラシ）/ TOOL-005（ケレン棒）/ TOOL-001（バケツ）/ TOOL-016（投光器）

### 使用薬剤

CHEM-001（アルカリ性洗剤）30〜50倍希釈。放置時間：5〜10分。

### 手順

1. トラップ管の取り外し方向・パッキン位置を確認する（パッキンを紛失しないよう注意）。

**【写真⑪：トラップ管取り外し前（パッキン確認）】**

2. トラップ管をゆっくり取り外す。
3. 投光器でトラップ管の内部を確認する（油脂・汚泥の付着状態を確認）。
4. CHEM-001希釈液をトラップ管の内部・外部に塗布する。放置時間：5〜10分。
5. ブラシをトラップ管の内部へ差し込む。押し込むだけでなく、**回転させながら引き抜く**（引き抜く動作で汚れを掻き出す）。3〜5往復する。
6. 外部はハンドブラシで全面を洗浄する。
7. 配管接続部（油脂が最も固着しやすい箇所）を重点的に洗浄する。
8. ケレン棒で固着した油脂を剥離する（約30〜45度に当てて引く方向に動かす）。
9. 清水で30秒以上すすぐ。
10. 投光器で内部を確認し、閉塞・油脂残留がないことを確認する。
11. パッキンを正しい位置に当てて、トラップ管を元の位置へ取り付ける。
12. 取り付け後に周囲に清水を流し、漏水がないか確認する。

**【写真⑫：トラップ管洗浄後】**

### 注意事項

- パッキンを紛失しない（パッキンがないと漏水・排水不良の原因）。
- 配管接続部を傷付けない（FRP・ステンレスの損傷）。
- 復旧後に必ず漏水確認を行う（水を流して確認する）。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| ブラシ操作 | 回転させながら引き抜く・3〜5往復 | 押し込むだけ → 奥の汚れが残る |
| パッキン | 正しい位置で取り付け・漏水なし | パッキン忘れ・向きが逆 → 漏水 |
| 完了確認 | 投光器で内部確認・清水流して漏水なし | 目視のみ → 漏水を見落とし |

### プロのコツ

- ブラシは「押し込むより引く動作」で汚れを掻き出す。引き抜く時に回転させると管内壁の油脂が効率よく剥離できる。
- トラップ管を取り外したついでに、取り付け口周辺の固着油脂もケレン棒で除去しておく。次回の除去が楽になる。
