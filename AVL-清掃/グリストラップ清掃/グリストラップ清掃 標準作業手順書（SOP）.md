# グリストラップ清掃 SOP

**対象：グリストラップ全般（日常・週次清掃）**

---

# 1. 適用範囲

## 対象施設

- 飲食店 / ホテル厨房 / 社員食堂 / 病院給食室 / 介護施設 / 食品工場
- 学校給食施設 / 商業施設フードコート

## 対象設備・作業範囲

- 受けカゴ / 第1槽〜第3槽内部 / 仕切板（バッフル）/ トラップ管
- 槽内壁面 / 底部 / 蓋（ふた）/ 周辺床面

## 施工可能条件

| 条件 | 基準 |
|------|------|
| 換気 | 窓・換気扇による換気が確保できること。密閉空間は施工禁止 |
| 廃棄物処理 | 回収した油脂・汚泥の産業廃棄物処理業者が確認済みであること |
| 作業許可 | 厨房責任者から作業許可を得ていること |
| 水道 | 清水での洗浄・給水ができること |
| 排水 | 排水が流れる状態であること（完全閉塞時はバキューム対応） |
| 雨天・強風・直射日光 | 屋内設備のため天候不問（バキューム車使用時は屋外搬入経路の安全確認が必要） |
| 凍結 | 室内施設のため通常不問。屋外設置型は水道・排水管の凍結がないことを確認 |
| 感電リスク対策 | 電気設備・コンセントへ薬剤・汚水が飛散しないよう養生すること |
| 高所作業 | グリストラップは床面作業のため高所作業不要（蓋が2m超の高所にある場合は脚立必要） |
| 養生 | 周辺床面・排水管カバー・食品接触面への飛散防止養生が実施可能なこと |

## 施工不可条件

| 条件 | 理由 |
|------|------|
| ガス臭・異臭が強い（硫化水素の疑い） | 有毒ガス中毒リスク。換気後10分待っても改善しなければ作業中止 |
| 換気が確保できない密閉空間 | 薬剤蒸気・腐敗ガスの滞留で中毒リスク |
| 排水が完全閉塞している | 洗浄水の排水不可。バキューム車を先に手配する |
| 蓋・部品が著しく破損している | 作業前にお客様・管理者へ報告し修理後に施工 |

## 作業中止基準

以下を発見した場合は即時作業を停止し、施設責任者へ報告する。

| 発見内容 | 対応 |
|------|------|
| 硫化水素臭（腐った卵の臭い）が10分換気後も続く | 即時退避・専門業者へ連絡 |
| 薬剤が目・皮膚に付着 | 流水で15分以上洗浄・受診 |
| 蓋・壁面の破損を発見（施工中） | 作業中止・写真撮影・報告 |
| 排水が逆流し始めた | 作業中止・バキューム車手配 |
| 施設責任者から中止指示 | 即時中止 |

# 2. グリストラップの構造と汚れの種類

## グリストラップの構造

グリストラップは厨房排水から油脂・食品残渣を除去する排水設備。構造を理解してから清掃する。

```
厨房排水
    ↓
[受けカゴ]──→食品残渣をキャッチ
    ↓
[第1槽]──→大きな固形物が沈殿
    ↓（仕切板）
[第2槽]──→上層：油脂層（スカム）
         中層：汚水層
         下層：ヘドロ・沈殿層
    ↓（トラップ管：下から出水）
[第3槽]──→比較的清浄な水が排水へ
    ↓
排水管
```

**清掃のポイント：油脂は水より軽いので上に浮く（スカム）。ヘドロは重いので底に沈む。この性質を利用して上から順に回収する。**

## 主な汚れの種類

| 汚れ | 性質 | 対応薬剤 | 場所 |
|------|------|---------|------|
| 食用油・スカム（浮上油） | 水より軽い・上に浮く | 手回収（ひしゃく）→アルカリ洗剤 | 水面上層 |
| 食品残渣 | 固形物 | 手回収 | 受けカゴ・底部 |
| ヘドロ・汚泥 | 重い・底部に沈殿 | 手回収→高圧洗浄 | 底部 |
| ぬめり・バイオフィルム | 細菌の集まり | アルカリ洗剤+ブラッシング | 壁面・底面全体 |
| 固着油脂 | 酸化・固化した油 | アルカリ洗剤+ケレン | 壁面・仕切板 |
| カビ | 湿気+有機物 | アルカリ洗剤 | 蓋裏・壁面上部 |

# 4. 施工前確認

## 作業前確認事項

1. 厨房責任者へ作業開始を報告する。
2. 換気扇を起動し、窓・ドアを開けて十分な換気を確保する。
3. グリストラップ蓋を少し開けて内部のガス臭を確認する（硫化水素臭＝腐った卵の臭いがする場合は、換気を強化して10分待ってから作業開始。改善しない場合は作業中止）。
4. 受けカゴ・仕切板・トラップ管の位置と状態を確認する。
5. 排水が正常に流れているか確認する（詰まりがある場合は報告）。
6. 作業前写真を撮影する。

**【写真①：グリストラップ全景（作業前・蓋を開けた状態）】**

**【写真②：受けカゴ（汚れ状況）】**

**【写真③：槽内（浮上油・ヘドロの状況）】**

# 9. 詳細作業手順

---

## 工程①　受けカゴ清掃

**目安時間：約10〜15分　必要人数：1名　頻度：毎日**

### 目的

受けカゴ内に溜まった食品残渣・油脂を取り除き、排水詰まりと悪臭の発生を防ぐ。受けカゴが詰まると第1槽以降への流入が阻害され、厨房が排水逆流する。

### 使用道具

TOOL-001（バケツ）/ TOOL-007（ハンドブラシ）/ TOOL-004（スクレーパー）/ TOOL-013（産業廃棄物用ゴミ袋）

### 使用薬剤

CHEM-002（弱アルカリ性洗剤）50〜100倍希釈

### 手順

1. PPEを着用していることを確認する。
2. グリストラップ蓋を開放する（蓋は安全な場所に立て掛ける。落とすと破損・怪我の原因）。
3. 換気扇が動作していることを確認する。
4. 受けカゴをゆっくり持ち上げる（急に持ち上げると汚水が飛散する）。
5. バケツの上で受けカゴを傾け、内部の水分・食品残渣を10〜15秒かけてしっかり切る。
6. 食品残渣を産業廃棄物用ゴミ袋へ掻き出す（排水管には流さない）。
7. スクレーパーを約30〜45度に当てて、カゴ内面・メッシュの固着物を除去する（メッシュに対して平行に動かす）。
8. CHEM-002（50〜100倍希釈）を使ってハンドブラシで洗浄する。メッシュに対して縦・横両方向から当て、3〜5往復する（力：約400〜500g程度）。
9. カゴの裏面・ハンドル部分も洗浄する。
10. 清水で30秒以上すすぐ（泡が出なくなるまで）。
11. 受けカゴの破損・変形・腐食がないか確認する。異常があれば管理者へ報告する。
12. 元の位置へ確実に戻す（向きを間違えないよう注意する）。

**【写真④：受けカゴ洗浄後（汚れ除去確認）】**

### 注意事項

- 食品残渣・油脂を排水管に流さない（詰まりの原因）。
- カゴを落とさない（メッシュ変形・破損の原因）。
- 復旧を忘れない（カゴなしで厨房を使用すると食品残渣が槽内に大量流入する）。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 食品残渣 | 全て産業廃棄物袋へ回収・カゴ内なし | 排水管に流した → 詰まりの原因 |
| 洗浄 | カゴ全面（裏面含む）・メッシュ内部まで洗浄済み | 表面だけ洗浄・メッシュ目詰まりが残っている |
| 復旧 | 正しい向きで確実に設置 | 向きが逆・浮いている → 排水不良 |

### プロのコツ

- 受けカゴを持ち上げる前に「カゴの縁を2〜3回揺すって」食品残渣を中央に集めると、持ち上げた際の飛散が少なくなる。
- カゴのメッシュが黒く変色している（バイオフィルム）場合は、CHEM-001（50倍希釈）に5〜10分つけ置きしてからブラッシングすると除去しやすい。
