# グリストラップ 定期清掃（バキューム清掃）SOP

**対象：定期清掃（バキューム・高圧洗浄）**

---

# 10. 定期清掃（バキューム清掃）

## 作業目的

日常・週次清掃では除去できない油脂・ヘドロ・スカム・沈殿物・固着油脂を完全に除去し、グリストラップ本来の分離・排水性能を回復させる。

## 推奨頻度

| 施設 | 推奨頻度 |
|------|---------|
| 飲食店（揚げ物多） | 1〜2ヶ月毎 |
| 飲食店（一般） | 2〜3ヶ月毎 |
| ホテル厨房 | 1〜2ヶ月毎 |
| 大型施設・食品工場 | 毎月以上（施設基準による） |

※保健所指導・自治体条例に従い変更する。

## 作業人数

バキューム清掃：2〜4名（バキューム車オペレーター1名＋現場作業員1〜3名）

## 作業前手配確認

- □ バキューム車の手配完了
- □ 産業廃棄物処理業者への処理依頼完了
- □ 現場の入場許可取得
- □ 車両駐車スペースの確保

---

## 施工可能条件

| 条件 | 基準 |
|------|------|
| 換気 | 窓・換気扇による換気が確保できること（バキューム作業中も継続） |
| バキューム車 | 手配済みかつ作業場所への搬入経路が確保されていること |
| 廃棄物処理 | 産業廃棄物処理業者が確認済みであること |
| 作業許可 | 厨房責任者から作業許可を得ていること |
| 水道 | 高圧洗浄に必要な清水が確保できること |
| 雨天・強風 | 屋内設備のため天候不問。バキューム車の搬入経路が滑らない状態であること |
| 感電リスク対策 | 高圧洗浄時に電気設備・コンセントへ水が飛散しないよう養生すること |
| 養生 | 周辺床面・搬入経路への飛散防止養生が実施可能なこと |

## 施工不可条件

| 条件 | 理由 |
|------|------|
| ガス臭が改善しない（10分換気後も続く） | 硫化水素中毒リスク。即時退避・専門業者へ連絡 |
| バキューム車の駐車場所が確保できない | 作業前に確保してから施工 |
| 産業廃棄物処理業者が未確認 | 廃棄物の不法投棄につながる |

## 作業中止基準

| 発見内容 | 対応 |
|------|------|
| ガス臭が突然強くなった | 即時退避・換気・専門業者へ連絡 |
| 薬剤が目・皮膚に付着 | 流水で15分以上洗浄・受診 |
| バキューム車のホースが破裂・漏洩 | 作業中止・弁を閉める |
| 施設責任者から中止指示 | 即時中止 |

## 薬剤選択フロー

```
汚れを確認する
    ↓
バキューム吸引後の残留油脂・ぬめり・バイオフィルム
→ CHEM-001（アルカリ性洗剤）
    通常：30〜50倍／放置10〜15分
    重度：10〜20倍／放置15〜20分
    ↓
つけ置き部品・受けカゴ
→ CHEM-002（弱アルカリ性洗剤）50〜100倍／20〜30分
    ↓
素材確認（FRP・ステンレス・コンクリート）
→ アルミ部品はCHEM-001使用禁止（アルカリ腐食）
    ↓
施工開始
```

# 詳細作業手順

---

## 工程⑥　バキューム吸引

**目安時間：約30〜60分（槽の容量・汚染状況による）　必要人数：2〜3名**

### 目的

槽内に蓄積した全ての油脂・ヘドロ・汚泥・排水をバキューム車で完全に吸引回収する。ケレン・薬剤洗浄・高圧洗浄の前処理として実施する。

### 使用道具

バキューム車 / 吸引ホース / TOOL-016（投光器）/ TOOL-005（ケレン棒）/ TOOL-004（スクレーパー）

### 作業前確認

1. バキューム車を作業箇所に最も近い安全な場所に停車させる。
2. 周辺に養生シートを敷く（油脂・汚水の飛散防止）。
3. 周囲の立入禁止区域を設定し、第三者を立ち入らせない。
4. 全員のPPE着用を確認する。

**【写真⑬：バキューム清掃前・全景（作業前）】**

**【写真⑭：槽内状態（バキューム前・油脂・ヘドロ量確認）】**

### 手順

1. グリストラップの全蓋を開放する。
2. 吸引ホースを第2槽に挿入する。
3. **吸引順序：浮上油（上層）→ 中間層排水 → 底部ヘドロ（下層）の順で吸引する**（上から順番に吸引することで、底部の汚泥が舞い上がらない）。
4. ホースの先端を底面から**2〜3cm浮かせながら**、5〜10cm/秒の速度でゆっくり移動させる（底面に押し付けると詰まる）。
5. 四隅は汚泥が最も蓄積しているため、ホースをゆっくり移動させて重点的に吸引する。
6. 第1槽・第3槽も同様に吸引する。
7. 投光器で槽内を確認し、吸引残りがないかチェックする。
8. 全槽の吸引完了後、目視で底部・壁面に油脂・ヘドロが残っていないか確認する。

**【写真⑮：バキューム作業中（吸引状態）】**

### 注意事項

- バキューム車のホースが跳ね返る可能性がある。ホースを持ちながら作業する際は周囲に人がいないことを確認する。
- 吸引中はホースの先端が詰まっていないか確認する（吸引音が変わった場合は詰まりの可能性）。
- 電気設備・照明・コンセントへホースを向けない。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 吸引順序 | 上層から順に・底部ヘドロは最後 | 底部から先に吸引 → 汚泥が舞い上がり視認性低下 |
| ホース位置 | 底面から2〜3cm浮かせて移動 | 底面に押し付ける → ホース詰まり |
| 四隅 | 四隅を特に丁寧に吸引 | 中央だけ吸引・四隅を見落とし |

### プロのコツ

- ホースは「底面を滑らせる」のではなく、「水中を浮遊させながら動かす」イメージ。浮かせた状態の方がヘドロを効率よく吸引できる。
- 吸引効率が下がってきたら（音が変わった・流量が減った）、一度ホースを水に浸けてから再吸引する。

## 工程⑦　ケレン作業

**目安時間：約20〜40分（固着状況による）　必要人数：1〜2名**

### 目的

バキューム後も壁面・底部・仕切板に残る固着した油脂・ヘドロ・スケールをケレン棒・スクレーパーで物理的に除去する。薬剤洗浄の効果を高めるために先に固着物を剥離する。

### 使用道具

TOOL-005（長柄ケレン棒）/ TOOL-004（スクレーパー）/ TOOL-006（ナイロンブラシ硬め）/ TOOL-016（投光器）

### 使用薬剤

固着が非常に強い場合のみCHEM-001（10〜20倍希釈）を塗布して10〜15分放置してから施工する。

### 手順

1. 投光器で固着箇所を確認する。

**【写真⑯：ケレン作業前（固着油脂・ヘドロの状態）】**

2. ケレン棒を固着部分に対して**約30〜45度**に当てる。
3. **押す方向ではなく、引く方向**に力をかけて剥離する（引く方が効率的に剥離できる）。
4. 一度に大きく剥がそうとせず、固着部の端から少しずつ剥離する。
5. 底部四隅・壁面の角部・バッフル周辺を重点的に施工する。
6. ケレン棒で剥離した固着物はスクレーパーで掻き集め、バケツへ回収する（排水管に流さない）。
7. ブラシで剥離面を整える。上下・左右方向に3〜5往復する。
8. 剥離した油脂・固着物を産業廃棄物として回収する。

**【写真⑰：ケレン後（固着物除去確認）】**

### 注意事項

- FRP製グリストラップは傷が付きやすい。力任せに削らず、固着部を少しずつ丁寧に剥離する。
- ステンレス製は一方向のヘアライン方向に合わせてケレンする（横方向に傷を付けない）。
- ケレン棒を槽内に落とさないよう、ストラップで体に繋いでおく。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| ケレン方向 | 引く方向に動かす・30〜45度の角度 | 力任せに押す → 素材に傷 |
| FRP素材 | 10〜20cm²ずつ段階的に剥離 | 強く削る → FRPに傷・亀裂 |
| 固着物回収 | バケツへ回収 | 槽内に落としたまま放置 |

### プロのコツ

- 「ケレン棒はノミ」と同じ感覚で使う。叩くのではなく、固着部に刃を当てて「テコの原理」で剥がす。
- 固着が非常に硬い場合は無理に削らず、薬剤（CHEM-001・10〜20倍）を塗布して15分放置してから再施工する。

## 工程⑧　薬剤洗浄

**目安時間：約20〜40分（槽の大きさ・汚染による）　必要人数：1〜2名**

### 目的

ケレン後も残留する油脂・ぬめり・バイオフィルムを薬剤で分解・除去する。目に見えない細菌・バイオフィルムも除去することで、次回清掃までの汚染速度を遅らせる。

### 使用道具

TOOL-015（スプレーボトル）/ TOOL-009（スポンジ）/ TOOL-006（ナイロンブラシ硬め）/ TOOL-007（ハンドブラシ）/ TOOL-016（投光器）

### 使用薬剤

CHEM-001（アルカリ性洗剤）

| 汚れ状況 | 希釈倍率 | 放置時間 |
|---------|---------|---------|
| 通常汚れ | 30〜50倍 | 10〜15分 |
| 重度汚れ（定期清掃） | 10〜20倍 | 15〜20分 |

使用量：壁面1m²あたり約150〜250ml

### 手順

1. CHEM-001を規定倍率に希釈する（計量カップで正確に計量する）。
2. テスト施工：目立たない箇所（底部の角など）に薬剤を約5ml（コイン大）塗布し、素材に異常がないか30秒確認する。
3. 壁面**上部から下部**へ向けてCHEM-001を塗布する（一度に全体に塗布せず、一面ずつ施工することで乾燥を防ぐ）。
4. 底部へ塗布する。
5. 放置時間を守る（上表参照）。放置中に乾燥しそうな場合は追加塗布する。
6. ナイロンブラシで壁面を洗浄する。円を描かず、上下方向・左右方向を交互に3〜5往復する（力：約500〜700g程度）。
7. 底部をデッキブラシで洗浄する。四隅を重点施工する。
8. 仕切板・トラップ管周辺もハンドブラシで洗浄する。

**【写真⑱：薬剤洗浄中（施工状態）】**

### 注意事項

- **酸性洗剤との混合禁止**（有毒ガス発生）。
- 薬剤使用中は換気を維持する。換気扇が停止した場合は作業を一時中断する。
- 薬剤ラベルを事前確認し、保護具を着用する。
- 薬剤が皮膚・目に付いた場合：即座に清水で15分以上洗浄し、医療機関を受診する。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 塗布方法 | 上から下へ一面ずつ・乾燥前に施工 | 全面に一度に塗布 → 一部が乾燥して効果なし |
| 放置時間 | 規定時間を守る | 「だいたい」で判断 → 油脂除去不十分 |
| 換気 | 換気扇・窓が稼働中 | 密閉空間で施工 → 薬剤蒸気中毒リスク |

### プロのコツ

- ブラシは「円を描く」より「上下・左右を繰り返す」方が油脂除去効果が高い。円を描くと同じ部分を擦るだけで新しい面にアクセスできない。
- 薬剤の放置時間中に他の部品（受けカゴ・仕切板）を洗浄すると時間を効率的に使える。

## 工程⑨　高圧洗浄

**目安時間：約20〜40分（槽の大きさによる）　必要人数：2名（1名操作・1名監視）**

### 目的

薬剤洗浄後に残留する洗剤・油脂・剥離したヘドロを高圧洗浄機で洗い流す。手が届かない細部まで洗浄し、洗剤残留ゼロの状態にする。

### 使用道具

高圧洗浄機 / 洗浄ノズル / バキューム車（汚水吸引用）/ 養生シート / TOOL-016（投光器）

### 水圧の基準

| 素材 | 適正水圧 | ノズル距離 |
|------|---------|----------|
| FRP製グリストラップ | 5〜8MPa | 20〜30cm |
| ステンレス製 | 5〜10MPa | 15〜20cm |
| コンクリート製 | 8〜15MPa | 10〜20cm |

### 手順

1. 周辺の電気設備・照明・コンセントを養生する（養生なしに高圧洗浄機を使用しない）。
2. 作業区域の周辺に養生シートを敷く（汚水・薬剤飛散防止）。
3. 高圧洗浄は必ず**上部から下部**へ施工する（下から上に洗浄すると汚水が上に飛散する）。
4. ノズルを壁面に対して**約30〜45度**に当てる。垂直（90度）に当てると飛散が大きくなる。
5. 上部壁面から下部壁面へ向けて、ノズルを約10〜15cm/秒の速度で移動させながら洗浄する。
6. 四隅・継ぎ目・バッフル周辺を重点洗浄する（汚れが残りやすい箇所）。
7. 底部を洗浄する（四隅から中央へ向けて施工すると汚水が中央に集まりバキュームしやすい）。
8. 各部品（仕切板・受けカゴ）も洗浄する。
9. 汚水がたまった場合はバキューム車で吸引する。
10. 投光器で槽内全体を確認し、洗剤残留・油脂・ヘドロがないことを確認する。

**【写真⑲：高圧洗浄中（施工状態）】**

**【写真⑳：高圧洗浄後（槽内清潔状態確認）】**

### 注意事項

- **人にノズルを向けない**（重大事故）。
- 電気設備への直接噴射禁止（感電・故障リスク）。
- FRP素材に5MPa以上の高圧を近距離（10cm未満）で当てない（表面剥離リスク）。
- 高圧洗浄中は操作者・監視者の2名体制を維持する。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 施工順序 | 上から下へ・四隅を重点施工 | 下から上へ施工 → 汚水が上部に飛散 |
| ノズル角度 | 30〜45度に傾けて当てる | 90度（垂直）に当てる → 飛散が大きい |
| 安全管理 | 操作者・監視者2名体制 | 1名で作業・周囲に人がいる状態で作業 |

### プロのコツ

- 「四隅は十字に交差するように洗浄する」。縦方向と横方向の両方から当てると角部の汚れが残りにくい。
- 汚水がバキュームの追いつかない量になってきたら、高圧洗浄を一時停止してバキュームを先に実施する。

## 工程⑩　復旧作業

**目安時間：約15〜20分　必要人数：1〜2名**

### 目的

清掃した全部品を正しい位置・向きへ取り付け、正常運転状態へ復旧する。復旧ミスは排水不良・漏水・臭気の直接原因になる。

### 使用道具

TOOL-010（クロス）/ TOOL-007（ブラシ）/ 計量カップ

### 手順

1. 全部品が洗浄済みであることを確認する。
2. **トラップ管**を元の位置へ取り付ける（パッキンを忘れない・向きを確認）。
3. **仕切板**を正しい向きで取り付ける（取り外し前の写真を参照）。
4. **受けカゴ**を正しい向きで取り付ける。
5. 蓋を取り付ける前に、槽内に工具・ウエス等が残っていないか投光器で全確認する。
6. 清水を規定水位まで給水する（トラップ管の下端が水面下に沈む水位が目安）。
7. 厨房から水を流し、排水が正常に流れるか確認する。
8. 全ての接続部から漏水がないか確認する。
9. 蓋を取り付ける。
10. 周辺床面の油脂・汚水を清掃する。床面が乾燥していることを確認する。

**【写真㉑：全部品復旧後・槽内確認】**

**【写真㉒：周辺床清掃後・作業完了全景】**

### 注意事項

- 部品の向きを間違えて設置しない（機能しなくなる）。
- 工具・ウエスを槽内に忘れない（排水詰まりの原因）。
- 給水を忘れない（規定水位がないとトラップ管のシール水がなくなり悪臭が逆流する）。
- 復旧後は必ず実際に水を流して動作確認する。

### OK例 / NG例

| | OK | NG |
|---|---|---|
| 部品確認 | 全部品の向き・位置を写真と照合 | 感覚で設置 → 向きが逆・機能しない |
| 槽内確認 | 投光器で工具・ウエスなし確認 | 確認省略 → 工具が槽内に残留 → 詰まり |
| 動作確認 | 清水を流して排水・漏水を確認 | 確認なしで終了 → 漏水・詰まりを見落とし |

### プロのコツ

- 「部品ケースが空になったら復旧完了」のルールを守る。ケース内に部品が残っていれば付け忘れ。
- 蓋を閉める前に「投光器で槽内の全方向を確認」するのを習慣化する。工具忘れ防止の最終チェック。
