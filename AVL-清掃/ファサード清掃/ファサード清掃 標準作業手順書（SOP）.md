# ファサード清掃 標準作業手順書（SOP）

**対象：建物外壁・ファサード・外装設備**

---

# 1. 適用範囲

## 対象部位・施設

| 区分 | 対象 |
|---|---|
| 対象部位 | 外壁・ファサード・エントランス壁面・外装パネル・タイル壁・金属パネル・サイディング・コンクリート壁・化粧壁・外部柱・軒天・外部梁・外部意匠部 |
| 対象施設 | オフィスビル・商業施設・マンション・ホテル・医療施設・学校・工場・公共施設 |

※屋根・ガラス・看板・植栽は別SOPによる。

## 作業人数目安

| 作業内容 | 必要人数 |
|---|---|
| 低所清掃（地上2m以下） | 1〜2名 |
| 高所作業車使用 | 2〜3名（操作者1名＋安全監視員1名以上） |
| ロープアクセス | 2名以上（有資格者のみ） |
| 足場作業 | 2〜4名 |

## 作業時間目安

| 規模 | 目安 | 1人あたりの施工可能面積 |
|---|---|---|
| 小規模店舗（〜100m²） | 2〜4時間 | 50〜100m²/日 |
| 中規模施設（100〜500m²） | 4〜8時間 | 50〜100m²/日 |
| 大型施設（500m²超） | 1〜3日 | 50〜100m²/日 |

※汚染重度・高所作業の有無により1人あたり20〜50m²/日になる場合あり。

## 施工可能条件

| 条件 | 基準 |
|---|---|
| 天候 | 晴れ〜曇り（施工後2時間以内に雨の予報がある場合は延期） |
| 気温 | 5℃〜35℃ |
| 風速 | 5m/秒以下（高所作業は3m/秒以下。旗が軽くなびく程度が目安） |
| 凍結 | 外気温5℃以上かつ外壁・足場が凍結していないこと |
| 直射日光 | 気温35℃超の直射日光下は薬剤乾燥が速いため避ける。早朝・曇天を優先する |
| 水道 | 使用可能であること |
| 排水先 | 適切な排水経路が確保できること |
| 感電リスク対策 | 架空電線・電気設備から1m以上の距離を保てること。高所作業車が電線に近づかないこと |
| 高所作業 | フルハーネス・足場・高所作業車が適切に使用できること（高さ2m以上は必須） |
| 養生 | 車両・植栽・窓・電気設備への薬剤飛散防止養生が実施可能なこと |

## 施工不可条件

| 条件 | 理由 | 対応 |
|---|---|---|
| 雨・雷・強風（5m/秒超）・積雪・凍結 | 墜落・薬剤飛散・転倒リスク | 作業中止・延期 |
| 気温5℃未満 | 薬剤効果低下・路面凍結リスク | 作業中止・延期 |
| クラック幅0.3mm以上のひび割れ | 高圧洗浄で悪化する | 報告して指示を仰ぐ |
| シーリングの著しい劣化 | 洗浄水浸入リスク | 報告・その箇所への高圧洗浄は中止 |
| 打診で10cm×10cm以上の浮き | 施工中に剥落する危険 | 施工中止・報告 |
| 対象素材が不明 | 素材損傷リスク | テスト施工で確認してから実施 |
| 架空電線から1m未満の高所作業 | 感電・接触リスク | 電力会社へ連絡・安全距離確保後に施工 |

## 作業中止基準

以下を発見した場合は即時作業を停止し、管理者・施設担当者へ報告する。

| 発見内容 | 対応 |
|---|---|
| 風速が急変（高所作業中） | 即時降下・安全確保 |
| 雷鳴・落雷の兆候 | 即時降下・屋内退避 |
| 薬剤が目・皮膚に付着 | 流水で15分以上洗浄・受診 |
| 外壁の浮き・剥落を発見 | 即時中止・立入禁止・写真撮影・報告 |
| 高所作業機材の異常（脚立のぐらつき等） | 即時降下・機材交換後に再開 |
| 施設担当者から中止指示 | 即時中止 |

# 2. 汚れ別攻略表

**まずこの表で汚れを特定し、薬剤と工程を決めてから施工に入ること。複数の汚れが混在する場合は、カビ・藻除去を最初に行い、次に排気ガス・雨筋の順で施工する。**

| 汚れの種類 | 見た目の特徴 | 推奨薬剤 | 主な道具 | 希釈倍率 | 放置時間 | 注意点 |
|---|---|---|---|---|---|---|
| 排気ガス・黒ずみ | 壁面全体の黒っぽい汚れ（均一に広がる） | 弱アルカリ洗剤（CHEM-002） | フォームスプレー＋ナイロンブラシ | 30〜50倍 | 3〜5分 | アルミ・天然石・ステンレスに使用禁止 |
| 雨筋汚れ | 縦方向の黒・茶色い筋（雨の流れに沿う） | 外壁専用洗浄剤（CHEM-003） | フォームスプレー＋ナイロンブラシ | 20〜50倍 | 3〜10分 | 乾燥させない。縦方向にブラッシング |
| カビ・藻・苔 | 緑・黒・茶色の生物汚染（触るとぬるつく） | カビ・藻除去剤（CHEM-004） | フォームスプレー（放置メイン） | 10〜30倍 | 5〜15分 | 植栽への飛散注意。テスト施工必須 |
| 鳥糞 | 白・黄色のべたついた汚れ（点在する） | 鳥害除去剤（CHEM-005） | スプレー＋ソフトブラシ | 10〜20倍（乾燥糞は原液） | 3〜5分湿潤後 | 乾燥糞の直接除去禁止（病原菌飛散） |
| 手垢・土埃 | 茶色・グレーの薄い汚れ（全面に広がる） | 中性洗剤（CHEM-001） | スプレー＋ソフトブラシ | 50〜100倍 | 1〜3分 | 全素材に使用可。落ちなければ濃度を上げる |
| 油汚れ | ベタつき・光沢のある汚れ（飲食店周辺に多い） | 弱アルカリ洗剤（CHEM-002） | フォームスプレー＋ナイロンブラシ | 30〜50倍 | 3〜5分 | 温水があれば効果向上 |
| 水垢（ミネラル） | 白い輪状・うろこ状の汚れ（水が溜まる箇所） | 弱酸性洗剤（クエン酸系） | スプレー＋スポンジ | 10〜20倍 | 5〜10分 | 天然石・アルミ・ステンレスに使用禁止 |
| エフロレッセンス | 白い粉状・結晶状の汚れ（コンクリート目地） | 外壁専用洗浄剤（弱酸性） | スプレー＋ナイロンブラシ | 10〜20倍 | 5〜10分 | テスト施工必須。除去後に防水確認が必要な場合あり |
| 落書き（水性） | 塗料の跡（色は様々） | 弱アルカリ洗剤（CHEM-002） | スプレー＋ナイロンブラシ | 20〜30倍 | 3〜5分 | 乾燥すると落ちにくい。早期対応が重要 |
| シール・テープ跡 | べたつき・変色した跡 | アルコール系除去剤 | クロス | 原液 | 1〜2分 | 塗装面への長時間接触は塗装剥がれの原因 |

### 複数汚れが混在する場合の施工順序

```
カビ・藻・苔（CHEM-004）→ 放置・除去・すすぎ
　↓
排気ガス・黒ずみ・油汚れ（CHEM-002）→ 放置・ブラッシング・すすぎ
　↓
雨筋・長期付着汚れ（CHEM-003）→ 放置・ブラッシング・すすぎ
　↓
鳥糞（CHEM-005）→ 湿潤・除去・すすぎ
　↓
仕上げ（CHEM-001）→ 全体の仕上げ洗浄
```

## 薬剤選択フロー

```
外壁の汚れを確認する
　↓
緑・黒・茶色のぬるつく汚れ（カビ・藻・苔）
→ CHEM-004（カビ・藻除去剤）10〜30倍 / 5〜15分放置
　※テスト施工必須。植栽養生必須
　↓
黒・茶色い縦筋（雨筋）
→ CHEM-003（外壁専用洗浄剤）20〜50倍 / 3〜10分放置
　↓
全体的な黒ずみ・油汚れ（排気ガス）
→ CHEM-002（弱アルカリ洗剤）30〜50倍 / 3〜5分放置
　※アルミ・天然石・ステンレスに使用禁止
　↓
白い斑点（鳥糞）
→ CHEM-005（鳥害除去剤）10〜20倍 / 3〜5分放置
　※乾燥した鳥糞は水で5分以上湿潤してから除去
　↓
全素材共通の土埃・手垢（軽度汚れ）
→ CHEM-001（中性洗剤）50〜100倍 / 1〜3分放置
　↓
素材確認（アルミ・天然石・ステンレス）
→ CHEM-001のみ使用可。強アルカリ・強酸・研磨材禁止
　↓
施工開始
```

# 3. 使用保護具（PPE）

## 必須

□ 作業手袋（薬剤・濡れ・切創から手を保護）

□ 保護メガネ（薬剤噴霧・高圧洗浄時の飛散から目を保護。薬剤を使用する間は常時着用）

□ 防水安全靴（屋外洗浄での濡れ・滑り防止）

□ 防塵マスク（カビ・藻除去時・粉塵発生時）

□ 防水エプロン（高圧洗浄・大量薬剤使用時）

## 高所作業時 追加必須（高さ2m以上）

□ ヘルメット

□ フルハーネス型安全帯（高さ2m以上で必須）

□ 命綱・親綱（高所作業中は常に接続）

# 5. 使用薬剤一覧（AVL Facilities 推奨基準）

## CHEM-001　中性洗剤

| 項目 | 内容 |
|---|---|
| 液性 | 中性（pH 6〜8） |
| 使う理由 | 素材へのダメージが最も少なく、全素材に使用可能。軽度汚れの基本薬剤。汚れが落ちない場合のみCHEM-002へ切り替える |
| 対象汚れ | 手垢・土埃・軽度汚れ・ホコリ |
| 対象素材 | 塗装面・金属パネル・サイディング・ガラス周辺・樹脂部品・全素材 |
| 推奨希釈倍率 | 通常：100倍 / 重度：50倍 |
| 使用量目安 | 約100〜150ml/m² |
| 放置時間 | 1〜3分 |
| 使用できない素材 | 特になし |
| 注意事項 | 最初に試す薬剤。これで落ちない場合のみ強い薬剤に切り替える |

---

## CHEM-002　弱アルカリ洗剤

| 項目 | 内容 |
|---|---|
| 液性 | 弱アルカリ性（pH 8〜10） |
| 使う理由 | アルカリ成分が油分を鹸化（乳化）して汚れを浮かせる。排気ガス・油汚れには中性洗剤より格段に効果が高い |
| 対象汚れ | 排気ガス・油汚れ・黒ずみ・皮脂汚れ |
| 対象素材 | タイル・コンクリート・モルタル・塗装面（短時間のみ） |
| 推奨希釈倍率 | 通常：50倍 / 重度：30倍 |
| 使用量目安 | 約150〜200ml/m² |
| 放置時間 | 3〜5分 |
| 使用できない素材 | **アルミ（白化・腐食）・ステンレス（長時間接触禁止）・天然石** |
| 注意事項 | 放置時間を超えると素材ダメージが出る可能性あり。必ず時間を守る |

## CHEM-003　外壁専用洗浄剤（アルカリ系）

| 項目 | 内容 |
|---|---|
| 液性 | アルカリ性（pH 9〜12） |
| 使う理由 | ミネラル分・有機汚れ・長期付着汚れに対応した複合洗浄成分を含む。雨筋のように複数成分が混ざった汚れに最も効果的 |
| 対象汚れ | 雨筋汚れ・長期付着汚れ・外壁全般の黒ずみ |
| 対象素材 | タイル・コンクリート・モルタル |
| 推奨希釈倍率 | 通常：50倍 / 重度：20倍 |
| 使用量目安 | 約150〜250ml/m² |
| 放置時間 | 3〜10分（重度汚れは10分） |
| 使用できない素材 | **天然石・アルミ・ステンレス・塗装面（変色・腐食リスク）** |
| 注意事項 | 乾燥させない。放置中も2〜3分ごとに追い噴霧で湿潤を維持する |

---

## CHEM-004　カビ・藻除去剤

| 項目 | 内容 |
|---|---|
| 液性 | アルカリ性〜中性 |
| 使う理由 | カビの菌糸・藻の細胞壁を分解する成分を含む。ブラッシングだけでは菌糸の根が残り再発する。薬剤で根から分解することが必要 |
| 対象汚れ | カビ・藻・苔・地衣類・生物汚染 |
| 対象素材 | コンクリート・モルタル・タイル目地 |
| 推奨希釈倍率 | 通常：30倍 / 重度：10倍 |
| 使用量目安 | 約150〜300ml/m²（泡が5〜10mm程度立つ量） |
| 放置時間 | 5〜15分（藻・苔が重度の場合は15分。乾燥したら追い噴霧） |
| 使用できない素材 | **天然石・金属パネル・塗装面（必ずテスト施工を実施）** |
| 注意事項 | 必ず目立たない場所でテスト施工を実施してから本施工。植栽への飛散を防ぐため養生を徹底する |

---

## CHEM-005　鳥害除去剤

| 項目 | 内容 |
|---|---|
| 液性 | 中性〜弱アルカリ性（pH 7〜9） |
| 使う理由 | 鳥糞に含まれるタンパク質・尿酸を分解する成分を含む。乾燥した糞は固着しており、湿潤させることで除去しやすくなる |
| 対象汚れ | 鳥糞・羽毛・巣材 |
| 対象素材 | 外壁全般 |
| 推奨希釈倍率 | 通常：20倍 / 乾燥糞：原液 |
| 使用量目安 | 糞が完全に浸る量（約50〜100ml/箇所） |
| 放置時間 | 3〜5分湿潤後に除去 |
| 使用できない素材 | 天然石（テスト施工必須） |
| 注意事項 | **乾燥した鳥糞は直接除去禁止（病原菌飛散リスク）。必ず薬剤で湿潤させてから除去。除去後は必ず手洗い** |

## 施工の3大原則

1. **上から下へ**：常に上部から施工する。逆順は汚れを再付着させる
2. **1区画ずつ完結**：1〜2m²の区画で薬剤塗布→ブラッシング→すすぎを完結させる
3. **力ではなく薬剤を効かせる**：薬剤の化学的な力で汚れを浮かせ、物理力は補助として使う

## 区画割りの方法

施工前に建物の面を区画に分けて計画を立てる。

1. 建物の1面（例：正面）を幅1〜2m × 高さ1〜2mの区画に分ける。
2. 上部から下部へ、左から右（または右から左）へ順番に番号を振る。
3. 1区画ずつ工程5〜8を完結させてから次の区画へ移る。
4. 隣接区画との境目は**2〜3cmオーバーラップ**させて施工する（境目の筋防止）。

```

└────┴────┴────┘  ← 下段で完了

```

## 工程1　現地確認・区画割り・作業開始前点検

**目安時間：約15〜30分　必要人数：1〜2名**

### 何を行うか

外壁の状態・汚れの種類・施工不可箇所を把握し、区画割りを決め、薬剤・工具・施工方法を決定する。**ここで見落とした異常は施工後に拡大する。絶対に省略しない。**

### どこを確認するか

建物全外周・全面（上部〜下部）・軒天・目地・シーリング部・排水経路

### 施工順序

1. 建物全体を外周一周歩き、目視で外壁の状態を確認する。

2. 打診棒で外壁を**軽く**たたきながら移動する（約5cm間隔）。
   - 澄んだ音（コンコン）→ 正常
   - 濁音（ボコボコ・こもった音）→ 浮き・剥離の可能性あり。写真撮影・メモ

3. 以下を確認・記録する：
   - クラック（幅0.3mm以上＝施工中止基準）
   - シーリング劣化（亀裂・剥がれ・欠落）
   - 漏水跡（白いシミ・茶色い跡）
   - 錆汁・エフロレッセンス（白い結晶・茶色い筋）
   - 浮き・剥離

4. **「Section 2 汚れ別攻略表」**で汚れを特定し、使用薬剤を決定する。

5. 区画割りを決める（「Section 7 区画割りの方法」参照）。

6. 作業前写真を撮影する（建物全景・各面・汚染箇所・異常箇所の拡大）。

7. KY活動を実施する：危険箇所を口頭で確認する（転倒・墜落・薬剤飛散・感電）。

**【写真①：建物全景（作業前・正面）】**

**【写真②〜⑤：各面の汚染状況・異常箇所（拡大）】**

### 使用工具

TOOL-012（打診棒）/ TOOL-013（LEDライト）/ TOOL-018（カメラ）

### 施工中止・報告の判断基準

| 発見内容 | 対応 |
|---|---|
| クラック幅0.3mm以上のひび割れ | 施工中止。写真撮影して責任者へ報告 |
| 打診で10cm×10cm以上の浮き | 施工中止。写真撮影して責任者へ報告 |
| シーリング欠落が著しい | その箇所への高圧洗浄は中止。他の部位は施工可 |
| 施工前からの漏水跡・錆汁 | 写真撮影して報告。施工は続行可（記録として残す） |

### ⚠ 失敗しやすいポイント

- **打診棒を強くたたく** → 壁面を傷める。コツン・コツンと軽くたたくだけで音の違いはわかる。
- **上ばかり見て歩く** → 足元が見えず転倒する。視線は上（2秒）→正面（2秒）→足元（1秒）と交互に動かす。
- **写真撮影を後回しにする** → 施工後に「このキズは施工前からあったのか施工中についたのか」でトラブルになる。必ず最初に撮る。
- **汚れを目視だけで特定する** → 見た目が似ている汚れ（例：エフロと水垢）でも使う薬剤が違う。Section 2の攻略表で必ず確認する。

### 【プロのコツ】

- 打診棒を持たなくてもコインで軽くたたくと音の違いがわかる。
- 外周一周は「仕上がりをイメージしながら歩く」。汚れが多い箇所・落ちにくそうな箇所を先に把握しておくと薬剤の調製量と時間配分の見当がつく。
- LEDライトを壁面に対して30〜45°の斜光で当てると、通常の目視では見えない薄い汚れ・傷・ムラが見えやすい。確認に使う。

### 次工程へ進む判断

✅ 作業前写真撮影完了

✅ 外壁の状態・汚れの種類を把握済み（区画割り決定）

✅ KY実施完了

✅ 異常箇所の記録・報告完了（施工続行の判断あり）

→ 工程2へ進む

## 工程2　作業区域養生

**目安時間：約20〜40分　必要人数：1〜2名**

### 何を行うか

薬剤・水の飛散から、窓・電気設備・植栽・看板・通行人を守る。**養生が不完全だと設備損傷・植栽枯れ・通行人への薬傷が発生する。施工を守るだけでなく周囲を守るための最重要工程。**

### どこを養生するか

窓ガラス / ドア・インターホン・郵便受け / 電気設備・照明 / 看板 / エアコン室外機 / 植栽 / 作業真下の地面

### 施工順序

**① 区画設置（最初に行う）**

1. 作業範囲の外側最低1mにコーン・バリケードを設置する。
2. 現在の風向きを確認し、**下風側（薬剤が飛散する方向）**に養生範囲を広げる。風の向きが変わる場合は养生を追加する。

**② 設備の養生（上から順番に施工する）**

3. 窓ガラスをマスカーで養生する：
   - 手順：上端をテープで固定（約5cm幅で密着）→ 両側をテープで固定 → シートを下へ広げる → 下端・窓枠の隙間を養生テープで塞ぐ
   - テープと窓枠の間に隙間がないことを確認する（指で全周を押さえて確認）

4. ドア・インターホン・郵便受け・電気設備をマスカーで養生する。

5. 看板・照明器具をブルーシートで覆い、テープで四辺を固定する。

6. エアコン室外機をブルーシートで養生する（吸気口・排気口も覆う）。

**③ 植栽・地面の養生**

7. 植栽はブルーシートで全体を覆い、**四隅＋各辺中央の計8点以上**をテープまたは重石で固定する。
8. 施工面の真下の地面にブルーシートを敷く。汚水の排水経路を確認する。

### 使用工具

TOOL-014（マスカー）/ TOOL-015（養生テープ）/ TOOL-016（ブルーシート）/ TOOL-017（コーン・バリケード）

### ⚠ 失敗しやすいポイント

- **風向きを考えずに養生する** → 養生していない方向に薬剤が飛んで植栽・設備が汚染される。施工前に必ず風向きを確認する。
- **マスカーのシートが外側に広がる** → 貼り始める前に「シートがどちらに広がるか」を確認してから貼る。広がる方向を間違えると養生の意味がない。
- **ブルーシートを4点だけ固定する** → 中央がたるんで風で飛ぶ。必ず8点以上固定する。
- **養生テープを長時間放置する** → 粘着剤が壁面に残る。施工終了後2時間以内に撤去する。

### 【プロのコツ】

- 窓の養生は「上端→両側→下端」の順で貼ると隙間なく密着できる。
- 養生完了後、コップ1杯の水を養生面の上端にかけて水が漏れないか確認する。漏れる箇所があれば本施工前に補強する。
- 植栽のブルーシートは「根元から全体を覆う」。茎だけ覆っても根元から薬剤が入ると枯れる。

### 次工程へ進む判断

✅ コーン・バリケードが作業範囲の外側1m以上に設置されている

✅ 窓・ドア・電気設備・植栽・看板・地面の養生が完了している

✅ 通行人の安全な導線が確保されている

✅ 排水経路が確認されている

→ 工程3へ進む

## 工程3　テスト施工

**目安時間：約10〜20分　必要人数：1名**

### 何を行うか

使用する薬剤が対象素材に対して安全かどうかを、目立たない箇所で実際に施工して確認する。**全現場・全素材・全薬剤で必ず実施する。省略は素材損傷→補修費発生の直接原因。**

### どこで行うか

目立たない箇所（建物の隅・裏面・低所）の約30cm×30cmの面積

### 施工順序

1. 目立たない箇所を選ぶ（30cm×30cm程度）。

2. 使用予定の薬剤を本施工と**同じ希釈倍率**でスプレー塗布する（約30〜50ml）。

3. **本施工と同じ放置時間**を守る。

4. スポンジで軽くこする（約100〜200gの力）。

5. 清水ですすぐ。

6. **乾燥後5〜10分待ってから**以下を確認する（乾燥前は変化が見えにくい）：
   - 変色がないか（色が薄くなる・濃くなる・黄ばむ）
   - 白化がないか（白く曇る）
   - 艶の変化がないか（ツヤが出すぎる・消える）
   - 素材の溶解・腐食がないか（表面がざらつく・欠ける）

7. **異常がある場合** → 薬剤を変更する（50%薄める→再テスト→それでも異常なら別薬剤へ切り替え）。

8. 結果を写真に残す。

**【写真⑥：テスト施工箇所（施工前）】**

**【写真⑦：テスト施工箇所（乾燥後・5〜10分後）】**

### 使用工具

TOOL-004（スプレーボトル）/ TOOL-008（スポンジ）/ TOOL-018（カメラ）

### ⚠ 失敗しやすいポイント

- **「たぶん大丈夫」でテスト施工を省略する** → 素材損傷が発生する。絶対に省略しない。同じ素材でも劣化状態によって反応が異なる。
- **テスト施工直後に確認する** → 乾燥前は変化が見えない。5〜10分後に確認する。
- **本施工と違う希釈倍率でテストする** → 意味がない。本施工と完全に同じ条件でテストする。
- **1箇所だけでテストして終わり** → 日当たりの良い面と日陰の面で素材の劣化状態が異なる。両面でテストする。

### 【プロのコツ】

- テスト施工の結果は写真で残す。後でお客様から「変色したのでは？」と言われたとき証拠になる。
- LEDライトを30〜45°の斜光で当てて確認すると微妙な変化も見えやすい。
- 素材が不明な場合は必ずCHEM-001（中性洗剤）から試し始める。最も素材ダメージが少ない。

### 次工程へ進む判断

✅ テスト施工で変色・白化・艶変化・素材損傷がないことを確認

→ 工程4へ進む

❌ 異常が出た場合 → 薬剤を変更（まず50%薄める）→ 再テスト → 問題なければ工程4へ

## 工程4　予備散水

**目安時間：約10〜20分（規模による）　必要人数：1名**

### 何を行うか

外壁全体を清水で濡らし、①汚れを浮かせる　②薬剤の乾燥を防ぐ　③薬剤を均一に広げる　の3つの準備をする。

### どこを散水するか

施工予定面の全体（上部から下部へ。1面ずつ完結させる）

### 施工順序

1. 電気設備・看板の養生を指さし確認してから散水を開始する。

2. 散水ホースを使い、上部から下部へ向けて流水する。
   - 水圧：**0.3MPa以下の低圧・流水のみ**
   - 散水量目安：**約3〜5L/m²**
   - 散水速度：1m²あたり約10〜20秒かけて均一に濡らす

3. 壁面が均一に濡れた状態（水が壁面を均一に流れ落ちる状態）を確認する。

4. 乾いた面が残らないよう全面に散水する。

5. 散水中は周囲の地面に水が溜まらないよう排水経路を確認する。

### 使用工具

TOOL-002（散水ホース）

### ⚠ 失敗しやすいポイント

- **高圧で散水する** → 汚れを拡散させる・外壁を傷める。0.3MPa以下の低圧・流水のみ使用。
- **電気設備の養生確認前に散水する** → 感電・故障リスク。必ず養生を指さし確認してから開始。
- **下から上へ散水する** → 落とした汚れを引き上げてしまう。必ず上から下へ。

### 【プロのコツ】

- 予備散水でしっかり濡らすと薬剤が均一に広がり、放置時間を短縮できる。焦らず全面を濡らす。
- 直射日光が強い真夏の壁面は予備散水後すぐに乾く。薬剤塗布を素早く開始する（散水→30秒以内に薬剤塗布）。
- 予備散水中に「どの区画から施工を始めるか」最終確認をしておくと段取りがスムーズになる。

### 次工程へ進む判断

✅ 外壁全面が均一に湿潤している（乾いた箇所がない）

→ 工程5へ進む

## 工程5　薬剤希釈・塗布・作用時間

**目安時間：希釈5〜10分、塗布10〜20分/区画　必要人数：1〜2名**

### 何を行うか

対象汚れに適した薬剤を正しい濃度で区画ごとに均一に塗布し、汚れを浮かせる。

### どこを施工するか

工程1で決めた区画（1〜2m²）を上から下・左から右の順番で1区画ずつ

### 薬剤を選ぶ理由（汚れ別）

| 汚れの種類 | 使用薬剤 | 選ぶ理由 |
|---|---|---|
| 排気ガス・黒ずみ・油汚れ | 弱アルカリ洗剤（CHEM-002） | アルカリ成分が油分を鹸化（乳化）して汚れを浮かせる |
| 雨筋・長期付着汚れ | 外壁専用洗浄剤（CHEM-003） | ミネラル・有機汚れの複合成分に対応した洗浄力がある |
| カビ・藻・苔 | カビ・藻除去剤（CHEM-004） | 菌糸・細胞壁を分解する成分を含む。物理力だけでは菌糸の根が残って再発する |
| 鳥糞 | 鳥害除去剤（CHEM-005） | タンパク質・尿酸を分解する酵素・アルカリ成分を含む |
| 軽度汚れ全般 | 中性洗剤（CHEM-001） | 素材ダメージが最も少なく、全素材に使用可能 |
| 水垢・ミネラル | 弱酸性洗剤（クエン酸系） | 酸がミネラル成分（炭酸カルシウム等）を溶解する |

### 薬剤希釈の手順

1. バケツに水を先に入れる（薬剤を先に入れると泡立ちすぎる）。
2. **計量カップ**で薬剤を計量し、水に加える（目分量禁止）。
3. バケツを5〜10秒ゆっくりかき混ぜる（激しく混ぜると泡立ちすぎる）。
4. 混合した薬剤をフォームスプレーに移す。

### AVL推奨 希釈倍率・使用量・放置時間

| 薬剤 | 通常汚れ | 重度汚れ | 使用量目安 | 放置時間 |
|---|---|---|---|---|
| CHEM-001 中性洗剤 | 100倍 | 50倍 | 100〜150ml/m² | 1〜3分 |
| CHEM-002 弱アルカリ洗剤 | 50倍 | 30倍 | 150〜200ml/m² | 3〜5分 |
| CHEM-003 外壁専用洗浄剤 | 50倍 | 20倍 | 150〜250ml/m² | 3〜10分 |
| CHEM-004 カビ・藻除去剤 | 30倍 | 10倍 | 150〜300ml/m² | 5〜15分 |
| CHEM-005 鳥害除去剤 | 20倍 | 原液 | 50〜100ml/箇所 | 3〜5分 |

### 薬剤塗布の手順

1. 施工する区画（1〜2m²）の上端から塗布を開始する。

2. フォームスプレーを壁面から**20〜30cm**離し、壁面に対してノズルを垂直に向ける。

3. 上から下へ、左から右へ**ジグザグ（Z字状）**に移動しながら均一に噴射する。
   - 各パスの重なり幅：約5cm
   - 移動速度：約10〜15cm/秒
   - 泡の厚さが5〜10mm程度立つ量が適切

4. 区画全体に均一に泡が広がったことを確認する。

5. 放置時間中に薬剤が乾燥しそうな場合（泡の高さが1cm以下になったら）追い噴霧する。

6. 放置時間中は次の区画の準備（薬剤の希釈・道具の準備）または隣接区画の養生確認を行う。

### ⚠ 失敗しやすいポイント

- **一度に広範囲に塗布する** → 端が乾燥して白化・洗剤跡の原因になる。1〜2m²が絶対の上限。
- **希釈倍率を目分量で行う** → 濃すぎると素材損傷、薄すぎると汚れが落ちない。必ず計量カップで計量。
- **放置中に壁面が乾燥する** → 泡が消えて白化・洗剤跡になる。泡が1cm以下になったら追い噴霧。
- **酸性薬剤とアルカリ性薬剤を同じバケツで混ぜる** → 有害ガスが発生する。混合絶対禁止。

### 【プロのコツ】

- 重度汚れには「2段階施工」が効果的：1回目（通常濃度→5分→すすがず）→2回目（同じ薬剤→5分→ブラッシング→すすぎ）。放置時間を単純に延ばすより効果的。
- 日当たりが強い南面は乾燥が早い。薄めに複数回塗布するほうが効率が良い（1回多めより2回薄めのほうが均一に行き渡る）。
- 泡が消えかけたら乾燥サイン。追い噴霧のタイミングがわかる。

### 次工程へ進む判断

✅ 全区画に均一に薬剤が塗布されている

✅ 泡・湿潤状態が維持されている（泡の高さ1cm以上）

✅ 放置時間を守っている

→ 工程6へ進む

## 工程6　ブラッシング・スポンジ洗浄

**目安時間：約15〜30分/区画（1m²あたり約2〜3分）　必要人数：1〜2名**

### 何を行うか

薬剤で浮かせた汚れをブラシ・スポンジで物理的に除去する。**「力で擦る」のではなく「薬剤の力＋軽い物理力」が基本。力を入れすぎると素材を傷める。**

### 使用するブラシと力加減（素材別）

| 素材 | 使用ブラシ | 力加減 | 理由 |
|---|---|---|---|
| タイル・コンクリート | ナイロンブラシ（TOOL-005） | 約300〜500g | 硬い素材にはある程度の物理力が有効 |
| 塗装面・金属・サイディング | ソフトブラシ（TOOL-006） | 約200〜300g | 柔らかい素材への傷防止 |
| 地面・駐車場 | デッキブラシ（TOOL-007） | 約500〜800g | 広面積を効率よく施工するため |
| 目地・細部・角部 | ハンドブラシ | 約200〜300g | 細部は小さいブラシのほうが届きやすい |
| デリケート素材・精密部位 | スポンジ（TOOL-008） | 約100〜200g | 傷がつきにくい |

### ブラッシングの方向・ストローク（汚れ別）

| 汚れの種類 | 施工方向 | ストロークの長さ | 速度 |
|---|---|---|---|
| 軽度の汚れ・全般 | 円を描くように | 直径約20〜30cm | 1周約2〜3秒 |
| 雨筋汚れ | 縦方向（上から下） | 30〜40cm | 約2〜3秒/ストローク |
| 目地の汚れ | 目地の方向に沿って | 目地の長さに合わせて | 約2〜3秒/ストローク |
| 角部・コーナー | 斜め45°方向から施工 | 10〜15cm | ゆっくり（約3〜4秒/ストローク） |

### 施工順序

1. ブラシの**毛先のみ**が外壁に接触する程度の力で当てる（毛先が曲がるほど力をかけない）。

2. 汚れの種類に応じた方向・ストロークで施工する（上表参照）。

3. 汚れが浮いてくる（泡が茶色・黒くなる）のを確認しながら施工する。

4. 1箇所で30秒以上ブラッシングしても落ちない場合 → 薬剤を再塗布して放置時間を延ばす（力で続けない）。

5. スポンジを使う場合：水に十分浸してから（絞らない）、滑らせるように施工する。押し付けない。

6. 区画全体のブラッシングが完了したら、工程7（高圧洗浄）または工程8（すすぎ）へ進む。

### 使用工具

TOOL-005・006・007・008

### ⚠ 失敗しやすいポイント

- **「落ちない → 力を入れる」** → 素材を傷めて補修費が発生する。力ではなく薬剤を再塗布する。
- **金属ブラシを使う** → 素材に傷が入る。ナイロンブラシ・ソフトブラシのみ使用。
- **洗剤が乾燥した状態でブラッシングする** → 効果がなく傷の原因になる。乾燥したら追い噴霧してから再開。
- **角部を正面から押し付ける** → 角のブラシが潰れて素材に傷が入る。必ず斜め45°方向から施工する。

### 【プロのコツ】

- 「ブラシの毛先が曲がる力＝かけすぎ」と覚える。毛先がまっすぐな状態で当たっている力が適切。
- 雨筋は「縦方向に施工する」。横方向にすると横筋が残る。
- 汚れが落ちているかどうかは泡の色で判断できる。透明・白い泡なら洗剤のみ、茶・黒い泡なら汚れが溶け出している証拠。
- スポンジは使い捨てと思って惜しまずに交換する。硬くなったスポンジは傷の原因になる。

### 次工程へ進む判断

✅ 目視で汚れの8割以上が除去されている（残りはすすぎで流れる）

✅ 素材に傷・変色がない

→ 高圧洗浄が必要な場合は工程7へ / 不要な場合は工程8へ

## 工程7　高圧洗浄（必要時のみ）

**目安時間：約20〜40分/区画（1m²あたり約3〜5分）　必要人数：1〜2名**

### 何を行うか

ブラッシングで除去できない固着汚れを高圧水流で洗浄する。**素材が適合する場合のみ実施する。必ず工程6（ブラッシング）の後に行う。**

### 素材別 水圧・距離・角度の基準（AVL推奨）

| 素材 | 水圧 | ノズル距離 | ノズル角度 | 備考 |
|---|---|---|---|---|
| 磁器・せっ器タイル | 5〜8 MPa | 20〜30cm | 30〜45° | シーリング部を避ける |
| コンクリート・モルタル | 5〜10 MPa | 20〜30cm | 30〜45° | ひび割れ箇所を避ける |
| 窯業系サイディング | 2〜3 MPa | 30〜40cm | 30° | 原則禁止。必要時は低圧のみ |
| 金属パネル・アルミ | 2〜3 MPa | 30cm以上 | 30° | 腐食・変形注意 |
| 塗装面 | 2〜3 MPa | 30〜40cm | 30° | 塗膜状態を確認しながら施工 |
| 天然石・ガルバリウム鋼板 | **使用禁止** | — | — | 素材損傷リスク |

### ノズルの動かし方（重要）

```
【正しいノズルの動かし方】

左端から開始
→→→→→→→→ 右端まで移動（10〜15cm/秒）
←←←←←←←← 10cm下に移動して左端へ戻る（重なり幅10cm）
→→→→→→→→ 右端まで移動
  （繰り返す）

・一方向に10〜15cm/秒の一定速度で移動する
・次のラインへ移る際は10cmオーバーラップさせる
・一点で止まって噴射しない（素材が削れる）
```

### 施工順序

1. 高圧洗浄機を起動し、壁面以外へ向けて圧力・水の状態を確認する（圧力が安定してから壁面へ向ける）。

2. 上部から下部へ向けて施工する。

3. ノズルを壁面に対して**30〜45°の角度**に保つ（垂直にしない）。

4. ノズルを左右に**10〜15cm/秒の一定速度**で移動しながら施工する（上のノズル移動図を参照）。

5. 同一区画を2〜3パス繰り返す。すすぎ水が透明になったら完了。

### 禁止事項

- シーリング部への直接噴射禁止（シーリング破損・浸水の原因）
- 電気設備・窓枠への噴射禁止（感電・浸水の原因）
- 人に向けての噴射禁止（重傷事故の原因）
- 塗装面への一点集中噴射禁止（塗膜剥離の原因）
- 天然石・ガルバリウム鋼板への高圧洗浄禁止（素材損傷）

### ⚠ 失敗しやすいポイント

- **ノズルを一点に止めたまま噴射する** → 塗膜が剥がれる・素材が削れる。常に動かし続ける。
- **「近くすれば落ちる」と近づける** → 規定距離を守る。近すぎると素材が傷む。
- **ノズルを垂直（90°）に当てる** → シーリング・目地に直接水が入る。必ず30〜45°の角度を維持する。
- **前のラインと重ならない** → 洗い残しの筋が残る。必ず10cmオーバーラップさせる。

### 【プロのコツ】

- ノズルを動かす速度は「汚水の色」で調整する。濃い茶・黒い汚水が出ているうちは速度を遅めに、薄くなってきたら速度を上げてもよい。
- シーリングが劣化している箇所には、高圧洗浄機のホースを0.3MPa以下に落として散水ホースと同様に使う。
- 高圧洗浄後は必ず「ドレン・排水経路」を確認する。排水が詰まると施設の床・廊下が水浸しになる。

### 次工程へ進む判断

✅ 洗浄水が透明になっている

✅ 素材に傷・変形がない

→ 工程8へ進む

## 工程8　すすぎ洗浄

**目安時間：約10〜20分/区画　必要人数：1名**

### 何を行うか

薬剤・浮かせた汚れを完全に洗い流す。**すすぎ不足は洗剤跡・白化・変色の最も多い原因。「もう十分」と感じてからさらに1L/m²追加するくらいの感覚で施工する。**

### 施工順序

1. 散水ホース（0.3MPa以下の低圧）で上部から下部へ向けて流水する。

2. すすぎ量の目安：**5〜10L/m²**。
   - 目安として「1m²に約10〜20秒かけて流水する」を繰り返す
   - 合計2〜3パス行う

3. **すすぎ水の確認方法**：
   - 壁面を流れる水：白濁・泡が残っていれば継続
   - 地面に溜まった水：泡が出ていれば薬剤が残っている証拠
   - 壁面の臭い：薬剤の臭いが消えるまで継続

4. 目地・角部・凹部は薬剤が残りやすい。特に重点的にすすぐ。

5. すすぎ水が透明・無臭・泡なしになったことを確認して終了する。

### 使用工具

TOOL-002（散水ホース）

### ⚠ 失敗しやすいポイント

- **「ある程度流した」でやめる** → 洗剤跡が乾燥後に出る。すすぎ水が透明・無臭になるまで必ず継続。
- **下から上へすすぐ** → 落とした汚れを引き上げてしまう。必ず上から下へ。
- **直射日光下で乾燥が早い** → すすぎ量を1.5倍に増やす（夏季・南面で特に注意）。

### 【プロのコツ】

- すすぎ水が流れ落ちる**地面**を見ながら確認する。地面の水に泡が出ていれば薬剤がまだ残っている。
- 2名作業の場合：1人がすすぎをしながら、もう1人が次の区画の薬剤塗布を始めると時間を効率化できる。

### 次工程へ進む判断

✅ すすぎ水が透明・泡なし

✅ 壁面に薬剤の臭いがしない

✅ 地面に流れた水に泡が出ていない

→ 工程9へ進む

## 工程9　水滴除去・仕上げ拭き

**目安時間：約15〜30分（規模による）　必要人数：1〜2名**

### 何を行うか

すすぎ後の水滴を除去し、乾燥後の水垢・洗剤跡・ムラを防止する。

### どこを施工するか

すすぎ後の全壁面・目地・金属部・ガラス周辺。水が溜まりやすい窓枠下・庇の下端を重点的に施工する。

### 施工順序

1. マイクロファイバークロスを四つ折りにする（8面使える）。

2. **上部から下部へ、一方向に**拭く。拭き戻しをしない。
   - 移動速度：約20〜30cm/秒
   - 壁面に対してクロスを平行に当てる（斜めにしない）

3. クロスの一面が汚れたら折り返す。全面が汚れたら新しいクロスに交換する。

4. 水滴が残りやすい箇所を重点的に拭く：
   - 目地・角部（水が溜まりやすい）
   - 凹部・庇の下端（水が溜まりやすい）
   - 金属部（錆の原因になる）

5. 平滑なガラス周辺はスクイジーで水切りする：
   - 上から下へ**20〜30cm/秒**で動かす
   - 刃を壁面に対して90°に当てる
   - 各ストロークの始まりはクロスで拭いてから開始する

6. ガラスに飛散した水滴も除去する。

### 使用工具

TOOL-009（マイクロファイバークロス）/ TOOL-010（スクイジー・平滑面のみ）

### ⚠ 失敗しやすいポイント

- **汚れたクロスで拭き続ける** → 汚れを広げる。一面が汚れたらすぐ折り返す・交換する。
- **クロスを壁面に引きずる** → 素材傷・拭きムラの原因。滑らせるように動かす。
- **上向き・横向きで拭く** → 重力で水が下へ流れるので、必ず上から下への一方向で拭く。

### 【プロのコツ】

- クロスを「四つ折り」にすると8面使える。1面ずつ使い切ることで拭きムラを防ぐ。
- 乾きが早い夏季・南面は1〜2m²ごとに拭き上げながら進む。「全面すすぎ→全面拭き」ではなく「1区画すすぎ→1区画拭き」を繰り返す。
- 金属部は拭き上げた後、乾いた面のクロスで空拭きをすると錆防止になる。

### 次工程へ進む判断

✅ 水滴なし・洗剤残りなし・拭きムラなし・白化なし

→ 工程10へ進む

## 工程10　最終確認・作業後写真撮影

**目安時間：約10〜20分　必要人数：1名**

### 何を行うか

施工全体の仕上がりを確認し、不良箇所を発見して再施工する。

### 確認方法と見るべきポイント

| 確認方法 | 距離・角度 | 確認できること |
|---|---|---|
| 斜光（LEDライトを30〜45°で当てる） | 0.5〜1m | 汚れ残り・ブラシ跡・洗剤跡・素材の傷 |
| 遠目（建物から5m以上離れて） | 5m以上 | 光沢ムラ・色ムラ・洗浄ムラ・全体のバランス |
| 近距離（目視） | 0.5m以内 | 目地の汚れ残り・細部の拭き残し |

### 仕上がり判断基準

| 確認項目 | 合格基準 | 再施工の目安 |
|---|---|---|
| 汚れ残り | 目視で確認できる汚れがない | 指で触れて汚れが指に付く |
| 洗剤跡・白化 | 白いムラがない | 乾燥後に白い筋・白化が残っている |
| 光沢ムラ | 均一な仕上がり | 一部だけ光沢が違う |
| ブラシ跡 | 擦り跡がない | ブラシの筋が残っている |
| 素材へのダメージ | 傷・変色・塗膜剥離がない | 施工前になかった傷・変色がある |
| 周辺の飛散 | 窓・看板・植栽に汚れ・薬剤がない | 養生外に汚れ・薬剤が付着している |

**【写真⑧：建物全景（作業後・作業前と同じ位置・同じ角度）】**

**【写真⑨〜⑫：各面の仕上がり確認】**

### 使用工具

TOOL-013（LEDライト）/ TOOL-018（カメラ）

### ⚠ 失敗しやすいポイント

- **正面からしか確認しない** → 斜光・遠目・近距離の3方向から必ず確認する。
- **「きれいに見える」で終わる** → 「汚れを探す」つもりで確認する。厳しく確認するほど見落としがなくなる。

### 【プロのコツ】

- 晴天時は直射日光の反射で汚れが見えにくい。LEDライトの斜光か、日陰にして確認する。
- 作業前後の写真を並べてスマートフォンの画面でお客様に見せると「ビフォーアフター」で品質が伝わりやすい。

### 次工程へ進む判断

✅ 全確認項目が合格基準を満たしている

✅ 作業後写真撮影完了（作業前と同一アングル）

→ 工程11へ進む

## 工程11　養生撤去・現場復旧

**目安時間：約15〜20分　必要人数：1〜2名**

### 何を行うか

養生材を撤去し、作業前の状態へ完全に復旧する。

### 施工順序

1. **最終確認が完了してから**養生を撤去する（確認前に撤去しない）。

2. 養生テープを**壁面に対して15〜30°の鋭角**でゆっくり剥がす（速くひっぱると壁紙・塗装が剥がれる）。

3. マスカー・ブルーシートを折り畳んでゴミ袋に入れる（汚水が漏れないよう内側に折り込む）。

4. テープの粘着剤が壁面に残っていないか指で触れて確認する。残っている場合はアルコール系除去剤で拭き取る。

5. コーン・バリケードを撤去する。

6. 植栽の状態を確認する。薬剤が飛散していた場合は清水で**2〜3L/植栽**散水する。

7. 地面・周辺の汚れを確認し、汚れていれば清掃する。

8. 工具・資機材を全て確認し、忘れ物がないかチェックする。

### ⚠ 失敗しやすいポイント

- **テープを急いで引っ張る** → 壁紙・塗装が剥がれる。必ずゆっくり鋭角で剥がす。
- **養生撤去後に植栽確認を忘れる** → 薬剤が付着したまま放置すると枯れる。必ず確認して清水散水する。
- **汚水が入ったバケツを傾ける** → こぼすと地面が汚染される。バケツは垂直に保ちながら運ぶ。

### 【プロのコツ】

- 養生テープは「壁面に対して鋭い角度で引く」ほど剥がれにくい（壁紙・塗装を保護できる）。
- 剥がしたテープ・マスカーは「内側に丸めながら」ゴミ袋へ入れる。汚れが外に出ない。

### 完了基準

✅ 養生材の撤去・処分完了（テープ糊残りなし）

✅ 植栽・地面・周辺に問題がない（薬剤飛散があれば清水散水済み）

✅ 工具・資機材の忘れ物がない

# 10. よくある失敗と対策

| 失敗 | 原因 | 対処法 | 防止策 |
|---|---|---|---|
| 洗剤跡・白化が残る | すすぎ不足・薬剤の乾燥 | 清水で再すすぎ。しつこい跡は中性洗剤で再洗浄 | すすぎ水が透明になるまで継続。放置中は湿潤を維持 |
| 色ムラが出る | 区画施工の境目・乾燥ムラ | 境目を2〜3cmオーバーラップして再施工 | 隣接区画との境目を2〜3cmオーバーラップさせる |
| ブラシ傷がつく | 力を入れすぎ・素材に合わないブラシ | 補修費が発生する場合あり。責任者へ報告 | 毛先のみ接触する程度の力。素材に合ったブラシを選ぶ |
| 白化（素材が白くなる） | 薬剤選定ミス・放置時間超過 | 中性洗剤で拭き取り。改善しない場合は報告 | テスト施工を必ず実施。放置時間を守る |
| 塗膜剥離 | 高圧洗浄の水圧過多・塗膜劣化 | 剥がれた塗膜は報告。施工中止 | 適正圧力の厳守。施工前に塗膜状態を確認 |
| シーリング破損 | シーリングへの直接高圧噴射 | 報告。補修は別業者へ | シーリング部には高圧洗浄をしない |
| 植栽枯れ | 薬剤の大量付着 | 清水で大量散水（2〜3L/植栽）。回復しない場合は報告 | 植栽の養生を徹底。施工後に清水散水 |
| テープ剥がし後の糊残り | 長時間放置後に急いで剥がした | アルコール系除去剤で除去 | 施工終了後2時間以内に撤去。壁面に対して15〜30°の鋭角でゆっくり剥がす |
| 区画境目の洗い残し筋 | 隣接区画との境目を施工しなかった | 境目を再施工 | 隣接区画に2〜3cmオーバーラップして施工する |
| 高圧洗浄の筋が残る | ノズル移動速度が一定でない・停止した | 再度高圧洗浄で均一に施工 | 10〜15cm/秒の一定速度を維持。一点で止まらない |

# 11. 安全管理

## 感電防止

- 電気設備・コンセント・照明への薬剤・水の噴射禁止
- 濡れた手で電気設備に触れない
- 高圧洗浄機の電源ケーブルが水に浸からないよう確認する

## 転倒・墜落防止

- 脚立は水平な床に設置する。傾斜面・濡れた床での使用禁止
- 高さ2m以上の作業ではフルハーネス着用必須
- 床面の水をこまめに拭く（滑り防止）
- 作業区域に通行人を入れない

## 薬剤管理

- 酸性・アルカリ性・塩素系を混合禁止（有害ガス発生）
- 希釈倍率を厳守する
- 薬剤が目に入った場合：その場で15分以上流水で洗眼し、医療機関を受診する
- 薬剤が皮膚に付いた場合：流水で15分以上洗浄する

## 高所作業の安全

- 高所作業車の操作は有資格者のみ
- ロープアクセスは有資格者のみ（特別教育修了者）
- 工具・資機材の落下防止コードを使用する
- 作業半径内への第三者立入禁止

## 緊急時対応

| 事故 | 対応 |
|---|---|
| 感電 | 電源を遮断してから対応。感電者に直接触れない。119番通報 |
| 墜落 | 動かさない。119番通報。責任者へ報告 |
| 薬剤が目に入った | その場で15分以上流水洗眼。医療機関を受診 |
| 薬剤が皮膚に付いた | 流水で15分以上洗浄 |
| 高圧洗浄で怪我 | 傷の大小にかかわらず医療機関を受診。責任者へ報告 |
| 植栽・設備を損傷した | 施工を中止。写真撮影。責任者へ報告 |

## KYリスクアセスメント（作業開始前に全員で確認）

| 危険要因 | 想定される事故 | リスク | 予防対策 |
|---|---|---|---|
| 高所作業 | 墜落・骨折 | 高 | フルハーネス着用・命綱接続確認 |
| 濡れた床 | 転倒 | 中 | コーン設置・防水靴着用 |
| 薬剤の飛散 | 薬傷・眼障害 | 高 | 保護メガネ・手袋着用必須 |
| 高圧洗浄の飛散 | 対人事故・設備損傷 | 高 | 人に向けない・養生徹底 |
| 養生テープの剥がし | 壁紙・塗装剥がれ | 中 | 壁面に対して鋭角でゆっくり剥がす |
| 薬剤の混合 | 有害ガス発生 | 高 | 混合禁止を全員で確認 |

# 15. 新人教育ポイント

## 最初に覚えること（優先順）

| 優先度 | 覚えること | なぜ重要か |
|---|---|---|
| 1 | テスト施工を全現場・全素材で必ず実施する | 省略は素材損傷→補修費の直接原因 |
| 2 | 「上から下へ」の原則を守る | 逆順は落とした汚れを再付着させる |
| 3 | 薬剤は乾燥させない（放置中も追い噴霧） | 乾燥＝白化・洗剤跡の最多原因 |
| 4 | 力で擦らない。薬剤の力を引き出す | 力→素材損傷。薬剤→汚れが浮く |
| 5 | すすぎ水が透明になるまで必ずすすぐ | 途中でやめる＝洗剤跡が乾燥後に出る |
| 6 | 区画割りを先に決める | 無計画な施工はムラ・境目の失敗につながる |

## 新人が間違えやすいポイントと正しい対応

| 間違い | 正しい対応 | なぜそうするか |
|---|---|---|
| 「落ちない→力を入れる」 | 薬剤を追い塗布・放置時間を延ばす | 力は素材を傷める。汚れは薬剤で浮かせるもの |
| 広範囲に一度に薬剤を塗布する | 1〜2m²の区画ごとに完結させる | 端が乾燥して白化・洗剤跡になる |
| すすぎを途中でやめる | すすぎ水が透明になるまで継続 | 乾燥後に洗剤跡・白化が出る |
| 金属ブラシを使う | ナイロンブラシ・ソフトブラシのみ使用 | 金属ブラシは素材に傷を入れる |
| テスト施工を省く | 全現場・全素材で必ず実施 | 素材損傷リスクがある |
| 薬剤を乾燥させる | 泡が1cm以下になったら追い噴霧 | 乾燥＝白化・洗剤跡 |
| 希釈倍率を目分量で行う | 必ず計量カップで計量する | 濃すぎ→素材損傷、薄すぎ→汚れが落ちない |
| 養生を長時間放置する | 施工終了後2時間以内に撤去する | 長時間放置→粘着剤が壁面に残る |
| ノズルを一点に止めて噴射する | 常に10〜15cm/秒で移動し続ける | 一点集中噴射は素材を削る・塗膜が剥がれる |
| 区画の境目を施工しない | 隣接区画に2〜3cmオーバーラップして施工 | 境目に洗い残しの筋が残る |

## 独立施工を許可する基準（自己確認）

以下を全て自己確認できること：

- 外壁材の種類を見て適切な薬剤を選択できる
- テスト施工を正しく実施し結果を判断できる
- 希釈倍率・放置時間を正確に管理できる
- 高圧洗浄の水圧・距離・角度・移動速度を素材別に適正設定できる
- 安全管理（PPE着用・高所作業・薬剤取扱い）を遵守できる
- 区画割りを自分で決めて施工計画を立てられる

## 早めの施工を推奨するケース

- カビ・藻が目視で確認できる（放置すると建材が腐食する）
- 雨筋汚れが著しくなっている
- クラック・シーリング劣化が発見された（施工前に補修が必要）
- 鳥害が多発している
