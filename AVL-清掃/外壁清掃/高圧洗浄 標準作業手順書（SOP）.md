# 高圧洗浄 標準作業手順書（SOP）

**対象：高圧洗浄機を使用した外壁・床・外構の洗浄**

---

# 1. 適用範囲

## 対象施設・部位

| 区分 | 対象 |
|---|---|
| 対象施設 | 戸建住宅・マンション・アパート・商業施設・オフィスビル・工場・倉庫 |
| 対象部位 | 外壁・タイル・土間・駐車場・通路・階段・外構・フェンス・ブロック塀・ベランダ床 |

## 施工可能条件

| 条件 | 基準 |
|---|---|
| 天候 | 晴れ〜曇り（雨・強風・雷は中止。施工後1時間以内に雨の予報は延期） |
| 気温 | 5℃〜35℃ |
| 凍結 | 外気温5℃以上かつ路面・外壁が凍結していないこと |
| 風速 | 3m/秒以下（高圧洗浄水の飛散防止のため） |
| 直射日光 | 気温35℃超は早朝・曇天を優先 |
| 水道 | 使用可能であること |
| 電源 | 漏電遮断器の使用が確保できること |
| 感電リスク対策 | 電気設備・屋外コンセントへの高圧洗浄水の飛散を養生で防ぐこと |
| 高所作業 | 高所での高圧洗浄は必ずフルハーネスまたは安全な足場を確保すること |
| 排水 | 高圧洗浄で発生する汚水が適切に排水できること |
| 養生 | 車両・植栽・窓・電気設備への水・薬剤飛散防止養生が実施可能なこと |

## 作業中止基準

| 発見内容 | 対応 |
|---|---|
| 風速が急変（3m/s超） | 即時作業中止 |
| クラック・シーリング劣化を発見（施工中） | その部位の高圧洗浄を中止・報告 |
| 薬剤・汚水が目・皮膚に付着 | 流水で15分以上洗浄・受診 |
| 高圧洗浄機のホース破損・漏洩 | 電源遮断・作業中止 |
| 感電症状（スパーク・しびれ） | 電源遮断・119番通報 |
| 施設担当者から中止指示 | 即時中止 |

## 高圧洗浄 絶対禁止箇所

以下への高圧洗浄は禁止する。

| 禁止箇所 | 理由 |
|---|---|
| コーキング部 | 直接噴射でコーキングが破損し浸水する |
| 劣化した塗膜・剥離部 | 塗膜が大面積で剥がれる |
| 木部外壁 | 素材を傷める・専門業者対応 |
| 漆喰 | 素材が溶ける |
| 深いクラック（0.3mm以上） | 水が内部に侵入して劣化が進む |
| ALC外壁 | 高吸水性のため水が浸入して変形・剥落 |
| 電気設備・換気口内部 | 感電・設備損傷 |
| インターホン・防犯カメラ | 浸水による故障 |
| 人への噴射 | 高圧水による重傷事故 |

## 薬剤選択フロー

```
汚れを確認する
　↓
土埃・砂埃・軽度汚れ
→ 水のみで高圧洗浄（薬剤不要）
　まず水だけで試してから薬剤使用を判断する
　↓
落ちない場合（排気ガス・黒ずみ・雨だれ・油・タイヤ跡）
→ CHEM-001（弱アルカリ洗剤）30〜50倍を先塗布→放置3〜5分→高圧洗浄
　※アルミ・金属外壁・ALCに使用禁止
　↓
カビ・コケ（黒・緑の斑点）
→ CHEM-002（カビ除去剤）10〜30倍を先塗布→放置5〜15分→高圧洗浄
　※テスト施工必須。植栽養生必須
　↓
素材確認（外壁・床の素材で水圧を設定）
→ タイル・コンクリート：5〜10 MPa
→ サイディング：2〜3 MPa
→ ALC：高圧洗浄禁止
→ コーキング部：高圧洗浄禁止
　↓
施工開始（上から下・50〜60cm/秒・ノズル距離20〜30cm）
```

# 7. 高圧洗浄機の設置・準備手順

## 機械設置の順序

1. 設置場所を確認する（水平な床・電源コードの届く範囲・水道の近く）。
2. 延長コードと漏電遮断器を接続する。**漏電遮断器を先に電源に差し込む（漏電遮断器なしで高圧洗浄機を使用しない）。**
3. 散水ホースを高圧洗浄機の給水口に接続する。
4. 高圧ホースを本体に接続する（カチッとロック音がするまで押し込む）。
5. 使用するノズルをガンに取り付ける（ノズルも「カチッ」と音がするまで）。
6. 散水ホースの水を先に開く（給水を確保してから電源を入れる）。
7. 電源を入れる前に、ガンを壁面以外の安全な方向に向ける。
8. 電源を入れて試運転する：ガンのトリガーを引いて圧力・噴霧状態を確認する。
9. 水漏れがないことを確認してから本作業を開始する。

### ⚠ 起動時の失敗しやすいポイント

- **水を先に出さずに電源を入れる** → ポンプが空回りして故障する。必ず給水→電源の順番
- **ノズルが正しく装着されていない** → ノズルが飛んで重傷事故になる
- **漏電遮断器なしで使用する** → 感電事故の最多原因

# 10. 詳細作業手順

---

## 工程1　現地確認・養生・KY

**目安時間：約20〜40分　必要人数：1〜2名**

### 施工順序

1. 建物を一周して外壁の状態を確認する（クラック・コーキング劣化・塗膜状態・ALC外壁）。
2. 高圧洗浄禁止箇所をマーキングまたはメモして作業者全員で共有する。
3. 養生を実施する（窓・電気設備・植栽・車両・コーキング部）。
4. 排水経路を確認する（高圧洗浄は大量の汚水が発生する）。
5. 作業前写真を撮影する。
6. KY活動を実施する（感電・転落・飛散・機械トラブルのリスクを全員で確認）。

**【写真①：洗浄前の全景・汚染状況】**

### 次工程へ進む判断

✅ 禁止箇所の確認・共有完了

✅ 全設備・植栽の養生完了

✅ 排水経路確認完了

✅ KY実施完了

→ 工程2へ進む

---

## 工程2　機械設置・試運転

**目安時間：約10〜20分　必要人数：1名**

### 施工順序

1. 漏電遮断器を電源に接続する（先に漏電遮断器の作動テストを実施する）。
2. 散水ホースを接続して水道を開く。
3. 高圧ホース・ノズルを接続する（カチッと音がするまで）。
4. ガンを安全な方向に向けてから電源を入れる。
5. トリガーを引いて圧力・水量・漏れを確認する。
6. 使用するノズルの噴射状態が正常であることを確認する。

### ⚠ 失敗しやすいポイント

- **電源を入れてからノズルを取り付ける** → 電源を切ってからノズルを交換する
- **漏電遮断器の作動確認を省略する** → 感電事故の原因になる

### 次工程へ進む判断

✅ 漏電遮断器の作動確認完了

✅ 圧力・水量が正常

✅ 水漏れがない

→ 工程3へ進む

---

## 工程3　予備散水

**目安時間：約10〜20分　必要人数：1名**

低圧（散水ホース使用）で上から下へ全体を湿らせる。表面の砂・土埃を除去し、薬剤の浸透を助ける。

→ 工程4（薬剤使用時）または工程5（薬剤不要の場合）へ進む

---

## 工程4　薬剤塗布・作用時間（汚れがある場合のみ）

**目安時間：塗布5〜10分/区画、放置3〜15分（汚れにより異なる）**

### 施工順序

1. 洗剤ノズルまたはスプレーボトルで薬剤を塗布する（上から下へ）。
2. 放置する：弱アルカリ洗剤3〜5分 / カビ・藻除去剤5〜15分。
3. 放置中に薬剤が乾燥しないよう追い噴霧する。

### 薬剤を選ぶ理由

高圧洗浄の前に薬剤を塗布・放置することで：
- **カビ・コケ**：薬剤で菌糸が分解されるため、高圧洗浄での除去が格段に容易になる（薬剤なしでは高圧でも再発しやすい）
- **排気ガス・油汚れ**：アルカリが油分を乳化させるため、高圧洗浄で一度に除去できる

→ 工程5へ進む

---

## 工程5　高圧洗浄

**目安時間：30〜180分（施工面積・汚れの程度による）　必要人数：1〜2名**

### ノズルの正しい動かし方（最重要）

```
【正しいノズルの動かし方】

左端から開始
→→→→→→→→ 右端まで移動（10〜15cm/秒）
←←←←←←←← 10cm下に移動して左端へ戻る（次のラインは10cmオーバーラップ）
→→→→→→→→ 右端まで移動
  （上から下へ繰り返す）

・一点に止まって噴射しない（素材が削れる）
・一定速度を維持する（遅すぎると削れる・速すぎると汚れが残る）
・隣のラインは10cmオーバーラップさせる（洗い残しの筋を防ぐ）
```

### 施工順序

1. **上部から開始する**（汚れを下へ流す）。
2. ガンを両手で保持し、ノズルを対象から素材別指定距離（20〜30cm）に保つ。
3. ノズル角度を30〜45°に保つ（垂直90°にしない。コーキング・目地に水が入る）。
4. 左から右へ10〜15cm/秒の一定速度で移動しながら洗浄する。
5. 次のラインへ移る際は10cmオーバーラップさせる。
6. 一点で止まって噴射しない（素材を削る）。
7. コーキング部・クラック部を避けながら施工する。
8. 汚れが残っている箇所は2〜3回繰り返す。
9. 汚水の色が透明になったら完了。

### 禁止事項

- 人への噴射禁止（重傷事故）
- 電気設備・インターホン・換気口への噴射禁止
- コーキング部への直接噴射禁止
- 一点集中噴射禁止
- 木部・ALC・劣化塗膜への高圧洗浄禁止

### ⚠ 失敗しやすいポイント

- **ノズルを一点に止めたまま噴射する** → 素材が削れる・塗膜が剥がれる。常に動かし続ける
- **ノズルを近づけすぎる** → 指定距離より近いと素材ダメージが急増する
- **90°の垂直角度で噴射する** → コーキング・目地に水が入る。必ず30〜45°の角度を維持する
- **スピードがバラバラ** → 速い部分は汚れが残り、遅い部分に筋が残る。一定速度を維持する

### 【プロのコツ】

- 汚水の色が透明になったらすすぎ完了のサイン。色付きの汚水が出ている間は継続する。
- 洗浄スピードは「汚水の色」を見ながら調整する。濃い汚水が出ているうちは少しゆっくり、薄くなったら速めにしてもよい。

### 次工程へ進む判断

✅ 洗浄水が透明

✅ 目視で汚れが除去されている

✅ 素材に傷・変形がない

→ 工程6へ進む

---

## 工程6　仕上げ確認・再洗浄

**目安時間：約15〜30分　必要人数：1名**

### 施工順序

1. LEDライトを斜め30〜45°で当てて汚れ残り・ムラを確認する。
2. 遠目（3m以上）と近距離（0.5m以内）の両方から確認する。
3. 洗い残し・洗浄ムラ・高圧洗浄の筋がある場合は再洗浄する。
4. 作業後写真を撮影する（作業前と同じ位置・角度）。

**【写真②：洗浄後の全景（作業前と同じ角度）】**

**【写真③〜⑤：各面の仕上がり確認】**

### 仕上がり判断基準

| 確認項目 | 合格基準 |
|---|---|
| 汚れ残り | 目視で確認できる汚れがない |
| 洗浄ムラ | 均一な仕上がり（筋・ムラがない） |
| 素材へのダメージ | 傷・塗膜剥離がない |
| コーキング | 損傷・欠落がない |
| 周辺への飛散 | 窓・植栽・車両に汚れがない |

## 工程7　機械片付け・現場復旧

**目安時間：約20〜30分　必要人数：1〜2名**

### 機械の片付け手順

1. 電源を切る。
2. 水道（散水ホース）を閉栓する。
3. ガンのトリガーを引いてホース内の残圧を抜く（安全な方向に向けて）。
4. ノズルを取り外す（ノズルが熱い場合は手袋着用）。
5. 高圧ホースを本体から取り外す。
6. ホース内の水を抜く（巻き取りながら排水）。
7. 本体・ホース・ガン・ノズルを清水で洗浄する。
8. 延長コード・漏電遮断器を撤収する。
9. 機械を乾燥させてから収納する。

### 養生撤去・現場復旧

1. 最終確認が完了してから養生を撤去する。
2. 養生テープを横方向にゆっくり剥がす（急ぐと塗装が剥がれる）。
3. 植栽に薬剤が付着していた場合は清水で散水する。
4. 工具・資機材の忘れ物を確認する。

# 11. 安全管理

## 感電防止（最重要）

- 高圧洗浄機には必ず**漏電遮断器を接続**してから使用する
- 漏電遮断器の作動テストを毎作業前に実施する
- 延長コードは防水型のみ使用する
- 濡れた手でプラグ・電源スイッチに触れない
- コードが水たまりに浸からないよう確認する

## 高圧水による事故防止

- ガンは必ず両手で保持する
- 使用しない時は安全ロックをかける
- 人・動物・ガラス・電気設備に向けない
- ノズル交換は電源を切ってから行う

## 転落防止

- 高さ2m以上の作業はフルハーネス着用必須
- 脚立は水平な床に設置。天板に乗らない
- 濡れた床での脚立使用禁止

## 緊急時対応

| 事故 | 対応 |
|---|---|
| 感電 | 電源を遮断してから対応（感電者に直接触れない）。119番通報 |
| 高圧水による怪我 | 作業停止。傷の大小にかかわらず医療機関を受診 |
| 転落 | 動かさない。119番通報。責任者へ報告 |
| 機械の漏水・異音 | 電源を切る。安全を確認して電源プラグを抜く。使用禁止表示 |
| コーキング・塗膜を損傷した | 施工中止。写真撮影。責任者へ報告 |

## KYリスクアセスメント（作業開始前に全員で確認）

| 危険要因 | 想定される事故 | リスク | 予防対策 |
|---|---|---|---|
| 漏電・感電 | 感電・死亡 | 極高 | 漏電遮断器必須・作動テスト実施 |
| 高圧水による怪我 | 重傷 | 高 | 人に向けない・安全ロック確認 |
| 高所からの転落 | 骨折・死亡 | 高 | フルハーネス・2名作業 |
| 機械トラブル（漏水・異音） | 感電・怪我 | 高 | 使用前点検・異常時即停止 |
| 高圧飛散 | 眼障害・対人事故 | 高 | 保護メガネ・養生徹底 |
| 素材損傷 | 塗膜剥離・コーキング破損 | 中 | 素材別設定厳守・禁止箇所確認 |

# 14. 新人教育ポイント

## 最初に覚えること（優先順）

| 優先度 | 覚えること | なぜ重要か |
|---|---|---|
| 1 | 漏電遮断器を必ず使用する | 感電事故の防止（命に関わる） |
| 2 | 水を先に出してから電源を入れる | ポンプの空回り防止・機械保護 |
| 3 | ガンは常に両手で保持する | 高圧水の暴発防止 |
| 4 | ノズルは常に動かし続ける | 一点集中は素材を削る |
| 5 | 素材別の水圧・距離・角度を守る | 素材損傷防止 |
| 6 | コーキング・ALC・劣化塗膜には使用しない | 建物損傷・浸水防止 |

## 新人が間違えやすいポイント

| 間違い | 正しい対応 | なぜそうするか |
|---|---|---|
| 電源を入れてからノズルを交換する | 電源を切ってからノズルを交換 | ノズルが飛んで重傷事故になる |
| ノズルを一点に止めて噴射する | 常に10〜15cm/秒で動かし続ける | 素材が削れる・塗膜が剥がれる |
| 90°垂直で噴射する | 30〜45°の角度を維持する | コーキング・目地に水が浸入する |
| サイクロンノズルを外壁に使う | 床専用。外壁には使用禁止 | 外壁の素材が削れる |
| 規定より近い距離で噴射する | 素材別の指定距離を守る | 近いほどダメージが急増する |
| 漏電遮断器を接続しない | 必ず漏電遮断器を使用する | 感電事故の最多原因 |

## 独立施工を許可する基準（自己確認）

以下を全て自己確認できること：

- 漏電遮断器の作動テストができる
- 素材別の水圧・距離・角度を正確に設定できる
- ノズルの種類と用途を使い分けられる
- 高圧洗浄禁止箇所を判断して避けられる
- ガンを両手で保持して安全に操作できる
- 異常時（漏水・異音・漏電）に即座に電源を切れる
